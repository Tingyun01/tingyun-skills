# 投资人友好 vs 创始人友好 条款对照表

> 决策辅助，非法律意见；谈判目标是在二者间取合理平衡。

| 条款 | 投资人友好表述 | 创始人友好表述 | 谈判落点建议 |
|---|---|---|---|
| 优先清算 | 1.5–2 倍、非参与/参与 | 1 倍、参与门槛高 | 争取 1 倍，限制参与权 |
| 反稀释 | 完全棘轮 | 广义加权平均 | 用加权平均替代棘轮 |
| 对赌 | 高额回购+违约金、个人连带 | 设触发上限、经营豁免、公司主体 | 限上限、避个人无限连带 |
| 一票否决 | 事项极宽（含日常经营） | 限定核心事项 | 列清清单，剔除日常 |
| 拖带权 | 低门槛强拖、无例外 | 高门槛、创始人例外 | 设高门槛+创始人保护 |
| 董事会 | 投资人占多数/多席 | 创始人保持控制 | 按融资比例，保控制权 |
| 跟售权 | 无或门槛高 | 小股东可随售 | 设合理小比例 |
| 信息权 | 高频、宽泛 | 季度、必要范围 | 季度+必要财务 |
| 估值 | 高估值绑高对赌 | 估值与对赌脱钩 | 控对赌压力 |

## 使用说明
- 本表用于**识别表述差异**，不是让创始人全盘推向"创始人友好"——过度对抗会吓退投资人。
- 谈判是交换：在可让项上示好，守住死守项。
- 任何条款均以正式 SPA/股东协议文本与律师意见为准。
