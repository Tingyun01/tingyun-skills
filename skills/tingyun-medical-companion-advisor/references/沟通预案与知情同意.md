# 沟通预案与知情同意

## 四种说法

| 目的 | 别说 | 改说 |
|---|---|---|
| 劝说就医 | "医生让的" | "我陪你去，我们一起问医生" |
| 给选择 | "去不去" | 二选一（今天去还是明天上午去） |
| 降低恐惧 | "没事的" | "有一点点不舒服，我们慢慢来" |
| 争取配合 | "听话" | "这一步做完就剩拿药了" |

## 遇到拒绝

1. 先接受情绪，不否定
2. 拆小目标（先只做第一步：走到楼下）
3. 找医护协助劝说
4. 必要时改约，不要硬碰

## 知情同意边界

- 患者本人有决定能力 → 必须本人同意
- 失去决定能力 → 法定代理人按顺序表态
- 陪诊、护工、邻居都不是代理人
- 涉及手术、侵入性检查、费用较大项目 → 确认书面告知与签署人

## 立即就医信号

意识障碍 / 大出血 / 剧烈胸痛 / 呼吸困难 → 不做流程安排，立即急救
