# 股权、债务、抚养与协议/诉讼取舍（规划辅助用）

> 以下内容用于梳理思路，不构成法律意见，具体以属地规定及持证专业人士意见为准。

## 一、股权/经营资产分割难点

- 估值难：非上市股权、个体户、合伙企业缺乏公开价格，需评估或协商作价。
- 经营权与所有权分离：直接拆分股权可能影响公司经营，常见替代方案为"一方折价补偿、另一方退出"或"保留经营、分期支付"。
- 其他股东优先购买权：涉及有限公司股权变更，可能受公司章程与股东优先购买权约束。
- 隐匿风险：账面不透明、公私账户混同，需借助审计/举证。
- 建议：此类资产宜做专项评估与协议设计，复杂度高时转持证专业人士。

## 二、债务分担清单

可能属共同债务（以用于家庭共同生活/共同意思表示等为准）：
- [ ] 为家庭日常生活需要所负债务
- [ ] 双方共同签字或事后追认的债务
- [ ] 一方名义但用于共同生活的债务

可能属个人债务：
- [ ] 一方超出家庭日常生活需要所负且未用于共同的债务
- [ ] 一方赌博、个人消费等个人原因所负债务

提示：债务认定争议大，举证是关键；协议中对债务承担的约定通常不能对抗善意债权人。

## 三、抚养权与抚养费框架

- 抚养权：以有利于未成年子女为考量原则，综合年龄、双方条件、子女意愿（达到一定年龄）等判断。
- 抚养费：通常涵盖生活费、教育费、医疗费，数额结合收入、当地生活水平、子女需要确定，可约定支付方式与期限。
- 探视权：非直接抚养方通常享有探视，具体方式与频次可协商。
- 提示：抚养安排以子女利益为先，协议应具可操作性。

## 四、协议离婚 vs 诉讼离婚 取舍

| 维度 | 协议离婚 | 诉讼离婚 |
| --- | --- | --- |
| 适用 | 双方对财产、子女、债务基本达成一致 | 争议大、无法协商、一方不同意 |
| 成本 | 低、周期短（含冷静期） | 高、周期长 |
| 可控性 | 高，条款自定 | 低，由法院裁定 |
| 查明力 | 依赖双方诚信 | 可借程序查明、保全、调查 |
| 风险 | 隐匿财产难发现 | 结果不确定 |

取舍建议：
- 信息对称、争议小 → 优先协议，效率高。
- 存在隐匿/转移财产、股权复杂、抚养争议激烈 → 考虑诉讼以借助程序查明与保全。

## 五、婚前协议衔接

- 已有婚前/婚内财产协议的，先核其效力与覆盖范围，作为本次分割的基础。
- 无协议但曾口头约定的，书面化、补强证据。
- 协议效力存疑（如显失公平、胁迫）时，建议由持证专业人士判断。

## 六、需立即转人工的情形

- 对方有隐藏、转移、变卖财产迹象；
- 涉及大额股权、经营资产或境外资产；
- 抚养权、家暴、债务争议激烈。
