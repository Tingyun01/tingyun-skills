# 宠物保险条款拆解与过度医疗识别

## 一、买保险前必拆的条款（只拆结构，不推荐产品、不报价）

| 条款项 | 重点看什么 | 常见坑 |
| --- | --- | --- |
| 等待期 | 投保后多少天起赔，不同病种等待期可能不同 | 等待期内出险不赔，既往症通常除外 |
| 免赔额 | 每次免赔还是年度累计，固定额还是比例 | 免赔过高导致小额用不上 |
| 赔付比例/限额 | 按比例报销还是定额，单次与年度上限 | 封顶后自付骤增 |
| 定点/网络医院 | 是否限定合作医院，非定点报多少 | 常去医院不在网络内 |
| 免责条款 | 遗传病、先天病、行为治疗、美容、疫苗 | 条款藏在细则，投保前不读易踩 |
| 续保与年龄 | 是否承诺续保，老年是否加费/拒保 | 带病后可能拒续 |

操作建议：把"等待期、免赔、定点医院、遗传病免责"四项先问清，再横向比 2~3 家条款，不急着下单。

## 二、过度医疗识别信号

- 未做基础检查就直接推高价项目，或同一指标短期内反复开单。
- 把"可观察随访"说成"必须立刻做"，且不给替代或暂缓方案。
- 回避费用明细、回避风险、用焦虑话术催单（"不马上做就晚了"）。
- 拒绝解释必要性，不提供书面方案与分项报价。
- 与你的宠物实际症状明显不匹配的"大包围"检查。

## 三、遇到可疑时的动作

1. 要求先出具**书面检查理由 + 分项报价**，逐项问"这项为什么必要、不做会怎样"。
2. 拿报告去**另一家执业机构二次问诊**，对比方案。
3. 不盲目拒绝必要治疗，也不被话术推着走；把"费用—必要性—预后"三件事问全。

> 本页不构成保险销售建议，不推荐具体产品、不报价。是否投保、投保哪款由用户自行判断。
