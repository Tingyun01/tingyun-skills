# 上线前合规自检清单

> 提审前逐项打勾，任何一项不过关都不要提审。老版本合规不代表新功能合规，每次提审都完整过一遍。

## 1. 文本合规

- [ ] 运行敏感词扫描：`python scripts/sensitive_words_scan.py <项目根目录>`，命中清零或有合理解释。
- [ ] 词库已按项目领域扩充（脚本内 `DEFAULT_WORDS` + `--extra` 追加）。
- [ ] 无绝对化用语与夸大承诺（广告法红线清单见审查工具词库）。
- [ ] 无诱导分享句式：分享解锁、转发领取、不分享不能用。
- [ ] 界面语言与申报类目气质一致（例：申报工具类目，界面不出现"运势预测"类文案）。

## 2. 版权合规

- [ ] 所有字体免费商用（安全清单：思源黑体/宋体、霞鹜文楷、阿里巴巴普惠体、OPPO Sans、HarmonyOS Sans）。不确定的一律换。
- [ ] 图片素材来源可追溯：AI 生成留存生成记录；下载素材确认授权（**免费下载 ≠ 可商用**）。
- [ ] 音频、图标、emoji 贴纸同上检查。
- [ ] 不使用他人小程序截图、品牌 Logo 作对比宣传。

## 3. 协议与隐私

- [ ] 「关于/设置」页可一键查看《用户协议》《隐私政策》。
- [ ] 隐私政策覆盖所有实际收集的信息类型（对照代码里用到的敏感接口清单）。
- [ ] 用户协议含**用户行为责任自负**条款与免责说明。
- [ ] 小程序后台「用户隐私保护指引」已逐项填写并与代码一致。
- [ ] 使用模板：`assets/privacy-policy-template.md`。

## 4. 体验完整性

- [ ] 真机（iOS + Android 各一台）从首页出发可达每一个页面。
- [ ] 无空白页、死链、报错弹窗；所有列表页有空状态兜底 UI。
- [ ] 图片全部可加载（重点检查云存储 fileID 路径、权限）。
- [ ] 测试数据清零（搜索 test / 测试 / 111 / aaa / 待补充）。
- [ ] 每个页面 `navigationBarTitleText` 已设置且含目标关键词。
- [ ] `sitemap.json` 已配置，需要被收录的页面未设 `disallow`。
- [ ] 分享卡片（标题+图）已为每个页面配置。
- [ ] 新增接口均在 `app.json` 无越权声明；`permission` 字段说明齐全。

## 5. 架构韧性（发布后不出事故）

- [ ] 实验性功能有内测开关，默认关闭。
- [ ] 关键云函数有错误捕获与日志上报。
- [ ] 本地存储与云端备份的主键策略已确认（建议用 OPENID，避免换设备丢失数据）。

## 6. 备案与资料

- [ ] ICP 备案号已下发并填入小程序后台。
- [ ] 小程序名称、简介、头像与实际功能一致（审核员会对照）。
- [ ] 服务类目覆盖当前版本全部功能，无越界。

## 7. 提审策略

- [ ] 首版只提 MVP：砍掉社交、UGC、支付等高危功能，后续版本逐步放开。
- [ ] 版本描述写清楚"本次新增/修改了什么"，帮助审核员快速理解。
- [ ] 被拒后按 `references/review-pitfalls.md` 流程处理，不要立即盲目重提。
