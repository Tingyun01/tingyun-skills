# 合并分立债务处理与减资注销取舍

> 规划辅助，以新《公司法》及登记机关要求为准。

## 一、合并（第218-220条）
- 程序：编制资产负债表及财产清单 → 决议 → **10 日内通知债权人、30 日内公告** → 债权人可要求清偿或担保 → 变更登记。
- 债务承继：合并后存续公司或新设公司承继全部债务。

## 二、分立（第223条）
- 程序：同合并须通知+公告。
- **债务承担**：分立前的债务由分立后的公司承担**连带责任**；
- **例外**：公司在分立前与债权人就债务清偿达成**书面协议另有约定**的除外。
- 实务：分立前务必与债权人签书面债务分担协议，否则连带追偿。

## 三、减资 vs 注销 取舍

| 维度 | 减资 | 注销 |
|---|---|---|
| 目的 | 调整资本、保留经营主体 | 终止主体 |
| 适用 | 仍经营、认缴过高/补亏 | 不再经营、无延续价值 |
| 程序 | 通知/公告/担保/变更 | 清算→清税→注销 |
| 债务处理 | 须保障债权人 | 清算中清偿 |
| 后续 | 主体继续存在 | 主体消亡、可另设 |

**决策建议**：
- 还想接着干、只是认缴额或亏损问题 → **减资**（普通或简易）；
- 彻底不干、无品牌/资质延续价值 → **注销**（但仍要先清税、清债）；
- 业务拆分或整合 → **分立/合并**。

## 四、注销前的衔接
注销须先结清税款、缴销发票、完成清算。若尚有税务异常或债务未清，注销会被退回。顺序：解异常 → 清债清税 → 清算 → 注销。

## 五、自检清单
- [ ] 重组目的：减资/合并/分立/注销是否定性准确；
- [ ] 合并分立是否通知公告债权人；
- [ ] 分立是否取得债权人书面债务协议；
- [ ] 减资程序是否合规（对应类型）；
- [ ] 注销前税务与债务是否清结；
- [ ] 重大重组是否经律师/会计师意见。
