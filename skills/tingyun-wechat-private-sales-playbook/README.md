# 微信私域资料变现路径顾问

> 为做知识付费与虚拟资料私域的人梳理定价分层、交付方式、复购与转介绍设计，输出可落地的变现路径表。

## 这个 Skill 解决什么

私域卖资料，很多人卡在两件事：免费的东西给多了没人买，收费的东西又说不清凭什么值这个价。这套顾问把变现路径拆成四层：免费框架怎么设计才能建立信任而不白送、付费部分具体交付什么、定价分几档各自对应什么服务、怎么设计复购和转介绍让一次成交变成多次。附三套可以直接用的定价表和一整套客户问答话术。

## 什么时候用

- I give away free checklists but nobody buys the paid version. What is the fix?
- How many price tiers should a materials product have and what goes in each?
- How do I design delivery for a virtual product so the buyer gets it without a link?

## 常见问答

**Q: How much should I give away for free?**

A: Enough to be genuinely useful and enough for the buyer to recognise the problem clearly, but not so much that the paid tier becomes redundant. The boundary checklist works through that line item by item rather than by percentage.

**Q: How many tiers should I run?**

A: Two or three, mostly. Each extra tier multiplies the explanation you have to do in every conversation. The three tables show what a two-tier and a three-tier structure look like with actual numbers.

**Q: Should delivery be a link or a file sent in chat?**

A: Sending the file directly in the platform message keeps the transaction and the delivery in the same place, which is both safer against platform rules and better for the buyer's experience.
