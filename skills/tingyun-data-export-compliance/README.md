# 数据出境与跨境合规顾问

> 梳理数据出境触发情形、三条路径适用条件与出境台账建法，输出跨境传输前自检清单与泄露处置顺序。不出具合规结论、不替代主管部门判定，不构成法律专业意见，需人工复核。技术触发词「出境情形判定、合规路径对照、出境前自检」。口语触发词「如果境外合作方发生了数据泄露，我们这边应该按什么顺序处理」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

数据出境合规路径与自检顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我们公司要做一个面向海外客户的后台系统，境内收集了境内员工的身份证号和手机号，也把境内用户的行为数据同步到境外云。这算数据出境吗？需要走哪条路径？
- 从去年1月起到现在，我们累计向境外提供了80万条不含敏感信息的个人信息，一直没做过安全评估也没签标准合同。现在需要补哪些手续？
- 我们的境内工单系统会把客户姓名和联系方式同步给境外的外包客服团队，这算出境吗？和供应商的合同该写哪些条款？
- 我需要一份工程师在每次跨境同步前真能跑一遍的自检清单，按顺序列出，并标明要调取哪些材料
