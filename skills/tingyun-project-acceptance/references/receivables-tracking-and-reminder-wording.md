# 回款跟踪表字段 · 卡点判定 · 催收合规措辞边界

> 用于项目回款的过程跟踪与催款函件措辞。本文是流程与文档辅助，不构成法律专业意见，需人工复核。

## 一、回款跟踪表字段（按四段设计）

### 段 1：合同层（一行一份合同）
| 字段 | 说明 |
|---|---|
| 项目名称 / 编号 | 与合同、施工文件一致 |
| 合同金额 | 注明含税口径、币种 |
| 合同模式 | 总价 / 单价 / 包干 / 框架 |
| 对方单位 | 全称 + 统一社会信用代码 |
| 质保金比例与返还条件 | 摘成一句话 |
| 整体结算状态 | 未结算 / 结算中 / 已结算 |

### 段 2：节点层（一行一个付款节点，这是核心）
| 字段 | 说明 |
|---|---|
| 节点序号与名称 | 如"进度款1-基础验收" |
| 节点金额 | 本节点应收金额（不是合同总额） |
| 触发条件 | 事件描述 + 对应文件编号 |
| 触发日期（实际） | 已发生的填实际日，未发生的填预计日并标注 |
| 约定天数 | 触发后 X 日内支付 |
| 前置资料 | 需先提供哪些（结算书/发票/验收单…） |
| 前置资料齐备日 | 实际齐备日（起算日可能被这个卡住） |
| 扣减项 | 质保金、扣款、代扣代缴，注明依据 |
| 应收日（可主张日） | = 触发日期 + 约定天数，且前置资料齐备 |
| 已开票金额 / 票号 / 票日 | 与应收对应 |
| 已回款金额 / 到账日 | 与应收对应 |
| 未回款金额 | 应收 − 已回款 |
| 逾期天数 | 今天 − 应收日（已超期才填） |
| 卡点 | 见下方判定表 |
| 责任人 / 对方对接人 | 内部责任人 + 对方具体人 |
| 下一动作与截止日 | 必填，防止"都在等" |
| 证据完备度 | 见下方三档 |

### 段 3：卡点判定表（这一栏决定表有没有用）
| 卡点 | 判定依据 | 典型下一动作 |
|---|---|---|
| 待验收 | 交付已完成但验收单未签 | 发验收申请 / 催验收函 |
| 验收中 | 已申请，期限内等待 | 到期后书面催告 |
| 验收不通过 | 存在未闭环遗留问题 | 出整改通知单，闭环后复验 |
| 待结算 | 验收通过但结算书未定 | 限期提交结算书并核对 |
| 待开票 | 已结算，发票未开或信息不全 | 补开票信息，核对票面金额 |
| 在途 | 已开票未到账 | 核对收款账户与流水，排查退票 |
| 待支付 | 资料齐备在对方手中，对方未付 | 发付款确认函（按期限分层） |
| 部分支付 | 已回款小于应收 | 出对账函，列明差额与差额原因 |
| 有异议 | 对方书面提出异议 | 逐条比对，区分争议项与非争议项 |
| 主体异常 | 对方失联/经营异常 | 升级并咨询专业人士，暂停无依据的施压动作 |

### 段 4：证据完备度三档（决定你能催到什么程度）
| 档 | 具备 | 可做的事 |
|---|---|---|
| 完备 | 约定文件 + 履行证据 + 对方知悉证据 + 付款凭证，四段齐全 | 可直接主张付款、按合同约定方式处理 |
| 基本齐 | 缺一段（如缺对方签收） | 先补证据，再催；催函中说明补正安排 |
| 薄弱 | 关键证据缺失（如验收未签、无签收） | 优先补证，不要先发强硬催款函 |

## 二、证据清单（发生争议时的取证范围）

按"链条"组织，四段缺一节，说服力就弱一节：

**第 1 段：约定**
- 合同及全部附件、补充协议、变更/签证单（编号对应）；
- 报价清单、图纸、技术规范中与结算和验收相关的页。

**第 2 段：我方履行**
- 开工与施工记录、施工日志；
- 材料进场与复检报告、检测报告；
- 交付物清单与签收记录；
- 隐蔽工程验收签认单与影像；
- 各节点验收单（分项/分部/阶段/竣工）。

**第 3 段：对方知悉与确认**
- 验收申请及送达凭证；
- 往来函件、催告函、会议纪要（含对方签署或可查的送达记录）；
- 整改通知单与复验签认；
- 对账函及对方确认或提出的具体异议。

**第 4 段：款项**
- 发票存根（票号、金额、日期、税额口径）；
- 银行回单/收款流水；
- 付款申请与内部审批记录；
- 已扣减项的依据（扣款通知、双方确认）。

**补充一段：损失与主张**
- 已投入成本的凭证（人工、材料、机械台账）；
- 因延误产生的实际支出凭证（须有因果关联证据）；
- 主张的金额计算过程（口径一致、逐项可算）。

> 金额主张、责任认定、是否可主张利息或违约金，属法律判断，需人工复核并由持证专业人士确定；本清单只解决"证据齐不齐"。

## 三、催款措辞的合规边界

### 安全区（可以写）
1. **事实陈述**——我方于某日完成什么，有书面依据；
2. **条款引用**——合同第 X 条约定的付款条件与天数；
3. **已完成前置**——资料齐全、验收完成、发票已开；
4. **明确期限**——请于某日前支付或书面说明安排；
5. **异议通道**——如有异议请于某日前提出具体异议项，以便逐项核对；
6. **后果的中性陈述**——按合同第 X 条约定处理（引条款，不自行定性）。

#### 可直接用的模板

**第 1 层 · 提醒（到期前）**
> 关于《项目名称》（合同编号 __）第 __ 号验收节点的付款事宜：我方已于 __ 年 __ 月 __ 日完成该节点交付并提交验收资料（附件 1、2），双方于 __ 年 __ 月 __ 日完成验收（附件 3）。按合同第 __ 条约定，该笔款项金额为 __ 元，付款期限为验收合格后 __ 日内，即 __ 年 __ 月 __ 日前。请协助安排支付并回复确认。

**第 2 层 · 正式（到期后，1–30 日内）**
> 前述第 __ 号节点款项应收日为 __ 年 __ 月 __ 日，截至本函发出日尚未收到该笔款项。按合同第 __ 条，我方已完成约定义务且验收合格（详见附件）。请于收函后 __ 个工作日内支付 __ 元，或书面说明付款安排与具体异议内容。我方将据此安排后续工作对接。

**第 3 层 · 严肃（逾期 30 日以上）**
> 经多次核对，截至 __ 年 __ 月 __ 日，第 __ 号节点款项 __ 元仍未收到，逾期 __ 日。按合同第 __ 条约定逾期付款的__, 我方保留按合同约定的处理方式追究相应责任的权利。现再次函告，请于 __ 年 __ 月 __ 日前予以支付或提出书面异议。本函不构成对任何责任归属的认定，具体权利主张由双方协商或依合同约定及法律途径解决。

### 危险区（不要写）
| 禁用写法 | 为什么危险 |
|---|---|
| "你方已构成违约，须赔偿 __ 元（含违约金 __）" | 定性属法律判断，未经复核不宜由本流程直接出具 |
| "再不付款 we'll 上网曝光 / 找媒体 / 举报" | 威胁性、施压性表述，可能构成不当施压 |
| "必定/ 一定 / 百分之百会收到钱" | 断言式承诺 |
| "我们已经在走法律程序"（实际未启动） | 事实性陈述不实，风险高 |
| "我们有权直接停工 / 拉闸 / 扣留设备" | 涉及违约认定与财产权利主张，需法律意见 |
| 委托不明的人"上门讨债"式表述 | 可能引发合规与安全问题 |
| 群发对方员工私人邮箱/公开客户信息 | 侵犯隐私与商业信息处理合规 |

### 措辞自查 6 问（发出前逐条过）
1. 只陈述了事实和条款，没有下定性结论吗？
2. 每个金额和日期都有依据吗？
3. 给了对方说明异议的通道吗？
4. 没有威胁、恐吓、施压或断言式表述吗？
5. 发送对象是合同对方或授权对接人，收件人信息来源正当吗？
6. 函件已存档（含发送版本、日期、送达方式与凭证）吗？

## 四、催款节奏表（分层，不越界）
| 逾期天数 | 动作 | 形式 |
|---|---|---|
| 到期前 7 日 | 内部提醒 + 确认付款安排 | 电话/邮件 |
| 0–7 日 | 付款提醒函 | 函件（模板 1） |
| 8–30 日 | 正式催款函 + 要求说明安排 | 函件（模板 2） |
| 30–60 日 | 书面确认逾期金额与责任依据，提示按合同处理 | 函件（模板 3） |
| 60 日以上 | 暂停无依据的催款动作，整理证据链，转专业人士评估路径 | 内部决策 + 专业咨询 |

> 超过 60 日后是否采取法律途径、是否主张利息或违约金、是否继续履行或暂停履行，**必须由持证法律专业人士判断**，本流程不代为决策。

## 五、跟踪表自检（每周）
1. 本周有哪几个节点到了应收日？金额合计多少？
2. 逾期节点中，"证据完备"档的占多少？"薄弱"档的是哪几个？
3. 卡点分布：待验收 / 待开票 / 待支付 各几个？
4. 有没有节点因为前置资料没齐而算不出应收日？缺什么？
5. 下一动作栏有没有空着的？
6. 本周发出的函件是否都留了送达凭证？
