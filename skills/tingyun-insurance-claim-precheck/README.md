# tingyun-insurance-claim-precheck

> 按险种与出险场景核对理赔材料齐备性，输出缺件清单、被退回原因与补齐路径
>
> 面向已出险的投保人、被保险人及其家属的理赔材料预检助手。按车险、医疗险、重疾险、寿险身故、伤残、雇主责任险六类场景拆分，逐项列出应备材料、常见退回原因、补齐路径与需向保险公司核实的问题清单，并给出自查表填写指引。

## 这个 Skill 做什么

把「理赔材料预检」这个场景最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

### 解决什么问题

理赔最耗时的往往不是"赔多少"，而是"材料没带齐被退回来"。一次退回意味着重新排队、重新等待、错过时效，还可能在第二轮争议中因证据缺失而处于不利位置。各险种口径差别很大：车险要认定书，医疗险要出院小结和费用清单，重疾险要病理报告，身故要死亡证明与受益人关系证明，多数人第一次只带了身份证和病历。

本技能把经验性要求整理成可勾选的自查表，按场景拆成必备、视情况必备、加分三档，说明每项"缺了会怎样""怎么补""补不了走哪条路"，目标是一次交齐少跑。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 车险出险了要准备哪些材料才能不白跑
- 住院理赔被说要补材料我该准备什么
- 家里老人走了保险理赔要什么手续

## 怎么用

1. 安装到你的 agent（Claude Skills 目录 / 扣子技能商店）
2. 直接用日常说法提需求，例如：
   车险出险了要准备哪些材料才能不白跑
3. 它会追问关键信息（缺的信息会标〔待补〕，不会替你编）
4. 输出可直接用的清单 / 对照表 / 台账

## 输出

- 判断步骤与检查清单
- 对照表 / 台账
- 待办与需要人工核实的问题

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
