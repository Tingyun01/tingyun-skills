# N / N+1 / 2N 测算框架与成本对比

用途：把"要赔多少钱"从感觉变成算式。本文是测算框架与算例，不构成法律专业意见，需人工复核。

---

## 一、三个符号的来源

| 符号 | 名称 | 法律依据 | 计算基数 |
|---|---|---|---|
| N | 经济补偿 | 第47条 | 每满1年支付1个月工资；6个月以上不满1年按1年算；不满6个月支付半个月工资 |
| 1 | 代通知金 | 第40条 | 未提前30日书面通知时额外支付1个月工资（仅限第40条路径） |
| 2N | 违法解除赔偿金 | 第87条 | 按第47条经济补偿标准的二倍 |

**月工资口径**：指劳动者在劳动合同解除或者终止前十二个月的平均工资（第47条第2款）。

---

## 二、N 的折算规则

```
N（月数）= 完整工龄年数 + 尾部折算
  尾部 ≥ 6 个月  → 计 1
  尾部 < 6 个月  → 计 0.5
```

| 工龄 | N（月数） | 说明 |
|---|---|---|
| 3年整 | 3 | |
| 3年8个月 | 4 | 8个月 ≥ 6个月，按1年算 |
| 3年3个月 | 3.5 | 3个月 < 6个月，计半个月 |
| 8年整 | 8 | |
| 11个月 | 0.5 | 不足1年且不满6个月之外的情况按第47条分段处理 |
| 2年11个月 | 3 | 2 + 1（11个月 ≥ 6个月） |

> 校验提示：折算结果应 ≥ 1（只要存在1天以上的在职时间）。实务中"工龄2年11.5个月"这类边界值容易被算成2.5或3，必须回到原始入职日期与离职日期重新核对。

---

## 三、封顶与调整口径（常被忽略）

1. **高工资封顶**：劳动者月工资高于用人单位所在直辖市、设区的市级人民政府公布的本地区上年度职工月平均工资**三倍**的，向其支付经济补偿的标准按职工月平均工资三倍的数额支付。
2. **年限封顶**：向高工资劳动者支付经济补偿的年限**不超过十二年**。
3. **平均工资口径**：奖金、津贴、补贴、加班费是否计入"月平均工资"，各地认定口径存在差异。测算表必须写明本次采用的口径及依据来源。
4. **尚未到退休年龄与已达法定退休年龄**：达到法定退休年龄后劳动合同终止的情形，与"解除"路径不同，不要混用。

## 四、算例（框架演示）

### 算例 A：工龄3年8个月，解除前12个月平均工资9000元

| 路径 | 算式 | 结果 |
|---|---|---|
| 协商解除（公司提出） | N = 4 → 4 × 9000 | 36000元 |
| 过失性解除（证据与制度成立） | 不支付 | 0元 |
| 无过失性解除，提前30日书面通知 | N = 4 → 4 × 9000 | 36000元 |
| 无过失性解除，未提前通知 | N+1 = 5 → 5 × 9000 | 45000元 |
| 违法解除（且员工不要求继续履行） | 2N = 8 → 8 × 9000 | 72000元 |

差额提示：过失性解除与违法解除之间相差 72000 元。这个差额就是"制度有没有公示、事实证据齐不齐、程序走没走完"的价格。

### 算例 B：工龄8年，月薪12000元

- N = 8 → 8 × 12000 = 96000元
- N+1 = 9 → 108000元
- 2N = 16 → 192000元

若该员工月工资高于本地区上年度职工月平均工资三倍，则按三倍数额计算且年限封顶12年，需重新测算。

## 五、违法解除的成本对比（决策表）

老板真正要看的不是"赔多少"，而是**几条路径的总账**：

| 路径 | 现金支出 | 非现金成本 | 结论风险 | 适合场景 |
|---|---|---|---|---|
| 过失性解除 | 0 | 举证与制度合规成本；败诉风险由公司承担 | 高（取决于证据） | 有明确、已公示的制度依据且事实清楚 |
| 协商解除 | N | 谈判轮次与时间；协议履行风险 | 低 | 双方有共识基础；争议不大 |
| 无过失性解除 | N 或 N+1 | 前期事实准备（调岗/培训/协商记录）；30日等待期 | 中 | 事由客观存在且可举证 |
| 经济性解除 | N | 程序成本高（说明情况、听取意见、报告）；优先留用成本 | 中 | 确属第41条情形且达到门槛 |
| 违法解除 | 2N | 可能被要求继续履行；复职/返岗安排成本；管理层注意力成本 | 高 | 无合法理由，或硬套条款 |
| 不解除（协商保留） | 0（但持续发生工资与用工成本） | 持续 | 低 | 岗位可调整、绩效可改进、双方关系尚可 |

**两个经常被漏算的成本项**：
- **继续履行路径**：员工要求继续履行时，2N 不是上限。恢复劳动关系意味着工资、社保、岗位、管理的持续投入。
- **群体性放大**：同一批次处理多人时，若其中一人认定程序违法，其余人的处理依据易被整体否定；群体性劳动争议还涉及合并审理与负责人出庭，时间成本远高于单案。

## 七、测算阶段的三个常见错误

1. **先算钱再定情形**。顺序反了。情形没定性就报数字，等于给了一个没人能用的数。**先分流，再测算。**
2. **用"上个月工资"代替"前12个月平均工资"**。单月数据波动大，且与法定口径不一致。
3. **把"谈下来的金额"和"法定应付金额"混在一栏**。协商达成金额与法定计算结果是两个数，测算表里要分列，否则复盘时看不出分歧来自哪。
