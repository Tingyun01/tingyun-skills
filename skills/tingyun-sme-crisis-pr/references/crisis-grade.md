# 危机分级与黄金 4 小时响应流程

> 本页为危机公关顾问的结构化工作底稿，供中小企业照单执行。不构成法律意见，需人工复核。

## 一、危机分级矩阵

按"影响面"与"是否涉监管/人身安全/群体利益"二维定级。涉监管或人身安全的，一律上调一级处理。

| 等级 | 影响面 | 是否涉监管 | 首响时限 | 对外动作 |
|---|---|---|---|---|
| 一级·观察 | 局部、小范围、可控 | 否 | 24h 内评估 | 暂不发声，持续监测 |
| 二级·处置 | 公开平台可见、有扩散迹象 | 否 | 4h 内首次响应 | 简短表态或事实澄清 |
| 三级·升级 | 多平台扩散、媒体/大 V 介入 | 可能 | 1h 响应，4h 出声明 | 正式声明 |
| 四级·重大 | 涉监管/人身安全/群体利益 | 是 | 立即内部启动 | 先对监管口径，对外审慎 |

判断信号（满足任一条即升级）：
- 主流媒体或行业媒体已报道
- 出现"人身安全""孩子""老人""食品/药品"等高敏感词
- 涉监管举报、投诉量短时间内集中
- 有视频/图片证据在扩散
- 出现"翻旧账"——历史同类问题被集中挖出

## 二、黄金 4 小时动作序列

```
T+0        成立临时小组：业务负责人 + 指定发声出口人（单一）
           指派记录员，全程留痕（谁、何时、说了什么）
T+0~30m    事实三栏盘点（务必分开写，避免混淆）：
           ① 已确认事实（有证据）
           ② 待核实事实（正在查）
           ③ 禁止对外说的猜测（哪怕"感觉是"也不能对外）
T+30m~1h   定级 → 决定首发策略：沉默观察 / 事实澄清 / 致歉受理
T+1~2h     起草声明初稿，逐条过"措辞红线"（见 statement-template.md）
T+2~4h     内部对齐三套口径（监管/客户/员工），对外发布或待命
全程监测   新增平台、媒体跟进、监管问询、同类旧账被翻
```

## 三、舆情监测启动清单

初期（前 24 小时）建议节奏：每 1~2 小时扫一次，稳定后降为每日 2 次。

| 盯什么 | 怎么盯 | 触发动作 |
|---|---|---|
| 主阵地扩散 | 搜索品牌名/产品名/老板名 | 记录新增平台与阅读量级 |
| 媒体跟进 | 行业媒体、地方媒体关键词 | 一旦报道，升级至三级以上 |
| 监管问询 | 是否有投诉/举报受理通知 | 立即切"对监管口径" |
| 翻旧账 | 历史同类负面被关联 | 准备统一回应，不逐条辩 |
| 情绪拐点 | 评论从"讨论"转"抵制/报警" | 升级响应，考虑线下动作 |

## 四、恢复信任动作清单（中期，危机平息后）

- 公开"整改进展"而非只发一次声明：用时间线展示做了什么
- 对受影响客户做一对一回访与补偿方案（经内部核定）
- 建立"危机复盘文档"：本次哪一步慢了、哪句措辞翻车、下次模板怎么改
- 沉淀一份"常态舆情值守"轻量机制，避免下次从零开始
