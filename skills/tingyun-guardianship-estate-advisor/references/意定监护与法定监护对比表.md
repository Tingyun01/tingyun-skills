# 意定监护与法定监护对比表（规划辅助用）

> 本表用于梳理差异、辅助决策，不构成法律意见，具体效力以持证专业人士与属地规定为准。

## 一、两种监护对照

| 维度 | 意定监护（提前约定） | 法定监护（依法律规定） |
| --- | --- | --- |
| 设立前提 | 本人有完全民事行为能力时，与意愿监护人协商订立 | 本人丧失或部分丧失民事行为能力后，依法定顺序确定 |
| 谁来决定监护人 | 本人事先选定 | 由配偶、父母、成年子女等按顺序，或法院/民政指定 |
| 是否体现本人意愿 | 强（本人主动选） | 弱（依顺位，未必符合本人真实想法） |
| 典型设立方式 | 书面协议，可公证增强举证力 | 依法自动产生或经申请指定 |
| 监督机制 | 可一并约定监督人 | 通常由民政、村/居委会等监督，实践中易缺位 |
| 灵活度 | 高，可细化人身照护与财产管理授权 | 低，按法定框架 |
| 争议处理 | 依协议与举证；有公证更顺 | 常需法院/民政介入 |

## 二、监护人设置要点（清单）

- [ ] 明确监护人候选（1 名或多名，是否设候补）
- [ ] 列明授权范围：人身照护（就医、照护机构选择）、财产管理（账户、房产、日常开支）分别授权到什么程度
- [ ] 约定生效条件：通常以"本人丧失或部分丧失民事行为能力"为触发，建议注明由谁/何种证明（如鉴定意见、医疗机构证明）确认
- [ ] 约定终止与更换条件：监护人失能、侵害利益、失联等情形下的替换路径

## 三、监督人设置要点（清单）

- [ ] 监督人应为独立于监护人的主体（亲属、朋友、律师、信托/机构均可作为候选）
- [ ] 明确监督内容：监护人履职、财产收支、重大医疗决定
- [ ] 明确监督频率与记录方式（定期报告、凭证留存）
- [ ] 约定监督人发现异常时的干预路径（提示、提请更换、向民政/法院反映）

## 四、风险信号（出现即建议人工复核）

- 监护人与监督人为同一人 → 失去制衡
- 授权范围过宽且无任何限制 → 易生争议
- 完全未提财产管理 → 失能后日常开支可能受阻
- 未做公证且无可信见证 → 日后举证困难
