# 用工合规体检顾问

> 为老板与HR梳理用工风险：劳动关系认定自检、社保工伤解除合规清单、个保法用工要点与稽查点排查。输出风险等级与整改清单，不做法律意见，需人工复核。技术触发词「劳动关系认定、社保工伤合规、用工稽查点」。口语触发词「我公司用了劳务外包，怎么判断到底是真外包还是假外包真派遣、给我一份解除劳动关系合规清单：辞退员工前必须准备哪些东西、列出高频的用工稽查点，以及我日常该备好哪些材料备查」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

用工合规体检与劳动关系顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 帮我把公司的用工模式做一次合规体检，重点看有没有假外包真派遣的风险
- 我公司用了劳务外包，怎么判断到底是真外包还是假外包真派遣？
- 给我一份解除劳动关系合规清单：辞退员工前必须准备哪些东西？
- 做员工背景调查和人脸考勤时，个保法方面有哪些用工场景要点要留意？
