# 跨境合同、知识产权、人员流动与落地前自检清单

---

## 一、跨境合同与争议解决条款要点

### 1.1 主体与授权

| 要点 | 说明 | 风险信号 |
|---|---|---|
| 签约方与履行方一致 | 签约主体应是有实际履约能力与资产的一方 | 用离岸壳签约、交付与开票由另一方承担 |
| 代表权有效 | 签署人授权文件齐备 | 仅凭邮件授权、口头授权 |
| 义务承担主体明确 | 交付、质保、售后分别由谁承担 | 合同只写一家，但实际服务由多家分别提供 |
| 关联披露 | 交易对方与本方存在关联关系时的披露与定价说明 | 关联交易未做同期资料支撑 |

### 1.2 适用法与争议解决

| 选择 | 优势 | 成本与限制 | 适合 |
|---|---|---|---|
| 机构仲裁（如国际商会仲裁、机构本地仲裁） | 中立、可执行性强、可合并多合同 | 费用较高、程序有周期 | 金额大、跨境、对方信用好 |
| 对方所在地诉讼 | 当地执行便利、语言无障碍 | 可能受当地保护倾向影响 | 金额小、当地有执行需求 |
| 己方所在地诉讼 | 熟悉本地程序 | 在对方境内执行不确定 | 己方为强势方且金额大 |
| 多层争议解决（先协商、再调解、再仲裁/诉讼） | 快速解决比例高 | 条款长、可能被视为拖延 | 长期合作关系类客户 |

条款要素清单（每一项都要落到具体值，不能留空）：
- 适用法（具体法域，不写"国际商法"这类模糊表述）
- 争议解决机构与地点
- 仲裁语言与仲裁员人数
- 裁决执行地确认（对方所在国是否为认可执行地）
- 紧急救济与临时措施条款
- 费用承担规则
- 送达方式与通知条款（含电子送达地址约定）
- 合并仲裁与多份合同合并处理的约定

### 1.3 商务与合规条款

| 条款 | 要点 |
|---|---|
| 价格与调整机制 | 调价触发条件、幅度上限、生效程序、生效时点 |
| 付款 | 币种、汇率机制、账期、预付比例、逾期利息、抵销与扣款 |
| 交付 | 交货地点、风险转移时点、包装与单证要求 |
| 质量与验收 | 验收标准、验收期限、异议期、视为验收条款 |
| 责任限制 | 责任上限、间接损失排除、产品责任与例外情形 |
| 期限与终止 | 初始期限、续约、终止情形、终止后过渡协助期 |
| 不可抗力 | 定义范围、通知期限、后果（部分履行/解除） |
| 合规与制裁 | 制裁与出口管制条款；许可失效时的处理与解除权 |
| 反商业贿赂与反洗钱 | 承诺条款、审计权、违反后果 |
| 数据与保密 | 保密范围、期限、数据处理与跨境传输安排 |
| 争议解决前行为 | 争议期间继续履行的范围与费用处理 |

关键提醒：**制裁与许可失效条款必须写"解除权"，不能只写"不可抗力"**。原因是许可被撤销通常不属于传统不可抗力的范畴，缺少解除权会导致合同锁死。

### 1.4 中外文本冲突

- 明确约定文本优先顺序（例如以中文本为准、英文本为准）
- 不同语言版本不逐字翻译，必要时以"以某语言文本为准"消解歧义
- 数字、日期、货币单位统一格式（中文合同常见"万/元"与英文"k/million"混用问题）

## 二、知识产权与人员跨境流动

### 2.1 知识产权安排

| 事项 | 要点 | 常见问题 |
|---|---|---|
| 商标注册 | 商标通常按市场注册，不随公司注册地自动获得 | 只在母国注册，进目标市场才发现被抢注 |
| 专利与软件 | 研发地与权利人所在地要对应 | 权利人在 A 地、研发全在 B 地，许可定价难解释 |
| 商标与专利的层级 | 集团用哪个主体持有、许可给谁 | 总部持有但无管理地安排，许可定价无依据 |
| 职务成果归属 | 员工在境外工作期间的成果归属与竞业边界 | 外派期间成果归属没写清 |
| 交易前尽调 | 目标方核心 IP 的权属、职务发明、第三方许可、开源合规 | 收购后才发现 IP 属前雇主 |
| 侵权责任分配 | 许可方对权利瑕疵的担保与赔偿上限 | 侵权索赔全部由被许可方承担 |
| 数据与商标使用 | 域名的管理权、使用规范、离职后回收 | 员工离职带走域名与客户数据 |

商标抢注的应对通常靠提前布局 + 渠道监控 + 争议准备，这三件事在方案阶段就该排期，不是在被投诉后才启动。

### 2.2 人员跨境流动

| 事项 | 要点 |
|---|---|
| 入境与工作许可 | 按目的地规则确认签证与工作许可类别；许可类型要与实际工作内容匹配 |
| 本地雇佣 vs 外派 | 本地雇佣成本与合规义务更高但用工风险更低；外派需评估当地对提供服务的常设机构判定口径 |
| 社保 | 本地缴纳、协定或社保互认安排、缴费义务的判断 |
| 个税 | 当地居民身份判定（居住天数与居住地标准）、雇主代扣代缴义务、协定待遇是否适用 |
| 常设机构联动 | 员工长期驻外提供服务会同时影响用工合规与税务判定，两者一起评估 |
| 薪酬结构 | 基本工资与津贴拆分、币种、支付地、福利在跨境场景下的处理 |
| 数据与设备 | 跨境数据传输与本地数据保护要求、公司设备的携带与出境 |
| 离职与交接 | 交接清单、竞业与保密义务的跨境可执行性、知识产权与账号回收 |

关键提示：**外派审批流程要同时挂两条线**——一条是人力与签证合规，一条是税务常设机构评估。多数公司只走前一条，出问题时才发现后一条没走过。

## 三、落地前自检清单

### 3.1 设立前

- [ ] 业务实质已写清（钱、合同、货、服务、决策分别在哪里）
- [ ] 出海模式已选定，放弃其他模式的理由已记录
- [ ] 各法域的用途与功能已写明，每层实体能回答"为什么存在"
- [ ] 需要专业机构确认的问题已列清单（税务认定、常设机构、转让定价、许可）
- [ ] 商标与专利在目标市场的注册计划已排
- [ ] 管制与制裁相关的初步筛查已完成（产品、技术、目标客户类型）
- [ ] 资金路径与收付方式已设计，并与合同条款一致

### 3.2 设立中

- [ ] 主体形式与经营范围符合业务需要
- [ ] 注册信息与受益所有人信息已建档
- [ ] 股东名册、受益所有人名册、集团实体台账已建立并纳入更新机制
- [ ] 银行账户与收付路径已跑通（含币种、跨境付款成本）
- [ ] 章程与治理文件中的决策地、签署地与实际安排一致
- [ ] 会计与账簿安排已落地（记账地、审计要求、申报频率）
- [ ] 关联方服务、许可、融资协议已签署并与定价政策一致
- [ ] 筛查流程已建立：责任人、触发时点、留痕期限、命中处置路径

### 3.3 开业前

- [ ] 用工方案已定（本地雇佣 / 外派 / 混合），许可与签证已落实
- [ ] 驻外台账已启用
- [ ] 合同模板已本地化（适用法、争议解决、文本优先顺序、币种与数字格式）
- [ ] 汇率与价格调整机制已写入合同
- [ ] 制裁与许可失效的解除权条款已加
- [ ] 保险安排已覆盖（产品责任、职业责任、运输、董事与高级管理人员责任）
- [ ] 商标与域名使用规范已发布

### 3.4 运营中

- [ ] 关联交易按季度复核定价与执行一致性
- [ ] 驻外台账每季度核对，与实际派驻一致
- [ ] 客户与对手方筛查在签约前、发货前、客户变更时执行并留痕
- [ ] 当地申报义务（税务、社保、工商、外汇）按期完成
- [ ] 知识产权续展与监测已排期
- [ ] 跨境数据传输与本地数据保护要求已定期复核
- [ ] 每半年做一次架构合理性复核：功能、定价、驻外、名单、许可

## 四、必须找专业机构的情形

| 情形 | 该找谁 | 为什么不能自己拍 |
|---|---|---|
| 需要给出税务居民认定、常设机构是否成立的结论 | 跨境税务师 | 涉及事实与当地口径双重判断，结论错误成本高 |
| 转让定价方法选择与同期资料准备 | 跨境税务师 + 转让定价顾问 | 方法选择与文档口径直接影响后续核查结果 |
| 以税务为目标的架构安排、协定待遇申请 | 跨境税务师 | 涉及主动安排与程序要求 |
| 管制物项判定、许可证申请、制裁名单命中 | 出口管制合规律师 | 涉及物项分类与许可流程 |
| 跨境数据出境合规评估 | 数据合规律师 | 涉及评估路径与本地要求 |
| 收购标的（历史税务、用工、IP 归属、诉讼） | 跨境并购律师 + 税务师 | 尽调发现的问题需要专业处置方案 |
| 员工长期外派、签证与社保 | 移民与劳动合规律师 | 用工形式选择影响税务与合规两条线 |
| 集团内重组与中间层新增 | 跨境律师 + 税务师 | 涉及既有安排的调整与生效条件 |
| 当地合规处罚、稽查应对 | 当地执业律师 | 需要本地执业资格与程序经验 |
