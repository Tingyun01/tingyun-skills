# 增项陷阱清单与变更签证操作要求

> 用途：把"多花的钱"归到具体成因上，识别高危话术，给出变更签证的要素与操作纪律。
> 内容为清单梳理，不构成法律专业意见，需人工复核。

## 一、四类增项成因对照

### 1.1 总览

| 成因 | 本质 | 责任归属倾向 | 核心应对 |
|---|---|---|---|
| 报价漏项 | 该做的工序没进报价单 | 视合同对报价范围的表述 | 签约前逐工序核对 |
| 表述模糊 | 同一句话两种理解 | 解释权归属需看条款与证据 | 把模糊表述改成可验证写法 |
| 按实结算 | 计量基数与单价都不封顶 | 看是否属双方约定 | 锁死计量方式、单价、上限、凭证 |
| 现场变更 | 合同外的新增内容 | 看变更由谁提出 | 先定单价再施工、书面签证 |

### 1.2 报价漏项

| 漏项类型 | 常见项目 | 施工方典型说法 | 签约前核对动作 |
|---|---|---|---|
| 收尾类 | 垃圾清运（含外运）、建渣装袋、清运至指定点 | "垃圾清运另算" | 问清从哪运到哪、含几车、超量单价 |
| 基层类 | 拆除后墙面找平、铲除后修补、新旧墙挂网、地面找平 | "这面墙不铲不行，找平得另外算" | 对照报价单看有无"基层处理""找平"行项 |
| 收口类 | 门洞收口、垭口、窗台石、门槛石、过门石 | "门洞得做个收口" | 报价单须含"门洞修补与收口" |
| 安装类 | 灯具、洁具、五金、开关面板、地板、橱柜安装 | "我们只管装不负责装" | 报价单须列"主材安装含/不含" |
| 保护类 | 地面保护、电梯保护、公共区域保护、门窗保护 | "保护费另计" | 报价单须含成品保护并列部位 |
| 拆改类 | 砌新墙、挂网、抹灰、拆除后修补 | "只含拆不含砌" | 报价单须写"拆改含拆、砌、挂网、抹灰、修补" |
| 开孔类 | 空调孔、烟道孔、排气孔、水电点位开孔 | "开孔另外算" | 写"含__孔以内，超出__元/个" |
| 运输类 | 材料上楼、垃圾下楼、无货梯搬运 | "没货梯，搬运费另计" | 问清楼层与是否含搬运 |
| 物业类 | 装修押金、施工管理费、电梯使用费、垃圾清运费 | "物业要收钱，你自己交" | 写明由谁垫付、据实结算、凭收据 |
| 检测类 | 空气质量检测、管道打压、电路测试 | "检测费另计" | 部分检测属施工方义务，问清归属 |

### 1.3 表述模糊

| 模糊写法 | 可能的两种理解 | 改写方向 |
|---|---|---|
| "品牌材料" | 任何品牌，含低端系列 | 品牌+系列+型号+规格+产地 |
| "一线品牌" | 无客观标准 | 写具体品牌与型号 |
| "按国家标准施工" | 引用哪一项标准不明 | 写标准编号与名称，并列可验证的检查项 |
| "整体厨房" | 含不含灶具、油烟机、消毒柜、水槽、龙头 | 逐件列明，含与不含各自标注 |
| "含水电改造" | 含不含拆改、点位数量、线径 | 写"含拆改，含__个点位，含开槽，含打压测试" |
| "含垃圾清运" | 运到楼下还是运到指定处置点 | 写起点与终点、含几车、超量单价 |
| "乳胶漆一桶" | 桶的大小、涂刷遍数、覆盖面积 | 写品牌+型号+净含量+涂刷遍数+理论覆盖面积 |
| "瓷砖铺贴" | 常规尺寸铺贴、含不含加工与倒角 | 写尺寸范围、铺贴方式、加工与倒角另计规则 |
| "含安装" | 只含安装还是含安装辅料 | 逐项标注 |
| "含五金" | 哪些五金 | 逐件列出 |
| "卫生间防水" | 高度、遍数、是否含闭水试验 | 写高度、遍数、试验时长与蓄水高度 |

**一个通用改写公式**：**任何一句报价行项，都应该能回答"用什么、做几次、做到什么程度、怎么算合格"这四个问题。**答不全的那一句，就是后面的争议口。

### 1.4 按实结算

| 环节 | 开口点 | 锁定要素 |
|---|---|---|
| 水电 | 按米计算 | 线管单米总价上限、线径与线材规格、点位单价、是否含开槽与打孔 |
| 拆除与清运 | 按车、按方 | 单价、含车数或总量上限、超量处理 |
| 找平 | 按平方米 | 单价、厚度标准、面积计量方式（展开面积或投影面积） |
| 防水 | 按实际面积 | 单价、涂刷高度与遍数、是否含闭水试验 |
| 人工 | 按工日 | 工日单价、计入范围 |
| 安装 | 按件 | 单价表 |
| 辅料 | 按实际用量 | 损耗率上限、单价 |

**按实结算的三件套（缺一不可）**：
1. **计量方式**：怎么数（按点位、按延米、按面积、按车、按件）、谁量的、什么时候量
2. **单价**：固定单价，还是区间单价；变更时按什么规则确定新单价
3. **凭证**：结算需要有据可查的记录（隐蔽工程验收记录、影像、量尺单、签字确认单），没有凭证不予结算

### 1.5 现场变更

| 变更来源 | 典型内容 | 责任归属倾向 |
|---|---|---|
| 业主需求变更 | 加插座、换材料、改布局、加储物、升级主材 | 业主承担价款与工期影响 |
| 设计师方案变更 | 造型调整、动线调整、风格调整 | 看是否在原设计范围内；超出且非施工方原因 → 业主 |
| 现场条件变更 | 墙体承重限制、管线位置与图纸不符、层高不足、地面不平超预期 | 视成因，属施工方勘察义务范围则施工方承担 |
| 施工工艺变更 | 材料升级、工艺改法、成品替代 | 业主承担价款差 |
| 安全必要变更 | 承重结构必须加固、燃气管道必须移位、防水必须加高 | 属安全必要，一般按变更处理并约定工期顺延 |

**分界方法**：变更由谁提出 + 提出时是否有客观依据。业主提出且无客观必要依据 → 业主变更；施工方提出且属其应尽的勘察义务未履行 → 施工方责任；施工方提出且有客观依据（图纸与实际不符） → 按变更处理，工期顺延由双方按责任分。

## 二、常见增项陷阱清单

按危险程度排序。每条给出识别信号与应对动作。

### 2.1 高度危险

| 编号 | 陷阱 | 识别信号 | 应对动作 |
|---|---|---|---|
| T1 | 低总价签单、进场后连续增项 | 报价单总价明显低于同档项目；开工头几天频繁"发现"新问题 | 签约前要求把报价拆到工序级并逐项确认；开工后频繁增项要书面说明依据 |
| T2 | 口头变更不落纸 | "这个不用写，你点头就行"；催你当场转钱 | 要求填变更单；当场不能签的，写明三天内补单，超期不施工 |
| T3 | 按实结算无上限 | 报价单水电只写"按实结算"，无单价 | 补单价与上限；否则拒签 |
| T4 | 材料只写品牌 | "都用一线品牌" | 要求写型号；封样 |
| T5 | 隐蔽工程不验收直接封闭 | 工长催促"先封上，不然来不及" | 坚持验收记录单签字后再封闭；宁可延后工期 |

### 2.2 中度危险

| 编号 | 陷阱 | 识别信号 | 应对动作 |
|---|---|---|---|
| T6 | 增项无单价先施工 | "先做着，多少钱回头算" | 坚持先定单价后施工 |
| T7 | 变更不写工期影响 | 变更单只写钱不写天数 | 变更单必须含工期影响栏 |
| T8 | 增项上限缺失 | 合同无累计变更比例约定 | 约定变更上限与超出后的协商机制 |
| T9 | 成品安装另计 | 报价含主材不含安装 | 报价阶段问清安装归属 |
| T10 | 垃圾清运起终点模糊 | 只写"含清运" | 写起点、终点、含车数、超量单价 |
| T11 | 开关插座按米另计 | "按点位算，一个点位多少钱另算" | 改按点位总价包死，或约定点位单价与上限 |
| T12 | 造型"特殊工艺"加价 | 弧形、灯槽、叠级造型被称特殊工艺 | 报价阶段要求造型按图纸报价，图纸外造型另行报价 |
| T13 | 找平被说成"不做无法施工" | 拆改后才提找平 | 报价单须含基层处理；拆改后提的要核是否真属必要 |
| T14 | 甲供材料损耗无约定 | 自购材料，结算多出损耗 | 约定损耗率与保管责任 |
| T15 | 质保金不给退 | "质保金不满一年不退" | 写明退还条件与时点 |

### 2.3 需留意但不必然是陷阱

| 编号 | 情形 | 判断方法 |
|---|---|---|
| N1 | 老房改造增项多 | 属客观条件；核对是否已列入报价范围 |
| N2 | 施工中出现设计变更 | 看变更单是否有据、是否双方签字 |
| N3 | 材料升级 | 看是否业主决定、价差如何确认 |
| N4 | 隐蔽工程量与预算不符 | 看预算有无量差预留；预留不足是报价问题 |
| N5 | 工期顺延伴随增项 | 顺延与增项的责任方常常不同，要分开看 |

### 2.4 一张快速判定表

拿到一张变更单或听到一个增项要求时，按这四问走：

```
第 1 问  这项在合同或报价单里有吗？
  有 → 属重复计费，书面提出核对
  没有 → 进第 2 问

第 2 问  这是"本该包含但漏报"，还是"新增的内容"？
  漏报 → 报价完整性问题，主张已含在总价
  新增 → 进第 3 问

第 3 问  是谁提出的、有没有客观依据？
  业主提出且无必要依据 → 业主承担价款与工期影响
  施工方提出且属其应尽勘察义务 → 施工方责任
  有客观依据（图纸与实际不符、安全必要） → 按变更处理，约定单价与工期

第 4 问  单价与工期影响确定了吗？
  未确定 → 不施工，坚持先定单价
  已确定 → 填变更单，签字后施工
```

## 三、变更签证单要素与操作要求

### 3.1 依据要点

民法典合同编关于合同变更的基本规则：当事人协商一致，可以变更合同；当事人对合同变更的内容约定不明确的，推定为未变更。同时，承揽合同项下，定作人中途变更承揽工作要求，给承揽人造成损失的，应当赔偿损失。

**落到操作上**：变更必须书面、口头不算；业主变更要承担对施工方的合理损失（这是谈判时的筹码，也是自身的责任点）；变更内容约定不清则视为未变更（这是要求对方写清楚的依据）。

### 3.2 变更签证单要素模板

```
变更签证单
编号：            日期：
工程名称：        所在部位：

一、变更事由
   （业主需求 / 图纸变更 / 现场条件不符 / 安全必要 / 其他，注明提出方）

二、变更前做法
   （原设计与原报价单对应行项）

三、变更后做法
   （具体做法、材料品牌与型号、工艺要求）

四、工程量
   （数量、单位、计量方式：按点位/延米/平方米/件/车/工日）

五、价款
   单价：          合价：
   单价来源：合同同类项目单价 / 双方协商 / 当地同期价格（勾选并写明依据）

六、工期影响
   顺延    个日历天  /  不影响工期
   理由：

七、附件
   现场照片（张数）  图纸标注  隐蔽工程记录  其他

八、确认
   甲方（业主）签字：            日期：
   乙方（施工方）签字/盖章：     日期：
   监理方（如有）签字：          日期：
```

### 3.3 操作纪律五条

| 纪律 | 原因 | 具体做法 |
|---|---|---|
| 先定单价，再施工 | 顺序颠倒就变成"先干活再谈钱" | 开工前把常用变更项单价表作为合同附件，现场直接查表签字 |
| 口头变更当天转书面 | 口头指令在实务中常被认可，但手上要有记录 | 当天发文字消息复述内容请对方确认，截图归档；复杂变更补正式签证单 |
| 变更单与隐蔽工程验收联动 | 封闭后无法回溯 | 签证单中写明该变更部位的验收方式与记录要求 |
| 签字要有日期 | 无日期的签字难对应时点 | 每份签证单写签署日期，跨日的分段签 |
| 一单一编号 | 口头与纸面混杂时无法核对 | 编号连续，不跳号；编号缺失要问为什么 |

### 3.4 聊天记录与即时通讯记录的取证用法

聊天记录可以作为沟通内容与过程证据使用，但**不能替代签证单**。正确用法：

| 场景 | 做法 |
|---|---|
| 收到口头变更 | 当天文字复述："师傅，今天说的加两个插座，我理解是在客厅东墙加两个五孔插座，位置在电视柜右侧，对吗？确认后我安排。"对方回复确认 → 截图归档 |
| 对方不愿书面确认 | 继续文字沟通，把单价、工期一并问清并留痕；同步在变更单上注明"该变更经__于__月__日口头提出，本人于同日以文字方式确认" |
| 大额变更 | 不接受仅聊天确认；坚持签证单或补充协议 |
| 争议发生后 | 整理完整时间线：提出 → 确认 → 施工 → 验收 → 付款，每一环对应材料 |

**提醒**：不要在聊天中留下"先做着，回头再说"这类表述。

### 3.5 变更导致工期顺延的写法

```
变更导致工期顺延的确认要点
  1 顺延起算与终止：自____年__月__日（变更提出日或封闭中断日）起，
    至____年__月__日（复工日）止，共__个日历天
  2 中断原因的证明材料：监理记录、书面通知、设计变更单、照片
  3 复工条件与时间：复工需具备的条件、实际复工日
  4 与合同工期的关系：原竣工日____，顺延后竣工日____
```

**要点**：写"日历天"而不是"工作日"，写具体日期而不是"若干天"，顺延天数要有起止日期支撑。跨节假日、跨停工待料期要单独说明。

## 四、增项金额的自我保护动作

| 动作 | 说明 |
|---|---|
| 签约前把报价拆到工序级 | 逐工序核，缺口在签约前补进报价 |
| 附一张"可能增项清单 + 单价表" | 把已知的不确定项写进合同附件，现场按表执行，避免现场议价 |
| 设变更上限条款 | 约定累计变更占合同总价的比例上限，超出部分另行协商 |
| 约定单价确定顺序 | 参照同类项目单价 → 双方协商 → 当地同期价格 |
| 每笔变更登记进台账 | 编号、事由、金额、工期、签字人，形成可核对的账 |
| 每月核对累计变更占总价比例 | 接近上限时提前处理，不要等到超了再谈 |
| 结算时按六类来源分流 | 可主张 / 需协商 / 应承担，分开处理 |
