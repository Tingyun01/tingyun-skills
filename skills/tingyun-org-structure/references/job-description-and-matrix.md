# 岗位职责书与责任矩阵

> 供「组织架构与岗位职责顾问」使用。职责落到人、落到可交付的写法与排查工具。

---

## 一、岗位职责书七段结构

### 1.1 模板骨架

```
【岗位名称】采购主管
【所属部门】供应链部
【岗位目的】通过供应商开发与成本谈判，保障生产物料的稳定供给与采购成本可控
【直接上级】供应链总监（虚线汇报：财务负责人，预算口径）
【下属】采购专员 2 名
【核心职责】（4~7 条，每条一个可交付结果）
  1. 负责合格供应商名录的开发与维护，纳入标准为：资质齐全、近两年无重大质量事故、能按期交付；名录每季度更新一次并留存评审记录
  2. 负责生产物料的采购执行，交付准时率不低于 95%，延期须在发现后 2 个工作日内向供应链总监发出预警
  3. 负责采购成本谈判与年度降本方案，每季度提交一次降本目标达成情况分析
  4. 负责采购订单与对账闭环，账实相符率要求全数核对无误，月度对账在次月 10 日前完成
  5. 负责供应商现场审核，每年完成不少于 8 家审核并输出整改跟踪表
  6. 负责备选供应商储备，主料双供应商覆盖率不低于 80%
【决策权】
  自主决定：单笔 5000 元以下的常规物料请购、供应商询价方式选择、催货与沟通安排
  需上级批准：单笔 5000 元以上的采购订单、新增供应商准入、年度降本目标调整
  共同决定：与研发共同确定物料选型替代方案；与财务共同确定付款节奏与账期调整
【关键绩效产出】
  交付准时率 95% 以上；年度综合采购成本下降 3% 以上（口径：同规格物料加权单价对比）；月度对账差错为零
【协作关系】
  输入给：生产计划（物料到货计划）、财务（对账单与付款申请）
  接收来自：研发（物料需求与规格）、品质（供应商审核结论与质量异常）
【任职要求】
  5 年以上制造业采购经验，其中 2 年带团队；熟悉物料成本构成与招标比价流程；具备供应商现场审核经验；需签署廉洁与保密承诺
```

### 1.2 七段各自的作用与常见缺失

| 段 | 作用 | 常见缺失 |
|---|---|---|
| 岗位目的 | 回答"这个岗位为什么存在"，是空转岗位排查的首要依据 | 缺失或写成部门职责 |
| 直接上级与汇报关系 | 明确行政上级只能有一个，虚线要写清"虚线不构成指令权" | 只写部门不写具体上级 |
| 核心职责 | 4~7 条，每条一个可交付结果 | 写动作不写结果；条目超过 10 条说明岗位过宽 |
| 决策权 | 三档分列，是防止决策上收的关键 | 完全空白或只写"重大事项报领导" |
| 关键绩效产出 | 把职责变成可观测指标 | 用"完成本职工作"这类不可测表述 |
| 协作关系 | 明确交接点，减少互相等 | 只写"相关部门" |
| 任职要求 | 硬门槛与加分项分开 | 把学历年限写成硬门槛而岗位实际不需要 |

### 1.3 写法硬规则

**规则一：写结果，不写动作**

| 反例（动作） | 正例（结果） |
|---|---|
| 负责采购询价、比价 | 负责合格供应商名录开发与维护，每季度更新，新供应商准入周期不超过 15 个工作日 |
| 负责与客户沟通 | 负责大客户续约，年度续约率不低于 Y%，风险提前 60 天预警 |
| 协助项目经理推进项目 | 负责项目节点交付物清单编制与跟踪，节点按期交付率不低于 Z% |
| 负责报表统计 | 负责经营周报编制，每月第 2 个工作日前发出，口径与财务一致 |
| 负责日常工作安排 | 负责团队任务分派与进度跟踪，周进度偏差率低于 10% |

**规则二：一条职责一个可交付物**
一条职责里出现"和"字连接两个不同交付物，通常要拆成两条。

**规则三：可归属**
只有这个岗位写这一条。若两份岗位书出现几乎相同的表述，说明制度性重复，必须划清触发条件与交接点（例如"销售在客户下单后 24 小时内把交付需求提交给交付负责人，交付负责人在需求提交后 2 个工作日内给出排期"——写清交接点与时限，两边都不算重复）。

**规则四：可衡量**
每条职责至少挂一个观测口径：数量、时效、质量、满意度、成本。

**规则五：不写"协助"作为主要职责**
"协助"意味着结果不由你担。若职责里 3 条以上以"协助"开头，结果责任实际在别人身上，这个岗位多半是空转岗。

**规则六：新员工可执行**
检验方法：给入职 30 天的人看，问"我知道今天该干什么吗"。答不上来说明缺了优先级与触发条件。

## 二、简化责任矩阵

### 2.1 三列版本（够用且好维护）

| 事项（动词 + 对象） | 谁做（执行） | 谁担结果（只能一位） |
|---|---|---|
| 报价单出具 | 销售专员 | 销售经理 |
| 交付排期确定 | 交付计划员 | 交付负责人 |
| 客户需求确认 | 销售专员 | 销售经理 |
| 采购下单 | 采购专员 | 采购主管 |
| 质量异常处理 | 品质工程师 | 品质主管 |
| 发票与回款 | 财务专员 | 财务经理 |
| 招聘需求提出 | 用人部门负责人 | 用人部门负责人 |
| 新员工入职带教 | 导师 | 用人部门负责人 |

**列的填写规则**
- "谁做"可以有多个，但标出主责（首位或加星号）
- "谁担结果"**有且仅有一个**。这是整套工具的核心约束

### 2.2 排查步骤

1. **先列事项**（20~40 项），覆盖经营闭环：获客、报价、合同、交付、收款、供应、质量、人员、对外事务、售后
   - 粒度标准：细到能判断谁在做，不细到能拆成动作步骤
   - 不要按现有岗位列事项，要按业务闭环列
2. **逐项填"谁做"**：填岗位名，不填人名
3. **逐项填"谁担结果"**：一人，多了就标红
4. **横向读（看事项）**：找重叠与空白
5. **纵向读（看岗位）**：找空转岗位与岗位过载
6. **出整改清单**：每条问题配一个处理动作与责任人

### 2.3 横向读出的五类问题

| 现象 | 含义 | 处理方向 |
|---|---|---|
| 一个事项有 2 个以上结果负责人 | 职责重叠，出事互相推 | 拆成不同事项，或合并为一个担责人 |
| 一个事项没有结果负责人 | 责任空白 | 指定一人，或明确取消该事项（不取消就指定） |
| 一个事项有 3 个以上执行方 | 交接成本高 | 划清前后环节或合并到两个 |
| 事项在两份岗位书里措辞几乎一致 | 制度性重复 | 写清触发条件与交接点、时限 |
| 事项实际执行人普遍是同一个人 | 该岗位名义职责与实际不符 | 按实际重写职责，或按职责调整配置 |

### 2.4 纵向读出的三类问题

| 现象 | 含义 | 处理方向 |
|---|---|---|
| 某岗位的"担结果"清单里全在其他岗位名下 | 岗位存在意义不清 | 重写职责 / 并岗 / 需复核的安置安排 |
| 某岗位承担 15 项以上结果负责人 | 岗位过载或矩阵填错 | 拆分职责或核查填写口径 |
| 某岗位一条结果负责人也没有 | 纯执行岗或填表遗漏 | 确认是否为纯执行岗并写明升级路径 |

### 2.5 与 RACI 的取舍

完整的 RACI（Responsible / Accountable / Consulted / Informed）四角色在中小企业的落地难点是：Consulted 与 Informed 会被大量填写，结果没人看。

**实用折中**
- 只保留"谁做"与"谁担结果"两列
- 沟通与知会需求，用一列"需要知会谁"补充即可
- 参与决策的岗位，写进该岗位的决策权"共同决定"段

这样一份矩阵 3 列、20~40 行，一小时能填完，也能真的被用起来。

## 三、一人多岗与兼岗

### 3.1 一人多岗的常见成因与判断

**成因**：人手不足、复合岗位要求、组织规模小、转型期职责未拆完。

**先判断是"一人多岗"还是"岗位混写"**
- 岗位数少于实际工作内容，且每件事都有明确归属 → 合理的一人多岗
- 一个人写着 5 个岗位名称，职责互相矛盾、无人能承接 → 岗位混写，需重写职责

### 3.2 兼岗写法（写进岗位说明书）

```
【兼岗安排】
  主责岗位：销售经理（考核与晋升依据以此岗位为准）
  兼任岗位：渠道拓展主管
  投入比例：渠道拓展占本岗位工作时间 30%~40%
  授权边界：
    金额审批权限：单笔 1 万元以下可自行决定；超过 1 万元需上一级批准（不因兼任而扩大）
    合同签署权限：不可独立签署，需加盖主责岗位对应审批层级
    对外承诺权限：仅可做已备案的价格与政策范围内的承诺，超出需书面确认
  冲突处理规则：主责岗位事项与兼任岗位事项冲突时，先保主责；兼岗事项受阻超过 3 个工作日可申请临时调整投入比例
  复核周期：每 6 个月复核一次投入比例与授权范围
```

### 3.3 授权边界要分开写的三类权限

| 权限类型 | 说明 | 兼岗时的默认规则 |
|---|---|---|
| 金额审批权限 | 花钱的额度 | 不因兼任而扩大 |
| 合同签署权限 | 对外签约 | 不因兼任而扩大；兼岗不默认获得签约权 |
| 对外承诺权限 | 对客户/供应商的口头与书面承诺 | 仅限已备案政策范围 |

### 3.4 兼岗的风险提示

| 风险 | 信号 | 处理 |
|---|---|---|
| 责任稀释 | 两边的事都"以为对方在做" | 写清主责与冲突处理规则 |
| 权限扩大 | 兼任后顺手批了原来批不了的 | 权限表与兼岗声明分开，不共用额度 |
| 绩效互挤 | 兼任岗位的产出在考核中被忽略 | 考核口径写明主责岗位的权重 |
| 知识单点 | 只有一人掌握两条线的关键环节 | 建文档备份与流程固化 |
| 过高比例 | 兼岗占本岗位时间超过三分之一 | 提示应考虑增员或重新划分 |

## 四、岗位职责书的落地节奏

| 阶段 | 动作 | 完成标志 |
|---|---|---|
| 起草 | 每个岗位一人写初稿，负责人过一遍 | 每份七段齐全 |
| 对齐 | 与相关岗位做双向核对：这些职责该我担吗、交接点清楚吗 | 无人提出"这条不该我担" |
| 量化 | 给每条职责挂可观测口径 | 核心职责每条都有指标 |
| 试用 | 新入职员工按说明书执行 4 周 | 新人能照做，主管不用重复解释 |
| 复核 | 每半年复核一次，与实际职责对比 | 差异项已更新 |

**常见失败模式**：一次性把 60 个岗位全写完，写完就压在抽屉里。更好的做法是**先写 8~12 个关键岗位**，跑通一两个部门，再复制格式铺开。
