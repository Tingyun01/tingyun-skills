# 薪酬结构与市场分位设计参考

配套专家包：tingyun-compensation-design（薪酬体系与调薪设计顾问）

本文件是可直接抄进表格与规则文本的作业底稿。所有比例与区间为一般性参考，需按公司阶段、地区与行业情况调整。

---

## 一、动手前的三个约束条件

| 约束 | 怎么问 | 影响什么 |
|---|---|---|
| 现金能不能扛住固定部分 | 未来 6~12 个月预计人工现金支出 ÷ 预计收入，落在什么区间 | 固定/浮动比例的上下限 |
| 老板是否接受人力成本上升 | "调薪意味着明年多花 X 万，你接受吗" | 调薪节奏是集中还是分期 |
| 当前的痛点是什么 | 招不到人 / 人留不住 / 干得多的拿得少 / 成本太高 | 先解决哪一块，其余暂缓 |

回答不了头一个约束，后面所有比例都是空转。

## 二、三段式结构比例表

| 段 | 作用 | 现金紧（融资维持或亏损） | 现金稳（正向现金流） | 扩张期（有明确融资进账） |
|---|---|---|---|---|
| 固定薪酬 | 保底与可承诺部分 | 70%~85% | 60%~75% | 55%~70% |
| 绩效薪酬 | 挂钩产出、承担波动 | 8%~15% | 12%~25% | 15%~30% |
| 长期激励（年度/留任/其他） | 绑定与上行分享 | 3%~8% | 5%~12% | 8%~15% |

按岗位类型微调（以现金稳为基准）：

| 岗位类型 | 固定 | 绩效 | 长期激励 | 说明 |
|---|---|---|---|---|
| 销售 | 40%~60% | 25%~40% | 5%~10% | 提成部分归入绩效段核算，避免重复计奖 |
| 研发 | 70%~85% | 8%~18% | 8%~15% | 产出周期长，固定部分不宜低于 70% |
| 产品 | 65%~80% | 12%~22% | 8%~15% | 指标以里程碑为主，不宜用月度销售口径 |
| 职能（财务/法务/人力/行政） | 75%~90% | 5%~15% | 5%~10% | 难归因，挂钩比例低，用专项奖替代 |
| 一线交付与运营 | 60%~75% | 15%~25% | 5%~10% | 质量与准时率可挂，但要注意指标数量 |

**使用要点**：
- 三段比例是"从现金红线倒推"的结果，不是行业惯例的抄写。
- 新建体系时先定比例区间，再定岗位带；修补旧体系时先看结构是否失衡，再动单点数字。
- 岗位类型混合度高（同一团队既有销售又有研发）时，先用团队平均结构做大盘约束，再允许个别岗位偏离并写明偏离原因。

## 三、简易要素法：岗位价值打分表

### 3.1 要素与权重（可调）

| 要素 | 观察点 | 默认权重 | 何时调高 |
|---|---|---|---|
| 影响范围 | 产出影响几个人、多大收入、多长的上下游链条 | 30% | 岗位是业务主链路上的关键环节 |
| 决策与承担 | 独立决策范围、是否承担资金、合规、交付责任 | 25% | 岗位含明确责任与风险承担 |
| 技能与经验门槛 | 上手周期、稀缺能力要求、是否需行业 know-how | 25% | 招聘难、市场上同类人少 |
| 知识与持续学习 | 知识更新频率、经验复用价值 | 10% | 岗位需长期积累、经验可迁移 |
| 工作条件与替代难度 | 加班强度、场地要求、招聘替代难度 | 10% | 存在明显难招岗位或高强度岗位 |

### 3.2 打分表模板

| 岗位 | 影响范围 | 决策与承担 | 技能与门槛 | 知识复用 | 工作条件 | 加权分 | 价值序 | 薪酬带 |
|---|---|---|---|---|---|---|---|---|
| （岗位 A） | 1~5 | 1~5 | 1~5 | 1~5 | 1~5 | 计算值 | — | 待定 |
| （岗位 B） | | | | | | | | |

加权分 = 各项打分 × 权重之和（1~5 分制）。

### 3.3 作业规则

- 两人独立打一遍，比较差异；差异集中在某一项要素，说明双方对该岗位的职责理解不一致，先对齐岗位定义。
- 分数只用于排序与分带，不直接换算金额。
- 若某岗位得分高但说不出理由，通常是岗位边界没划清，优先改岗位说明，而不是反复调分数。
- 每半年复评一次，或在岗位实质变化、职责扩大后即时复评。

### 3.4 价值序 → 薪酬带映射

| 价值序分位 | 薪酬带定位 | 带宽设置 | 说明 |
|---|---|---|---|
| 高（加权分 4.2~5.0） | 关键岗带 | 带宽较窄（约基准 ±15%） | 关键岗定位靠区间内的位置控制，不靠带宽宽度 |
| 中高（3.4~4.2） | 骨干岗带 | 中等（约 ±20%） | 主力带，晋升与调薪的主要发生区 |
| 中（2.6~3.4） | 通用岗带 | 较宽（约 ±25%） | 带宽宽给的是"同岗不同人"的容纳空间 |
| 基础（1.0~2.6） | 基础岗带 | 较宽（约 ±30%） | 外部市场可比性高，宽带用于吸收差异 |

带宽宽度与晋升、调薪机制强相关：带宽越窄，内部晋级空间越小，晋升就必须伴随带宽扩张；带宽越宽，越依赖绩效分档来拉差距。两者必须自洽。

## 四、市场分位选择与适用条件

### 4.1 三种分位对照

| 维度 | 领先 | 匹配 | 滞后 |
|---|---|---|---|
| 相对市场中位 | 高于中位（常见取 P60~P75） | 贴近中位 | 低于中位（常见取 P25~P40） |
| 招聘效果 | 缩短招聘周期、降低拒 offer 率 | 常规 | 周期拉长、候选人流失在终面阶段 |
| 留存效果 | 降低主动流失，尤其是核心骨干 | 常规 | 核心骨干流失风险上升 |
| 成本影响 | 人工成本整体上抬 | 可控 | 表面省、后期被动补涨成本更高 |
| 适用阶段 | 扩张期、抢人期、利润上行期 | 平稳期、利润敏感期 | 现金紧张、转型收缩期、岗位易替代 |
| 需要的补偿 | 无 | 无 | 成长空间、灵活性、股权预期 |
| 主要风险 | 形成只涨不降的预期，退出时难降 | 抢人时力度不足 | 补涨发生在离不开的人身上，成本更高 |

### 4.2 决策树

```
现金流能扛住固定部分？
├─ 否 → 分位只能取匹配或滞后，且固定部分要压到 75% 以上
│        └─ 关键岗仍招不到人 → 该岗位可能不适合现有业务阶段，考虑改用外包/项目制
└─ 是 → 本轮核心痛点是什么？
         ├─ 招不到人 → 领先（先补关键岗，不必全员上调）
         ├─ 留不住核心骨干 → 领先 + 配留存方案（留任奖金/长期激励衔接）
         ├─ 干得多的拿得少 → 匹配 + 重设绩效挂钩（钱不动，让动起来的人多得）
         └─ 成本太高 → 先动固定部分与福利口径，不动分位（先动分位会直接伤留存）
```

### 4.3 分位选择的复盘触发条件

出现下列任一情形，说明分位需要重估：

| 触发信号 | 观察方式 | 可能的原因 |
|---|---|---|
| 招聘周期明显拉长 | 同一岗位投递到入职的周数环比 | 分位偏低或岗位画像与市场脱节 |
| 核心岗主动离职增加 | 骨干岗年度流失人数与结构 | 分位偏低、成长空间不足 |
| 外部报价超出带宽上限 | 收到的候选人报价 | 分位设定与市场脱节 |
| 成本率越过红线 | 人力成本占收入比 | 分位偏高或编制扩张失控 |
| 被动补涨金额上升 | 年内"市场追赶调薪"次数 | 历史分位偏低积累的欠账 |

复盘周期建议半年一次，或在触发条件出现时立即启动。

## 五、与股权激励的衔接清单（现金侧）

本清单只做现金侧的衔接判断，股权工具本身的选择与条款设计属于股权激励与员工持股专业包。

| 衔接点 | 现金侧要做什么 | 常见错误 |
|---|---|---|
| 分位与股权的关系 | 先定现金分位，再评估股权是否需承担额外拉力 | 用股权故事掩盖现金明显低于市场的事实 |
| 角色分工 | 现金定当期到手与稳定性，股权定上行与长期绑定 | 两边都指望对方出 力 |
| 兑现状态一致性 | 未走完程序的股权不在薪酬口径中当作固定收入 | 招聘时承诺股权、兑现时改口 |
| 长期激励段的口径 | 现金包里的"长期激励"若实为年度奖金/留任奖金，要与股权激励分开列示 | 两者混在一个数字里，员工理解为都是股权 |
| 预算关系 | 股权摊销/成本与现金总成本分开测算，合起来看总负担 | 只看现金包不看股权成本，总成本失真 |
| 沟通口径 | 现金沟通讲当月到手与规则，股权沟通讲条件与不确定性 | 用"公司做成了你会很值钱"替代具体说明 |

## 六、作业顺序建议

1. 算出现金红线（人力成本占收入比的上限）→ 决定三段大比例。
2. 列岗位清单并做要素打分 → 得到价值序。
3. 价值序映射薪酬带 → 定带宽与基准。
4. 选市场分位 → 得各带的基准水平。
5. 按岗位类型微调绩效挂钩比例 → 定浮动段。
6. 写调薪与晋升规则 → 定变动规则。
7. 扫描压缩与倒挂 → 出处置方案。
8. 写沟通话术与自检 → 交付。

顺序颠倒（先定具体数字再拼结构）是这类项目里出现频率较高的返工原因。
