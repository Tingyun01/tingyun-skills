# tingyun-renovation-quote-defense

> 拆解装修报价单的五要素，标出按实结算与品牌不明的活口条款，算清增项风险并给出议价话术与合同条款补充建议
>
> 面向装修业主的报价单审查助手。把装修公司给的报价单拆成项目、单位、数量、单价、是否按实结算、是否写明品牌型号等要素，逐项标出留了活口的条款，按付款节点倒推被卡住的风险，测算可能的增项区间，并给出可直接使用的议价话术与合同条款补充参考文本。

## 这个 Skill 做什么

把「装修报价核价」这个场景最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

### 解决什么问题

业主真正难受的不是"看不懂材料清单"，而是**看不懂别人写给他的那份合同附件**。

**漏项是行业系统性现象。** 报价单是销售工具，条目越少越容易报出"看起来不贵的总价"；施工时该有的工序一项都不会少，缺的部分只能以增项回来。业主拿到的往往是一份"看起来很全"但口径没锁死的清单。

**问题性质是"没说清"，不是"报贵了"。** 同样一套水电改造，写"400 米 × 120 元"和写"400 米 × 120 元（按实际发生）"，前者锁死、后者开放。差别不在价格高低，在条款是否留了后路。

**金额可量化，痛点就能量化。** 每行都有金额，"缺什么、留了什么口"最终落到可估算的区间上。这让"看不懂"变成"看得清但说不破"——而谈判需要的恰恰是后者。

本技能做的事：**逐行拆成可核对要素，标出开口条款，算出风险量级，给出能直接说出口的话术和能直接粘进合同的条款。**

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 帮我看看这份装修报价单有没有坑
- 报价单上哪些项目没写清楚
- 装修增项一般能有多少
- 报价单里写着按实结算是什么意思

## 怎么用

1. 安装到你的 agent（Claude Skills 目录 / 扣子技能商店）
2. 直接用日常说法提需求，例如：
   帮我看看这份装修报价单有没有坑
3. 它会追问关键信息（缺的信息会标〔待补〕，不会替你编）
4. 输出可直接用的清单 / 对照表 / 台账

## 输出

- 判断步骤与检查清单
- 对照表 / 台账
- 待办与需要人工核实的问题

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核

- 单次购买、单人授权使用；**不可转售或再分发**
