# 程序合规要点、证据链留存、交接结算与求助触发条件

用途：把"流程走完"变成一份可签收、可归档、可复盘的清单。本文为清单与流程设计辅助，不构成法律专业意见，需人工复核。

---

## 一、程序合规要点（按时间顺序）

### 阶段 0：解除前（决定是否动手）

| 动作 | 判断条件 | 留痕 |
|---|---|---|
| 确认劳动关系真实状态 | 是否为劳动关系、有无劳务/外包/派遣混同 | 合同、用工管理记录 |
| 确认工龄起算 | 入职日期、是否合并计算前单位工龄（有约定的从约定） | 档案、社保缴纳记录 |
| 排除第42条特殊保护情形 | 逐项对照医疗期、三期、工伤职业病、临近退休 | 见 references/termination-classification.md 第五节表格 |
| 核算是否触发第41条门槛 | 拟裁人数 / 企业职工总数 | 人数统计表 |
| 核对规章制度是否已公示告知 | 民主程序 + 公示告知 | 讨论记录、签收表、发布记录 |
| 证据缺口盘点 | 每一条"事实"是否有对应证据 | 证据索引表 |

### 阶段 1：解除通知

**必备要素**：
1. 明确解除的**具体事实**（时间、行为、经过，不写"多次严重违反"这类概括）
2. 明确**法律依据**（第39条第几项 / 第40条第几项 / 第41条）
3. 明确**所依据的规章制度名称与条款号**
4. 明确**解除生效日期**
5. 明确**工资与经济补偿结算方式**
6. 明确**社保与档案转移办理路径**
7. 明确**离职证明出具安排**
8. 明确**工作交接要求**
9. **工会通知**（第43条）：建立了工会组织的，单位单方解除应事先将理由通知工会，并研究工会的意见、将处理结果书面通知工会
10. **第40条路径**：提前30日书面通知本人，或支付1个月工资代通知金（二者择一）

**不成立的做法**：仅口头通知、仅在聊天工具中发一句话、仅让保安不让进门、"你先写个辞职信"、用停工停岗代替书面解除、让员工在空白文件上签字。

### 阶段 2：送达

- 送达本人并留存签收证据（签收人签字、写明日期）
- 本人拒收或无法当面送达的：邮寄送达，保留邮寄凭证、面单、投递与签收记录
- 留存通知文本原件或加盖公章的副本，以及送达环节的全套材料

**提示**：送达争议是这类争议的高频争点。送达链条不完整，后面所有实体论证都会受影响。

### 阶段 3：协商与沟通（谈判期）

- 保留每一次协商的时间、地点、参与人、议题与结论
- 书面方案发给员工并保留其回复
- 涉及员工放弃权利的条款（放弃社保、放弃仲裁权、放弃加班费）要单独提示风险
- 达成的协议应书面化，明确款项金额、支付时间、支付方式、签署时间与生效条件

## 二、证据链留存清单

按"主张 → 证据"对应整理，避免只有结论没有支撑：

### A. 劳动关系与主体资格
- [ ] 劳动合同（各版本及变更协议）
- [ ] 录用通知、offer、入职登记表
- [ ] 社保缴纳记录、个税申报记录、工资表与银行流水
- [ ] 考勤与排班记录、请假与加班审批
- [ ] 岗位说明、岗位职责文件
- [ ] 员工手册签收单、制度培训签到表

### B. 解除理由的事实支撑（按情形选取）
- [ ] 违纪类：事件时间线、书面告知、申辩记录、处罚决定、整改要求
- [ ] 不胜任类：岗位职责、考核标准与结果、沟通记录、培训/调岗记录、改进期反馈
- [ ] 医疗期满类：诊断证明、住院记录、医疗期起止确认、调岗安排与答复、医疗期满后仍不能从事工作的判断依据
- [ ] 客观情况重大变化类：经营或业务调整依据、变更劳动合同的书面提议、员工答复记录
- [ ] 经济性情形类：经营困难或重整的依据、方案说明材料、听取意见记录、报告材料

### C. 程序材料
- [ ] 解除通知书原件 + 送达凭证
- [ ] 工会通知函与工会回复（若有工会）
- [ ] 提前30日通知的送达证据（走第40条时）
- [ ] 代通知金支付凭证（走第40条且未提前通知时）
- [ ] 第41条程序材料（说明情况记录、听取意见记录、报告材料、优先留用落实情况）
- [ ] 协商过程记录、书面协议、款项支付凭证

### D. 特殊保护情形核查材料
- [ ] 医疗期相关：诊断证明、住院记录、累计病休假统计表
- [ ] 三期相关：孕检记录、出生证明、哺乳期凭证
- [ ] 工伤相关：工伤认定结论、伤残鉴定结论
- [ ] 职业病相关：告知书、体检记录、诊断或医学观察期材料
- [ ] 临近退休相关：连续工龄证明、出生日期证明

### E. 交接结算材料
- [ ] 交接单（含物品清单、账号密码交接、款项核对）
- [ ] 工资结算表与支付凭证
- [ ] 经济补偿计算表与支付凭证
- [ ] 离职证明（存根）
- [ ] 社保减员手续凭证、档案转移手续凭证
- [ ] 解除或终止劳动合同文本

## 三、交接与结算清单

### 结算类

| 项目 | 要点 | 备注 |
|---|---|---|
| 工资结算 | 截止解除日的应发工资、已发部分、扣款项 | 加班费、年假折算一并核对 |
| 经济补偿 | 计算表 + 支付凭证 | 支付时间与离职手续办理的衔接 |
| 代通知金 | 1个月工资 | 仅第40条且未提前通知时 |
| 未休年假 | 折算或补偿 | 依制度与属地口径 |
| 社保公积金 | 减员时间、转移指引 | 出具社保转移提示 |
| 档案关系 | 转移路径与接收方 | 属地档案管理规定 |
| 离职证明 | 依法出具 | 不得设置障碍性条件 |
| 工伤/医疗期相关待遇 | 按对应规则处理 | 涉及工伤保险与医保衔接 |

### 交接类

- 工作事项与在办事项清单（含责任交接人签收）
- 客户/供应商/项目等对外关系交接
- 公司资产与物品（电脑、门禁卡、工牌、制服、密钥）回收与签收
- 办公账号、系统权限回收记录
- 保密与数据处理相关交接（涉及数据交接时另做合规核对）

### 台账类

- 解除或终止劳动合同的文本，**至少保存二年备查**（《劳动合同法》第50条）

## 四、群体性处理的风险预警

| 预警信号 | 风险 | 应对动作 |
|---|---|---|
| 同一批次处理人数达到20人或占职工总数10% | 触发第41条程序要求，未走即违法 | 先做门槛核算，再走程序 |
| 多名员工被适用同一理由解除 | 个案不成立时易被整体认定依据不当 | 逐人核对事实差异，材料个别化 |
| 员工之间存在联络、串联迹象 | 易形成群体性劳动争议 | 统一口径、逐个谈、避免差别待遇引发争议 |
| 内部已有群聊或沟通记录传播 | 沟通内容可能成为证据 | 统一由固定对接人沟通，避免多头发消息 |
| 涉及区域集中（如同一门店、同一班组） | 同一批次人数易越过门槛 | 重新统计口径，避免分批操作掩盖人数 |
| 员工已集体委托代理人或准备材料 | 争议将升级为仲裁诉讼 | 立即引入专业机构与属地沟通 |
| 员工在孕期、工伤、医疗期内且被列入名单 | 违法解除风险叠加 | 逐个排除或改走其他路径 |

## 五、什么时候必须请专业机构

以下情形**不要在顾问层继续推进**，应立即建议用户咨询专业劳动法律师或其他相应专业机构：

1. 已进入劳动仲裁或诉讼程序（含收到仲裁通知、已被申请仲裁）
2. 涉及女职工孕期、产期、哺乳期，或员工处于医疗期内
3. 涉及工伤、职业病、疑似职业病人在诊断或医学观察期间
4. 涉及工伤亡故
5. 群体性裁员（达到第41条门槛）或已经出现集体维权迹象
6. 涉外用工、港澳台人员用工，或涉及境外法律适用
7. 涉及竞业限制、保密义务、商业秘密、知识产权归属争议
8. 企业已进入破产清算或重整程序
9. 涉及高管、核心技术人员、创始团队成员的解除
10. 涉及股权、期权、代持等与劳动关系交织的安排
11. 需要就解除协议的条款效力作判断，或员工已提出反要挟条件
12. 员工已委托专业代理人并发出正式函件
13. 涉及兼职、劳务、外包、派遣人员被"一并清退"的混合用工场景
14. 对送达方式存在实质争议，或员工已明确拒绝接收任何文件
15. 舆情风险较高，或解除涉及公众关注事项

**同时应请专业机构的还有另一类**：单位内部没有劳动法务或HR专业能力，而解除数量超过1人的——多对一的单方解除，一个人做容易出纰漏。
