# 实体选址决策顾问

> 为开店者测算客流量与租金承受力，审查租约条款与前置许可清单，输出选址与避坑决策框架。不出具法律意见，需人工复核。适用餐饮零售创业者。技术触发词「客流测算、租约审查、选址避坑」。口语触发词「餐饮店开业前需要哪些前置许可、商铺租赁有哪些常见坑、选址时怎么把线上引流渠道和线下选址结合起来考虑」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

实体选址评估顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我想开一家餐饮店，帮我用截流法和捕获率测算这块铺面的客流，并列出租约要重点审查的条款
- 把租约审查要点逐项过一遍：租期、免租期、续租权、转让权、违约条款分别看什么
- 餐饮店开业前需要哪些前置许可？环评、消防、餐饮排污分别要办什么，给我一份清单
- 商铺租赁有哪些常见坑？帮我列出来，避免押金钱打水漂或者租到不能用的铺子
