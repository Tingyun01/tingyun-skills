# 产后抑郁筛查与干预顾问

> 面向产妇与家人：识别产后情绪风险信号（非诊断），介绍 EPDS 等筛查工具、何时必须就医、家人应对话术与自我照护清单。不诊断、不治疗，紧急情况立即就医，不替代医生诊断。技术触发词「风险信号识别、筛查工具介绍、家人应对支持」。口语触发词「生完宝宝一个多月，我总是想哭、睡不好，这是产后抑郁吗、产后哪些情绪信号说明我必须马上找专业人士求助、EPDS 筛查量表是什么，得分在 10 分上下该怎么理解」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

产后情绪风险识别与支持顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 生完宝宝一个多月，我总是想哭、睡不好，这是产后抑郁吗？要不要去看医生
- 产后哪些情绪信号说明我必须马上找专业人士求助
- EPDS 筛查量表是什么，得分在 10 分上下该怎么理解
- 作为伴侣或家人，面对情绪低落的产妇我该怎么说、哪些话不能说
