# 常见失败模式、沟通话术与方案自检清单

---

## 一、常见失败模式对照

### 1.1 方案设计层面的 10 个坑

| # | 失败模式 | 表现 | 根因 | 修法 |
|---|---|---|---|---|
| 1 | 只分钱不分权 | 只约定分红，没有增值与退出路径 | 把股权激励做成了延迟发奖金 | 补齐增值权、转让与回购安排 |
| 2 | 没有回购条款 | 离职后股份悬空，无人受让 | 只想着授予，没想退场 | 三条线（离职/未达标/变更）都写条款 |
| 3 | 激励池没预留 | 融资后才发现无可授予额度 | 只统计已授予，忽略预留 | 按"目标总额 − 已授予 − 已预留"计算 |
| 4 | 定价与外部估值脱节 | 授予价远低于同轮融资价 | 为省事按面值给 | 用融资价或评估值为锚并留依据材料 |
| 5 | 全员同一份 | 同价格、同节奏、同额度 | 用一套模板覆盖所有层级 | 分层 + 系数 + 封顶 |
| 6 | 业绩指标脱节 | 指标与真实业务无关，员工判定"定不到" | 从同行模板照抄 | 指标 ≤3 个，写清数据来源方 |
| 7 | 只讲上市不讲现金路径 | 沟通里反复提上市时间表 | 内部缺少退出路径设计 | 补上退出路径再谈预期 |
| 8 | 授予与登记未闭环 | 协议签了、股东名册与工商没做 | 流程无归口 | 指定专人负责登记与留痕 |
| 9 | 拿虚拟股绑关键人 | 关键人只有收益权、无股东身份 | 为省登记成本 | 核心层必须给到实股或干股 |
| 10 | 离职回购无人出资 | 条款存在但没人付钱 | 只写义务不写履行机制 | 明确受让主体、出资时点、逾期处理 |

### 1.2 治理层面的 3 个隐藏代价

- **创始人表决权稀释**：直接持股给到 30% 以上人数后，创始人可能在下一次股东会上失去决议控制。用持股平台 + 表决权委托可缓解，但需在设立时就说清。
- **未来融资的谈判成本**：投资人看 fully diluted 口径，池子占比高会直接压低创始人持股比例与后续估值谈判空间。
- **上市前的核查工作量**：员工持股计划需要穿透核查、披露人员构成、离职处理、股份锁定安排，方案设计时就要预留材料，临时补做成本极高。

## 二、员工沟通与预期管理

### 2.1 四步沟通结构

```
第 1 步 讲本质：股权不是工资，是一份带条件的风险资产
第 2 步 讲条件：什么情况下拿到什么（归属条件写清楚，不模糊）
第 3 步 讲情景：保守 / 中性 / 乐观三档可能价值区间，不给单一数字
第 4 步 讲路径：怎么变成钱（公司回购、股东受让、上市后流通）以及时间尺度
```

### 2.2 可直接用的表达方式

| 场景 | 可以这样说 | 不要这样说 |
|---|---|---|
| 解释激励价值 | "这笔股权的价值取决于公司未来的每股价值，你出的力是其中一个变量。" | "跟着我干，三年肯定上市。" |
| 讲归属条件 | "满 12 个月且完成 X 指标，这部分归属；没完成就不归属，条款在这里。" | "反正早晚是你的。" |
| 讲退出路径 | "上市是其中一条路，另外还有公司回购和股东受让两条，具体看这份协议第几条。" | "以后上市了你就发财了。" |
| 讲不确定性 | "我给你三档情景，你看哪一档是你能接受的。" | "这个肯定能行。" |
| 讲分层差异 | "分层标准是岗位不可替代性和对交付结果的责任，写在这里，谁来都能核。" | "没办法，公司就这么定。" |
| 谈离职回购 | "规则是先定好的，对谁都一样，所以不用为公司担心，也不用担心我临时改口。" | "你走了股份就作废了。" |
| 回应"什么时候变现" | "现在没有时间表，我不会给你一个不存在的日期。协议里写的是条件。" | "明年融资完就差不多了。" |

### 2.3 三个不该说的承诺

1. **上市时间承诺**：上市取决于监管审核、业绩与市场环境，不可控。
2. **回购价格承诺**：回购价通常按公式或公允价值确定，承诺具体数字等于替公司背风险。
3. **保底收益承诺**：股权本身不承诺收益，承诺保底会改变整个方案的税务与法律性质。

### 2.4 沟通时机与对象

| 时机 | 对象 | 目标 |
|---|---|---|
| 方案定稿前 | 核心层 3~5 人（私下） | 先听意见，避免上线后返工 |
| 正式宣布 | 全员 | 统一口径，讲机制不讲个案 |
| 授予时 | 每人单独 | 逐条讲归属条件与到手动作 |
| 每个归属节点 | 归属人 | 确认归属事实与后续操作 |
| 离职发生时 | 离职人 | 按规则执行，把话说清，避免委屈外溢 |

## 三、方案自检清单

### 3.1 战略与工具

- [ ] 激励目的是留人、绑业绩还是换团队结构，写在方案开头
- [ ] 所选工具与公司阶段匹配（对照阶段适配矩阵）
- [ ] 工具形态向员工解释过（拿到的是股权、权利还是收益权）
- [ ] 虚拟股、期权、实股的口径在内部没有混用

### 3.2 额度与稀释

- [ ] 激励池目标稀释比例已确定，并写入方案
- [ ] 池子预留已扣除已授予与已预留
- [ ] 分层标准写成可核验条款
- [ ] 单人与单层额度有封顶
- [ ] 未来 12~18 个月招聘计划与池子覆盖做过对照
- [ ] 创始人持股稀释后仍在控制范围内

### 3.3 授予、归属与定价

- [ ] 归属方式（时间轨）与节奏已定
- [ ] cliff 长度与业务周期匹配
- [ ] 业绩指标 ≤3 个，定义、数据来源方、考核周期完整
- [ ] 授予价格与行权价口径已确定，依据材料留存
- [ ] 授予与归属的工商/登记动作有归口负责人
- [ ] 与融资协议中的股权条款没有冲突

### 3.4 退出与变更

- [ ] 主动离职与非主动离职分别有条款
- [ ] 回购价格口径与支付期限明确
- [ ] 回购资金来源与受让主体明确
- [ ] 已评估回购是否涉及减资程序
- [ ] 业绩未达只处理未归属份额，未混入"回购已归属份额"
- [ ] 控制权变更的加速归属或结算方式已定
- [ ] 死亡、伤残、退休、违规情形有对应条款

### 3.5 合规与沟通

- [ ] 税务路径与备案要求已由税务师确认
- [ ] 会计处理（股份支付费用、递延所得税）已由会计师确认
- [ ] 公积金、章程、股东协议相关事项已由公司法律师确认
- [ ] 员工沟通口径与协议条款逐条对齐
- [ ] 未作出上市时间、回购价格、保底收益三类承诺
- [ ] 授予仪式与后续沟通节奏已排入日程

### 3.6 红项判定（出现任意一项就不建议上线）

- 授予价格与同轮外部估值差距大到无法用一句理由解释
- 回购条款存在但无出资方与受让方
- 池子预留为零或未扣除已授予部分
- 关键人拿的是虚拟股
- 业绩指标公司自己都说不清口径
- 与融资协议的股权条款直接冲突
