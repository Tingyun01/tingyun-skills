# 激励工具形态对比与定价口径选择

适用于非上市公司（含未上市股份公司）的股权激励与员工持股方案设计。上市公司另有披露与审核口径，需单独处理。

---

## 一、四种工具的形态对比

### 1.1 形态对照表

| 维度 | 股票期权 | 限制性股票 | 干股 | 虚拟股 |
|---|---|---|---|---|
| 法律实质 | 远期购买权（权利） | 已归属但受限的股份（所有权） | 无偿/低价赠与的股份（所有权） | 合同约定的收益权（债权性质） |
| 员工是否出资 | 行权时出资 | 授予时通常出资或由公司代持 | 一般无需出资 | 无需出资 |
| 是否工商登记 | 行权后需登记 | 需登记 | 需登记 | 不涉及 |
| 股东身份 | 行权后取得 | 授予后登记即为股东 | 登记即为股东 | 始终不是股东 |
| 表决权 / 知情权 | 行权后按持股比例 | 按持股比例 | 按持股比例 | 通常无 |
| 分红权 | 行权后有 | 有 | 有 | 可约定有 |
| 转让与退出 | 靠公司或他人受让 | 靠公司或他人受让 | 靠公司或他人受让 | 离职即自动失效 |
| 员工离职时 | 权利失效（未行权） | 未归属份额被回购/作废 | 按协议处理 | 直接失效 |
| 激励强度 | 中高 | 高 | 高（真实股东） | 中低 |
| 公司现金压力 | 行权时收到行权款 | 授予时可能需垫资 | 零 | 视方案而定 |
| 会计与税务复杂度 | 中 | 高（需确认费用与递延所得税） | 高 | 中（通常按工资薪金处理） |

### 1.2 阶段适配矩阵

| 公司阶段 | 主推工具 | 原因 | 要避开的事 |
|---|---|---|---|
| 种子期 / 尚无产品 | 虚拟股 + 干股 | 现金紧张、估值不确定，股权登记成本高 | 大范围限制性股票（形成费用压力且难回购） |
| 天使至 A 轮，团队 10~40 人 | 股票期权为主，核心给限制性股票 | 期权把估值风险留给双方，行权价远期确定 | 授予价格定得过低，丧失价格约束 |
| B 轮及以后，计划上市 | 限制性股票 + 持股平台间接持股 | 权属清晰、便于穿透核查与离职处理 | 口径不一的"口头干股" |
| 存量企业，现金流稳定 | 限制性股票 + 虚拟股普惠 | 让员工看到长期收益，同时不冲击股权结构 | 池子不预留，靠下轮融资临时稀释 |
| 拟引进合伙人/关键人 | 干股或实股直接赠与 | 绑定强度高，进入决策层 | 用虚拟股绑关键人 |

### 1.3 直接持股 vs 持股平台间接持股

| 对比项 | 直接持股（员工是公司股东） | 有限合伙持股平台间接持股 |
|---|---|---|
| 股东名册 | 人数多，工商变更频繁 | 平台是登记在册的股东，工商变更少 |
| 控制权 | 分散后创始人表决权被稀释 | 创始人担任普通合伙人掌握执行事务权 |
| 离职处理 | 每次需工商变更 | 平台内部份额转让，流程轻 |
| 员工认知 | "我是股东"，归属感强 | "我是平台合伙人"，需要解释 |
| 核查要求 | 每次授予都需穿透核查 | 平台内份额变动仍需留痕 |
| 适合 | 核心层少量授予 | 中大规模普惠覆盖 |

设计要点：普通合伙人（GP）由创始人或核心方担任；有限合伙人（LP）为激励对象；平台合伙协议中必须写明份额转让、离职回购、表决委托三个条款，否则平台会变成一团乱麻。

## 二、定价口径选择

### 2.1 常用口径

| 口径 | 计算方式 | 适用 | 局限 |
|---|---|---|---|
| 每股净资产 | 净资产 ÷ 总股本 | 轻资产、重人力、早期公司 | 无形资产与团队价值未体现，普遍偏低 |
| 融资轮价格 | 本轮每股认购价 | 刚完成融资、有真实外部定价 | 只有一轮锚点，之后估值变化需重新评估 |
| 收益法 | 未来现金流折现 | 业务模式稳定、收入可预测 | 对增长率假设极敏感 |
| 市场法 | 参考同类交易倍数 | 行业可比样本充足 | 样本选取偏差大 |
| 资产基础法 | 各项资产重估加总 | 资产型、重资产 | 不适合人力驱动的轻资产公司 |

### 2.2 折让区间参考

| 层级 | 常见折让方向 | 说明 |
|---|---|---|
| 核心层 | 折让幅度较小 | 已是内部人，价值主要来自未来增长 |
| 骨干层 | 适度折让 | 用价格让渡换取长期承诺 |
| 普通层 | 折让较小或按面值 | 普惠性质，避免与市场估值差距过大 |

定价红线：**授予价格与同期外部可观察估值差距过大时，后续会同时触发税务评估关注与上市前审核关注**。方案设计阶段就要把这个差距控制在合理可解释范围内，并保留定价依据材料（估值报告、董事会决议、融资文件）。

### 2.3 每股权利价值的通俗算法

给员工讲的时候用这个口径讲，不要用"股价"讲：

```
员工这笔股权的价值 = 未来可能拿到的股数 × 未来退出时的每股价格 − 本人出资 − 行权成本
```

三个变量里，员工能控制的只有"努力程度"和"留多久"，另两个都不确定。把这个不确定性讲明白，比讲"公司做成了你就有钱"更负责任。

## 三、激励池预留口径

```
可授予额度 = 目标总稀释比例 − 已授予未行权部分 − 已预留未授予部分 − 其他已承诺部分
```

常见坑：只统计"已授予"，忽略"已预留"。判断标准是——**下一轮融资时如果外部投资人要求按 fully diluted 口径计算，你手上的池子是否还能覆盖两年内的核心团队需求**。覆盖不足时的处理顺序：先压缩普通层额度，再拉长授予节奏与归属期（同样金额、同样稀释、留住更久），把稀释压力放到下一轮再谈，而不是现在就动创始人的比例。
