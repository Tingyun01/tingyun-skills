# 失能等级与照护等级判定关系

> 本页解释两个等级的区别与常见误解。评估结论由评估专业人员作出，本页只做理解层面的梳理，不替代评估。

## 一、两个等级，一句话分清

- **失能等级**：回答"这个人的身体功能受损到哪一档"。它由统一标准下的评估产生，作用是**决定能不能进入待遇范围、待遇档次如何**。
- **照护等级**：回答"这个人在日常生活上需要多少照护"。它结合失能状态与实际照护需求确定，作用是**决定给什么服务、居家还是机构、频次多高**。

一个是入口门槛，一个是服务内容的匹配依据。**门槛没到，什么都谈不上；门槛到了，服务多少还要看照护需求。**

## 二、对比表

| 维度 | 失能等级 | 照护等级 |
|---|---|---|
| 判定主体 | 评估机构按统一评估标准作出 | 结合评估结论与照护需求，由服务安排环节确定 |
| 判定依据 | 功能受损状况（意识、进食、穿衣、如厕、行走、控制等维度） | 失能等级 + 日常生活困难项 + 居住与照护条件 |
| 输出的作用 | 待遇资格与档次 | 服务形式、强度、频次 |
| 是否可调整 | 随病程变化可复评 | 随照护安排变化可调整 |
| 家属常见误解 | "能坐轮椅就算失能" | "等级越高家里花得越少" |

## 三、失能判定常用维度（帮助家属理解材料该围绕什么准备）

各地标准在维度和权重上会有差异，但大体围绕这几类功能展开：

| 维度 | 看什么 | 材料上对应什么 |
|---|---|---|
| 意识与认知 | 意识清醒程度、能否理解与配合、认知状况 | 诊断记录、认知评估记录、家属说明 |
| 进食 | 能否自主进食、需否协助、吞咽情况 | 营养科或相关科室记录、住院营养支持记录 |
| 穿衣与沐浴 | 能否独立完成、需多少协助 | 功能评定、护理记录 |
| 如厕与排泄 | 能否控制、有无失禁、需否协助 | 诊断与护理记录 |
| 移动与转移 | 能否行走、翻身、上下床、是否需两人协助 | 康复记录、辅助器具使用情况 |
| 皮肤与压疮 | 有无压疮风险、护理需求 | 护理记录 |

### 由此推出的材料准备原则

1. **围绕功能写，不围绕诊断写**。评估看的是"这个人现在能做什么、做不到什么"，不是"他得了什么病"。诊断证明是佐证，护理与功能记录才是主线。
2. **记录越具体越有用**。"生活不能自理"是结论，"进食需他人协助、翻身需两人、肛门失禁、不能自行如厕"是事实。评估人员看的是后者。
3. **时间线要连续**。能体现"从能走到现在不能走"的病程记录，比孤立的某次结论更有说服力。
4. **家属说明要写日常场景**。谁在照料、每天怎么照料、哪些环节较吃力，是评估现场的重要补充。

## 四、被拒后的三种结果与应对

拿到书面结果后，先分清落在哪一类。

### 类型一：条件不符

**表现**：结论明确指出未达到当地认定的失能口径，或参保身份、缴费年限、年龄等条件不满足。

**应对**：
- 逐条比对结论中指出的具体差距，而不是笼统地觉得"肯定还有办法"
- 差距属于可补的（材料未交全、证明不完整）→ 补交后重新申请
- 差距属于客观条件的（当前失能程度确实未到门槛）→ 短期内难以改变，重点转向：随病程进展定期复评的条件、以及商业长护险等其他家庭保障安排
- 明确记录本轮结论的档位与差距，作为下一次申请的基线

### 类型二：材料不足

**表现**：结论指出材料不完整、证明不足或前后不一致。

**应对**：
- 按结论指出的具体缺口补，不要把全部材料重新做一遍
- 补正时重点解决一致性问题：诊断结论、病历描述、护理记录之间的功能描述要对得上
- 保留补正前后的材料版本，说明补充了什么
- 记住补正有时限，错过可能需要重新排队

### 类型三：评估争议

**表现**：对功能状态的判定与家属实际情况不符，例如家属描述能部分完成的事项被判定为完全不能完成。

**应对**：
- 优先走复核或复评渠道，按当地规定的时限提出
- 复核材料以"补充功能证据"为主：护理机构的照护记录、康复治疗记录、带时间标注的日常影像说明、第三方照护人员的书面说明
- 准备一份清晰的事实陈述：什么时候、由谁、怎么照护的，具体到动作
- 复核结论仍不认同时，向当地主管部门了解进一步渠道；涉及权益主张的，请咨询执业律师

## 五、复核与再申请的动作清单

```
第 1 步 取到书面结论      → 看清理由与依据，分清属于哪一类
第 2 步 记录关键点        → 结论档位、差距项、时限、可否复评
第 3 步 补齐或补强材料    → 按缺口清单补，按一致性要求重整
第 4 步 通过规定渠道提交  → 走复核/复评或重新申请，注意时限
第 5 步 等待结论并跟进    → 保留全部提交凭证
第 6 步 无论通过与否      → 更新家庭档案，记下新结论与下次复评时间
```

## 六、易混淆点速查

| 说法 | 澄清 |
|---|---|
| 失能等级越高越好 | 等级决定待遇范围，不是越高越有利；要与实际照护需求匹配 |
| 家里有人照顾就不用申请 | 家属照护是负担来源，不是不需要服务的理由 |
| 商业长护险赔付了就不申请社保 | 两条路径独立，商业赔付不产生社保资格，也不占用社保申请 |
| 一次评估定终身 | 多数情形会有定期复评，随状态变化调整 |
| 社区能开的证明都能用 | 材料种类与出具主体有明确要求，需按当地清单确认 |
