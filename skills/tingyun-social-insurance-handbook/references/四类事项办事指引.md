# 四类高频事项完整办事指引

> 本文件是 `SKILL.md` 第四节的展开版：全国通用逻辑 + 材料规格细节 + 白跑警示。
> **政策有时效，办理前请以参保地最新公告为准；是否受理、是否符合条件以参保地经办机构为准。**
> 本文不提供任何待遇金额测算，也不替代经办机构审核。

---

## 一、异地就医备案

### 适用范围

- 跨省长期居住人员：异地安置退休人员、异地长期居住人员、常驻异地工作人员（派驻、长期驻外工作生活）。
- 跨省临时外出就医人员：异地转诊就医人员、因工作或旅游等原因异地急诊抢救人员、其他跨省临时外出就医人员。
- 参保类型：职工基本医疗保险、城乡居民基本医疗保险均可办理。

### 不适用范围

- 省内异地就医是否需要备案，由各省自行规定，**本指引不覆盖省内规则**。
- 普通门诊统筹、定点药店购药、特药门诊等情形是否需要备案，各省规定不一。
- 本指引不处理住院费用报销比例、起付线、封顶线等**待遇标准**问题。

### 材料清单表

| 材料 | 具体规格 | 常见问题 | 备注 |
| --- | --- | --- | --- |
| 身份证 | 有效身份证件原件；线上可用医保电子凭证或已激活的社保卡替代 | 只带复印件、证件已过期、身份证与医保账户信息不一致 | 线上办理可直接调取信息，通常无需上传 |
| 医保电子凭证 / 社会保障卡 | 已激活状态，3.0 版社保卡需可正常使用 | 社保卡未激活、状态异常 | 就医结算时同样要用它 |
| 居住证（长期居住类） | **公安部门制式居住证**，含电子版；已申请尚未领取的可提交受理凭证 | 社区、村委会、乡镇街道开的居住证明、流动人口登记凭证、就医地房产证**均不作为**认定材料 | 这是最高频的退回原因 |
| 户口簿（长期居住类） | 迁入就医地的户口簿首页与本人常住人口登记卡 | 只带首页、户主页不同框 | 与居住证二选一 |
| 异地工作劳动合同 / 单位派出凭证（常驻异地类） | 需能体现姓名、身份证号、派驻地、派驻时间、单位名称与公章等要素 | 只带内部派遣单无公章 | 格式不作强制要求 |
| 转诊转院材料（转诊类） | 参保地具有转诊资质的定点医疗机构开具的转诊转院单 | 社区医院、药店开的转诊单无效 | 一般要求二级及以上定点医院 |
| 承诺书（承诺制办理时） | 《异地长期居住人员备案个人承诺书》 | 勾选承诺后忘记补齐材料 | **次日起 30 日内必须一次性补齐**，逾期备案失效且今后不再享受承诺制备案服务 |

### 办理流程

**线上（推荐）**

1. 打开国家医保服务平台 APP / 国家异地就医备案小程序 / 国务院客户端小程序，或地方平台（皖事通、随申办市民云、南京医保等）。
2. 选择"异地就医备案" → 选择备案类型（长期居住 / 临时外出）。
3. 填写参保人信息、就医地市（备案到就医地市，不是具体医院）。
4. 上传认定材料，或在符合条件时勾选个人承诺书。
5. 提交后查询备案状态与生效日期。

**线下**

1. 到参保地医保经办窗口（或社区事务受理服务中心）取号。
2. 提交身份证件 + 对应情形材料 + 《异地就医登记备案表》（窗口提供）。
3. 窗口核验后当场办结或受理后反馈。

**步骤要点**

- 先定**备案类型**，类型决定要交什么材料；类型选错等于白跑。
- 长期居住类如果材料暂时拿不出，**先做承诺制备案保待遇**，同时记住补材截止日。
- 备案生效后要在备案地使用，直接结算需选择**跨省联网定点**医疗机构。

### 办理时长参考

| 情形 | 参考时长 |
| --- | --- |
| 线上提交 | 系统自动审核，即时或 1—2 个工作日内生效 |
| 线下窗口 | 材料齐全当场办结 |
| 承诺制备案 | 提交后即时或当日生效，但有效期短，须在限期内补齐 |

### 白跑警示

1. **承诺制备案次日起 30 日内未一次性补齐有效认定材料，本次备案失效，且今后不再享受承诺制备案服务。** 期间已发生的异地住院或门诊慢特病医保结算可能被纳入医保信用评价；部分地区还可能全额追回承诺期内发生的异地就医结算资金。这是本事项最贵的坑。
2. 居住证明规格不符：居住证必须是公安部门制式居住证，社区、街道、村的居住证明、就医地房产证都不认。
3. 备案对象错位：备案到"就医地市"，不是具体医院；跨省门诊结算时未选跨省联网定点机构。
4. 长期居住类未提供居住证明就选临时外出类型，待遇与报销口径会明显不同。
5. 承诺制签了又撤不掉，即使最终没发生结算，承诺制资格也已用掉。

### 时间节点

| 节点 | 内容 | 逻辑说明 |
| --- | --- | --- |
| 承诺制补材截止日 | 备案申请提交**次日起 30 日内**一次性补齐 | 逾期失效且失信，**这是硬红线** |
| 长期居住类备案有效期 | 各地不同：一次备案长期有效，或 2 年 / 1 年等；以参保地公布为准 | 到期前需确认是否需续办或变更 |
| 临时外出类备案有效期 | 各地不同：6 个月 / 12 个月 / 1 年等；以参保地公布为准 | 有效期内可在就医地多次就诊 |
| 补办备案 | 跨省出院结算前可补办备案并直接结算；已自费出院的，补办后可按参保地规定申请手工报销 | 补办开始日期能否往前追溯，各省规则不同 |
| 承诺制失信后果 | 一定期限内不得再通过承诺方式备案，并纳入医保信用评价 | 影响后续所有备案操作 |

## 二、门诊慢特病认定

### 适用范围

- 已参保且**处于正常缴费状态**的职工基本医疗保险、城乡居民基本医疗保险参保人。
- 职工医保参保人可由单位代办，也可本人自办；居民医保参保人一般由本人或定点医疗机构协助办理。

### 不适用范围

- 处于断缴、欠费状态的参保人，一般无法提交认定或认定后资格中止。
- 已确诊但未达到参保地病种目录与认定标准的疾病。
- 本指引不涉及门慢特待遇的报销比例、起付线、年度限额。

### 材料清单表

| 材料 | 具体规格 | 常见问题 | 备注 |
| --- | --- | --- | --- |
| 医保电子凭证 / 身份证 / 社保卡 | 任选其一，需可正常读取参保信息 | 证件信息与参保信息不一致 | 线上提交可授权调取 |
| 疾病诊断材料 | 二级及以上定点医疗机构出具的出院小结、门诊病历、检验检查报告、病理报告等 | 社区诊所或非定点医院材料不认；缺页、缺关键页 | 需覆盖病种认定标准要求的全部要素 |
| 《门诊慢特病病种待遇认定申请表》 | 由有认定资质的主诊医师填写，并加盖医院医保主管部门印章 | 医师漏签名、医院漏盖章、跨院材料未附表 | 申请表由医院医保办或窗口领取 |
| 近期复查资料 | 部分病种需近 3 个月内的检查报告 | 检查报告超时效被退回 | 是否需要以参保地认定标准为准 |

### 办理流程

**线上**

1. 国家医保服务平台 APP 搜索"门诊慢特病待遇认定"（或地方医保 APP / 小程序对应入口）。
2. 登录并选择要认定的病种。
3. 上传病历材料扫描件与认定申请表。
4. 提交，等待审核结果。

**线下 / 委托医院**

1. 先到二级及以上定点医院就诊，取得完整诊断材料。
2. 由主诊医师填写《门诊慢特病病种待遇认定申请表》并加盖医院医保部门印章。
3. 到参保地医保经办窗口递交，或交由定点医疗机构代为申报。
4. 定点医疗机构鉴定后由医院上传，经办机构审核后备案。

**步骤要点**

- **顺序错就是白跑**：没有医院的诊断材料，申请表拿不到；没有盖章的申请表，病历再全也退回。
- 先确认参保地病种目录是否包含你要认定的病种，再准备材料。

### 办理时长参考

| 情形 | 参考时长 |
| --- | --- |
| 材料齐全、线上提交 | 1 个工作日内办结，部分地区当场办结 |
| 委托定点医院鉴定 | 由医院院内鉴定后上传，经办机构审核 |
| 普通病种（部分地区） | 不超过 20 个工作日 |
| 重症病种绿色通道（部分地区） | 不超过 7 个工作日 |

### 白跑警示

1. **认定前已结算的费用通常不能按慢特病待遇追溯报销**，只能按普通门诊政策处理。先认定、再开药是唯一稳妥顺序。
2. 社区诊所、乡村卫生室、非定点医院的材料一律不认。
3. 诊断证明缺医师签名或医院公章、检查报告超时效、门诊病历未写明分期与治疗方案，都会导致退回。
4. 断缴期间资格可能中止甚至作废，缴费中断前应先确认状态。
5. 病种不在参保地目录内时，材料准备得再齐也办不了，应先核对目录。

### 时间节点

| 节点 | 内容 | 逻辑说明 |
| --- | --- | --- |
| 国家统一目录 | 2026 年 4 月 1 日起执行 62 种基础目录（33 种慢性病 + 29 种特殊疾病） | 各地可增补，**是否扩目录以参保地公布为准** |
| 省级执行口径 | 江苏按苏医保发〔2022〕46号执行全省统一门特范围并允许市级原有病种保留；安徽执行全省统一目录、各统筹区不得自行新增 | 省级统筹、地市执行的差异来源 |
| 资格有效期 | 各地 1—2 年不等，个别病种与地市另有约定 | 到期前需办理续办，否则待遇中断 |
| 续办窗口 | 各地一般要求到期前提前提交复查材料 | 具体天数以参保地公布为准 |
| 断缴影响 | 断缴期间慢特病资格可能中止 | 重新参产后可能需要重新认定 |

## 三、住房公积金提取

### 适用范围

- 在职职工本人提取。
- 离休、退休；完全丧失劳动能力并与单位终止劳动关系；出境定居：这三种情形提取时可以**同时注销住房公积金账户**。
- 单位可以代办，但需要单位证明与本人授权。

### 不适用范围

- 本指引不提供任何**提取额度上限**测算。额度规则各地差异极大且调整频繁，须查本地公积金中心最新公告。
- 不处理公积金贷款、组合贷、商转公等业务。
- 不处理账户封存、销户、转移接续等专项业务。

### 材料清单表

| 材料 | 具体规格 | 常见问题 | 备注 |
| --- | --- | --- | --- |
| 身份证 | 本人有效身份证件原件 | 代办未带双方证件 | 单位代办需同时提供代办人身份证 |
| 社保卡 / 本人名下银行账户 | 用于资金划转 | 银行卡非本人名下或已销户 | 需与账户预留信息一致 |
| 租房提取材料 | 住房证明（无房证明 / 房屋租赁合同等） | 租赁合同过期、无房证明口径不符、合同主体非本人 | 2026-09-20 起国家层面取消"房租超出家庭工资收入规定比例"门槛，但**各地提取方式与额度口径仍不同** |
| 购房提取材料 | 不动产权证书或购房合同、付款凭证 | 只带合同未带付款凭证、房屋为共有未带共有人材料 | 具体件数以参保地要求为准 |
| 装修提取材料 | 装修合同、装修费用发票等 | 发票抬头非本人、装修合同缺失 | 2026-09-20 起新增情形，各细则未齐备 |
| 物业费提取材料 | 房屋权属证明、物业费缴费凭证 | 缴费票据与房屋不对应 | 2026-09-20 起新增情形，各细则未齐备 |
| 单位代办材料 | 单位证明、本人授权书 | 缺公章、缺委托书 | 各地形式要求不同 |
| 退休 / 丧失劳动能力 / 出境定居证明 | 相应证明文件 | 证明未加盖有效印章 | 这三种情形可同时注销账户 |

### 办理流程

1. **先定提取情形**：支付房租、购买/建造/翻建/大修自住住房、偿还购房贷款本息、装修自住住房、支付自住住房物业费、离休退休、完全丧失劳动能力并与单位终止劳动关系、出境定居，以及国务院批准的其他住房消费情形。共 9 类。
2. **按情形备齐对应证明**（见上表）。
3. 线上提交（住房公积金网上业务办理平台、随申办市民云公积金专区、当地住建部门线上平台）或线下到公积金中心窗口 / 受委托银行递交。
4. 受理后按法定时限作出准予或不准提取决定；准予提取的，由受委托银行办理支付手续。

### 办理时长参考

| 环节 | 时限 |
| --- | --- |
| 提取决定 | 自受理申请之日起 **3 日内**作出准予或不准提取决定并通知申请人（国务院令第 844 号修改后第二十五条） |
| 银行支付 | 由受委托银行办理支付手续，具体到账时间以银行为准 |
| 贷款审查 | 自受理申请之日起 **10 日内**作出准予贷款或不准贷款决定（供参考） |

### 白跑警示

1. **拿错提取情形的材料**：用租房合同去办购房提取、拿购房材料去办装修提取，窗口无法受理。
2. **证明不在有效期内**：租赁合同过期、无房证明口径与本地不符、发票超过有效期，直接退回。
3. **同一用途重复提取被认定为骗提**：国务院令第 844 号第四十一条规定，以欺诈、伪造证明材料等方式违法提取的，责令限期退回违法提取的住房公积金，**3 年内不得提取住房公积金或者使用住房公积金贷款**；违法获得住房公积金贷款的，**5 年内**不得提取或贷款。跨年度重复报销同一笔装修、物业费支出是最常见的踩雷点。
4. 装修、物业费提取是 2026-09-20 新增情形，**各地细则尚未齐备**，办理前务必先查本地公积金中心最新公告。

### 时间节点

| 节点 | 内容 | 逻辑说明 |
| --- | --- | --- |
| 新条例施行日 | 2026 年 9 月 20 日（国务院令第 844 号，2026 年 8 月 10 日公布） | 提取情形由 6 种扩至 9 种；新增装修自住住房、支付自住住房物业费、国务院批准的其他住房消费情形 |
| 租房门槛取消 | 取消"房租超出家庭工资收入规定比例"的限制 | 改为"支付房租的"，但各地方式与额度不同 |
| 灵活就业人员可缴存 | 同令第四十九条：个体工商户、非全日制从业人员及其他灵活就业人员可以自愿缴存住房公积金 | **具体办法由设区的市级以上地方人民政府制定**，落地进度各地不一 |
| 提取决定时限 | 受理后 3 日内 | 决定作出后由受委托银行支付 |
| 骗提骗贷惩戒期 | 违法提取 3 年 / 违法贷款 5 年 | 信用记录纳入全国信用信息共享平台 |
| 年度额度与连续提取规则 | 各地不同，部分城市按年度或按次设限 | 须以参保地公积金中心公告为准 |

## 四、灵活就业参保与断缴补缴

### 适用范围

- 年满 16 周岁且未达到法定退休年龄、在本地劳动就业的自雇人员、无雇工个体工商户、未在用人单位参加职工养老和医疗保险的非全日制从业人员及其他灵活就业人员。
- 各地参保范围与材料要求略有差异，例如上海明确涵盖本市户籍、外省市户籍、港澳台居民、取得在华永久居留资格的外国人，以及农民专业合作社（联合社）和家庭农场从业人员。

### 不适用范围

- 与用人单位存在劳动关系的人员，应由单位办理参保，不走灵活就业渠道。
- 城乡居民基本养老保险（居民养老）与职工养老保险是两套制度，本指引只讲职工养老 + 职工医保。
- 不提供缴费年限是否够退休的测算结论。

### 材料清单表

| 材料 | 具体规格 | 常见问题 | 备注 |
| --- | --- | --- | --- |
| 身份证 | 本人有效身份证件原件 | 线上人脸识别失败、证件过期 | 线上办理需实名认证 |
| 居住证 / 居住登记材料 | 非本地户籍人员通常需要 | 未办居住证或已过期 | 各城市要求不同 |
| 就业登记信息 | 部分省份要求"先就业登记、再办参保"（江苏等地） | 直接跳到参保环节被退 | 就业登记常在社区事务受理中心或线上人社平台办 |
| 缴费档次选择记录 | 在税务端选档后按月缴 | 未选档、选档后长期不缴 | 选档在税务渠道完成 |
| 银行代扣协议（如用） | 与经办银行签订 | 卡内余额不足导致扣款失败 | 建议开通代扣并保持余额 |

### 办理流程

1. **就业登记**（部分省份为强制前置）：线上通过地方人社 APP 或小程序，线下到街道/社区人社窗口。
2. **灵活就业参保登记**：地方人社 / 医保 APP、"灵活就业一件事"专区、线下社区事务受理中心 / 街道人社窗口。
3. **选档缴费**：参保登记信息同步到税务后，在税务渠道（线上缴费小程序、办税服务厅、税银经办银行柜面）选择缴费档次按月缴纳。
4. **关注缴款状态**：避免扣款失败导致断缴。
5. 医保待遇起算按参保地规则执行，等待期长短差异很大。

### 白跑警示

1. **把"断缴了能不能补缴"当成能补**——国家层面明确城镇个体工商户和灵活就业人员**不得以事后追补缴费的方式增加缴费年限**。上海按《关于灵活就业人员参加本市职工基本养老、职工基本医疗保险有关问题的通知》（沪人社规〔2023〕5号）明确灵活就业人员实行按月缴费、不得以事后追补缴费的方式增加缴费年限；江苏自 2019 年 12 月起停止办理灵活就业跨年度补缴业务。把补缴当成"单位应缴未缴"的情形去申请，主体不对，一定会被驳回。
2. **待遇起算误解**：安徽规定灵活就业人员首次参加职工医保，连续缴费满 3 个月的次月享受待遇；中断缴费超过 3 个月重新参保的，需连续缴费满 3 个月后次月享受待遇。中断期间的医疗费用按规定处理。误以为"交上一个月就能报销"是最常见的预期落差。
3. **未做就业登记直接参保**（江苏等省份要求先登记），或跳过参保登记直接去税务缴费，导致无法生成参保信息、缴款失败。
4. **代扣失败未察觉**：绑定银行卡余额不足导致扣款失败，事后才发现断缴，补缴又不被允许，只能等下一个缴费周期。

## 五、四类事项的通用提醒

- **顺序原则**：先确认身份类型 → 再确认属地 → 再查属地数据 → 最后按顺序准备材料。
- **材料原则**：必带材料缺失会当场退回，按情况带材料要按自己的备案类型对应准备，建议带材料能降低退回风险但不强制。
- **时限原则**：承诺制补材、慢特病资格有效期、公积金提取决定时限、灵活就业缴费补差截止日，四类时限互不通用，逐项核对。
- **属地原则**：本文的全国通用部分可直接使用；凡涉及具体天数、金额上限、目录范围、渠道名称，一律以参保地最新公告为准。
