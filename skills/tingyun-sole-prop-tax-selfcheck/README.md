# tingyun-sole-prop-tax-selfcheck

> 逐项说明个体户年报与经营所得汇算的填报口径，填完自动跑十项风险自检，标出易被抽查的填法
>
> 面向个体工商户与小规模纳税人的年度报告与经营所得汇算填报自检助手。逐项讲清从业人数、资产总额、营业额、纳税额等字段的填报口径与常见填法，填完后自动跑十项提交前风险自检，标出最容易被抽查到的填法差异，输出异常名录预防清单与需要向税务机关确认的问题。

## 这个 Skill 做什么

把「个体户年报自检」这个场景最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

### 解决什么问题

官方免费给你的是**填报入口**，不是**填报答案**。自助年报页确实能自己填，熟练的话半小时能提交完，但它不会告诉你"资产总额按账面还是按估值""从业人数算不算我自己""零收入能不能不报"——这些才是被抽查出事的地方。

错填的代价是有层级的：

- **年报逾期**：未在规定期限报送年度报告的，由登记机关列入经营异常名录，可以处 1 万元以下罚款（《市场主体登记管理条例实施细则》第七十条；核对日期 2026-11-01，实际裁量多在千余元至数千元，以本级裁量基准为准）。

- **税务逾期申报另算一套**：未按期申报的，责令限期改正，可以处 2000 元以下罚款；情节严重的，可处 2000 元以上 1 万元以下罚款（《税收征收管理法》第六十二条）。这就是"2000 元以下 / 2000 至 1 万元"两档的真实出处，与年报罚则不同。

- **付费市场已定价**：个体户年报代报 200 至 300 元，小规模 300 至 500 元，一般纳税人 500 至 800 元，移出异常名录另加 300 至 800 元，乱账整理 500 至 2000 元每年。付费的正是"替你填对"。

- **公开案例很具体**：官方渠道自曝过一名做电商的客户自己报年报，把资产总额 50 万填成 500 万，被抽查发现。

## 怎么用

1. 安装到你的 agent（Claude Skills 目录 / 扣子技能商店）
2. 直接用日常说法提需求，例如：
   个体工商户年报要填什么
3. 它会追问关键信息（缺的信息会标〔待补〕，不会替你编）
4. 输出可直接用的清单 / 对照表 / 台账

## 输出

- 判断步骤与检查清单
- 对照表 / 台账
- 待办与需要人工核实的问题

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
