# 涉税信息报送准备与留痕举证清单

> 卖家侧准备清单。核心认知：平台报送是平台的义务，卖家要准备的是"能被随时调取的业务台账与证据资料"。

## 一、规定与税务口径的基本框架（背景，非结论）

- 《互联网平台企业涉税信息报送规定》（国务院令第 810 号）自 2025 年 6 月 20 日公布之日起施行。规定要求平台企业向主管税务机关报送平台内经营者和从业人员的身份信息、收入信息等涉税信息。
- 报送节奏：平台于季度终了的次月内报送身份信息与上季度收入信息；平台从事互联网经营业务之日起 30 日内报送平台域名、业务类型、统一社会信用代码及名称等基本信息。
- 报送渠道：电子税务局、数据接口直连、其他渠道。数据接口直连面向系统能力较强的平台，上传导入面向中小平台。
- 身份信息按"名称（姓名）＋统一社会信用代码（纳税人识别号）＋店铺（用户）名称＋店铺（用户）识别码"分多行填报——**同一经营者在同一平台开多个店铺，会被拆成多行报送**，这一点卖家自己要有数。
- 收入信息报送表包含收入总额、退款金额、收入净额、收入确认时间、交易（订单）数量等字段。其中交易数量按**净交易（订单）数量**统计，即当期结算的订单总数减去当期退单数量；同一笔订单包含一个店铺多件商品的按一笔计，一次性下单多个店铺多件商品的按分店铺生成的订单数量统计。
- 税务检查或发现税收风险时，税务机关可要求平台及相关方提供经营者的**合同订单、交易明细、资金账户、物流**等涉税信息。平台与相关方应按执法文书要求如实提供，不得以技术原因、账号限制、数据权限等理由拒绝或隐瞒。
- 平台核验义务履行到位后，因经营者或从业人员过错导致信息不真实、不准确、不完整的，不追究平台企业责任。

**卖家据此得到的推论**：平台把数报上去了，税务要往下核，先核的是"平台报的收入数"和"你申报的收入数"对不对得上。所以三账核对不是自查的加分项，是必答题。

## 二、卖家侧台账清单（五类，按可调取性排序）

### A. 订单台账（按订单逐笔）

必备字段：
- 订单号、店铺名称与店铺识别码、下单时间、发货时间、签收时间、退款时间与退款金额；
- 商品 SKU、数量、单价、金额、是否赠品/样品、是否搭赠；
- 物流公司、单号、发货重量；
- 订单状态（已完成/退款中/已退款/关闭）；
- 结算金额与结算周期。

留存要求：至少覆盖税务核查可能覆盖的年度，且能与申报记录勾稽。

### B. 收款台账（双轨：平台结算 + 银行到账）

- 平台结算单：区分**货款、平台佣金、服务费、运费与运费险、优惠券/补贴、活动奖励、退款扣回**；
- 银行流水：企业结算账户 + 实际用于收款的个人账户/收款码/第三方支付账户，逐笔标注对应订单号；
- 提现记录：平台余额 → 银行账户的每一笔转移；
- 账户清单：每个收款账户的开户主体、与店铺/申报主体的关系、绑定或授权关系说明。

遗留风险提示：**多主体共用一个收款账户**是高频问题。同一账户收多个主体的货款，会让订单台账与申报主体之间的对应关系断裂，核查时难以自证。

### C. 商品与实物台账

- SKU 对应的实物出库记录、库存变动；
- 赠品领用记录、样品出库记录、样品用途说明；
- 组合品/套装中的赠品标注。

### D. 主体与账户台账

- 各店铺的名称、店铺识别码、开设日期、经营类目；
- 申报主体：名称、统一社会信用代码、纳税人识别号、纳税人身份（一般/小规模）；
- 主体与店铺的归属关系（自有店铺、代运营店铺、代发模式下销售方身份）；
- 是否存在多主体经营、是否使用个人独资企业或个体工商户等不同组织形式。

### E. 供应商与代运营台账

- 供应商合同、采购订单、送货单、结算单；
- 付款记录与发票记录；
- 代运营合作协议、服务内容与结算方式、发票开具主体；
- 代发模式下的角色划分说明（谁对外销售、谁发货、开票主体是谁）。

## 三、留痕与举证资料目录

按"能否直接说明某个税务问题"组织，而非按业务类型组织：

| 举证目的 | 需要的资料 |
|---|---|
| 说明收入已完整申报 | 订单台账 + 申报表 + 发票记录（按月对应表） |
| 说明平台与申报差额属跨期 | 发货时间表、结算时间表、开票时间表三列对照 |
| 说明退款已冲减 | 售后退款明细与申报冲减记录对应表 |
| 说明商品已实际出库 | 物流单号 + 出库单 + 签收记录 |
| 说明赠品与样品处理 | 赠品/样品领用台账 + 成本凭证 |
| 说明补贴与佣金口径 | 平台结算单 + 科目对应说明 |
| 说明款项流向合规 | 收款账户清单 + 逐笔匹配表 + 账户主体关系说明 |
| 说明主体与实际经营一致 | 店铺清单 + 主体清单 + 归属关系表 |
| 说明供应商与代运营安排 | 合同 + 对账单 + 发票 + 付款记录 |

## 五、留痕的几条实操要求

- 台账用可导出的结构化格式（表格或系统导出），不要只留截图或聊天记录；
- 关键字段留可追溯来源：金额能追到订单号，订单号能追到物流单号；
- 修改留痕：确需更正的历史数据，保留更正前后的版本与更正原因说明，不要直接覆盖；
- 电子资料与纸质件的保存位置统一，建议做一份索引表，避免核查时找不到；
- 银行流水、平台账单的导出件保留原始格式，必要时可校验完整性；
- 沟通记录留书面（邮件、书面确认、系统工单），口头结论事后补一条书面确认。

## 六、什么情况下不要继续自查，转专业机构

出现下列任一情形，停止自行归因，直接转持证税务师或税务律师：
- 已收到《税务行政处罚事先告知书》或已被立案；
- 收到税务机关的税务检查通知书、检查证已出示；
- 涉及金额较大、跨多个年度、跨多个主体；
- 涉及主体拆分、隐匿收入等已被指向为涉嫌偷税的情形；
- 涉及跨境业务、出口退税、税收协定适用；
- 涉及自然人代开、核定征收适用争议；
- 拟注销主体且存续期内存在差异未了结。

**注销不消灭纳税义务**：主体注销只代表经营活动终止，存续期间产生的违法责任与纳税义务不因注销而自动消除。这一点在与代账机构沟通时经常被误解。
