# 绩效面谈与目标设定工具

> 沟通准备工具。绩效管理是管理动作，落到具体文书与程序时需专业复核。

## 一、面谈前的准备（15 分钟能做完）

| 检查项 | 通过标准 | 不通过怎么办 |
|---|---|---|
| 保护情形 | 已确认该员工不在医疗期、孕期产期哺乳期、工伤、职业病、本单位连续工作满十五年且距法定退休年龄不足五年等情形 | 命中任一项，停止推进该路径，转专业机构 |
| 标准来源 | 考核标准能指向具体出处（岗位说明书、目标书、制度条款），且员工事前已确认 | 缺出处 → 本次先做标准澄清，不做结论 |
| 事实材料 | 手上有具体的时间、事项、结果、数据，不是印象 | 无材料 → 取消结论式谈话，改成了解式面谈 |
| 制度状态 | 考核制度已履行民主程序并公示/告知，有留痕 | 无留痕 → 本次不谈结论，先补程序 |
| 资源准备 | 已想好要提供什么支持（培训、带教、权限、数据） | 没想好 → 面谈不要提"改进期"，先做辅导 |
| 自身状态 | 有时间、不赶场、不是在气头上 | 时间不够就改期，气头上不做绩效谈话 |

## 二、四段结构话术脚本

### 第 1 段：事实（开场即入正题，约 30%）

**开场三句式**：
> "今天这次谈是关于 [周期] 的绩效，我把事实和标准过一遍，也想听你的版本。你先说完，我再补充。"

> "我这边记到的几件具体的事：[日期]，[事项]，结果是 [结果]；[日期]，[事项]，结果是 [结果]。"

**要点**：
- 只说可核验的具体事：时间、动作、交付物、结果、数据；
- 一次讲 3~5 件，太多会变成举证堆砌，反而让人只盯着"你早就想动我"；
- 主动邀请对方陈述事实，这既是尊重，也让事实更完整。

**禁区**：
- 人格化评价（"你态度有问题""你不够上进""你总是不配合"）；
- 跨周期翻旧账（除非本次目标书本来就包含该周期）；
- 对比同事（"小李就比你做得好"）。

### 第 2 段：标准（约 20%）

> "判断的依据是 [目标书第 X 条 / 岗位说明书第 Y 项 / 制度第 Z 条]，你在 [日期] 确认过。当时约定的口径是 [ ]。"

**要点**：
- 把标准"念"出来并确认是事前约定的；
- 明确本次不新增标准：临时加的标准在争议中站不住；
- 若员工对标准有异议，当场记录但不放弃执行——异议处理与考核执行可以并存。

**常见难应对场景**：

| 员工说 | 不要这样答 | 建议这样答 |
|---|---|---|
| "标准太高了" | "我觉得不高" | "这个标准我们一起核一下：和同岗位 [ ] 的对比是 [ ]；你认为是哪一段偏高，我们记下来，必要时一起调整口径" |
| "我完成了，是别人拖累" | "那不是理由" | "我们先把你能控的部分列出来 [ ]；协作这部分我们另看，但你负责的部分是 [ ]" |
| "为什么别人没被谈" | "每个人情况不一样" | "别人的事不在这次范围。你这边我看到的差距是 [ ]，我们只谈这个" |
| "标准是临时改的" | "一直是这样" | "我核实一下，如果确实是期间调整的，我们把调整记录找出来一起看"（务必实际去核实） |

### 第 3 段：差距（约 20%）

> "差距是 [指标] 目标 [值]，实际 [值]，差 [幅度]。集中在 [时间/环节/客户/项目] 上。"

**要点**：
- 用数据或事实描述，不用形容词；
- 差距要落到"可改进的动作"上，而不是"能力不行"这种不可改的判断；
- 说清差距的性质：是结果没达成、时效、质量、协作，还是资源不足导致的。

**禁区**：
- 推断动机（"你就是不重视"）；
- 结论式定性（"你确实不胜任"）——这是管理者的判断，不该在面谈里作为结论抛给员工。

### 第 4 段：下一步（约 30%）

> "接下来 [周期] 我们要做三件事：一是 [指标] 做到 [目标值]，口径是 [ ]；二是 [具体行为/能力项]，公司这边会提供 [培训/带教/数据/权限]；三是 [日期] 我和你复盘一次，看 [用什么材料/数据] 评。"

**要点**：
- 三件事以内，多了执行不了；
- 目标可衡量：指标 / 口径 / 基线 / 时限 / 数据来源，五项齐全（见下节模板）；
- 支持写具体：公司做什么，不是"公司会支持你"；
- 复评时间点明确，且早于任何期限压力点——留出观察期；
- 说明"达标后会怎样"（回到常规管理），这能显著降低防御姿态。

**收尾三句**：
> "今天说的这些你看有没有要补充的，或者你觉得我记错了的地方，现在就可以提。"

> "我把今天的要点写成 [面谈记录/目标确认书] 发给你，你看完有异议可以写在备注栏，我们下周对一次。"

> "复盘时间 [日期]。"

**收尾要点**：给员工"书面提出异议"的通道，并明确会被阅读；不签的也要留记录。不要在面谈结尾加一句"你先想想"——那等于把球扔回去，容易在两周后变成投诉。

## 三、可衡量目标五要素模板

```
目标名称：
指标（可计数/可核验的事实）：
口径（计算范围、排除项、数据来源）：
基线（对比参照：同岗位平均 / 上期实际 / 目标书原值）：
时限（起止日 + 中期复盘日 + 期末复评日）：
数据来源（从哪个系统/台账取，谁导出）：
支持（培训、带教、权限、数据、资源）：
评价方式（谁评、看什么材料、什么时点出结论）：
员工意见（认同 / 部分异议 / 不认同 + 理由）：
员工签署 / 电子确认 + 日期：
```

### 指标选取的四个筛选条件

一个候选指标能不能用，四个条件全过才留：
1. **可计数或可核验**——能被两个不同的人独立算出同一个数；
2. **本人可控**——主要受本人努力影响，而不是完全受外部因素支配；
3. **有数据来源**——说得清从哪张表导出；
4. **与岗位价值相关**——和这个岗位实际要产出的东西有关。

**典型的不可用指标**：笼统态度评价、难以定义边界的事件数、没有对照基线的增长率。

### 波动性岗位（销售、运营、内容等）的目标写法

月度波动大的岗位，用"单点承诺"会不断制造纠纷。改用三种结构之一：

| 结构 | 写法 | 适用 |
|---|---|---|
| 周期总额 | "本季度签单金额达成率不低于 80%，口径按开票金额、剔除退款与内部测试单" | 波动可被季度总量吸收 |
| 阶梯式 | "3 月 60%、4 月 70%、5 月 80%、6 月 90%，逐月设中间检查点" | 需要爬坡期 |
| 保底+挑战 | "保底达成率 70%，挑战档 90%；保底未达成触发辅导，挑战达成计激励" | 有激励资源可挂 |

配套要点：口径里的排除项要写清（退款、内部测试单、跨期确认、赠品），否则同一笔业务在目标书和账上算两个结果。

## 四、面谈记录模板（每次必填，归档）

```
面谈编号：            日期：            主管：
员工（岗位/工号）：    周期：
保护情形排查结果：
一、事实（时间/事项/结果，逐条）
二、标准（来源出处 + 员工确认状态）
三、差距（指标/目标值/实际值/差距幅度/性质）
四、下一步（目标要素五项 + 支持 + 复评安排）
五、员工陈述要点（逐条记录，不做删改归纳）
六、员工异议（如有，原样记录 + 处理方式 + 处理人）
七、本次产出物（目标书/辅导记录/改进计划，编号）
八、双方签署 + 日期
```

**记录原则**：
- 员工陈述原样记录，不删改、不概括成"情绪激动"；
- 异议必写处理痕迹（谁处理、何时、如何反馈）；
- 面谈记录不追认、不可补造，时间线必须连续；
- 主管与员工各留一份，同时归档到季度证据包。

## 五、薪酬调整与绩效面谈的衔接

绩效面谈里提到调薪，要分清三种完全不同的事：

| 类型 | 性质 | 风险点 | 处理建议 |
|---|---|---|---|
| 绩效奖金按考核结果浮动 | 已在制度中约定 | 争议点在于制度是否经民主程序并公示、考核过程是否客观 | 绩效面谈里只讲考核结果与计算方式，不现场改规则 |
| 绩效工资/奖金扣减 | 报酬减项 | 若制度未约定扣减依据，或未经民主程序，可能被认定不能克扣工资 | 先核制度，再谈；不要在面谈现场首次提出扣减 |
| 固定工资结构调整 | 劳动合同内容变更 | 属于劳动合同变更，原则上需协商一致并书面变更 | 单独沟通、单独书面确认，不挂在绩效面谈里顺手做 |

**衔接原则**：绩效面谈只谈"表现—标准—差距—改进"，涉及钱的事项若已在制度内，明确指向制度条款；若需新设或变更，另开一次沟通并留书面。不要把"扣奖金"作为绩效谈话的筹码，也不要在面谈记录里写"再不行就扣钱"，这类表述在争议中会被当作以减薪施压的证据。

## 六、什么时候不该开这场面谈

- 员工当日处于休假、医疗期或刚经历重大个人事件；
- 所需事实材料缺失或由他人转述、无记录支撑；
- 上一次沟通距今很短且无新事实；
- 你希望在这次谈话里让对方接受某个既定结果（谈判式面谈，绩效面谈不适合承担这个功能）；
- 涉及多人，尚未完成保护情形全量排查。
