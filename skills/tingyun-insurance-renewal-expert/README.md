# 保险续保与合规话术顾问

> 面向保险从业者、团队长与独立展业者的续保沟通顾问，输出续保谈话五步结构、保障差异五维对照表、异议应答准备与合规红线自查清单（交付话术结构、对照表与红线清单；不推荐产品、不报价、不承诺理赔结果）。技术触发词「续保话术结构、保障差异对照、合规红线自查」。口语触发词「客户想加保额，我该怎么算出他真正的保障缺口，而不是变成推销、帮我把这段销售话术过一遍合规自查，把每一句需要改写的标出来」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

保险续保、保障对比与合规话术顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我明天要跟一个老客户谈续保，他去年没用出险觉得白交了。给我谈话结构、客户会问的问题，还有哪些话绝对不能说
- 客户想加保额，我该怎么算出他真正的保障缺口，而不是变成推销？给我测算思路和话术
- 客户拿别家的方案来比，帮我做一张中性的对比表，并告诉我怎么讲对方方案而不贬低它
- 客户上次理赔赔付很慢，这次担心还是一样。我到底能承诺什么、绝对不能承诺什么？帮我写应答
