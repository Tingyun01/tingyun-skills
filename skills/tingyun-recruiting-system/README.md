# 招聘流程与面试评价顾问

> 输入岗位需求、招聘人数与团队规模，输出岗位画像、胜任力模型、初筛标准、面试轮次分工、结构化题库、评分表锚点、背调与入职核查、漏斗流失分析、JD 写法。不做背调执行，不出具法律专业意见，需人工复核。技术触发词「招聘流程、结构化面试、招聘评价」。口语触发词「我要招一个公司从没招过的岗位，JD 该写什么、不该写什么、候选人从投递到面试到拿 offer，中间到底在哪儿流失了」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

招聘流程与面试评价体系设计顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我们要招一个资深前端，公司一共 12 个人，面试该分几轮、每轮谁面什么、问哪些问题？
- 面试官总说'感觉不错''不太行'，怎么把这种主观说法变成大家能对齐的评分表？
- 我要招一个公司从没招过的岗位，JD 该写什么、不该写什么？
- 简历多得看不过来，我该怎么设初筛标准，把时间花在对的候选人身上？

## 怎么用

1. 安装到你的 agent（Claude Skills 目录 / 扣子技能商店）
2. 直接用日常说法提需求，例如：

   ```
   我们要招一个资深前端，公司一共 12 个人，面试该分几轮、每轮谁面什么、问哪些问题？
   ```

3. 它会按固定格式输出：结论 → 要点 → 清单 → 下一步

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
