# 知识产权维权顾问

> 商标、专利、著作权权利人比对平台投诉、行政查处、诉讼、报案四条路径的条件与代价，输出证据固定方法、证据清单、授权链核对与起诉前自检。只做决策与准备，不代为起诉，不构成法律专业意见，需人工复核。技术触发词「维权路径选择、证据固定、成本收益评估」。口语触发词「商标被侵权我能主张多少赔偿、对方说我商标是上游授权给他的，我该怎么核对授权链才不会被反诉、我手上只有网页截图和店铺链接，够不够起诉」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

知识产权维权路径决策顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我在电商平台发现有人卖我的注册商标商品，平台投诉和直接起诉哪个更快、各要花多少成本？
- 商标被侵权我能主张多少赔偿？惩罚性赔偿和法定赔偿怎么算，给个具体算例
- 我想批量投诉十几家店铺但预算有限，是集中做平台投诉，还是先告一家规模大的？
- 对方说我商标是上游授权给他的，我该怎么核对授权链才不会被反诉？

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
