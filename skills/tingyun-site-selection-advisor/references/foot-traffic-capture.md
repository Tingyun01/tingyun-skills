# 客流测算：截流法与捕获率

本页给一套可直接照做的测算步骤，用于判断"这块地方到底能来多少人、能不能养活租金"。所有数字以现场实测为准，本表仅为方法框架。

## 一、截流法（算"总盘子"）

截流法测的是"门前经过的潜在人流"。操作：

1. 选 3 个典型日（一个工作日、一个周末、一个节假日或促销日）。
2. 每天分 4 个时段计数：早 7–10、午 10–14、晚 17–21、其余时段抽样。
3. 记录"路过总人数"与"面向本业态的可见度系数"（店招是否被遮挡、是否单向人流、是否在主行进动线右侧）。

| 时段 | 路过人数 | 可见度系数(0.3–1.0) | 有效截流=人数×系数 |
|---|---|---|---|
| 早 7–10 |  |  |  |
| 午 10–14 |  |  |  |
| 晚 17–21 |  |  |  |
| 合计日截流 |  |  |  |

可见度系数参考：主街双向、店招醒目取 0.8–1.0；支路或需绕行取 0.4–0.6；被遮挡或背向动线取 0.3。

## 二、捕获率（算"能吃到多少"）

捕获率 = 进店并成交的客人 ÷ 有效截流人数。

不同业态经验区间（仅作测算起点，需用自身数据回校）：

| 业态 | 捕获率测算区间 | 说明 |
|---|---|---|
| 高频餐饮（快餐） | 10%–20% | 午晚高峰集中 |
| 正餐/特色餐饮 | 5%–12% | 目的性较强 |
| 零售便利店 | 8%–15% | 顺路转化 |
| 服鞋零售 | 3%–8% | 停留与挑选 |
| 服务/体验 | 2%–6% | 强目的性 |

## 三、租金反推公式

```
日捕获客流量 = 有效截流 × 捕获率
日销售额 ≈ 日捕获客流量 × 客单价 × 复购折减(新店取 0.6–0.8)
可承受月租 ≈ 月毛利 × 租金占比上限(餐饮常取 15%–20%，零售 10%–15%)
```

判断：当"可承受月租"低于房东报价，明确结论为"按当前模型养不活，需谈租或换址"。

## 四、常见失真来源

- 只数晴天、只数周末 → 高估。
- 把"路过所有人"当"有效截流"不乘可见度系数 → 高估。
- 用别人的捕获率套自己的业态 → 偏差大，须回校。
- 周边将修路、拆迁、竞品密集进驻 → 捕获率会变，需做悲观情景。
