# 扩张失败信号与人员复制

## 一、按月监控的失败信号

| 信号 | 表现 | 含义 |
|---|---|---|
| 收入不及预期 | 新点连续低于悲观情景 | 选址或模型假设错 |
| 缺口提前 | 现金流缺口早于测算 | 投入或爬坡失控 |
| 岗位空缺 | 关键岗长期招不到/离职高 | 复制失败前兆 |
| 老点抽血 | 现有点客流/精力被分流 | 协同变内耗 |
| 质量下滑 | 交付随规模下降 | 供应链/管控掉链 |

监控节奏：前 3 个月每周看，之后每月看，对照基准与悲观情景。

## 二、人员复制难度评估

核心岗位：店长/班组长/技术骨干。评估：

- 能否在 1–3 个月培养或外聘到岗。
- 是否高度依赖创始人个人（依赖度越高越难复制）。
- SOP 与培训体系是否就绪。

判断：关键岗位依赖个人 → 复制难度高，先建 SOP + 接班人机制，再谈点位扩张。

## 三、降低复制风险的计划

1. 先固化单点 SOP（流程、标准、检查表）。
2. 储备关键岗 backups，避免一人牵制一点。
3. 新点首期由老点骨干带教，而非完全新人。
4. 管理半径内优先扩张，控制异地数量。

## 四、止损阈值

预设：当新点连续 N 个月低于悲观情景且缺口扩大，启动止损评估（收缩/转手/关停），避免无限输血。
