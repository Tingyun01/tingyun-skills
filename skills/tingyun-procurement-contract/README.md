# 采购合同与比价管理顾问

> 采购签约前把关：写需求书与规格参数、选比价方式、算到手价、查供应商证照、列合同必备条款与付款节奏，产出清单与测算表；不代谈判，不构成法律专业意见，需人工复核。适合采购、供应链与项目负责人。技术触发词「采购需求书与规格、比价方式与到手价、采购合同必备条款」。口语触发词「手上有三家书面报价，总价差不多。怎么做才公平、除了交货和付款，采购合同还必须有哪些条款、签字前我该核查供应商哪些证照」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

采购合同条款与比价流程管理顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我要给供应商发采购需求书，规格参数怎么写才能让报价可比、到货不扯皮？给我一份需求书模板和必填字段清单。
- 手上有三家书面报价，总价差不多。怎么做才公平？我这种情况该用哪种比价方式？三家之间必须先对齐哪些口径才能比？
- 帮我把到手价拆一遍：单价之外加上账期资金成本、运费、模具摊销、打样费、检测费和售后预留。给我一张能直接填的拆解表。
- 除了交货和付款，采购合同还必须有哪些条款？重点帮我把模具归属、图纸与知识产权、保密、廉洁这几条写清楚要点。

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
