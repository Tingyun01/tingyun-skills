# tingyun-aging-institution-compliance

> 按两项强制性国标把养老机构的建筑燃气消防食安防汛服务资金六类检查项逐条落成三态判定表，算清护理员配比与证书到期，产出整改闭环台账与证据留痕方案
>
> 面向养老院、敬老院、日间照料中心运营主体的合规自查助手。按 GB48013-2026《养老机构基本规范》90 项要求与 GB48014-2026《养老机构重大事故隐患判定准则》25 条直接判定要素的逻辑，把主管部门实际使用的检查项逐条拆成检查什么、依据什么、留什么证据三列，输出符合、不符合、需人工确认三态判定表。

## 这个 Skill 做什么

把「养老机构合规」这个场景最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

### 解决什么问题

养老机构最怕的不是"不知道有标准"，而是**知道有标准，但不知道检查那天会看什么、拿什么出来**。

2026-07-30，市场监管总局会同民政部发布《养老机构基本规范》《养老机构重大事故隐患判定准则》两项**强制性国家标准**，2027-08-01 实施，设 1 年过渡期。前者从选址与建筑、设施与设备、入院出院管理、基础服务、安全管理、运营管理、评价与改进 7 个方面提出 **90 项具体要求**；后者把重大事故隐患划分为 **25 条直接判定要素、28 条综合判定要素和 2 类排除情形**。

官方给了标准，也给了地方检查清单（辽宁民政厅 2026-10-29 版：64 项，33 项必查 + 31 项抽查）。**但这两样东西都不是给机构自己用的**——标准写的是要求，清单写的是检查表，**"我这家现在缺什么、缺了怎么补、补完怎么证明"没有任何一方给**。

**问题性质是"证据不可自证"，不是"标准不清楚"。** 检查组到现场，问的是"上个月 3 号你做了什么，记录在哪"。绝大多数机构不是没做事，是**做了但证明不了**，或者**制度在墙上但记录断了**。

本技能做的事：**把检查项逐条落成可勾选的判定表 → 分出必须先处理的 → 算出缺多少人和缺多少证 → 生成整改台账 → 配齐留痕清单。**

## 什么时候会触发

- 养老院要自查哪些东西
- 新的养老国标怎么对
- 护理员配比要几个人
- 消防记录怎么留
- 整改台账怎么做

## 怎么用

1. 安装到你的 agent（Claude Skills 目录 / 扣子技能商店）
2. 直接用日常说法提需求，例如：
   养老院检查要准备什么材料
3. 它会追问关键信息（缺的信息会标〔待补〕，不会替你编）
4. 输出可直接用的清单 / 对照表 / 台账

## 输出

- 判断步骤与检查清单
- 对照表 / 台账
- 待办与需要人工核实的问题

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
