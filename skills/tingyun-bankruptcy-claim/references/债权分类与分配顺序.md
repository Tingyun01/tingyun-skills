# 债权分类与分配顺序

> 本页用于判定债权类别与受偿顺位、区分破产费用与共益债务、建立分配顺序框架与测算公式，并梳理股东有限责任与出资加速到期的情形。
> 本页为程序与规则梳理材料，不构成法律专业意见，需人工复核。

---

## 一、四类债权分类表

### 1.1 分类总表

| 类别 | 认定要点 | 常见来源 | 受偿顺位 |
|---|---|---|---|
| 破产费用 | 为全体债权人共同利益而发生的程序性支出 | 诉讼费、管理人报酬、财产保管与处置费用、公告与审计评估等费用、分配费用 | 顺位靠前 |
| 共益债务 | 受理后为全体债权人共同利益而发生的债务 | 继续履行合同所负债务、购置必要财产、无因管理人行为所负债务、财产被侵占时的返还请求、因债务人财产受益产生的债务等 | 顺位靠前 |
| 职工债权 | 基于劳动关系产生的债权 | 拖欠工资、伤残补助、抚恤费用、应划入个人账户的社保基金、法定经济补偿金 | 早于税款与普通债权 |
| 税款债权 | 依法应由债务人缴纳的税款与相关款项 | 欠税、欠缴的社保（单位部分）、滞纳金等 | 早于普通债权 |
| 有财产担保债权 | 就特定财产设定担保的债权 | 抵押、质押、留置 | 就担保财产优先受偿，不足部分转普通债权 |
| 普通债权 | 无财产担保的常规债权 | 货款、服务费、借款、租金、无担保的股东借款等 | 靠后，同顺位按比例 |

### 1.2 三个高频误判

**误判一：以为有担保就排在前面。**
有财产担保债权是**就特定担保财产优先**，不是排在全部债权之前。担保物变价后不足以清偿全部担保债权的，**不足部分作为普通债权**参与按比例分配。这两条线的差别直接影响测算，必须分开列。

**误判二：以为共益债务是债务人的旧债。**
共益债务是**受理之后**为全体债权人共同利益新发生的债务，性质上是程序的费用，由债务人财产随时清偿。把它和旧债混在一起，会把分配顺序整体算错。

**误判三：以为未申报债权不参与分配。**
法律规定债权人在破产财产末尾分配前可以补充申报，但此前已进行的分配不再对其补充分配。**漏报的代价是分不到前面几轮，不是分不到任何。**

### 1.3 取回权与债权申报的区分

| | 债权申报 | 取回权 |
|---|---|---|
| 标的 | 对债务人享有的债权 | 属于债务人财产但由他人占有的物、货币、财产利益 |
| 对象 | 债务人本身 | 第三人（如代为保管、借用、错误支付） |
| 主张对象 | 债务人（由管理人接收） | 管理人 |
| 常见情形 | 货款、服务费、借款 | 出租物被占用、错付到账的款项、代保管物 |

**实务提示**：如果你的"债权"其实是"东西被占了"或"钱打错了"，走取回权路径比走债权申报更合适。判断不清时先向管理人书面询问主张路径。

## 二、分配顺序框架

### 2.1 顺序结构

```
破产财产（变现所得 + 债务人自有资金 + 追缴回款）
  │
  ├─ 第 1 顺位：破产费用 + 共益债务
  │    └─ 不足全额支付时，先行支付，不足部分按法定规则处理
  ├─ 第 2 顺位：职工债权
  ├─ 第 3 顺位：税款债权
  └─ 第 4 顺位：普通债权
       └─ 有财产担保债权就担保财产优先受偿后，其不足部分进入本顺位按比例分配
```

**同顺位内按比例**：同一顺位内多个债权人按各自债权额占该顺位总额的比例受偿。

### 2.2 测算公式

```
第 1 步：算第 1 顺位占用
  可分配财产 = 变价所得 + 债务人货币资金 + 已追缴回款 − 破产费用 − 共益债务

第 2 步：算本顺位受偿率
  本顺位受偿率 = 可分配财产 ÷ 本顺位债权总额   （大于 1 则全额受偿，余额向下顺位传递）
  本债权人受偿额 = 自己的债权额 × 本顺位受偿率

第 3 步：向下顺位传递
  传递到下一顺位的财产 = 可分配财产 − 本顺位已受偿额
```

**有财产担保债权单独走一条线**：

```
担保财产变价所得 → 先给担保债权人（以其债权额为限）
  超出部分 → 归入一般可分配财产，参与第 1 顺位起的顺序分配
  不足部分 → 担保债权人的余额作为普通债权，进入第 4 顺位按比例分配
```

### 2.3 测算需要的数据

| 数据项 | 从哪来 | 拿不到时怎么办 |
|---|---|---|
| 债务人财产总额与评估/变价结果 | 管理人财产报告、评估报告、变价公告 | 明确说明数据缺失，不给数字 |
| 各顺位债权总额 | 债权表（公示后可得） | 给出公式与所需字段，标注为待填 |
| 破产费用与共益债务金额 | 管理人费用报告、审计报告 | 同上 |
| 追缴与撤销回款情况 | 管理人工作 reports、债权人会议材料 | 同上 |

**没有这些数据，任何具体回收百分比都是编的。** 正确做法：给出公式 + 明确的数据缺口 + 标明数据取得的时间点（债权表公示后 / 财产报告披露后）。

### 2.4 三种情景的表达方式

数据不全时，用情景表而不是单一数字：

| 情景 | 变价实现率假设 | 本顺位受偿率 | 本债权人受偿 |
|---|---|---|---|
| 乐观 | 较高 | X% | = 债权额 × X% |
| 中性 | 中等 | Y% | = 债权额 × Y% |
| 悲观 | 较低 | Z% | = 债权额 × Z% |

同时标注："上述比例基于假设，实际以管理人披露的财产报告与债权表数据为准，需人工复核。"

## 三、股东有限责任与出资加速到期

### 3.1 原则与例外

| 情形 | 责任形态 | 说明 |
|---|---|---|
| 股东按期足额出资 | 有限责任，以认缴出资额为限 | 基本原则 |
| **出资期限届满仍未出资**，且公司不能清偿到期债务 | 股东未出资部分对公司债务承担补充赔偿责任 | 出资加速到期 |
| **股东未届出资期限**，但公司已不能清偿到期债务 | 出资义务加速到期，股东应予缴纳 | 加速到期的适用情形 |
| **抽逃出资** | 股东应在抽逃范围内对公司债务承担赔偿责任 | 抽逃出资在破产程序中常被管理人追缴 |
| **滥用公司法人独立地位与股东有限责任逃避债务**，严重损害债权人利益 | 对公司债务承担连带责任 | 法人人格否认的具体情形由有权机关认定 |
| **财产混同、账簿不清、无法清点资产** | 可能被认定为人格混同情形 | 事实与后果由有权机关认定 |
| 股权转让后转让方未履行出资义务，受让方明知或应知 | 责任承担方式有专门规则 | 需个案分析 |

> 上表为规则框架梳理，具体适用与后果认定须由执业律师依据现行法律与个案事实判断。

### 3.2 为什么这一层对债权人重要

```
若股东未缴出资未被追缴：
  债务人财产池 = 变价所得 + 自有资金（少一块股东应缴部分）
  → 普通债权的受偿率被直接压低

若股东出资被追缴到位：
  债务人财产池扩大 → 各顺位受偿率同步提高
```

**在破产程序中，这一层不是靠债权人自己去追，而是靠管理人追缴。** 债权人的动作是：
1. 在申报债权的同时，向管理人书面提出股东出资未缴、存在抽逃出资的线索与证据线索
2. 在债权人会议上关注追缴进展
3. 若管理人未采取行动，了解是否可依法定途径推动（含向法院提出相关申请）

### 3.3 股东主张出资加速到期时的准备

| 准备项 | 说明 |
|---|---|
| 公司不能清偿到期债务的证据 | 生效裁判、执行裁定、债权人会议文件、管理人材料 |
| 股东出资期限已届满的证据 | 章程、股东协议、工商登记的认缴出资额与出资期限、催缴函与股东回复 |
| 股东未履行的证据 | 银行流水（无实缴记录）、验资材料缺失、财务账册 |
| 抽逃出资的线索 | 股东与公司之间的资金往来、关联账户、异常的转账与分红 |
| 主张路径 | 向管理人书面提出；必要时由管理人依职权主张或申请 |

**要点**：主张的是"出资义务加速到期/应予缴纳"，**不是直接要求清偿你的债权**。股东责任是向公司（也就是财产池）缴纳，不是向你个人付款。这个区别在提请管理人追缴时要讲清楚。

## 四、申报口径与计算要点

### 4.1 金额构成

| 项目 | 计算口径 | 高频错误 |
|---|---|---|
| 本金 | 合同或生效裁判确定的金额 | 把含税价与不含税价混用 |
| 利息 | 按合同约定利率或法定标准，算到**受理日** | 算到申报日，多算的部分会被核减 |
| 违约金 | 按合同或裁判确定的方式算 | 与利息重复计算 |
| 已受偿金额 | 扣减 | 漏扣，导致被认定重复主张 |
| 担保情况 | 抵押/质押的物与登记情况 | 只写"有担保"不写担保物与登记信息 |

**关于计息截止**：附利息的债权自破产申请受理时起停止计息。申报时把计算区间明确写成"自 X 年 X 月 X 日至 X 年 X 月 X 日（受理日）"，并附计算过程。

### 4.2 担保主张的写法

不要只写"有担保"。要写清三件事：

```
① 担保物：具体名称、数量、规格、存放地
② 担保类型：抵押 / 质押 / 留置
③ 登记与公示：登记机关与登记编号、登记日期；已登记的是关键证明
```

**为什么写得细很重要**：担保物描述不清或登记信息错误，管理人核对时无法对应，债权可能被按普通债权登记，直接影响受偿顺位。

### 4.3 债权性质的附随主张

除本金与利息外，可在申报材料中附随提出（是否成立由管理人认定）：

- 有财产担保债权的主张
- 破产费用与共益债务的主张（若确属为全体债权人共同利益支出的费用）
- 取回权的主张（若标的属债务人财产而被他人占有）
- 抵销权的主张（若同时对债务人负有到期债务）
- 尚未到期的债权（法律上视为到期申报）
- 或有债权与未决诉讼、仲裁形成的债权（需说明进展）

**主张与担保权相关时，一并附上登记证明原件复印件与证据说明**，减少核对往返。
