# 社保、工伤、解除合规三张清单

> 本清单为规划辅助，具体比例、基数、时限以当地主管部门口径为准。

## 一、社保合规清单

- [ ] 入职之日起 **30 日内** 办理社保登记并申报缴费；
- [ ] 缴费基数按职工本人工资如实申报，不按下限基数"一刀切"；
- [ ] 异地用工：在用工所在地参保，或依法办理转移/代缴备案；
- [ ] 试用期也须依法参保，不得"转正再交"；
- [ ] 保留工资表、银行流水、参保凭证备查。

**常见雷点**：只交工伤不交其他险种、基数长期按下限、试用期不交——均为稽查高发。

## 二、工伤合规清单

- [ ] 事故发生后立即救治并留存病历、现场证据；
- [ ] 单位应在事故伤害发生之日起 **30 日内** 申请工伤认定（单位不申请的，职工或其近亲属可在 1 年内申请）；
- [ ] 明确"48小时"视同工伤的边界（突发疾病死亡或在 48 小时之内经抢救无效死亡）；
- [ ] 未依法参保的，工伤待遇由**单位按工伤保险标准支付**；
- [ ] 保留劳动关系证明、考勤、工资凭证——这是认定前提。

**要点**：未参保时单位全额买单，所以"不交社保省成本"在工伤上反而代价较高。

## 三、解除合规清单（区分两类路径）

### 过错解除（劳动合同法第39条，无需补偿）
适用：严重违纪、严重失职、双重劳动关系、欺诈入职、追究刑事责任等。
必备：
- [ ] 合法有效的规章制度（经民主程序+公示）；
- [ ] 违纪事实证据链（通报、笔录、监控）；
- [ ] 解除通知送达留痕。

### 无过错解除（第40条 前置通知/代通知金；第41条 经济性裁员）
适用：不胜任、客观情况重大变化、裁员。
必备：
- [ ] 不胜任需先培训或调岗仍不胜任；
- [ ] 提前 30 日书面通知或支付代通知金；
- [ ] 支付经济补偿（N 或 N+1）；
- [ ] 裁员优先留用与报告程序。

**高风险动作**：仅凭口头不满辞退、未签合同直接辞退、辞退"三期"女职工——极易被判违法解除，赔偿金为 2N。

## 四、三张清单的交叉风险

社保漏缴 + 解除争议 往往同时爆发：员工离职时一并举报社保，单位需补缴+滞纳金。体检时要把三张清单合并看，而不是孤立处理。
