# 破产程序阶段与路径选择

> 本页用于判断是否已触发破产程序、定位当前所处阶段、推算关键期限，并在破产清算、重整、和解三条路径之间做选择。
> 本页为程序梳理材料，不构成法律专业意见，需人工复核；实体判断须由执业律师复核或由管理人、法院认定。

---

## 一、触发情形与受理条件

### 1.1 谁可以申请

| 申请人 | 前提条件 |
|---|---|
| 债务人（公司自行申请） | 不能清偿到期债务，且资产不足以清偿全部债务或明显缺乏清偿能力 |
| 债权人申请 | 债务人不能清偿到期债务，债权人认为其符合破产条件 |
| 股东（出资人）申请 | 有限责任公司股东出资期限届满未出资、且不能清偿到期债务；需先经法定程序确认 |

**实务提醒**：债权人申请破产后，债务人未自行清算的，清算组或人民法院指定的清算组/管理人接管财产与账簿。**债权人在申请前先把证据备齐**（合同、对账单、付款记录、催收函），申请被受理后这些材料就是申报底稿。

### 1.2 受理条件的判断维度

```
第 1 维：到期债务不能清偿
├─ 有生效判决/裁决/调解书且未履行 → 事实清楚
├─ 有合同与对账单但无生效文书 → 需其他证据佐证
└─ 仅有到期未付的确认函/承诺书 → 证明力偏弱

第 2 维：资产不足以清偿全部债务，或明显缺乏清偿技术能力（清偿能力不足）
├─ 资产总额 < 负债总额（资不抵债）
├─ 资产存在但无法变现或变现价值明显低于负债
├─ 明显缺乏清偿能力：账簿缺失、无法清点资产、负责人失联、停业、现金流断裂
└─ 主要资产已被查封、抵押或已被其他案件优先执行

第 3 维：是否存在挽救价值（决定可能走哪条路）
├─ 经营仍在运转、有订单与技术团队 → 有重整或和解的可能
├─ 已停业、无订单、资产处置型 → 更可能走清算
└─ 资产主要是有价证券、股权、房产 → 清算变现为主
```

> 上表的"技术能力"表述源自实务惯用说法，实质是**明显缺乏清偿能力**这一法定要件的判断。是否成立由法院认定，本页只提供判断维度。

### 1.3 三个容易被忽略的前置事实

1. **是否已进入执行程序**——已被强制执行且无财产可供执行，是"明显缺乏清偿能力"的常见支撑证据。
2. **是否存在逃避债务的行为**——如转移资产、抽逃出资、擅自处理财产，这些既是受理的支持事实，也可能在程序中被主张撤销。
3. **是否已被裁定进入清算程序**——已受理破产的，个别债权清偿、个别执行、单独起诉都可能被中止。

## 二、三个阶段与关键节点

### 2.1 阶段一：申请与受理

```
申请（债务人 / 债权人 / 股东）
  → 法院审查受理条件
  → 裁定受理（同时指定管理人）
  → 法院指定管理人，公告受理情况
  → 通知已知债权人
  → 确定并公告债权申报期限
```

| 节点 | 说明 | 对债权人的意义 |
|---|---|---|
| 受理裁定 | 法院作出 | 债务人财产由管理人接管，个别清偿与单独执行被中止 |
| 指定管理人 | 法院指定 | 申报与联系人的正式入口 |
| 发布受理公告 | 法院在报纸及全国企业破产重整案件信息网等渠道公告 | **申报期限起算点** |
| 通知已知债权人 | 管理人通知 | 通知与公告不一致时以公告为准，需书面询问 |
| 申报期限确定 | 法院确定 | 常见区间为 30 日至 3 个月，具体看公告 |

### 2.2 阶段二：申报、核查与异议

```
债权人在申报期内提交申报材料（取得回执）
  → 管理人审查债权，编制债权表
  → 债权表公示/通知
  → 债务人、债权人对债权表记载有异议的，在法定期限内提出异议
  → 管理人复核；仍有争议的，按法定途径处理
  → 债权人会议核查债权
```

| 节点 | 说明 | 高频问题 |
|---|---|---|
| 申报期提交 | 提交申报书与证据材料 | 未按期提交；材料缺主体资格证明被退回 |
| 取得回执 | 管理人出具接收凭证 | 没留回执，出问题无法证明已交 |
| 债权表公示 | 记载已初步确认的债权 | 没看公示，自己的债权被记错金额或漏记 |
| 异议期 | 对债权表记载有异议的提出 | 错过异议期，只能另走诉讼途径 |
| 债权人会议核查 | 会议表决确认债权 | 未出席视为放弃表决权，对确认结果有影响 |

### 2.3 阶段三：财产变现与分配

```
重整路径：重整计划草案编制 → 分组表决 → 法院批准 → 计划执行 → 转入清算或终结
和解路径：和解协议草案表决 → 法院确认 → 协议执行 → 转入清算或终结
清算路径：管理人接管财产 → 清理变价 → 编制分配方案 → 表决 → 分配 → 终结
```

| 节点 | 说明 | 债权人要做的动作 |
|---|---|---|
| 财产变价 | 资产处置方式由管理人决定 | 关注变价方式与节奏，必要时在债权人会议上提出意见 |
| 分配方案编制 | 按顺位排列 | 核对顺位与本组比例 |
| 分配方案表决 | 表决通过后执行 | 关注表决比例与是否按本组意愿 |
| 终结 | 程序终结，未受偿部分不再清偿 | 留存全套文书备查 |

### 2.4 期限推算表（实际以公告为准）

| 期限 | 起算点 | 常见长度 | 应对动作 |
|---|---|---|---|
| 债权申报期限 | 法院受理公告发布之日 | 30 日至 3 个月 | 日历标注 + 提前 5 个工作日完成材料 |
| 债权表异议期 | 收到债权表或公示之日起 | 较短 | 一收到就核算金额、担保、利息三项差异 |
| 债权人会议表决 | 会议通知载明的时点 | 按通知 | 提前取得债权表与会议材料 |
| 补充申报期 | 破产财产末尾分配前 | 视程序进度 | 漏报者必须盯紧 |

**推算方法**：以"持有文件"上的日期为准做起点，用公告或通知载明的期限做长度，得出截止日，再倒推内部完成日 = 截止日 − 5 个工作日（留出补正与寄送缓冲）。

## 三、三条路径对比与选择

### 3.1 对比表

| 维度 | 破产清算 | 重整 | 和解 |
|---|---|---|---|
| 启动与转换 | 债权人申请或债务人申请 | 债务人申请重整，或债权人在清算程序中申请转换 | 债务人提出和解协议草案 |
| 债务人经营 | 停止经营，财产集中变价 | 原则上保留经营（可由债务人自行管理或由管理人管理） | 部分维持经营，受协议条款约束 |
| 核心文件 | 财产分配方案 | 重整计划草案 | 和解协议草案 |
| 表决机制 | 分配方案表决；另有关于财产变价、继续营业等事项的表决 | 按债权性质分组表决（担保债权组、职工债权组、税款债权组、普通债权组等），各组分别通过 | 就协议内容协商表决 |
| 债权人杠杆点 | 债权确认环节、财产变价方式与节奏的监督 | 分组设置、债权金额确认、表决策略、债转股与清偿安排 | 协议条款、履行保障、退出节奏 |
| 主要风险 | 变价折价、破产费用与共益债务优先扣除、周期长 | 计划执行依赖经营恢复与管理层配合 | 协议履行依赖债务人信用与后续经营 |
| 时间量级 | 以月到季度计 | 计划表决与执行周期较长 | 相对短 |

### 3.2 选择路径的判断树

```
第 1 步：债务人还有经营价值吗？
├─ 没有（停业、无订单、资产处置型）
│    └─ 走破产清算路径，重点在债权确认与分配方案表决
└─ 有（经营在运转、有技术与订单）
     ├─ 有恢复经营并清偿能力的可能 → 评估重整
     └─ 更可能通过与债权人协商解决 → 评估和解
第 2 步：申请或转换的时机
├─ 尚未进入程序 → 由债权人申请破产清算，或由债务人申请重整/和解
└─ 已在清算程序中 → 债权人可在转为重整或和解的表决中行使选择权
第 3 步：我方的影响力在哪个环节更大？
├─ 重整/和解 → 集中在计划与协议的表决
└─ 清算 → 集中在债权确认与变价监督
```

### 3.3 重整计划表决要算什么

在重整程序中，普通债权人往往单独成组。要点：

1. **本组通过所需的门槛**——通常需要出席会议的债权人过半数同意，且其所代表的债权额占本组债权总额的三分之二以上（具体以现行规定与法院要求为准）。
2. **本组的债权份额**——你在本组占的债权比例，决定你的票权重不重要。
3. **清偿方案的形态**——现金分期清偿、债转股（以股抵债）、留债清偿、信托受益权等，不同形态对不同债权人差别很大。
4. **清偿期限与折价**——同比例折价但快速到位，与高比例但长期分期，风险结构完全不同。

**测算建议**：做情景对比表，至少覆盖"折价率 × 到期年限"两个维度，各列出 2-3 组情景，让你判断哪种方案更符合自己的底线。

## 四、程序阶段自查表

对着手上的文件逐项打勾，就能定位自己处在哪一步。

| 已持有的文件或事实 | 推定阶段 | 立即要做的动作 |
|---|---|---|
| 只有传闻、听说公司资金链紧张 | 尚未确认进入程序 | 核实是否已被申请、是否已受理；关注法院公告渠道 |
| 法院受理裁定 | 阶段一 | 核对公告日，确定申报截止日，倒排材料 |
| 管理人发出的债权申报通知 | 阶段一（申报期） | 核对通知期限与公告期限是否一致；准备材料并取得回执 |
| 已提交申报材料并拿到回执 | 阶段二 | 等待债权表公示，主动核对记载内容 |
| 收到债权表或公示截图 | 阶段二（异议期） | 逐笔核对金额、担保、利息、分类；有差异立即提异议 |
| 收到债权人会议通知 | 阶段二/三 | 准备表决意见，确认本组份额与门槛 |
| 收到重整计划草案 | 重整 | 做情景测算，决定表决意向 |
| 收到和解协议草案 | 和解 | 逐条比对与普通债权的清偿条件差异 |
| 收到分配方案 | 阶段三 | 核对顺位与本组比例，表决 |
| 收到终结裁定 | 终结 | 留存全套文书；评估对未受偿部分的追偿路径 |

**信息获取渠道清单**：

| 渠道 | 能拿到什么 | 注意 |
|---|---|---|
| 受理法院公告 | 受理裁定要点、申报期限、管理人联系方式 | 申报期限起算以此为准 |
| 管理人书面通知 | 具体申报安排、材料要求、会议时间 | 与公告不一致要书面询问并留痕 |
| 全国企业破产重整案件信息网 | 案件公告、进展信息 | 检索时用公司全称与统一社会信用代码 |
| 人民法院公告网等公开渠道 | 受理公告、债权申报公告、分配公告、终结公告 | 按公司名称定期检索 |
| 管理人联系渠道（公告中载明） | 清单核对、异议提交、进度询问 | 沟通后务必留书面记录 |
| 工商与征信信息渠道 | 主体状态、股东变更、涉诉记录 | 核对主体名称是否曾变更 |
| 债权人与同行交流 | 群体动向、其他债权人的口径 | 信息口径未必准确，以正式文件为准 |

## 五、给非专业读者的三条判断提示

1. **一切以文件为准。** 转述、群聊、口头告知都可能失真。申报期限、表决时间、金额记载，只认书面文件。
2. **看到"公告"两个字就把它当正式依据。** 正式公告有固定格式（受理裁定、申报公告、分配公告、终结裁定），由受理法院发布并可在公开渠道检索到。
3. **主动核对，不要被动等。** 债权表公示、分配方案这类环节，主动核对和被动接收的结果差别很大——被动接收的结果是"按记载执行"，主动核对才有纠错机会。
