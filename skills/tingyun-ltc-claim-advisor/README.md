# 长期护理保险申领规划顾问

> 帮家庭梳理长护险申请与照护开支：申请条件与流程、材料清单、失能与照护等级关系、被拒复核路径、社保与商业险衔接、居家与机构费用结构、护理资源清单。不代客申请、不推荐产品、不报价，口径以当地主管部门为准。技术触发词「长护险申领、照护费用规划、失能等级评估」。口语触发词「长护险申请被拒说失能等级不够，还能复核或再申请吗、居家照护和住机构一个月差多少钱、社保长护险和商业长护险有什么区别」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

长期护理保险申领与照护规划顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我父亲脑梗后卧床在家，想申请当地社保长护险，从准备材料到提交该按什么顺序做
- 长护险申请被拒说失能等级不够，还能复核或再申请吗？该准备什么材料
- 居家照护和住机构一个月差多少钱？把费用项拆开给我看，缺口在哪
- 社保长护险和商业长护险有什么区别？我这种情况先弄哪一边，怎么衔接
