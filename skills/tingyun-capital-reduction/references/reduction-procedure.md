# 普通减资与简易减资程序对照

> 规划辅助，时限以新《公司法》及登记机关要求为准。

## 一、普通减资（新《公司法》第224条）
适用：向股东返还出资、免除股东认缴义务、或实质减少责任财产。
步骤：
1. 编制资产负债表及财产清单；
2. 股东会作出减资决议（有限责任公司须经代表三分之二以上表决权通过）；
3. 自决议之日起 **10 日内通知债权人**；
4. 自决议之日起 **30 日内** 在报纸或国家企业信用信息公示系统**公告**；
5. 债权人在接到通知 30 日内、未接到自公告 45 日内，有权要求公司**清偿债务或提供担保**；
6. 办理注册资本变更登记。

## 二、简易减资（第225条，弥补亏损）
适用：公司弥补亏损后仍有亏损，以减资弥补亏损。
特征：
- **不得向股东分配**；
- **不免除**股东缴纳出资或股款的义务；
- 适用时**免通知债权人、免提供担保**，但应自决议之日起 **30 日内**公告。

## 三、两者对照

| 项目 | 普通减资 | 简易减资 |
|---|---|---|
| 目的 | 返还/免缴/缩责任财产 | 弥补亏损 |
| 向股东分配 | 可能 | 禁止 |
| 通知债权人 | 必须（10日） | 免 |
| 提供担保 | 债权人可要求 | 不适用 |
| 公告 | 必须（30日） | 必须（30日） |
| 登记 | 必须 | 必须 |

## 四、减资程序自检清单
- [ ] 目的定性：普通还是简易；
- [ ] 是否编制报表与财产清单；
- [ ] 决议表决权是否达标（三分之二以上）；
- [ ] 普通减资：是否 10 日内通知、30 日内公告；
- [ ] 是否预留债权人清偿/担保窗口（45 日）；
- [ ] 简易减资：确认未分配、未免缴；
- [ ] 完成后办理变更登记。

## 五、常见错误
- 以为"简易"就可以完全不公告（仍须公告）；
- 普通减资漏通知直接公告，跳过债权人保护；
- 减资未同步处理税务与章程变更。
