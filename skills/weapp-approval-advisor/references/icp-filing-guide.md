# ICP 备案全流程指南（小程序）

> 适用：微信小程序上线前的 ICP 备案（小程序备案）。自 2023 年起，所有新注册小程序提审前必须完成备案。

## 一、前置条件

1. 小程序已完成注册（个人 / 个体工商户 / 企业主体）。
2. 主体信息已在微信公众平台认证通过。
3. 准备好主体证件：身份证（所有主体必备）、营业执照（个体户/企业）。

## 二、流程总览（周期约 1~4 周）

```
微信公众平台发起备案
  → 填写主体信息（自动带出认证信息，需核对）
  → 填写小程序信息（名称、服务内容、类目）
  → 上传材料 + 人脸核验（负责人）
  → 微信平台初审（1~3 个工作日）
  → 通信管理局审核（各省 1~20 个工作日不等，多数 1 周内）
  → 备案号下发（如：苏ICP备XXXXXXXX号-1X）
  → 在小程序后台填写备案号 → 提审上线
```

**注意**：备案期间小程序无法提审，务必与开发并行推进。

## 三、逐项填写要点（高频驳回处）

| 字段 | 填写要点 | 驳回风险 |
|---|---|---|
| 小程序名称 | 与实际功能一致；个人主体不可含商业词（商城、平台、公司等） | 高 |
| 服务内容/备注 | 用平实语言描述核心功能，与类目强对应；避免夸大（绝对化用语与排名类表述） | 高 |
| 所属类目 | 与服务内容逐字呼应；工具类最稳妥 | 高 |
| 负责人 | 可以是经营者本人；人脸核验时环境光线充足、正脸 | 中 |
| 前置审批 | 涉医疗/教育/出版/金融需前置批文——没有就换类目或换方向，不要硬闯 | 致命 |

## 四、常见驳回原因与修复

1. **服务内容与类目不符**：驳回理由通常为"请选择正确的服务类目"。修复：重新核对功能与类目映射，必要时拆分功能——首版只申报最保守的类目。
2. **名称含禁用词**：删除商业性、夸大性、行业专控词汇后重提。
3. **内容描述过于简单或与截图不符**：用 2~3 句话写清"为谁提供什么功能"，确保与小程序实际界面一致。
4. **人脸核验失败**：换环境重试；负责人信息必须与身份证完全一致。
5. **主体信息不一致**：备案主体必须与小程序注册主体、执照信息逐字一致（含统一社会信用代码）。

## 五、备案号使用规范

- 下发后在小程序管理后台「设置 → 基本设置」填写备案号。
- 备案号后缀（如 -1X）是平台自动分配的序列号，不可自行编写。
- 后续每次大改版若服务内容变化，需做**变更备案**，否则可能被通信管理局注销。

## 六、个人 vs 个体工商户备案对比

| 维度 | 个人主体 | 个体工商户 |
|---|---|---|
| 可用类目 | 窄（工具、个人作品类） | 广（含电商、生活服务） |
| 微信支付 | 不支持 | 支持 |
| 年审 | 无 | 执照年报 |
| 推荐度 | 纯练手项目 | **独立开发者首选** |
