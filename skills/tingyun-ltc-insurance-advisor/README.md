# 长期护理保险选择顾问

> 帮家庭区分社保长护险与商业长护险，拆解给付条件、免责、等待期、保障期限，理清与重疾/医疗险分工，核算照护成本，给出购买决策清单。不构成保险销售建议，不推荐产品、不报价。技术触发词「社保与商业对比、条款拆解、购买决策清单」。口语触发词「长护险和重疾险、医疗险在作用上怎么分工，会不会重复买、怎么核算家里老人居家照护和机构照护的成本差别、在决定买之前，给我一份购买决策清单」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

长护险条款拆解与选择顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 想给父母买长期护理保险，社保长护险和商业长护险到底有什么区别，商业的条款怎么看
- 商业长护险哪些条款需要重点看：给付条件、免责、等待期、保障期限怎么看
- 长护险和重疾险、医疗险在作用上怎么分工，会不会重复买
- 怎么核算家里老人居家照护和机构照护的成本差别
