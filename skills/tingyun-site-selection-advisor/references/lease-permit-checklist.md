# 租约审查与前置许可清单

本页给签约前与开业前的两张硬清单。涉及法律效力与行政审批，本清单仅供参考，须由持证人士与主管部门复核。

## 一、租约五查清单

| 审查项 | 看什么 | 风险信号（出现即须问清/改） |
|---|---|---|
| 租期 | 是否短于回本周期 | 短租期 + 高装修投入，回本前被赶 |
| 免租期 | 是否真免租、利息是否资本化 | "免租"却计入本金生息 |
| 续租权 | 是否自动续、涨幅约定 | 续租需重新竞价、涨幅无上限 |
| 转让权 | 能否转租/转让、是否要房东同意 | 禁止转让，退出时铺面砸手里 |
| 违约条款 | 提前退租赔多少、房东解约条件 | 退租赔全部押金+数月租金、房东可随意解约 |

补充核对：房屋规划用途是否允许本业态（餐饮须确认可办食品经营与排污）、房东产权证/转租权是否完整、交付标准与"现状交付"陷阱、押金退还条件。

## 二、前置许可办理顺序（以餐饮为例）

顺序原则：先确认"能不能办"，再"什么时候办"，避免装修完卡证。

1. **房屋用途核查**：确认规划用途允许餐饮，否则后续许可无法办理。
2. **环评/排污**：餐饮油烟、隔油池、排水许可，常需房东配合与物业同意。
3. **消防**：装修前报审图纸，完工后验收/备案，擅自改动会不通过。
4. **食品经营许可**：现场核查布局（生熟分开、三防），与装修强相关。
5. **营业登记**：以上齐备后办理。

## 三、非餐饮业态许可提示

- 零售：营业执照、特殊商品许可（如食品、药品、器械）按品类另办。
- 教培/医疗/危化：属许可条件严格行业，须先确认场地与资质匹配，再投入装修。

## 四、办理时点判断

- 卡点前置：房屋用途、排污、消防图纸——这些不定，后面全停。
- 可并行：营业登记准备材料与装修同步。
- 风险红线：未取得食品经营许可即营业属违规，会被责令停业。
