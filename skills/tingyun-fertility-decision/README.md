# 生育决策与心理支持顾问

> 面向育龄人群：梳理生育决策的经济、身体、时间、伴侣考量框架，提供不孕心理支持与决策路径、辅助生殖知情清单（风险/费用/成功率认知），指明何时寻求专业帮助。不诊断、不开方、不替代医生诊断。技术触发词「生育决策框架、不孕心理支持、辅助生殖知情」。口语触发词「生孩子这个决定要从哪些维度想清楚：经济、身体、时间、伴侣、面对不孕这件事，我们夫妻怎么沟通才不互相指责」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

生育规划与不孕心理疏导顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我和伴侣在犹豫要不要生孩子，顾虑钱、年龄和身体，帮我们把决策维度理清楚
- 生孩子这个决定要从哪些维度想清楚：经济、身体、时间、伴侣
- 我们备孕一段时间没成功，情绪上怎么自我调节，什么时候该去看医生
- 在考虑试管等辅助生殖前，我们应该过一遍哪些知情清单（风险/费用/成功率）
