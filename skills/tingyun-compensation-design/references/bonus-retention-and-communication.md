# 年终奖与留任奖金、沟通话术与薪酬表自检

配套专家包：tingyun-compensation-design（薪酬体系与调薪设计顾问）

本文件提供逐项对照、话术骨架与交付前自检清单。所有内容为一般性参考。

---

## 一、年终奖与留任奖金逐项对照

| 维度 | 年终奖 | 留任奖金 |
|---|---|---|
| 触发依据 | 公司整体经营结果 + 个人绩效 | 在职满约定周期 + 约定的个人交付达成 |
| 与业绩关联 | 强：随公司整体业绩与利润波动 | 弱：主要随在职时间与留存率波动 |
| 与回款关联 | 常见做法是挂钩回款、利润或营收达成 | 一般不直接挂钩公司回款 |
| 与个人表现关联 | 通过考核分档体现 | 通过是否达成约定的个人交付事项体现 |
| 金额确定性 | 弹性大，可能打折甚至不发 | 相对确定，承诺感强 |
| 发放时点 | 通常在年度考核结束后集中发放 | 可约定在周期届满时或分批发放 |
| 员工心理账本 | 常被当成"固定收入的一部分"，年初谈薪时算进到手 | 明确归为"额外一笔"，通常不进日常收入预期 |
| 适用场景 | 把全员努力与年度目标绑在一起 | 留住关键人、对冲外部挖角 |
| 常见毛病 | 员工当成固定收入 → 老板发少了、被认为是欠薪 | 条款含糊（"表现良好即发"）→ 到期争议大 |
| 对老板的含义 | 是"分蛋糕"，蛋糕大小随经营波动 | 是"买时间"，成本相对可预期 |

### 1.1 选择建议（决策树）

```
这笔钱想解决什么？
├─ 全员对齐年度经营目标 → 年终奖
│    ├─ 公司现金流随业绩波动明显 → 年终奖 + 回款/利润挂钩
│    └─ 需要稳定感但仍要对齐目标 → 年终奖 + 高比例固定
├─ 留住某几个关键人 → 留任奖金
│    ├─ 关键人已经在看外部机会 → 留任奖金 + 调薪 + 长期激励衔接
│    └─ 关键人暂无外部机会、只是防风险 → 留任奖金 + 明确周期与条件
└─ 两者都要 → 可叠加，但要说清各段触发条件互不替代
     └─ 叠加总额要落在薪酬包预算内，且分别列示
```

### 1.2 年终奖规则要写清的六项

1. **触发条件**：公司层面的达成条件（营收/利润/回款/经营目标），写明是"全部达成"还是"分级达成"。
2. **计算口径**：奖金池怎么算、个人分档系数怎么定、系数与发放金额的关系。
3. **分档标准**：各档对应的系数区间，以及绩效档次如何映射到系数。
4. **发放时点**：定在什么时间、发放的是哪一部分、是否有分批。
5. **不发或打折的情形**：哪些情况下发 0、哪些情况下按比例发，提前列明。
6. **离职处理**：发放日在离职员工的处理规则（如按在职月份折算、离职不发等），提前写明。

### 1.3 留任奖金规则要写清的六项

1. **服务周期**：从哪天算到哪天，中途离职如何计算。
2. **个人交付条件**：约定要完成的具体事项（尽量可客观核验，不用"综合表现优异"）。
3. **发放金额与时点**：金额或计算方式，周期届满后多久发。
4. **提前离职的处理**：全部不发、按比例发、还是按公司原因与个人原因区分（这条争议高，建议在发放前就与员工单独确认理解一致）。
5. **竞业与保密的配合**：若同时签有这两类协议，注明关系，避免条款互相冲突。
6. **可撤销条件**：公司经营异常、违规失职等情形下的处理，写明触发条件与判断流程。

### 1.4 两个常见漏洞

| 漏洞 | 表现 | 修法 |
|---|---|---|
| 双重计算 | 同一笔金额既进绩效段又进年度奖池 | 在结构表里明确归属段，绩效段不再重复计提 |
| 员工当固定收入 | 谈薪时把"去年拿到的年终奖"算作今年固定到手 | 沟通中明确区分"固定部分"与"随经营波动的部分"，并在 offer 口径上写清 |

## 二、股权激励与现金薪酬的衔接（现金侧视角）

| 衔接点 | 现金侧动作 | 判断标准 |
|---|---|---|
| 分位是否已到位 | 先完成现金分位判断，再评估股权是否需要承担额外拉力 | 若现金低于市场分位且差距明显，股权难以替代当期到手 |
| 长期激励段口径 | 现金包中的"长期激励"若实为年度奖/留任奖，要与股权分列 | 两者混在一个数字里，员工会理解为都是股权 |
| 兑现状态 | 股权方案与程序未走完的，不写入薪酬承诺 | 招聘与调薪沟通中不得把未落地股权当作固定收入 |
| 成本合并测算 | 股权成本与现金成本分开算、合起来看总负担 | 只看现金包会低估总成本 |
| 沟通分工 | 现金沟通讲当月到手与规则，股权沟通讲条件与不确定性 | 不用"做成了你会很值钱"这类表述替代具体说明 |

**边界提示**：股权工具选择、授予比例、归属与退出机制属于股权激励与员工持股专业包的范围；相关程序性事项（章程、激励计划、授予与登记）需由公司法务与专业机构复核，本包不提供该部分结论。

## 三、薪酬沟通话术

### 3.1 三段式结构

| 段落 | 讲什么 | 不讲什么 |
|---|---|---|
| 先讲依据 | 本轮调整对应哪类规则、为什么现在做（业务阶段、团队变化） | 不讲"公司决定"这类单一理由 |
| 再讲结论 | 调整多少、从什么时候生效、落在什么位置 | 不在会上现场改数字 |
| 再讲未来 | 下一次按什么规则走、员工自己可以看懂的判断条件 | 不给没有时间点的模糊承诺 |

### 3.2 宣布版（全员会，3~5 句）

> "这次调整对应的是年度调薪规则里的【绩效调薪 / 结构性调薪】，触发条件写在制度里，本次一共调整了 X 人。调整从【日期】起生效，体现在下月发放里。明年这一档怎么定，规则里写了达成条件，你们可以对照着看自己差在哪。"

注意：宣布会上不逐人解释、不做横向对比、不现场承诺额外金额。

### 3.3 主管一对一版（骨架）

1. 先问对方的感受："这次调整你有什么疑问，或者觉得哪里没说清？"
2. 再讲依据与结论：哪类触发、调整多少、生效时间。
3. 讲未来路径：下一次按什么条件评估，需要他做什么。
4. 收尾确认理解：确认对方明白了，没有新增承诺。

### 3.4 常见异议应答骨架

| 异议 | 背后诉求 | 应答骨架 | 不要这样答 |
|---|---|---|---|
| "为什么是他不是我" | 公平感缺失 | 确认对方的岗位价值与带宽位置 → 说明本次对应哪一类触发规则 → 给出他自己下次达到什么条件可进入同类调整 → 收口在标准而不是人的高低 | "他比你努力"（无标准、易对抗）、"下次吧"（无时间点） |
| "我工作量比他大" | 计价单位错位 | 岗位价值按影响范围与承担定，不按当前手头任务量定 → 若确实承担了额外职责，走结构性调薪通道而不是临时补贴 → 说明通道的存在 | 直接否认对方工作量（会引发第二轮争执） |
| "这点涨幅太少了" | 预期锚定 | 回到规则：本次触发类型与对应区间 → 说明区间内取值依据 → 给出下一次评估的时间点与条件 | 现场加钱（破坏规则，且下次无法谈） |
| "我要走了" | 情绪表达或真实意向 | 不辩解、不追问去向 → 先确认诉求是钱还是别的 → 若是钱，进入留存方案讨论（留任奖金、调薪节奏、长期激励衔接），仍由老板拍板 → 会后书面确认 | 追问"你要去哪"、当场承诺涨薪挽留 |
| "为什么我的涨幅比某人低" | 横向比较 | 回到各自触发类型与规则口径，说明差异来自触发类型不同 → 不披露他人具体数字 | 拿两人的具体数字对比 |

### 3.5 沟通禁忌清单

- 不在会上现场改数字（哪怕员工当场提出新情况）。
- 不用"以后会好""公司不会亏待你""你是我信任的人"这类无信息量表述。
- 不把个人情况与其他人横向对比。
- 不用股权预期替代现金沟通。
- 不做规则之外的单独承诺（否则下次谈判以它为基准）。
- 不在非正式场合先行透露未定的数字（会引发猜测与传话失真）。

## 四、薪酬表设计自检清单

### 4.1 结构层

- [ ] 现金红线（人力成本占收入比上限）是否已明确
- [ ] 三段比例是否与现金红线一致
- [ ] 岗位类型与浮动比例的对应关系是否清楚
- [ ] 固定部分是否足以支撑员工当期生活与招聘承诺
- [ ] 长期激励段是否与股权安排分列、口径一致

### 4.2 岗位与带宽层

- [ ] 每个岗位都在自己所属薪酬带内（越界项已列出并有说明）
- [ ] 薪酬带之间是否重叠或断裂，重叠是否会造成跨级抢人
- [ ] 带宽宽度与晋升、调薪机制是否自洽（窄带需要带宽扩张作为晋升空间）
- [ ] 要素打分是否有两人独立评分记录，差异大的要素是否已对齐岗位定义

### 4.3 内部公平层

- [ ] 同岗位内部差异是否可由能力、绩效、年限、区域四类因素解释
- [ ] 是否存在新人高于同岗资深者的倒挂，差额与处理方式是否已定
- [ ] 是否存在跨级倒挂，带宽边界与晋级切换规则是否需修订
- [ ] 压缩率是否在合理区间（低于 40% 说明绩效差异无法体现）
- [ ] 差额较大的个案是否已逐个有解释口径

### 4.4 绩效与规则层

- [ ] 各岗位挂钩比例建议是否与产出可归因程度匹配
- [ ] 指标数量是否不超过 3 个，口径能否在 30 秒内讲清
- [ ] 调薪规则是否写明触发类型、幅度区间、审批层级、生效时点
- [ ] 晋升规则是否写明依据、结果、频次三字段
- [ ] 结构性调薪与市场追赶调薪是否与绩效调薪分开计算
- [ ] 一年内调薪频次上限是否写明

### 4.5 激励与沟通层

- [ ] 年终奖的触发条件、计算口径、分档、发放时点、不发情形是否齐全
- [ ] 留任奖金的服务周期、交付条件、提前离职处理是否可客观核验
- [ ] 沟通话术是否与规则文本口径一致（规则里没写的别在会上说）
- [ ] 是否有沟通疑问的收集渠道与回复时限
- [ ] 股权部分的表述是否与可兑现状态一致

### 4.6 成本与合规层

- [ ] 人力总成本测算是否含社保、公积金、提成与奖金全年实际发生额
- [ ] 股权相关成本是否单独测算并合并查看
- [ ] 个税与社保基数变动对实发到手的影响是否已提示
- [ ] 劳动合同、规章制度变更程序相关事项是否已标记需专业复核
- [ ] 是否明确标注本方案不构成法律、税务或用工专业意见，需人工复核

## 五、交付物清单（完整项目应包含）

1. 现状盘点表（人数、岗位清单、现行结构、现行薪酬表）
2. 三段式结构比例表 + 现金红线说明
3. 岗位要素打分表（含评分人、评分时间、差异说明）
4. 价值序与薪酬带映射表（带宽上下限、基准）
5. 市场分位结论与复盘触发条件
6. 各岗位绩效挂钩比例表与指标草案
7. 调薪规则与晋升规则条款文本
8. 薪酬压缩与倒挂诊断表 + 处置方案
9. 沟通材料（宣布版、一对一版、异议应答表）
10. 薪酬表自检清单结果（含红项）
11. 待专业复核事项清单
