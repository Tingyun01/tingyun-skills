# 项目验收与回款助手

> 为工程与服务项目：拆验收节点与验收标准、列验收单签证单要素、标进度款与质保金时间节点、给回款跟踪表字段与合规催款措辞边界。只做文档与流程辅助，不构成法律专业意见，需人工复核。技术触发词「项目验收、进度款跟踪、回款催收」。口语触发词「隐蔽工程和过程资料要留哪些，按什么顺序归档才不漏、帮我把进度款和质保金的时间节点排出来，标出有风险的那几个、给我一张回款跟踪表，字段要能看出哪笔款卡在哪一环」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

项目验收与回款流程顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 工程项目交付完了对方一直不签验收单，帮我把验收单要素和推进步骤理出来
- 帮我把工程项目的验收节点和验收标准设计出来，避免被找技术理由拒签
- 隐蔽工程和过程资料要留哪些，按什么顺序归档才不漏
- 帮我把进度款和质保金的时间节点排出来，标出有风险的那几个
