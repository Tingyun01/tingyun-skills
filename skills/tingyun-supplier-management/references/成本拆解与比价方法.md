# 成本拆解与比价方法

## 一、三层价格结构

| 价格层 | 定义 | 用途 | 常见误区 |
|---|---|---|---|
| 名义单价 | 报价单上的数字 | 仅用于初筛 | 拿它直接比价、直接定供应商 |
| **到手成本** | 单价 + 模具摊销 + 运费 + 税费 + 账期资金成本 + 售后与呆滞摊销 | **决策用价格**，比价表必须算到这一层 | 漏算模具与账期，低估低报价厂 |
| 生命周期成本 | 到手成本 + 质量损失 + 切换成本 + 库存呆滞 + 断供损失 | 评估长期合作对象 | 忽略切换与断供的隐性代价 |

**判断标准**：**比价表的落脚点必须是到手成本这一层**。名义单价只出现在比价表的首列，作为对照基准存在。

## 二、到手成本逐项拆解表

把每一项都填上，填不到的写"待确认 + 谁去问"，不留空格。

### 2.1 成本项清单

| 项 | 计算口径 | 常见问法 | 备注 |
|---|---|---|---|
| 出厂单价 | 报价单数字，需确认是否含税 | "这个价是含税还是不含税？" | 口径不一致的比价无效 |
| 包装 | 内外箱、隔垫、贴标是否另计 | "包装是包含还是另算？" | 定制包装常常另计且不便宜 |
| 运费 | 目的地、方式、是否含装卸 | "送到我仓库的运费是多少？" | 到仓价，不是出厂价 |
| 税费 | 增值税、附加、可能的代扣代缴 | "发票税率多少？含不含税？" | 口径要跟财务对齐 |
| 模具费 | 金额、是否摊销进单价 | "模具多少钱？是一次性还是摊进单价？" | 见 2.3 三种算法 |
| 打样与试产费 | 每轮打样、试模、首件 | "打样怎么收费？试产单怎么算？" | 试产费常被忽略 |
| 认证与检测 | 第三方检测报告、认证费用 | "检测报告谁出、费用谁担？" | 关键品类才有 |
| 账期资金成本 | 见 2.4 | 需自算 | 你自己的资金成本，不是对方的 |
| 售后与返工摊销 | 见 2.5 | 需自算 | 用你自己的历史不良率 |
| 呆滞与报废摊销 | 见 2.6 | 需自算 | 用你自己的库存周转数据 |
| 切换成本 | 模具转移、打样、爬坡、双源并行 | 需自算 | 只在评估长期对象时算 |

**差异说明这一栏不能空**。比价只给数字不给理由，用户不知道该选谁；给了理由，他才知道自己在为什么付钱。

### 2.3 模具摊销的三种算法

| 算法 | 公式 | 适用 | 陷阱 |
|---|---|---|---|
| 按预计总用量摊 | 模具费 ÷ 预计总用量（件） | 你能规划总用量的常规品 | 预计用量估大了，摊销就低，实际用不完就亏 |
| 按生命周期总用量摊 | 模具费 ÷ 该模具生命周期预计产出 | 生命周期明确的品 | 生命周期算短了，单件成本被高估 |
| 按首单全摊 | 模具费 ÷ 首单数量 | 小批量试单、试产阶段 | 首单数量小，单件成本看起来极高，误判供应商 |

**判断标准**：**按"预计总用量"摊，同时在表里注明这个预计数字从哪来**（历史销量 + 现有渠道排期 + 客户预测）。如果预计总用量就是首单量，那这家供应商的单件成本天然高——但这不代表它贵，可能只是它更适合小单。

**模具所有权必须写清楚**：谁付钱归谁、存放在谁那里、供应商是否有权处置、合作结束后模具如何转移、模具损耗如何认定。这几点一旦含糊，合作结束时会很难谈，属于法律问题，条款起草请交给执业律师。

### 2.4 账期资金成本测算

```
账期资金成本单价 = 单次订单金额 × 年化资金成本率 × 账期天数 ÷ 365 ÷ 单次订单数量

年化资金成本率取值（按你自己的情况填，不要套用别人的）：
  现金充足、有低成本融资渠道：可填 0.05~0.08
  用自有资金但机会成本明显：可填 0.08~0.12
  靠短期借款周转：按实际借款利率填

单次订单金额 100,000 元、账期 60 天、年化 0.10：
  100,000 × 0.10 × 60 ÷ 365 = 1,643 元
  按每批 2,000 件分摊 → 单件 0.82 元
```

**判断标准**：**账期带来的资金成本通常大于同样金额下的价格谈判收益**。这是很多中小卖家忽略的账——为了省 5% 单价而接受 60 天账期，往往算下来是亏的。谈判时正确的问法是"价格能否降、账期能否延"，不要用其中一项直接换另一项，要分开谈。

### 2.5 售后与返工摊销

```
售后返工摊销单价 = 你在该供应商上的年度售后成本 ÷ 年度到货件数

售后成本构成：
  返工/补发货值（按补发数量 × 单位成本）
  客诉处理与补偿（退货、折价、补偿券的实际金额）
  二次物流（挑出、返厂、回来的运费与装卸）
  质量检验的内部工时（挑检、全检的投入）
  平台/渠道侧的扣分与赔付（若适用）
```

**必须用你自己的历史数据**。用行业通用不良率去套，等于给这家供应商白送一个免费数字。首次合作没有历史数据时，用两种极端做区间估算：乐观（行业低位）与保守（你自己的历史峰值），把区间给用户，别给单点。

### 2.6 呆滞与报废摊销

```
呆滞报废摊销单价 = (年度呆滞损失 + 年度报废损失) ÷ 年度出货件数

呆滞来源：预测偏差、卖不动、SKU 过多、渠道调整
报废来源：运输破损、质检淘汰、效期、跌价、平台下架
```

**判断标准**：**SKU 越多、预测周期越短，呆滞摊销越高**。这直接影响"该做多少 SKU"的决策——多一个 SKU 不只是多一个模具费，还多一份呆滞摊销，而这项在报价单上完全看不见。

## 三、降本路径对照表

### 3.1 四条路径的性质区分

| 路径 | 具体动作 | 性质 | 验证方式 | 常见失败 |
|---|---|---|---|---|
| 设计与规格 | 减件、减工序、换通用规格、改材料但不改效果要求 | **真降**（对手艺材料无要求放松） | 出一版新 BOM 对比成本 | 降了配置却降不了售价 |
| 工艺与工装 | 共模、拼版、多穴、提高模具寿命、工序合并 | **真降** | 让工厂出工艺对比方案 | 工厂不愿承担模具风险，要你承担 |
| 批量与集中 | 合并下单、合并提货、集中到一地再分拨 | **交换或真降**（视物流结构） | 算单位物流成本随批量的变化 | 单量下降导致的价格上浮吃掉收益 |
| 商务与付款 | 账期换价格、年度量换阶梯价、包销换单价 | **交换**（有对价） | 列可让步项与不可让步项 | 换来的是条件不是能力，要标清楚 |

### 3.2 谈判议题表（模板）

```
议题            我的诉求              可让步项              不可让步项          对方可能的反驳
单价            目标价 ________       批量/账期/付款方式     质量与规格要求      "量不够做不了这个价"
模具费          摊进单价或分期        模具保管地             所有权归属          "模具本来就贵"
账期            延长到 ___ 天         现款比例略降           对已验收货的付款     "账期长我资金压力大"
交期            承诺到货日            淡旺季浮动幅度         大促期刚性排产      "旺季谁都难承诺"
包装            改为通用包装          尺寸微调             抗压与外观          "你的量配不上通用箱"
```

**谈判顺序建议**：先谈**规格与用量**（把"我要什么"定清），再谈**价格**，再谈**条件**。顺序反了——先谈价格再谈条件——容易被"价格降了但你得接受这些条件"打包。

### 3.3 压价的正确与错误做法

| 做法 | 判断 | 说明 |
|---|---|---|
| 引入第二家同规格报价做参照 | 可用 | 参照要有具体型号与口径，不是随手一个网上价 |
| 以年度量与长期稳定下单换阶梯价 | 可用 | 交换关系，写清条件 |
| 用账期延长期限换单价下降 | 可用 | 交换关系，算清资金成本再算 |
| 要求供应商在不改规格的前提下降价 | 风险高 | 通常换来减料、减工序、拖交期，三个月后以质量问题回来 |
| 用"别家更便宜"施压但不给证据 | 无效 | 对方只要问一句"哪家、什么价"就无法接话 |
| 压到供应商无利润的价格 | 无效 | 供应商不会做亏本生意，成本会从别处出来 |

**判断标准**：**任何一次价格下降，都要问"钱是从哪里省出来的"**。答案是"工艺改进/批量集中"，是降本；答案是"材料换便宜一档/工序减一道/交期放宽"，是转移，不是降本。你要做的是把这两种分开记账。

## 四、成本口径的常见错误

1. **税口径不一致**：含税价与不含税价直接比，差一个税率级别的钱。
2. **运费口径不一致**：送到仓价与出厂价直接比。
3. **MOQ 未计入**：A 厂单价低但 MOQ 是你的三倍，多出来的库存资金与呆滞风险没算。
4. **模具费重复计算**：既摊进单价又在表外单列。要问清"这个单价里含不含模具"。
5. **摊销基数错误**：按首单量摊模具，等于把整副模具成本摊在很小的批量上，看起来这家单价偏高，实际未必。
6. **忽略账期**：用现款价对比 60 天账期价，结论会完全反过来。
7. **忽略坏料与不合格**：低价通常伴随更高的不良率，售后摊销会吃掉价差。
8. **忽略切换成本**：拿现供应商的历史交付优势当作沉没成本忽略。切换成本是要真实发生的，只是它不出现在报价单上。

## 五、这套逻辑不成立的情形

- **量级太小**：模具摊销、检测费、切换成本摊到每件上会畸高。此时应放弃年度框架思路，改用现货小单、按次比价。
- **产品还在测款阶段**：需求量不确定，此时算资金成本与呆滞摊销意义不大，重点是打样速度与小批量柔性。
- **价格由市场决定、供给稀缺**：讨价还价空间本就有限，重点应转到产能预留与交期优先级上。
- **对方报价口径与你完全不一致且不愿澄清**：成本拆解无法进行。此时该做的是换供应商评估，而不是继续猜。
