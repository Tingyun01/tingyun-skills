# 租赁常见坑与线上线下协同选址

## 一、商铺租赁常见坑信号

出现任一信号，建议暂停签约、先核实：

| 坑 | 表现 | 后果 |
|---|---|---|
| 产权瑕疵 | 房东无产权证、转租权存疑 | 被真房东清退、租金打水漂 |
| 用途不符 | 写"商业"但禁餐饮/禁特定业态 | 办不下许可，无法经营 |
| 现状交付陷阱 | "按现状交付"隐瞒漏水/违建/前租户欠费 | 接手即大修或背债 |
| 免租利息化 | 免租期金额计入本金生息 | 表面免租实际更贵 |
| 押金难退 | 退还条件模糊、扣款无标准 | 退租时被大额克扣 |
| 相邻权纠纷 | 楼上住户/周边反对餐饮油烟 | 投诉导致停业整改 |
| 自动续租陷阱 | 默认续租且租金跳涨 | 想退退不掉、想留被涨价 |

## 二、签约前三步核实

1. 查产权：要求看房产证与房东身份，转租须有原房东书面同意。
2. 查用途：到主管部门或物业确认本业态可办证。
3. 查历史：问清前租户为何退、有无欠费与纠纷。

## 三、线上线下协同选址逻辑

选址不能只看线下截流，要把"线上可触达人群"纳入捕获率测算：

- **社区店**：重复购与私域运营为主，重周边 1–3 公里常住人口密度，线上做熟客复购与口碑。
- **商圈店**：重截流与曝光，线上做引流与团购，到店半径可放大但要算获客成本。
- **目的性业态**（如教培、体验）：重周边配套与交通，线上做精准人群触达。

判断方法：把"线上可触达且会到店的人群"估一个数，加进捕获率测算的总盘子；当线上获客成本持续高于到店客毛利的获客预算，说明位置与渠道不匹配，要么换址要么换渠道结构。

## 四、决策检查

- 线下截流覆盖不了租金时，先看线上能否补足，不能补足则换址。
- 线上引流强但到店不便（停车难、动线差），转化率会塌，须一并评估。
