# 隐蔽工程留证、验收节点与质保付款安排

> 用途：给出隐蔽工程该留什么证、每个节点该验什么、工期延误和质量问题的处理路径、保修依据与付款节奏安排。
> 内容为清单与流程梳理，不构成法律专业意见，需人工复核。

## 一、隐蔽工程留证四件套

隐蔽工程封闭后无法回溯，业主举证处在被动位置。留证必须前置，且留证形态要满足"能对应到具体位置与具体时间"。

### 1.1 四件套

| 留证项 | 具体要求 | 常见问题 | 作用 |
|---|---|---|---|
| 影像资料 | 原始文件，不压缩不裁剪；带拍摄时间；画面中含参照物（开关面板、门套、管道走向标识、墙面尺寸标注） | 只有局部特写，看不出在哪；只有压缩图，细节不可辨 | 证明工程位置与状态 |
| 隐蔽工程验收记录单 | 按工序逐项填写，双方签字，各方持有一份 | 事后补签，或只签一页总表 | 证明双方已共同确认该工序、且封闭在此确认之后 |
| 过程记录 | 打压试验数值、绝缘电阻值、闭水试验时长与蓄水高度、蓄水观察记录 | 只拍照不记数值 | 证明性能达到约定 |
| 材料凭证 | 出厂合格证、质检单、进场验收记录、型号与批次、可追溯到具体用量 | 只留合格证不留型号，无法核对用了哪一批 | 证明实际材料与合同约定一致 |

### 1.2 影像留证的具体做法

| 做法 | 说明 |
|---|---|
| 开拍前先拍参照物 | 先拍开关面板、门套或已完成的地面，再拍管线，形成空间关系 |
| 同一工序拍"远-中-近"三张 | 远景看整体走向，中景看节点，近景看接口与固定方式 |
| 管线走向要能拼出完整路径 | 每个房间单独拍不够，要让接口处有重叠画面 |
| 标尺或卷尺入镜 | 关键尺寸（管径、线径、间距、蓄水高度）要有参照物 |
| 关键节点单独拍 | 三通、接线盒、分水器、防水翻边、闭水口、地漏与过水口 |
| 保留原文件与文件路径 | 分类命名（如 2024-05-12_卫生间_水路_原图_01），集中存一处并做备份 |
| 时间信息不被抹除 | 不要用修图工具去掉时间水印 |

### 1.3 各工序的留证重点

| 工序 | 必拍内容 | 必测记录 |
|---|---|---|
| 拆改 | 拆除前后对照、墙体属性判断依据（如需）、已剔凿的墙体剖面、垃圾堆放点 | — |
| 水路 | 冷热水管走向、分水器位置、管道接口、墙面开槽、管道固定方式 | 打压试验压力与保压时长、结果判定 |
| 电路 | 线管走向、线径、回路走向、接线盒内部接线、强弱电分管距离 | 绝缘电阻测试数值、接地测试、通断测试 |
| 防水 | 基层处理状态、涂刷遍数与高度、门口与管根附加层、涂刷完成面 | 闭水试验蓄水高度、时长、观察记录、有无渗漏 |
| 吊顶与轻质隔墙 | 龙骨间距与固定方式、吊杆、板材层数、检修口位置 | — |
| 瓷砖铺贴 | 空鼓检查位置与数值、找平层、排版起铺点、缝隙均匀度 | 空鼓率抽检记录、平整度检测 |
| 地暖与找平 | 分水管布局、埋管深度与间距、找平厚度 | 打压试验记录 |

### 1.4 两条不能破的底线

| 底线 | 原因 | 替代方案 |
|---|---|---|
| 未验收不封闭 | 封闭后无法回溯，复查只能靠破坏 | 确有工期压力时，约定带检验条件的隐蔽工程封盖，验收不合格时由责任方承担开启费用 |
| 验收记录当场签 | 事后补签的记录证明力差别很大 | 现场拍照记录当日签字；确实无法当场签的，约定补签时限与逾期视为确认 |

## 二、六个验收节点检查表

| 节点 | 验收内容 | 检查方法 | 通过标准 |
|---|---|---|---|
| 开工交底 | 现场原状、拆改范围、图纸与报价单逐项确认、进出路线与垃圾堆放点、施工时段 | 现场逐项对照 | 交底记录双方签字；原状影像留存 |
| 水电验收 | 点位数量与位置、线管与线径、回路划分、强弱电分管、水路走向与固定、开关底盒、检修口 | 现场逐项目视 + 查验打压与绝缘测试记录 | 与图纸和报价单一致；测试数值在约定范围；验收记录单签字 |
| 防水验收 | 基层处理、涂刷高度与遍数、附加层、闭水试验 | 目视 + 闭水试验 | 涂刷高度与遍数符合约定；闭水试验无渗漏；记录签字 |
| 泥木验收 | 瓷砖铺贴（空鼓、平整度、排版、缝隙）、找平厚度、防水层成品状态、吊顶标高与平整、门槛石与过门石 | 空鼓锤逐片敲击 + 卷尺与靠尺抽检 | 空鼓率在约定范围（无约定时按当地通行做法并在验收记录中写明判定值）；标高与平整符合约定 |
| 油漆验收 | 墙面平整度、阴阳角顺直、涂刷遍数与均匀度、成品保护完好 | 靠尺与目视 | 平整度符合约定；无透底、流坠、明显色差；保护完好 |
| 竣工验收 | 整体观感、功能性（给排水通畅、电路负荷、门窗启闭、插座通电）、清洁与垃圾清运、资料交付 | 逐房间逐项功能测试 | 功能全部正常；资料齐备（质量保修书、材料设备说明书、保修单、环保说明书）；问题清单闭环 |

### 2.1 竣工验收的资料交付清单

| 资料 | 依据 | 备注 |
|---|---|---|
| 住宅室内装饰装修质量保修书 | 《住宅室内装饰装修管理办法》第三十条：验收合格后，装饰装修企业应当出具住宅室内装饰装修质量保修书 | 书面出具，写明期限与范围 |
| 材料设备说明书、保修单、环保说明书 | 同办法第三十一条：由装饰装修企业负责采购装饰装修材料及设备的，应当向业主提交说明书、保修单和环保说明书 | 逐项对应甲供与乙供材料 |
| 竣工图纸或变更汇总 | 实际施工与原图纸的差异 | 变更多时尤其必要 |
| 隐蔽工程验收记录单汇总 | 留证四件套中的记录部分 | 按工序装订 |
| 保修联系方式 | 合同约定 | 含联系人、电话、地址 |

### 2.2 空气质量检测的触发条件

《住宅室内装饰装修管理办法》第二十九条：装修人委托企业对住宅室内进行装饰装修的，装饰装修工程竣工后，空气质量应当符合国家有关标准。装修人可以委托有资格的检测单位对空气质量进行检测。检测不合格的，装饰装修企业应当返工，并由责任人承担相应损失。

**动作**：合同中写明"竣工后由甲方委托具备资质的检测单位进行室内空气质量检测"，并写明检测不合格时的处理方式（返工、费用承担、复检次数）。

### 2.3 验收不合格的处理闭环

```
发现问题 → 书面整改通知（部位、现象、依据条款、完成时限）
        → 整改完成 → 双方共同复验并签字
        → 复验合格 → 关闭；复验仍不合格 → 升级处理
```

每一步留材料：通知、整改前后对比照片、复验记录。闭环的证据是"有始有终"，不是"改过一次"。

## 三、工期延误责任归属判断表

司法处理这类纠纷的基本思路是**先分延误原因归属**。装修方原因引起的延误，按合同约定支付逾期违约金；没有违约金约定的，可以主张实际损失。消费者一方原因引起的延误（未及时结清阶段性款项、未及时验收导致停工、自身改动方案或增项、未及时购买材料），相应后果由消费者承担。

| 延误原因 | 归谁 | 依据与处理路径 | 需准备的材料 |
|---|---|---|---|
| 施工进度安排不合理 | 施工方 | 按合同约定主张逾期违约金；无约定的主张实际损失 | 合同条款、开工日与实际竣工日对比 |
| 质量问题导致返工、达不到要求 | 施工方 | 返工 + 整改期限 + 逾期违约金；造成损失的另行主张 | 验收记录、整改通知、损失凭证 |
| 设计方案改动 | 看提出方与是否超出原范围 | 业主提出且非施工方设计缺陷 → 业主承担；施工方设计问题 → 施工方承担 | 变更签证单、提出方签字 |
| 业主未按时付款 | 业主 | 相应的工期顺延由业主承担 | 付款凭证与约定付款日 |
| 业主未按时验收导致停工 | 业主 | 相应顺延由业主承担 | 验收通知送达记录 |
| 业主未及时购买甲供材料 | 业主 | 相应顺延由业主承担 | 采购与到货记录、催告记录 |
| 材料未到场（乙供） | 施工方 | 若合同约定采购期限则按约定判断 | 采购约定、到货记录 |
| 物业批准、报批未成就 | 按合同是否约定为开工前置条件 | 约定为前置条件的顺延 | 物业与主管部门往来记录 |
| 隐蔽工程等待定夺 | 看谁的原因导致变更 | 业主改方案 → 业主；施工方应勘察未发现 → 施工方 | 变更通知、等待期记录 |
| 不可抗力 | 按不可抗力规则 | 及时通知、提供证明、协商处理 | 证明材料、通知记录 |

### 3.1 违约金主张的三点

| 要点 | 说明 |
|---|---|
| 看有无约定 | 有约定按约定；无约定可主张实际损失，但实际损失的举证难度高于违约金 |
| 看约定是否过高 | 约定金额明显高于实际损失的，对方可能请求调整，条款是否会被调整由裁判机构认定 |
| 看比例与上限 | 约定每日标准与总额上限，核算总额是否在上限内；超过上限部分不主张 |

### 3.2 一句要记住的话

**"业主自身原因导致的延误，相应后果由业主承担"**——这句话写在合同里要写，在审查时也要看：合同是不是把业主付款、验收、采购的义务时间写得极其模糊，导致延误后施工方主张"你付款晚了所以我延期"，而业主拿不出自己按期履约的记录。**付款凭证、催告记录、验收通知送达记录，都属于合同履行证据。**

## 四、质量问题处理路径

### 4.1 处理顺序

```
第 1 步  固定现状
  影像资料（含参照物）+ 书面记录 + 第三方检测
  第三方检测适用情形：涉及主体结构、渗漏原因不明、双方对成因有分歧

第 2 步  书面通知整改
  写明：问题部位、具体现象、依据条款、要求完成时限、逾期处理方式
  用可留痕的方式送达（快递、聊天软件文字、短信、邮件），保留送达凭证

第 3 步  约定复验
  整改后由双方共同复验并签字；不认可的按第 4 步走

第 4 步  争议渠道
  先协商 → 调解 → 仲裁或诉讼（按合同约定的路径）
  《住宅室内装饰装修管理办法》第二十五条：工程发生纠纷的，可以协商或者调解解决；
  不愿协商、调解或协商、调解不成的，可以依法申请仲裁或者向人民法院起诉

第 5 步  费用与工期主张
  整改期间的实际支出凭证固定（票据、付款记录）
  工期主张按第三节的延误责任判断表区分责任方
```

### 4.2 质量责任的对等规则

民法典合同编承揽合同部分的基本规则：承揽人交付的工作成果不符合质量要求的，定作人可以合理选择请求承揽人承担修理、重作、减少报酬、赔偿损失等违约责任；而定作人中途变更承揽工作要求，给承揽人造成损失的，应当赔偿损失。

**落到审查上，两面都要看**：
- 业主权利：成果不合格时可选择修理、重作、减少报酬、赔偿损失，不是只有"返工"一种
- 业主责任：中途变更要求造成施工方损失的，要赔偿；成果本身不合格时不能只付钱不担责

### 4.3 证据意识的三条实操提示

| 提示 | 说明 |
|---|---|
| 通知必须留痕 | 口头反映整改，对方可以说不记得。用可留痕方式送达并保存凭证 |
| 检测在争议早期做 | 拖久了现场被修复、痕迹被覆盖，检测就没有意义 |
| 别自己先修再索赔 | 自行修理后主张费用难以核算；确需先修的，修理前先做现状记录与第三方检测 |

## 五、保修依据与条款要点

### 5.1 法定依据

《住宅室内装饰装修管理办法》（建设部令第110号，2002年3月1日施行）第三十二条：**在正常使用条件下，住宅室内装饰装修工程的保修期限下限为二年，有防水要求的厨房、卫生间和外墙面的防渗漏为五年。保修期自住宅室内装饰装修工程竣工验收合格之日起计算。**

配套：
- 第三十条：验收合格后，装饰装修企业应当出具住宅室内装饰装修质量保修书
- 第三十一条：由装饰装修企业负责采购装饰装修材料及设备的，应当向业主提交说明书、保修单和环保说明书

### 5.2 合同条款要点

| 条款 | 要点 | 缺口表现 |
|---|---|---|
| 保修期限 | 写明下限，不得低于法定要求 | 写"质保1年" |
| 保修起算日 | 竣工验收合格之日 | 写交付使用之日、尾款付清之日 |
| 保修范围 | 分施工质量与产品自身质量，列除外责任 | 只写"质保X年"，无范围 |
| 响应时限 | 接到报修后的响应时限与到场时限分别写 | 完全不写 |
| 质量保修书 | 出具义务与时间 | 不写 |
| 售后联系 | 联系人、电话、地址、响应方式 | 不写 |
| 保修金退还 | 退还条件、时点、方式 | 只口头说留5% |
| 保修与责任划分 | 施工问题与产品问题的分界 | 不写导致推诿 |

### 5.3 保修范围划分的对照

| 现象 | 通常归属 | 依据与说明 |
|---|---|---|
| 墙砖空鼓、脱落 | 施工责任 | 铺贴工艺问题（基层处理、粘结材料、养护） |
| 地面返潮、渗漏 | 施工责任（防水施工） | 防水涂刷与闭水试验环节的问题 |
| 水管接头漏水 | 施工责任 | 焊接与安装工艺 |
| 电路跳闸、局部不通 | 施工责任 | 线路敷设与接线工艺 |
| 墙面开裂 | 视成因 | 材料收缩与工艺做法问题常为施工责任；结构变形引起的需先做结构判断 |
| 门窗合页、把手松动 | 施工责任 | 安装与固定 |
| 涂料色差、滚痕 | 视程度 | 明显色差与涂刷不匀常为施工责任；批次色差属产品责任 |
| 洁具划伤、崩边 | 产品责任 | 属供货方或厂商责任 |
| 地板起拱 | 视成因 | 铺设工艺与含水率问题常为施工责任；产品自身变形属产品责任 |
| 柜体变形、板材开裂 | 视成因 | 工艺与养护问题常为施工责任；材料自身属产品责任 |
| 五金件损坏 | 产品责任（正常使用范围） | 人为损坏另议 |

**落点**：合同里不写清划分，出问题时施工方会以"产品问题"推掉施工责任，业主也难以举证属于施工工艺问题。合同阶段写清，是成本很低的一次投入。

### 5.4 保修期内的动作节奏

| 时间点 | 动作 |
|---|---|
| 竣工验收合格当日 | 记录起算日；索取质量保修书与材料资料 |
| 保修期内定期自查 | 每个雨季前检查防水相关部位（卫生间、外墙面、阳台、窗框渗水） |
| 保修期内发现问题 | 按书面报修流程走，保留报修与响应记录 |
| 保修期届满前 | 提前核对未处理事项；确认保修金退还条件是否成就 |
| 保修期届满后 | 索取保修金（如有）；做一次整体检查留存记录 |

## 六、付款节奏与风控

### 6.1 节点结构参考

| 节点 | 对应工程内容 | 比例参考 | 支付前提 |
|---|---|---|---|
| 开工 | 材料进场、水电开工 | 较小比例 | 合同生效、图纸确认、开工前置条件成就 |
| 水电验收 | 水电改造完成并验收合格 | 较大比例 | 隐蔽工程验收记录单双方签字 |
| 泥木验收 | 泥木工程完成并验收合格 | 较大比例 | 阶段验收合格 |
| 油漆验收 | 油漆工程完成并验收合格 | 中等比例 | 阶段验收合格 |
| 竣工验收 | 整体验收合格、资料交付、垃圾清运完毕 | 尾款部分 | 竣工验收合格 + 质量保修书出具 |
| 保修期后 | 无 | 无 | 保修金按约定退还 |

比例属谈判范畴，合同中没有法定比例要求。上表用于判断结构是否合理：结构合理性的判据是"每期付款对应的工程量与该期金额大致匹配"。

### 6.2 四条风控动作

| 动作 | 理由 | 具体做法 |
|---|---|---|
| 不早付 | 开工前大额付款意味着款项在未开工时已交出，主动权全无 | 把大比例节点放在水电验收之后 |
| 每期付款绑定一次验收 | 让付款成为施工的约束而非奖励 | 写"验收合格并签署验收记录后__日内支付" |
| 留尾款 | 约束售后与保修响应 | 保留一定比例至保修期结束，退还条件写进合同 |
| 付款主体一致 | 合同主体、收款主体、开票主体三者一致是履约能力的基本信号 | 公司合同由个人账户收款是风险信号；付款时备注用途并留存凭证 |

### 6.3 合同里还要写进这三条

| 条款 | 内容 |
|---|---|
| 变更款与进度款分开 | 变更款需先完成签证手续，与进度款分别支付 |
| 材料款与人工款是否分离 | 如分离，写明支付条件与比例 |
| 逾期付款责任 | 业主方逾期付款的违约标准与对应的工期顺延天数 |

### 6.4 付款凭证的留存

| 环节 | 凭证 |
|---|---|
| 每笔付款 | 付款凭证（备注用途）、对应验收记录单的复印件 |
| 收款方信息 | 收款账户名称、户名与合同主体一致性核对记录 |
| 变更款 | 变更签证单 + 付款凭证，两者日期顺序须符合"先签证后付款" |
| 甲供材料 | 采购发票或收据、进场验收记录、保管与损耗记录 |
| 保修金 | 退还条件记录、退还凭证 |
