# 共同财产识别与房产分割（规划辅助用）

> 以下内容用于梳理思路，不构成法律意见，具体认定以属地规定及持证专业人士意见为准。

## 一、共同财产识别清单

通常属共同财产（以婚姻存续期间、属地规定为准）：
- [ ] 工资、奖金、劳务报酬
- [ ] 生产、经营、投资收益
- [ ] 婚姻期间购置的房产、车辆、存款
- [ ] 住房补贴、公积金、养老金中婚姻期间部分
- [ ] 知识产权收益（婚姻期间取得）

通常属个人财产：
- [ ] 婚前财产
- [ ] 因受到人身损害获得的赔偿/补偿
- [ ] 遗嘱或赠与合同中确定只归一方的财产
- [ ] 一方专用生活用品
- [ ] 夫妻另有书面约定的，从约定

提示：有婚前协议或婚内财产约定的，优先按约定处理，但约定效力需依法判断。

## 二、房产分割的几种处理路径

房产是离婚财产分割中较常见的争议点，关键看三个变量：

### 变量1：出资与登记
- 婚前一方首付、登记其名下、婚后共同还贷 → 房产常归登记方，共同还贷及增值部分另一方可能获补偿
- 婚后共同出资、共同登记 → 通常作为共同财产分割
- 一方父母出资 → 需区分是借款还是赠与、赠与是否指定归一方

### 变量2：贷款
- 剩余贷款由谁继续偿还需在协议中明确
- 变更贷款人/过户涉及银行同意，操作有前置条件

### 变量3：加名
- 婚后加名可能被视为对另一方的赠与或财产约定，影响分割比例（具体以证据与规定为准）

### 常见处理选项
| 情形 | 处理选项 |
| --- | --- |
| 一方要房 | 得房方补偿另一方（含共同还贷+增值），并承担剩余贷款 |
| 双方都不要 | 出售分割价款 |
| 无法协商 | 诉讼由法院依法处理 |

## 三、需立即转人工的情形

- 房产涉及父母出资且性质不清；
- 对方可能转移房产或拒不配合过户；
- 涉及多套、境外或共有产权复杂情形。
