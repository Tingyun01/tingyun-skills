# 合同到期处理 · 续约决策 · 五个高频漏项

> 用于合同生命周期末段的判断与交接。本文是流程与清单辅助，不构成法律专业意见，需人工复核。

## 一、到期不是"到那天再说"

合同到期前 60 天就该有动作。多数纠纷不是因为合同没写，而是**没人做决定**：不续、续、还是按原条件继续执行，空着就拖成了争议。

### 时间轴（倒排）
| 时点 | 要做的事 | 产出 |
|---|---|---|
| 到期前 60 天 | 盘点该合同及所有关联合同/补充协议的到期日 | 到期清单（含续约、终止、顺延三类） |
| 到期前 45 天 | 判断价值与替代性：还做不做、有没有更好的供应商/客户 | 续约建议初稿 |
| 到期前 30 天 | 定决策人、谈条件、评估谈判空间 | 决策记录（谁定的、依据是什么） |
| 到期前 15 天 | 走内部审批；如需续约拟条款或续约意向 | 审批记录 / 意向书 |
| 到期前 7 天 | 发书面确认函（续约意向或终止通知、交接安排） | 书面函件 + 送达证据 |
| 到期日 | 执行：交接、停工、停止服务、结算截止 | 交接单 / 结算确认 |
| 到期后 7 天 | 完成资料归档与台账标注 | 台账关闭/续期标记 |

## 二、续约 / 终止 / 按原条件继续 —— 三选一判断表

| 判断项 | 倾向续约 | 倾向终止 | 倾向继续执行 |
|---|---|---|---|
| 履约情况 | 对方履约良好，收益稳定 | 出现持续违约、付款严重拖延 | 双方都想先维持，等新条件 |
| 替代成本 | 更换供应商/客户成本高、切换期风险大 | 替代资源充足或业务已调整 | 换人换流程的隐性成本高于收益 |
| 争议状态 | 无未决争议 | 有未决争议且无法协商 | 有争议但金额小、可先挂账 |
| 财务状况 | 结算正常 | 主体异常（失联、经营异常、被执行） | 暂不追究，先保关系（需书面留痕） |
| 战略契合 | 业务方向一致 | 业务方向调整 | 中长期待定 |

**决策必须留痕**：谁决定、依据什么、什么时候定的、是否有对方书面确认。四要素缺一，日后无法解释决策合理性。

### 终止前的交接清单（8 项）
1. 已完成/未完成工作量的确认与记录；
2. 已交付物清单与接收确认；
3. 费用与已付款核对（多退少补的处理）；
4. 资料与文件交接（纸质与电子，含账号/权限移交说明）；
5. 设备/物料/场地返还记录（数量、状态、签收）；
6. 质量责任与保修责任的处理约定（是否继续、期限）；
7. 保密、数据、知识产权的延续义务确认；
8. 后续联系人与通知方式确认（避免断联）。

### 终止通知的写法要点
- 写明终止依据（合同条款号 + 触发事实 + 日期）；
- 写明终止生效时间；
- 写明善后安排（结算、交接、资料、保密延续）；
- 送达方式与送达记录要留存；
- **不写情绪化指责、不夸大后果、不使用断言式措辞**；定性（是否构成违约、是否需赔偿）交由专业人士判断。

## 三、五个"合同签了但没人做"的高频动作

### 动作 1：履约节点提醒
- **触发条件**：合同有付款节点或交付节点，且提醒规则未落到责任人；
- **该做什么**：把每个节点写进台账，挂责任人 + 提前量（7/14 天），设 L1–L4 升级；
- **留痕**：台账记录 + 提醒发出记录；
- **完成标准**：每个节点都有责任人和日期，无"待定"责任人。

### 动作 2：变更书面化
- **触发条件**：出现任何"再多做一点""价格再商量""时间往后挪""按新方案来"的口头信息；
- **该做什么**：三问判定 → 登记 → 评估 → 内部审批 → 出变更单 → 双方签 → 回写台账；
- **留痕**：变更单原件（编号、日期、双方签章）；
- **完成标准**：台账中该变更状态为"已变更"且关联文件可查。

### 动作 3：验收留痕
- **触发条件**：交付物已发出或现场工作已完成；
- **该做什么**：先发书面验收申请 → 收验收单 → 有遗留问题则列整改清单并闭环 → 复验留痕；
- **留痕**：验收申请 + 签收记录 + 验收单 + 整改闭环记录；
- **完成标准**：验收单双方签署或有明确的"逾期未回复"记录在案。

### 动作 4：结算对账
- **触发条件**：出现任一情况——节点已确认、变更已签、合同到期前 30 天、账龄超过 60 天；
- **该做什么**：按 A 应做 / B 已做 / C 已开票 / D 已收 四栏逐笔核；发对账单请对方书面确认；
- **留痕**：对账单 + 对方确认或异议记录 + 发票与回单；
- **完成标准**：差异项全部有归因和下一步动作，无"待查"项挂空。

### 动作 5：到期决策
- **触发条件**：合同或关联协议在 60 天内到期，或有自动顺延条款且临近触发日；
- **该做什么**：判断表选续约/终止/继续 → 决策人审批 → 书面通知对方 → 交接与结算 → 归档；
- **留痕**：决策记录 + 审批留痕 + 对方书面回执 + 交接单；
- **完成标准**：台账标注清楚该合同是"续期/终止/关闭"，并写明生效日期。

## 四、五个动作的通用自检（每季度一次）

| 编号 | 自检问题 | 不通过信号 |
|---|---|---|
| 1 | 有没有节点的"责任人"是空的？ | 表格里出现"待定""-" |
| 2 | 有没有变更只存在于聊天记录里？ | 台账变更位置为空 |
| 3 | 有多少比例的交付没有验收申请记录？ | 验收栏大量空白 |
| 4 | 超过 60 天未核销的应收有多少？ | 应收账款账龄拉长 |
| 5 | 未来 60 天内到期的合同有几份、决策人是谁？ | 到期清单无人认领 |

## 五、常见误区

1. **把提醒当成催款**：提醒是内部动作（提前准备），催收是对外动作（要求付款），两者混用会让对方反感，也让内部节奏乱掉。
2. **台账一次性做大**：先上 12 个字段跑一个月，再加字段。上来就 40 列必然烂尾。
3. **只对外留痕，不对内留痕**：内部审批、决策记录、提醒记录同样是证据的一部分。
4. **到期不吭声**：不续也不通知，是后续较容易产生"是否默示继续"争议的做法。明确写一封函，成本很低。
5. **拿合同文本当单独的依据**：合同之外的实际履行情况、往来函件、签收记录，共同构成履行事实。

## 六、何时必须转给专业人士

出现以下任一情况，停止自行推进并建议咨询持证法律专业人士：

- 涉及金额较大或存在重大争议；
- 对方已明确书面拒付、拒签或主张合同已解除；
- 对方主体出现经营异常、被执行、失联等信号；
- 涉及可能需要主张惩罚性条款、违约金调整、时效抗辩等法律判断；
- 已进入诉讼、仲裁或收到律师函；
- 涉及担保、抵押、连带责任等担保类安排；
- 涉外合同或跨境付款安排。

> 本清单不替代法律判断。是否构成违约、条款是否有效、应采取何种法律手段，均需人工复核并由持证专业人士决定。
