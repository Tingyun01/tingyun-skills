# 陪诊决策顾问

> 帮家属判断：要不要陪诊、怎么安排一天、跟老人怎么沟通、哪些情况得找医生。技术触发词「需求评估、流程安排、照护沟通」。口语触发词「我爸 78 岁有多个慢病，需要陪诊吗、去之前要准备什么，结束后要带回什么、怎么让固执的老人同意住院又不强行」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

就医陪诊需求评估与全程陪护规划顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我爸 78 岁有多个慢病，需要陪诊吗？一天的流程怎么安排
- 去之前要准备什么，结束后要带回什么
- 怎么让固执的老人同意住院又不强行
