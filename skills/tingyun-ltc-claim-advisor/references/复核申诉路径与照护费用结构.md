# 复核申诉路径与照护费用结构

> 本页两部分：一是被拒后的复核与再申请路径的细节；二是居家与机构照护的费用结构与护理资源清单。费用部分只给结构与算账方法，不列具体金额——各地水平与各机构报价差异极大，请自行向当地询价。

## 一、复核与再申请的细节动作

### 提交前的准备

| 材料 | 作用 | 准备要点 |
|---|---|---|
| 原申请材料全套 | 基础 | 留有副本与提交凭证 |
| 书面结果与理由 | 争议对象 | 逐句拆出被指出的具体问题 |
| 补充功能证据 | 补强 | 见下表 |
| 照护实际情况说明 | 补充 | 家属视角的日常照护描述 |

### 补充功能证据的来源（按说服力排序）

1. **护理机构的照护记录**：护理单、翻身记录、如厕协助记录、进食协助记录——这些是有时间、有签名的连续记录，证明力强
2. **康复治疗记录**：康复科的功能评定与训练记录，能体现功能下降的轨迹
3. **带时间标注的影像说明**：说明拍摄时间、场景、由谁拍摄，能对应到具体动作
4. **照护人员书面说明**：全职护工或主要家属对日常照护内容的说明
5. **医疗记录中的功能描述**：从病程记录中摘取关于生活自理能力的描述

### 提交时的表达要点

- 不用情绪化叙述，用**事实 + 时间 + 频次**："2025 年 3 月起需两人协助翻身，此前可自行完成"
- 一次讲清一件事，不把多个诉求混在一起
- 明确提出希望复核哪一项认定
- 附带一句请求：请在结论中说明理由，便于后续依法主张

### 渠道与时限

- 按当地公布的方式提出（书面提交、线上渠道、窗口等）
- **时限是硬约束**：复核申请通常有时限要求，逾期可能失去本次机会
- 提交后主动确认受理，留受理凭证
- 若复核结论仍不认同，向当地主管部门了解进一步渠道；涉及权益主张的，请咨询执业律师

### 再申请的时机判断

| 情形 | 建议 |
|---|---|
| 材料问题已补齐 | 尽快按渠道重新提交，不必等 |
| 失能程度确有变化 | 按当地复评周期或条件变化时提出 |
| 条件未达门槛且短期无变化 | 先记录基线，重点转向家庭内部照护安排与商业保障安排 |
| 参保状态发生变化（补缴、迁入实施地区） | 先把参保问题解决，再谈申请 |

## 二、居家照护费用结构

| 费用项 | 内容 | 常见变动因素 |
|---|---|---|
| 照护人力 | 护工或护理员的服务费用 | 服务档次、时长、是否需夜间照护、当地人工水平 |
| 家庭成员时间成本 | 家属陪护占用工作时间与休息 | 是否需全职陪同、是否需家属承担专业操作 |
| 餐食与营养 | 日常饮食、特殊营养支持 | 是否需流食或特殊配方、有无营养师介入 |
| 耗材 | 一次性护理用品、失禁用品、皮肤护理 | 消耗量随失能程度上升 |
| 辅具 | 护理床、轮椅、助行、移位、洗澡椅、防褥疮用品 | 可租可购；租赁适合短期，购置适合长期 |
| 居家环境改造 | 防滑、扶手、卫生间改造、床位空间 | 改造范围与房屋条件相关 |
| 其他专业服务 | 康复训练、压疮处理、导管维护等 | 频次与专业程度 |

## 三、机构照护费用结构

| 费用项 | 内容 | 常见变动因素 |
|---|---|---|
| 床位与房间费 | 房间类型（多人间/单人间）、楼层 | 房型与设施等级差异明显 |
| 护理等级费用 | 按照护等级对应的人力投入 | 等级越高人力越密 |
| 餐食 | 日常餐与特殊饮食 | 一般包含在月费内，需确认 |
| 耗材与额外服务 | 特殊护理耗材、康复项目、外出陪诊 | 多为不含项，需单独计 |
| 医保相关结算 | 医疗与护理部分的结算方式 | 与医保目录、政策有关，需向机构确认 |

## 四、算账方法：先服务缺口，再现金缺口

这是容易被算错的一步。多数家庭的错误算法是"总月费减待遇"，结果算出一个虚假的缺口。

**正确顺序**：

```
第 1 步 列出照护需求项           → 吃、穿、如厕、翻身、行走、进食、洗澡
第 2 步 每项标注由谁承担          → 长护险服务 / 家庭自付 / 商业保险 / 需自费购买
第 3 步 汇总成"服务缺口"          → 长护险服务形式覆盖不到的部分
第 4 步 汇总成"现金缺口"          → 服务缺口 + 现金支付部分（餐食、辅具、改造等）
第 5 步 评估现金缺口的承担方式     → 家庭积蓄 / 商业长护险给付 / 保险理赔 / 其他安排
```

**为什么要分两步**：
- 长护险给付多以服务形式提供（上门护理、机构服务等），不是等额现金
- 若把服务形式按等额现金折算，会高估家庭实际要掏的钱
- 若把服务形式完全忽略，又会高估缺口
- 现金缺口的规模决定商业长护险保额、辅具预算与储备金该定多少

### 自建算账表（家庭填写）

| 项目 | 月费用 | 承担方 | 是否一次性 |
|---|---|---|---|
| 护工/护理员 | | | |
| 机构床位与护理 | | | |
| 餐食与营养 | | | |
| 耗材 | | | |
| 辅具（租赁/购置） | | | |
| 居家改造 | | | |
| 其他专业服务 | | | |
| **合计** | | | |

再算一组数：
- 预计需要照护的月数区间（按病情趋势估两个情形）
- 一次性支出（改造、大件辅具）
- 家庭可承担的上限
- 缺口 = 合计 × 月数 − 已有保障 − 可动用储备

## 五、护理资源清单（提前找，不等需要时再找）

### 1. 护理员 / 护工

| 找什么 | 怎么挑 | 提前确认 |
|---|---|---|
| 住家护理员 | 有照护失能长者经验、能做基础护理操作 | 排班方式、替班安排、是否有健康证与相应技能证明 |
| 白班/日间护工 | 家属白天上班、需有人处理日间照护 | 单次时长、可否兼顾康复训练与喂饭 |
| 专业护理员 | 需导管护理、压疮处理、注射等技术操作 | 是否有资质证明、可承担哪些操作 |
| 喘息服务 | 家属需要阶段性休息 | 服务时长、频次、是否需提前预约 |

### 2. 机构

| 类型 | 适用 | 考察点 |
|---|---|---|
| 养老机构 | 日常照护需求稳定 | 护理等级对应人力、能否处理失禁与翻身、应急能力 |
| 护理型机构 | 医疗期后转长期照护 | 护理人员配置、压疮与导管护理能力、与医院的转介衔接 |
| 日间照料 | 家属白天上班，晚间回家 | 接送时间、能否做康复训练、是否含餐 |
| 居家服务机构 | 机构派员上门 | 派员稳定性、能否覆盖约定时段、能否处理突发情况 |

**考察机构的通用问题**：
1. 护理员配比是多少？夜班怎么排？
2. 失禁、翻身、压疮这些日常能不能处理，处理到什么水平？
3. 家属能探视或陪住吗？条件是什么？
4. 有哪些费用不含在月费里？
5. 出现紧急情况（如呛咳、发热、跌倒）怎么处理？怎么通知家属？
6. 退出机制是什么？提前多久告知？押金与结算怎么算？

### 3. 辅具

| 辅具 | 解决什么问题 | 租赁还是购置 |
|---|---|---|
| 护理床（电动/手动） | 翻身、起卧、减轻家属体力 | 长期用购置，短期租 |
| 防褥疮垫 | 长期卧床的皮肤保护 | 视卧床时长与皮肤状况 |
| 轮椅 | 转移与外出 | 长期用购置 |
| 移位机 | 家属单人完成体位转移 | 视照护人手力与失能程度 |
| 助行器 | 站立与行走训练 | 视康复方案 |
| 洗澡椅 | 沐浴安全 | 一次性投入 |
| 床边扶手与防滑 | 居家防跌 | 一次性改造 |
| 护理耗材（一次性用品） | 日常消耗 | 按量采购 |

### 4. 喘息与替代支持

- **喘息服务**：让主要照护者阶段性休息或离岗，通常由社区或机构按服务安排提供，频次与时长各地不同
- **社区日间照料**：白天有人照护，晚上回家
- **互助与志愿支持**：部分社区有助浴、助洁、助医等公益支持，可提前登记

### 5. 提前准备的意义

- 护理员与机构的档期在需求集中时很紧张
- 辅具租赁、改造施工都需要时间
- 喘息服务通常需要提前预约
- 家庭成员的学习与培训需要时间（翻身技巧、压疮预防、喂饭技巧、紧急处理）

## 六、常见误区补充

| 误区 | 澄清 |
|---|---|
| 以为评估结果一出费用就固定 | 服务安排与结算方式在资格确定后还有一道落地环节 |
| 只算人力费用 | 辅具、耗材、改造、餐食、喘息都是实打实的支出 |
| 以为长护险能覆盖全部照护开销 | 长护险多以服务形式提供，覆盖范围与上限按当地办法 |
| 以为申请越早越好 | 过早申请可能因未达失能口径被退回，反而消耗材料与信心 |
| 以为可以同时享受多个机构服务 | 居家服务与机构服务通常不能并行，须按当地规则选择一种 |
| 以为家属全职照护就没有成本 | 时间成本、健康损耗、误工都是真实成本，应计入算账 |
