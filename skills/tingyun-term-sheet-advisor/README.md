# 股权融资条款与TS谈判顾问

> 为创始人拆解TS核心条款（估值、优先清算、反稀释、对赌、一票否决等），给谈判优先级与条款对照。仅作决策辅助，不构成法律意见，需人工复核。技术触发词「TS条款、估值与对赌、谈判优先级」。口语触发词「投资人发来一份TS，帮我逐条拆解哪些条款对创始人风险较高、用大白话讲讲优先清算权和反稀释，退出时怎么坑创始人、投资人逼我们签对赌（估值调整），真实风险有哪些」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

融资条款规划顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 投资人发来一份TS，帮我逐条拆解哪些条款对创始人风险较高
- 用大白话讲讲优先清算权和反稀释，退出时怎么坑创始人
- 投资人逼我们签对赌（估值调整），真实风险有哪些？效力上怎么看？
- 帮我把这些条款按'该死守'和'可以让'排个优先级
