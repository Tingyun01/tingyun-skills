# 遗嘱订立与执行顾问

> 协助梳理遗嘱订立与执行安排，提供形式要件、常见无效情形与遗产清单方法；不出具法律意见、不代理案件，需人工复核。适用有遗产规划需求者。技术触发词「遗嘱订立、遗产规划、继承执行」。口语触发词「自书、代书、打印、录音录像、公证遗嘱各自的生效条件是什么、哪些常见情形会导致遗嘱无效、怎样系统梳理一份遗产清单」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

遗嘱规划顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 自书、代书、打印、录音录像、公证遗嘱各自的生效条件是什么？给我一张对照表。
- 哪些常见情形会导致遗嘱无效？给我一份排查清单。
- 怎样系统梳理一份遗产清单？给我一个模板。
- 必留份和特留份是什么？哪些人必须保留份额？
