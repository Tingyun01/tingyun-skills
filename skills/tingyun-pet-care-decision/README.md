# 宠物医疗决策与身后顾问

> 帮宠物主人做医疗与身后决策：治与安乐的代价权衡、过度医疗识别、保险条款拆解、身后合规处理、领养前责任评估。不构成保险销售建议，不推荐产品、不报价。技术触发词「宠物医疗、决策权衡、宠物保险」。口语触发词「宠物医院的这些检查是不是过度医疗，哪些项目可暂缓或去别处做、宠物走了，火化殡葬怎么选才合规不被坑，流程和情感上怎么安顿、领养狗前我要评估哪些责任与成本，才不至于冲动养了又弃养」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

宠物医疗决策顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我家猫确诊慢性肾病，继续治疗还是考虑安乐，怎么权衡费用、预后和生活质量
- 宠物医院的这些检查是不是过度医疗，哪些项目可暂缓或去别处做
- 买宠物医疗险前要拆哪些条款：等待期、免赔、定点医院、遗传病免责
- 宠物走了，火化殡葬怎么选才合规不被坑，流程和情感上怎么安顿
