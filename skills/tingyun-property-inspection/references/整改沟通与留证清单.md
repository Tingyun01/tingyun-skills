# 整改沟通与留证清单

## 一、整改沟通的基本原则

### 1. 四个原则

1. **先定性责任方，再提诉求**。责任方不清就去谈，容易陷入"你找物业、物业找开发商、开发商说不是我们" 的循环。判断责任方见 `查验清单与严重度分级.md` 的责任对照表。
2. **书面优先，口头补充**。口头沟通快但不可执行。所有诉求要有书面载体：EMS 挂号信、邮件（保留完整邮件头）、现场签收单、业主群或政务服务渠道的书面提交记录。
3. **分级分批，不要一次全摊**。一级问题单独提出并要求限期书面答复；二级问题合并成"限期返工+复验"一组；三级问题批量归集为"交付清单核对"。一次提 40 条会让对方用一个"已统一记录"把整件事压住。
4. **不升级对抗，只升级层级**。手段只有一条线：书面沟通 → 复验催告 → 投诉主管部门 → 诉讼。堵门、围堵办公场所、找媒体曝光施压、组织他人施压，都不在工具箱里。

### 2. 沟通稿的要素顺序

写整改通知时按这个顺序写，逻辑更顺，对方更容易接受：

```
① 我方身份与房屋基本信息（房号、合同编号、交付日期）
② 已发现的问题清单（位置 - 现象 - 依据）
③ 定性（保修责任范围 / 合同约定不符 / 需排查）
④ 诉求（分级，各自对应明确的处理动作与期限）
⑤ 告知后续动作（期限未响应则向主管部门投诉或提起诉讼）
⑥ 落款与日期、附件清单
```

第⑤条是必要条款，不是威胁话术。它让对方知道不响应的后果，也让用户知道升级路径是明确的。措辞保持平静。

### 3. 措辞对照表

| 不要写 | 改成 |
|---|---|
| 你们这是欺诈 | 该处施工不符合合同约定的交付标准，请说明处理方案 |
| 这房子根本没法住 | 该问题影响正常使用，请安排修复 |
| 我要你们赔 | 请说明修复方案与完成时间；如无法修复，请说明处理方式 |
| 你们侵犯消费者权益 | 依据合同第 X 条与《建设工程质量管理条例》第 X 条，请予处理 |
| 大家都这样 | 同一单元 X 层存在同类情况（见附件编号），可一并处理 |
| 赶紧的 | 请于 X 年 X 月 X 日前书面答复 |

### 4. 常见诉求类型（按级别配）

**一级问题的诉求组合**
- 要求在 X 个工作日内出具书面处理方案（含是否需要检测、检测由谁委托、费用如何承担）
- 明确是否影响居住使用，是否建议暂停入住
- 要求书面告知整改完成时间与验收方式

**二级问题的诉求组合**
- 限期返工（写明部位与做法要求，不写死具体工艺细节，除非你确有把握）
- 明确复验方式与复验参与方（用户、物业、对方）
- 修复期间的使用影响如何处理（书面留待协商，不先提金额）

**三级问题的诉求组合**
- 批量列出，统一处理
- 可给出处理方式选项：修复、更换、补偿（补偿方式与金额留待协商）

**费用类（用户想主张时）**
- 修复费用及修复期间造成的其他损失，由责任方承担——这是《建设工程质量管理条例》第四十一条与商品房买卖合同司法解释的规则方向；自修前先书面声明并留存费用凭证
- 逾期交付的损失可参照同地段同类房屋租金标准（司法解释有相应规则）
- 面积误差比超出合同约定的部分，按司法解释的规则处理

**提醒用户**：金额主张涉及证据与计算，交给专业人士复核。你给方法与清单，不出数额结论。

## 二、可直接改写的整改通知模板

> 以下是结构模板，替换方括号内容即可使用。方括号里的内容必须按实际情况填，缺失信息的地方宁可留白让用户补，也不要填猜测值。

```
房号：[XX 栋 X 单元 XXX 室]
合同编号：[XXXXXXXX]

关于房屋交付验收问题的整改通知书

尊敬的[开发商/物业/建设单位名称]：

本人系上述房屋买受人，已于[交付日期]完成交付验收。验收中发现下列问题，
现依据《商品房买卖合同》第[ X 条]及《建设工程质量管理条例》第四十条、第四十一条，
提出整改要求，请予书面答复与处理。

一、问题清单

1. 位置：[主卧东北角墙面]
   现象：[裂缝，宽约 0.4mm，斜向约 45 度，长约 40cm，无错台]
   定性：[涉及主体结构，请提供本单元主体结构质量说明]
   诉求：[请于 X 月 X 日前书面答复处理方案]

2. 位置：[二层卫生间东北角地漏周边地面]
   现象：[闭水试验蓄水 24 小时后，楼下顶面出现约 20cm 洇湿痕迹，附照片编号 A-07]
   定性：[属卫生间防水保修范围]
   诉求：[请于 X 月 X 日前完成排查与修复，并安排复验]

3. 位置：[客厅南面窗框下沿]
   现象：[室内窗台下方约 30cm 水渍，纸压留痕明显，附照片编号 A-12]
   定性：[属外窗密封保修范围]
   诉求：[请于 X 月 X 日前完成排查与修复]

（其余问题按同一格式逐条列出，一级问题单独列在前面）

二、随附材料

1. 问题照片及编号对照表（共 X 张，含比例参照物）
2. 闭水试验记录（时间、水位标记、楼下观察结果）
3. 本通知书要求的答复期限：[X 年 X 月 X 日]

三、后续

如未在上述期限内收到书面答复，本人将依据合同约定向房屋所在地的住房和城乡建设
主管部门反映，或依法主张相应责任。

特此通知。

[姓名]
[日期]
```

**使用要点**
- 照片编号与正文里的编号必须一一对应，附件里放对照表
- 闭水试验记录要写清起止时间与水位标记，这是更有说服力的一项
- 一级问题里不要写"影响安全"这类定性词，写"请提供本单元主体结构质量说明"，把定性交给有资质的机构
- 一份通知只谈一件事。防水、门窗、电路分三份发，或按级别分批发，避免对方合并处理

## 三、验房工具准备清单

### 3.1 核心工具（必备）

| 工具 | 用途 | 备注 |
|---|---|---|
| 手机或相机 | 全部影像记录 | 存储空间清空、电池充满、关闭时间戳水印之外的其他叠加信息 |
| 空鼓锤或硬币 | 敲击查墙面地面空鼓 | 硬币边缘也能用，但空鼓锤手感与效率更好 |
| 2m 靠尺 | 平整度与垂直度 | 配合塞尺读数 |
| 塞尺（塞尺片） | 读平整度间隙 |  |
| 强光手电（带备用电池） | 柜体内侧、管井、吊顶、窗角 | 手电的窄光束在查暗角时不可替代 |
| 卷尺 | 量裂缝宽度、间隙、尺寸 | 裂缝拍照时作为比例参照 |
| 直尺或硬币 | 裂缝与空鼓的比例参照物 | 拍近景时放在裂缝旁 |
| 插座测试笔（带指示灯） | 插座通断与接线是否正确 | 顺便区分左右火线 |
| 记号笔 | 墙上标记问题位置与编号 | 拍照前标记，照片里能对得上 |
| 编号贴纸 | 每个问题贴一个 | 与清单编号一致 |
| 笔记本与笔 | 现场手写记录 | 手机备忘录容易丢，写纸上更可靠 |
| 拖鞋或鞋套 | 进屋前换 | 精装房保护地面，也保护你自己 |

### 3.2 增强工具（按需）

| 工具 | 用途 | 备注 |
|---|---|---|
| 激光水平仪 | 水平与垂直快速判断 | 比靠尺效率高，室内多遮挡时更好用 |
| 红外测温计 | 地暖温度分布、墙面空鼓辅助判断 | 温差处可能有问题，需与环境温差配合判断 |
| 温湿度计 | 返潮与结露判断 | 南方梅雨季有用 |
| 管道内窥镜 | 看排水管内部、地漏深处、吊顶内管道 | 老房二手房与精装房有价值 |
| 闭水试验工具 | 堵漏工具、防水沙袋、砂浆与挡水坎 | 自做闭水需要 |
| 望远镜 | 远观外立面与屋面 | 外墙问题往往只能远观 |
| 手电 + 备用电池 | 断电时查管线井 | 精装房常做吊顶暗藏管线 |
| 钳形表 | 电流检测（判断回路是否带载） | 需要一点基础 |
| 灰刀或铲刀 | 检查空鼓范围边界 | 不建议用于破坏性探测 |
| 塑料袋与扎带 | 装碎屑、标记管线位置 | 装修前标记暗埋管线很有用 |

### 3.3 自带物料
- 干抹布、纸巾（渗水纸压测试）
- 记号笔与贴纸（多备）
- 双面胶或美纹纸（贴编号）
- 小型收纳袋（装螺丝、塞尺等小件，防止丢失）

### 3.4 不建议带的东西
- 大锤（容易造成损坏，且空鼓锤足够）
- 电钻（属于破坏性探测，未经物业同意不应使用）
- 任何化学试剂

## 四、留证规范

### 4.1 影像

| 要求 | 做法 |
|---|---|
| 定位照 | 拍到房间全貌，能看出方向与相邻关系 |
| 中景照 | 整块墙面、整件设备 |
| 近景照 | 能看清裂缝宽度、渗水边界、空鼓范围 |
| 比例照 | 裂缝用直尺或卷尺；空鼓用记号笔圈边并写编号；渗水用纸巾按压留痕 |
| 时间信息 | 保留原始拍摄时间信息，不要后期编辑图片 |
| 原始文件 | 原图另存一份，标注用的副本单独存 |
| 连续性 | 渗漏类问题可在不同时间点各拍一组，形成时间序列 |

### 4.2 文字

- 问题清单：编号、位置、现象、级别、诉求（用统一表格，一行一条）
- 闭水试验记录：起止时间、蓄水深度、水位标记、期间观察次数、楼下观察结果、参与人
- 往来记录：EMS 面单号与投递时间、邮件完整往来、现场签收单、投诉平台的提交回执
- 设备清单：交付时附赠的设备（家电、车位、储藏室）逐项签收，缺项当场记

### 4.3 第三方

- 有资质的检测机构报告（结构安全、室内空气污染等）
- 物业或开发商出具的整改回复函（哪怕只是回复不改，也要留）

### 4.4 时间节点记录
做一张表，按节点打勾：

```
[ ] 交付当日：问题写入交付确认文件
[ ] 交付后 3-7 日内：书面整改通知发出（留存 EMS 号 / 邮件）
[ ] 约定答复期限届满：核对是否收到回复
[ ] 未回复：催告函发出
[ ] 复验日：整改情况记录 + 影像
[ ] 升级节点：向主管部门投诉 / 委托律师
[ ] 装修开工前：全部问题状态确认（已整改 / 未整改 / 待定）
```

## 五、升级阶梯与各级要点

```
第 1 级  交付现场
  动作：把问题写进交付确认文件，注明"限期整改后书面答复"
  要点：除非真的查过，不签"无异议"

第 2 级  书面整改通知（交付后 3 至 7 日内）
  动作：EMS 挂号 / 邮件 / 现场签收，留存凭证
  要点：写明具体期限与后续动作；一级问题单独成文

第 3 级  期限届满 + 复验
  动作：上门复验核对，逐条标注整改状态，拍整改前后对比照
  要点：未整改项与新增项一起记录，不打断沟通

第 4 级  投诉
  渠道：房屋所在地的住房和城乡建设主管部门、市场监管部门、政务服务便民热线
  动作：提交书面材料 + 证据目录，说明诉求（责令整改、核实处理）
  要点：一次提交完整，不要分批零散投诉

第 5 级  诉讼
  动作：整理证据目录、诉求与计算依据，委托律师或自行处理
  要点：诉讼主张要落到具体金额与法律依据，交给专业人士复核
```

### 各级的时间与法律要点
- 保修期内，出卖人承担修复责任；出卖人拒绝修复或在合理期限内拖延修复的，买受人可以自行或者委托他人修复，修复费用及修复期间造成的其他损失由出卖人承担（商品房买卖合同司法解释的规则）
- "合理期限"没有法定天数，所以书面通知里要写明具体期限。常见做法是 7 至 15 个工作日，这属于操作惯例，在通知里写具体日期更有力
- 保修期自竣工验收合格之日起算。核查竣工验收时间，核算剩余保修期
- 房屋毁损、灭失的风险在交付使用前由出卖人承担，交付使用后由买受人承担；买受人接到书面交房通知无正当理由拒绝接收的，风险自通知确定的交付使用之日起转移（司法解释规则）。所以"拖着不办手续"不是好策略

## 六、红线（用户提了要劝退的）

| 用户可能说 | 你的回应方向 |
|---|---|
| "你帮我去物业闹一场" | 不做对抗性动作。给书面表述和投诉渠道，效果更稳 |
| "我先不收房，看他们能拖多久" | 提醒风险转移规则与自行承担的后果，把"拖延"的具体法律风险讲清楚 |
| "发到网上曝光他们" | 不协助。这类做法可能涉及名誉权侵害或商业诋毁，风险由用户承担，且通常无助解决问题 |
| "物业费先欠着当筹码" | 劝退。《民法典》第九百四十四条规定，物业服务人已按约定提供服务的，业主不得以未接受服务为由拒交物业费，也不得以停水停电停气方式催交 |
| "我找人做一份检测报告" | 明确拒绝造假 |
| "我拆开看看里面什么情况" | 提醒：拆改前须与物业、产权方书面确认同意（涉及承重与外立面的更需谨慎），拆改会毁掉证据且可能承担修复责任与违规责任 |
| "帮我拟一份仲裁申请书" | 可以协助整理事实与证据清单，但法律文书应由执业律师审核或起草 |

## 七、给你自己的三条纪律

1. **数字要准**。规范里的允许偏差值、闭水试验的深度与时长、保修年限，能确认的写具体值，不确定的明确说"以现行规范与合同约定为准，请核实"。宁可说"这个数值我不确定，你去查合同交付标准附件"，也不要给一个自己半信半疑的数——用户拿着错数字去跟开发商对质，会当场被指错，专业度就没了
2. **定性的活儿交给别人**。结构安全、是否严重影响正常居住使用、赔偿数额，这三类只给分级建议与取证路径，不给结论
3. **把不该做的挡在前面**。谈判、鉴定结论、结果承诺，这三样用户都会想要，也更可能把用户推向有代价的处境。你的价值是把这条路走稳，不是让用户觉得爽
