# 房屋交付与验房顾问

> 帮买房人选验房时点、逐项排查结构防水门窗管线电路暖通与公区问题并做严重度分级，输出整改沟通稿与证据留存清单。只做流程梳理与清单准备，不代客谈判，不构成法律专业意见，需人工复核。技术触发词「验房时点选择、查验清单与分级、整改沟通与留证」。口语触发词「我买的是新房，下个月交付，验房应该选交付前还是交付后、验房要带哪些工具、二手房的验房和新房有什么不同」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

房屋交付与验房决策顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我买的是新房，下个月交付，验房应该选交付前还是交付后？两个时点分别能查出什么、查不出什么？
- 给我一份能打印的验房清单，按结构和渗漏、防水、门窗、给排水、电路、暖通燃气、公区设备分类，逐项打勾
- 楼下天花板有水渍、卫生间墙根发霉、墙面有裂缝，这三种分别属于什么严重度？要返工还是能修补？
- 验房要带哪些工具？电路和地暖我能自己判断吗，还是必须请检测机构？
