# 合同必备条款审查清单与报价单核查

> 用途：逐行核对一张装修合同与它附着的报价单，核出条款缺口与结算差异来源。
> 内容为条款审查与清单梳理，不构成法律专业意见，需人工复核。

## 一、七组必备条款逐条审查清单

用法：每组逐项打勾，"缺"的一律写上建议补法。审查时按本表顺序查，不按装修公司给的合同目录顺序查——对方写的目录顺序通常就是他的责任排序。

### 1.1 工期与开工条件

| 检查项 | 合格写法 | 缺口表现 | 建议补法 |
|---|---|---|---|
| 开工日 | 写明具体日期或可确定日期的触发条件 | 只写"工期60天" | "自甲方发出书面开工通知且下列条件全部成就之日起__个日历天" |
| 竣工日 | 与开工日对应的确定日期 | 只写总工期天数 | 同时写总工期与竣工计算方式 |
| 开工前置条件 | 逐项列出：物业批准、图纸确认、材料到场、付款到位、场地移交 | 完全不写 | 列成清单，每项写"未成就时工期顺延__天" |
| 工期顺延事由 | 列举可顺延事由及证明方式 | 不写，或写"因客观原因" | 列举：物业未批准、材料未到场、设计变更、隐蔽工程等待定夺、不可抗力、第三方原因 |
| 顺延确认流程 | 书面提出与书面确认的时限 | 不写 | "任一方应在事由发生后3日内书面通知对方并附证明，逾期未通知的不得主张顺延" |
| 逾期责任 | 逾期违约金标准与计算方式、上限 | 完全不写 | 写明每日标准与总额上限，并写明超过上限时的解除权 |
| 提前交付 | 是否允许提前交付、如何处理 | 不写 | 明确约定，避免为提前交付产生质量争议 |

**注意**：顺延事由里一定要有"隐蔽工程等待定夺"这一项。这一条是装修纠纷里高频的争议点——拆开之后发现原方案不可行，等设计师或业主拿主意，这段时间算谁的。

### 1.2 承包方式与报价边界

| 检查项 | 合格写法 | 缺口表现 | 建议补法 |
|---|---|---|---|
| 承包方式 | 包工包料 / 包工不包料 / 全部清包，写明 | 只写"全包""半包" | 写全称并加一句解释："半包（乙方提供辅料，甲方提供主材）" |
| 报价是否含设计费 | 明确含或不含 | 不写 | 明确写"含设计费/不含设计费" |
| 是否含管理费 | 明确含或不含 | 不写 | 同上 |
| 垃圾清运 | 从哪运到哪、含几车、超量怎么算 | 只写"含垃圾清运" | "含施工垃圾清运至物业指定堆放点；外运及超量部分按__元/车计" |
| 成品保护 | 保护哪些部位、由谁做 | 不写 | 列举部位：地面、电梯、门框、窗框、公共区域 |
| 成品安装 | 灯具、洁具、五金、地板、橱柜是否含安装 | 不写 | 逐项写含或不含，以及不含时的价格 |
| 开孔费用 | 空调孔、烟道孔、燃气孔、水电点位开孔 | 不写 | 写"含__孔以内，超出部分__元/个" |
| 物业相关费用 | 装修押金、垃圾清运费、电梯使用费由谁承担、能否退还 | 不写 | 明确"由甲方承担，据实结算，多退少补，凭物业收据结算" |
| 开口条款 | 逐条列出所有"按实结算""暂列金""另计""其他费用" | 只在一处出现，容易漏 | 在合同正文列出开口项清单，每项写：计量方式、单价、上限、结算凭证 |

**核心动作**：拿到报价单后，把所有含"按实""暂""另""以实际""具体为准""视情况"的行项用笔圈出来。这些行项是后续所有争议的入口。

### 1.3 付款节点

| 检查项 | 合格写法 | 缺口表现 | 建议补法 |
|---|---|---|---|
| 每期对应工序 | 每个节点写明对应的工程内容 | 只写"首期/二期/尾款" | 按开工、水电、泥木、油漆、竣工五段写 |
| 节点比例 | 每期比例明确 | 只写首付与尾款 | 每期写明比例或金额 |
| 支付前提 | "验收合格后__日内支付" | "按进度支付" | 每期绑定该期验收合格 |
| 付款与验收的先后 | 明确先验收后付款 | 不写 | 写"经验收合格并签署验收记录后__日内支付" |
| 尾款比例与退还条件 | 比例、退还时点、退还前提 | 只写"留5%质保金" | "竣工验收合格后__日内支付__%；余__%作为保修金，保修期满且无未处理质量问题后__日内无息退还" |
| 逾期付款责任 | 业主方逾期付款的后果 | 不写 | 写明标准与对应的工期顺延天数 |
| 付款主体 | 收款账户与合同主体一致 | 公司合同、个人收款 | 写"乙方收款账户为签约主体在银行开立的账户" |

**比例参考**：行业常见做法是开工、水电、泥木、油漆各段按工程量分布支付，竣工后留一定比例至保修期结束。具体比例属谈判范畴，合同中没有法定比例要求。

### 1.4 材料品牌与型号

| 检查项 | 合格写法 | 缺口表现 | 建议补法 |
|---|---|---|---|
| 主材品牌 | 品牌名称 | "品牌材料""一线品牌""知名品牌" | 写具体品牌名 |
| 系列或型号 | 型号或系列编号 | 只写品牌 | "品牌__ 系列__ 型号__" |
| 规格与产地 | 规格、产地、等级 | 不写 | 写规格与产地 |
| 辅料 | 水泥、砂石、板材、电线、水管、防水、腻子等逐项 | 大量辅料不写 | 列辅料清单，品牌+系列 |
| 采购责任 | 谁采购（甲方自购 / 乙方采购） | 不写 | 逐项标"甲供""乙供" |
| 到场验收 | 进场验收流程与不合格处理 | 不写 | "材料进场须经甲方验收并留存合格证、质检单；不合格的退场，费用由责任方承担" |
| 封样 | 样品封存与比对 | 不写 | "主材样品封存并经双方签字确认，交材料以封样为准" |
| 替换规则 | 替换的条件、告知与价差处理 | 不写 | "未经甲方书面同意不得替换；确需替换的须书面说明理由与价差处理方式" |
| 甲供材料损耗 | 损耗比例、保管责任 | 不写 | 写损耗率与超耗责任 |

**关键的一句**：**型号**。品牌定的是档次，型号定的是那一样东西。写"某品牌地砖"和写"某品牌某系列 800×800 型号"在结算时可以差出很大一截，争吵也全在这里。

### 1.5 工艺与验收标准

| 检查项 | 合格写法 | 缺口表现 | 建议补法 |
|---|---|---|---|
| 工艺做法 | 逐工序写具体做法 | "按规范施工" | 写清做法：例如墙面基层处理方式、瓷砖铺贴方式与错缝方式、吊顶龙骨间距与石膏板层数 |
| 引用标准 | 写具体标准号或名称 | "国标" | 写标准编号与名称 |
| 验收节点 | 分阶段验收节点清单 | 不写 | 写开工交底、水电、防水、泥木、油漆、竣工六节点 |
| 隐蔽工程验收 | 记录单形式与签字方 | 不写 | "隐蔽工程须经甲方验收合格并签署验收记录单后方可封闭" |
| 验收标准 | 可验证的判定要求 | 不写 | 写可核对项：墙地面平整度、缝隙均匀度、防水蓄水高度与时长、水压试验数值、电路绝缘测试、通水通电测试 |
| 不合格处理 | 整改、复验、费用承担 | 不写 | "不合格的由责任方在__日内无偿整改，整改后重新验收，验收合格前不进入下一工序" |
| 竣工验收流程 | 流程与交付物 | 不写 | 写清交付物清单：质量保修书、材料设备说明书、保修单、环保说明书 |

**一个可检验的技巧**：把"合格"两个字换成"能被双方验证的数字"。验收标准要能被一根卷尺、一把空鼓锤、一次打压试验判定，而不是靠"看着还行"。

### 1.6 变更签证

| 检查项 | 合格写法 | 缺口表现 | 建议补法 |
|---|---|---|---|
| 变更提出方 | 谁可以提出、什么情形必须提出变更 | 不写 | "变更由任何一方提出，须经双方书面确认后实施" |
| 书面形式 | 变更单形式与要素 | 只写"甲方确认后施工" | "变更须填写书面变更单，载明变更事由、内容、工程量、单价、合价、工期影响，经甲方签字确认后生效" |
| 先定单价再施工 | 顺序要求 | 不写 | "未经单价确定的变更不得实施" |
| 单价确定顺序 | 参照合同原单价 / 新单价协商 / 第三方定价 | 不写 | "变更单价参照合同同类项目单价；无同类项目的，由双方协商确定或按当地同期价格确定" |
| 无书面确认的后果 | 业主可否拒付 | 不写 | "未经甲方书面签字确认的施工内容，甲方有权拒绝支付相应价款" |
| 变更上限 | 累计变更占总价比例上限 | 不写 | 写明确上限与超出后的处理方式 |
| 紧急情形 | 危及安全或财产时可否先施工 | 不写 | "为避免人身或财产损失需紧急处理的，应事后__日内补办书面手续" |
| 变更与隐蔽工程联动 | 变更涉及隐蔽部位的验收要求 | 不写 | 写明验收方式与记录要求 |

### 1.7 保修与售后

| 检查项 | 合格写法 | 缺口表现 | 建议补法 |
|---|---|---|---|
| 保修范围 | 逐项列举，并写除外责任 | 只写"质保X年" | 列举施工项与材料项，区分责任方 |
| 保修期 | 不低于法定下限 | 写"质保1年" | 写下限，主体工程与防水按法定要求 |
| 起算日 | 竣工验收合格之日 | 写"交付使用之日""尾款付清之日" | 写"自竣工验收合格之日起算" |
| 响应时限 | 接到报修后多久响应、多久到场 | 不写 | 写响应与到场两个时限 |
| 质量保修书 | 出具义务与时间 | 不写 | "竣工验收合格后__日内出具书面质量保修书" |
| 材料设备说明书 | 说明书、保修单、环保说明书的提交 | 不写 | 写明提交义务与时间 |
| 售后渠道 | 联系人、电话、地址 | 不写 | 写明确联系人与响应方式 |
| 保修金退还 | 退还条件与时间 | 口头承诺 | 写进合同 |
| 保修与施工责任划分 | 哪些属施工质量、哪些属产品自身质量 | 不写 | 明确划分，争议时按此划分 |

### 1.8 其他值得单独核的两条

| 条款 | 依据 | 说明 |
|---|---|---|
| 装修装饰工程施工时间限制 | 《住宅室内装饰装修管理办法》第二十六条 | 装饰装修企业从事住宅室内装饰装修活动，应当严格遵守规定的装饰装修施工时间，降低施工噪音，减少环境污染。合同里可写明施工时段与噪声限制 |
| 固体废物清运要求 | 同办法第二十七条 | 施工过程中形成的各种固体、可燃液体等废物，应当按照规定的位置、方式和时间堆放和清运。严禁违反规定将废物堆放于住宅垃圾道、楼道或其他地方。合同里写清堆放点与清运责任 |
| 材料设备标准 | 同办法第二十八条 | 装修工程使用的材料和设备必须符合国家标准，有质量检验合格证明和有中文标识的产品名称、规格、型号、生产厂厂名、厂址等。禁止使用国家明令淘汰的建筑装饰装修材料和设备 |
| 室内环境质量 | 同办法第二十九条 | 竣工后空气质量应当符合国家有关标准；装修人可以委托有资格的检测单位进行检测，检测不合格的装饰装修企业应当返工 |
| 纠纷解决路径 | 同办法第二十五条 | 工程发生纠纷的，可以协商或者调解解决；不愿协商、调解或协商、调解不成的，可以依法申请仲裁或者向人民法院起诉。合同里要选一条并写清机构 |
| 装修申报登记 | 同办法第三十五条 | 装修人未申报登记进行住宅室内装饰装修活动的，由城市房地产行政主管部门责令改正。二手房改造、涉及外立面与结构时，申报登记的实际要求要向物业与当地主管部门核实 |

## 二、报价单核查方法

### 2.1 逐工序核对：把报价单当施工流程读

不要按报价单的行序读，按施工顺序读，然后逐道工序问"这一步花的钱在不在里面"。

| 施工阶段 | 逐项核对的问题 |
|---|---|
| 开工准备 | 进场测量与放线、成品保护、垃圾清运起点、临时用电用水、拆改范围与结构安全 |
| 拆改 | 拆除范围（哪些墙）、砌筑新墙、门洞修补与收口、垃圾外运、新旧墙挂网、拆改后基层处理 |
| 水电 | 点位数量与位置、线管与线径、回路划分、强弱电分管、水管走向与打压、开关底盒、检修口、开孔 |
| 防水 | 基层处理、涂刷遍数、涂刷高度、附加层、闭水试验 |
| 泥木 | 找平厚度、瓷砖铺贴方式与排版、瓷砖加工与倒角、美缝、门槛石与过门石、吊顶龙骨与石膏板、背景墙基层 |
| 油漆 | 基层处理（铲除、找平、挂网）、腻子、涂料遍数与遍涂、阴阳角处理 |
| 安装 | 灯具、洁具、五金、开关面板、地板、橱柜、门窗、晾衣架 |
| 收尾 | 开荒保洁、垃圾清运完毕、成品保护拆除、竣工清洁、资料交付 |

**逐项问三遍**：这一步做不做？做了谁付？写在哪一行？

### 2.2 识别开口项：报价单里的五类危险字样

| 字样 | 风险 | 处理动作 |
|---|---|---|
| 按实结算 / 按实际用量 | 计量基数与单价双开口 | 补计量方式、单价、上限、结算凭证 |
| 按米计算 / 按延米 | 走线走管路径由施工方掌握 | 补单米总价上限，或改为按点位计价 |
| 暂列 / 暂列金 / 暂估价 | 一笔预留的自由资金 | 写明用途与结算方式，未使用如何处理 |
| 另计 / 其他费用 / 不含 | 报价边界外的内容 | 补单价表 |
| 以实际为准 / 具体现场而定 | 全部由现场解释 | 补可验证的写法或明确上限 |
| 甲供 / 甲方自理 | 采购责任与损耗责任易空 | 补损耗率与保管责任 |

### 2.3 三种计价方式的比较

| 计价方式 | 优点 | 风险点 | 合同要补什么 |
|---|---|---|---|
| 闭口（固定总价） | 业主预算可控 | 范围变更时易扯皮 | 变更须书面签证；写清报价包含范围清单 |
| 按实结算（单价×实际量） | 量变价不变 | 基数与工时不可控 | 单价固定、计量方式明确、总量上限、结算凭证要求 |
| 成本加酬金 | 灵活 | 成本口径难验证 | 成本构成范围、计价依据、酬金比例或金额、上限 |

**判断建议**：闭口并非一定优于其他方式。关键是范围清单是否完整、变更是否有签证机制。范围不清的闭口合同，比有清晰规则的按实结算更容易失控。

## 三、报价单与实际结算差异的六个来源

| 来源 | 识别特征 | 责任归属倾向 | 主张所需材料 |
|---|---|---|---|
| 报价本身不含 | 报价单无对应行项，施工方以"必备项"提出 | 视合同对报价范围的表述与行业通常理解 | 报价单、完整施工范围对照表、往期沟通记录 |
| 表述模糊 | 同一项双方理解不同 | 解释权归属需看条款与证据 | 合同条款、报价单文字、变更前沟通记录、实际施工做法 |
| 按实结算 | 计量方式或单价超出预期 | 看是否属双方约定范围 | 合同约定单价、隐蔽工程验收记录、影像与量尺记录 |
| 现场变更 | 新增合同外内容 | 看变更提出方 | 书面变更签证单、提出方确认记录、影像 |
| 业主自身改动 | 方案调整、材料升级、功能增加 | 业主承担相应价款与工期影响 | 变更签证单、业主签字记录 |
| 质量整改返工 | 施工方原因导致的返工 | 施工方承担 | 整改通知、原因说明、验收记录 |

### 3.1 结算核对四步法

```
第 1 步  三方对照
  结算书 × 报价单 × 变更签证单，逐行对照，标出每一行的来源

第 2 步  归类标注
  每一行标注属于六个来源中的哪一类；无对应来源的行项单独标出

第 3 步  分流处理
  可主张行项（报价已含却被重复计费、按实结算项未提供计量凭证、属施工方责任的返工）
  需协商行项（表述模糊项、按实结算项单价争议）
  应承担行项（业主变更、约定内的按实结算部分）

第 4 步  单价复核
  剩余行项逐行核对单价与合同或签证约定是否一致；无约定的按当地同期价格水平提出参照
```

### 3.2 复核时容易漏的四处

| 位置 | 漏掉的后果 |
|---|---|
| 数量单位 | 报价单写"延米"、结算写"米"，米数口径要核 |
| 重复计费 | 同一工序在报价单出现一次，在结算单出现两次（换行名目） |
| 材料损耗 | 报价单按主材整量报，结算按实际用量加损耗计，需核损耗率约定 |
| 成品安装 | 报价含材料不含安装，结算按安装另计，核是否已在报价中 |
