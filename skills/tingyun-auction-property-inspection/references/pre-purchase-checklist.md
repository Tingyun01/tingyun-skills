# 买前必核清单

> 用途：出价前逐项过一遍。清单按"能不能做决定"排序，不按流程顺序。
> 每一项写明：在哪查、怎么查、看到什么算红旗。
> 本清单不构成法律专业意见，涉及权属、优先受偿、租赁对抗力、居住权效力的问题须由执业律师复核。

---

## 一、阻断项清单（命中任意一项，原则上不该出价）

| 编号 | 核查项 | 在哪查 / 怎么查 | 红旗信号 | 处理动作 |
|---|---|---|---|---|
| B1 | 居住权登记 | 不动产登记信息查询渠道的"其他登记事项"栏 | 存在居住权登记 | 取得居住权人书面放弃或变更登记文件后再评估 |
| B2 | 权利人与公告一致性 | 登记簿打印件 + 拍卖公告逐字比对 | 姓名/证件号/共有方式不一致 | 要求书面澄清，必要时由律师发函 |
| B3 | 共有人意思表示 | 共有方式与共有人名单；委托与授权文件 | 按份共有人未全部参与或未授权 | 补齐授权，否则不参与 |
| B4 | 在先租赁冲突 | 住建/房管租赁备案台账 + 现场实际占有 | 租期长、租金明显偏低、签约日晚于查封日 | 转律师核实对抗力，价格计入长期让渡占有 |
| B5 | 处置主体资格 | 拍卖公告、执行法院或处置方出具的委托与资格文件 | 主体与登记链条说不通 | 要求补齐材料 |
| B6 | 是否进入破产或分配程序 | 向承办法官/执行局核实程序状态 | 已启动破产或参与分配程序 | 重新测算资金与周期，可能改为观望 |
| B7 | 竞买资格条件 | 竞买须知中的资格条款 | 你的主体条件不满足 | 调整参与方式或放弃 |
| B8 | 尾款支付能力 | 自有资金与融资安排书面确认 | 无法在规定期限内备齐尾款 | 不参与，避免悔拍 |

## 二、高风险项清单（可做，但必须调价或调方案）

| 编号 | 核查项 | 怎么查 | 影响 |
|---|---|---|---|
| H1 | 查封轮次与来源 | 登记查封信息栏 | 多轮查封 → 分配不确定、时间拉长 |
| H2 | 优先受偿权种类与规模 | 向执行法院了解分配口径 | 成交价款扣除顺序影响资金回流 |
| H3 | 抵押余额与登记状态 | 登记抵押信息栏 | 影响过户路径与扣除金额 |
| H4 | 实际占有人身份 | 现场 + 物业 + 邻居走访 | 非产权人长期占用 → 腾退难度上升 |
| H5 | 被执行人配合意愿 | 处置方书面回复、历史沟通记录 | 决定腾退走协商还是走强制程序 |
| H6 | 垫付税费规模 | 按当地当期税率口径测算 | 卖方税费回收率通常极低 |
| H7 | 欠费与停供停暖 | 物业与公用事业台账 | 影响居住可用性与修缮预算 |
| H8 | 户口与学位 | 现场核实 + 物业走访 | 影响学位使用与腾退难度 |
| H9 | 交割周期 | 与当地登记、法院办事周期核对 | 决定资金占用与月供压力 |
| H10 | 拍卖轮次与降价安排 | 竞买须知与历史拍卖公告 | 决定是否有再拍空间 |

## 三、常规项清单（查完留档，计入预算）

| 编号 | 核查项 | 怎么查 |
|---|---|---|
| R1 | 户型、面积、朝向、楼层 | 登记信息 + 现场实测比对 |
| R2 | 装修与设备状况 | 现场查勘：管线、防水、空调、地暖、热水器 |
| R3 | 电梯、楼道、门禁、停车 | 现场与物业确认 |
| R4 | 物业费标准与欠费 | 物业台账 |
| R5 | 供暖费与供暖状态 | 供热单位台账 |
| R6 | 水电燃气开户与欠费 | 营业厅查询 |
| R7 | 车位权属与使用 | 车库管理方 |
| R8 | 违章搭建与改扩建 | 现场比对登记平面图 |
| R9 | 产权证办理状态与历史遗留问题 | 登记信息与向登记中心核实 |
| R10 | 小区维修资金与改造计划 | 物业与业委会 |
| R11 | 违约金与交割条款 | 竞买须知逐条读，重点看交付与违约条款 |
| R12 | 竞买担保金退还规则 | 竞买须知 |

## 四、法院通常不负责处理的瑕疵清单（买受人自行承担的部分）

| 类别 | 具体项目 | 建议动作 |
|---|---|---|
| 房屋质量 | 渗漏、结构改动、防水失效、外墙屋面状况 | 现场查勘并留存影像，必要时请专业人员出报告 |
| 装修与设备 | 老旧管线、空调地暖、热水器、厨卫设备 | 按更换或大修计入修缮预算 |
| 欠费类 | 物业费、供暖费、水电燃气、有线、车位费 | 拉台账实数，确认停供停暖恢复条件与费用 |
| 户口与学位 | 户口未迁出、学位被占用 | 书面确认处理方案与时限 |
| 违章与历史遗留 | 搭建、改扩建未办证、未办出产权证、办证年限限制 | 向登记部门核实可办性与时间 |
| 权属争议 | 共有权人异议、继承人异议 | 要求书面澄清，必要时律师介入 |
| 优先购买权 | 承租人主张同等条件优先购买权 | 记录主张情况与时间，转律师 |
| 腾退本身 | 腾退衍生出的补偿争议与额外主张 | 在上限中计入缓冲 |
| 交付内容 | 家具家电与固定设施归属、拆改痕迹 | 交接单据逐项写明并留档 |
| 小区层面 | 物业规则、业委会决议、后续改造与维修资金使用 | 向物业与业委会了解 |

## 五、必问主体与提问清单

### 5.1 向承办法官 / 执行局
1. 本标的登记查封几轮、分别来自哪些法院、顺位如何？
2. 是否已有其他债权人申请参与分配？分配方案处于什么阶段？
3. 优先受偿权的种类与大致金额区间？
4. 是否存在已启动的腾退安排或已办理的腾退裁定？
5. 成交后的交割与过户由谁办理、需要哪些材料、大致周期？
6. 竞买担保金与尾款的规则、悔拍处理口径？
7. 公告中税费由买受人承担的约定，在本案实际如何操作？

### 5.2 向不动产登记机构（查档）
1. 登记簿完整打印件（含权利、抵押、查封、其他事项四栏）
2. 共有方式与共有人名单
3. 居住权、异议登记、预告登记等是否存在
4. 查封顺位与轮候次数
5. 登记中的面积、用途、房屋性质、权属来源
6. 抵押权人与抵押登记日期

### 5.3 向物业 / 物业与业委会
1. 欠费明细与是否停供停暖
2. 房屋实际占用情况、是否有外来人员长期占用
3. 车位归属与使用状况
4. 装修与改造的报批要求（后续若要改造）
5. 维修资金余额与近期改造计划
6. 垃圾清运、暖气开通等恢复类事项的条件与费用

### 5.4 向处置方 / 中介（仅取信息，不作为结论依据）
1. 完整竞买须知、评估报告、拍卖公告与附件
2. 房屋现状说明与照片视频的拍摄时间
3. 被执行人腾退态度的历史信息
4. 历次拍卖与流拍记录、降价幅度
5. 竞买担保金与尾款的具体数额与支付方式

### 5.5 向承租人（谨慎，以核实租约为目的）
1. 租赁合同签订时间、租期、租金、是否备案
2. 实际入住与使用情况、押金情况
3. 是否主张优先购买权、是否已主张

## 六、交付前后的收尾清单

- [ ] 交接单据：水电气读数、供暖、有线、家具家电归属、钥匙门禁数量逐项确认
- [ ] 更换门锁，并留存新锁凭证
- [ ] 现场照片与录像留存（房屋现状、表读数、交付时点）
- [ ] 取得处置方或执行法院出具的腾退与交接书面记录
- [ ] 户口迁出结果确认，未迁出部分的处理方案书面化
- [ ] 物业欠费与公用事业欠费结清凭证
- [ ] 全部沟通记录、书面回复、公告与竞买须知归档
- [ ] 尾款与各项费用凭证留存，作为后续争议的事实基础

## 七、一页纸速查（打印贴在桌上）

```
出价前五问：
 1. 居住权清了吗？          → 没有就别出价
 2. 权利人、共有人对得上吗？ → 对不上就停
 3. 现在的租客和占用人是谁？→ 身份与依据写清楚
 4. 腾退我按几个月算？      → 按悲观档算，别按乐观档
 5. 尾款我能按时凑齐吗？    → 凑不齐不参与

出价时两问：
 6. 我的熔断数字是多少？    → 写下来，到数停手
 7. 我买完真实到手多少钱？  → 三档成本表算过吗

交割前两问：
 8. 腾退完成、钥匙到手了吗？
 9. 交接单据和影像留全了吗？
```
