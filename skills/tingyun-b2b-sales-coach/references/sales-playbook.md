# 方案式销售、报价让步、招投标陪跑与丢单复盘

> 本页为销售陪跑执行底稿。不构成经营结论，需人工判断后执行。严禁任何违法违规动作。

## 一、从推销到方案式销售（对决策层结构）

```
1. 客户业务痛点：用客户的行业语言，不堆产品参数
2. 我们的理解与目标：先对齐，证明你听懂了
3. 方案逻辑：为什么这样做、解决哪几件事
4. 投入与回报：算得清的账（含节省、提效等隐性收益）
5. 落地节奏与风险兜底：分阶段、有退路，让他放心
6. 下一步：明确谁、何时、做什么（不悬空）
```

原则：决策者要的是"价值与确定性"，执行层要的是"细节与可控"。同一次汇报，准备两套深度。

## 二、报价与让步纪律

- **先锚价值再谈价**：让客户先认可价值，价格才有谈判空间。
- **让步必换条件**：每一次降价/让利，绑定一个推进动作。
  - 例："价格让 3%，需先签框架意向"；"再降 2%，需锁定首年量"
- **让步阶梯（示例，自底向上递进）**：
  ```
  样品/小批试单免费或低价  →  首单优惠价  →  年框量价  →  战略合作价
  ```
  每次只放一层，不一次性到底。
- **守住底线价**：提前算好"低于此价不如不做"，避免被拖入消耗战。
- **忌**：主动大幅降价示好、为抢单跌破成本、把底价一次性亮给采购。

## 三、招投标陪跑要点

| 环节 | 易丢分点 | 做法 |
|---|---|---|
| 读标 | 漏看废标条款 | 先列"硬门槛清单"，不满足直接评估是否参与 |
| 商务标 | 报价策略失衡 | 用阶梯价，留谈判余量；不恶意低价 |
| 技术标 | 答非所问 | 逐条对应评分项，能打分的每一条都给证据 |
| 述标 | 讲产品不讲价值 | 面向评委讲"解决什么、为什么选我们" |
| 陪标风险 | 围标串标 | 严禁；只做自身材料合规 |

## 四、丢单复盘框架（五问）

```
1. 输在哪一层？需求没确认 / 关键人没找对 / 价值没讲清 / 价格没谈拢 / 关系或合规出局
2. 我们何时该看出信号？回溯跟进记录里的转折点
3. 竞品强在哪？价格、关系、案例、交付还是响应速度
4. 我们自己哪步慢了或错了？响应、材料、跟进节奏
5. 下次同类单，前三条动作怎么改？落到可执行的 1~3 点
```

复盘目的不是追责，是让下一单少走弯路。结论要具体到"下次在 X 阶段多做 Y"。

## 五、红线

不承诺成交；不教回扣、围标、虚假资质；不冒充客户内部人员。
