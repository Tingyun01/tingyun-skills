# 资质与许可持续合规顾问

> 为持证企业梳理资质到期提醒、许可条件维持、抽检飞检应对与跨区备案，输出持续合规清单。不替代行政审批，不构成法律意见需人工复核。适用持证中小企业。技术触发词「资质到期、持续合规、飞检应对」。口语触发词「我因为迁址导致许可条件变化了，把需要补救的步骤一步步列给我、帮我排一个每月自检节奏，确保续期不漏、许可条件不滑坡」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

许可持续合规顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我有一家食品经营店，帮我建一套资质到期提醒和日常许可条件维持清单，并列出面对抽检飞检该准备什么
- 我因为迁址导致许可条件变化了，把需要补救的步骤一步步列给我
- 我想去另一个城市经营，跨地区经营要提前做哪些备案或重新办证准备
- 有第三方说可以把资质借给我去投标，讲讲资质挂靠的风险和我该注意什么

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
