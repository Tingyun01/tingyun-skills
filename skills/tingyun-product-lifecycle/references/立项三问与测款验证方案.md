# 立项三问、测款方案与需求验证

## 一、立项三问答题模板

三问是**评审门**，不是问卷。每问都要写出可被反驳的具体答案，写不出就是还没到投钱的阶段。

### 1.1 问一：卖给谁

```
填空结构（逐项填，不要跳）
  人群：________________（具体到年龄段、职业、生活状态、消费习惯）
  场景：________________（在什么情况下会想到需要这个产品）
  现有替代：____________（现在用什么代替？替代品价格多少）
  切换理由：____________（凭什么让他从替代品换成你）
  现有支出：____________（他目前在这件事上每月/每次花多少钱）
  可触达方式：__________（通过哪个渠道能以低成本重复触达他）
```

**答案质量对照**

| 不合格 | 及格 | 为什么 |
|---|---|---|
| "年轻女性" | "25~35 岁、在城市租房、桌面空间小于 1 平方米、用折叠布柜代替收纳" | 有没有具体人群 + 场景 |
| "追求品质的人" | "预算 200~300 元、买过一次就坏过、对售后响应敏感" | 有没有可观察的偏好与约束 |
| "市场很大" | "我已有 800 个同类购买者，近 30 天复购率 12%" | 有没有你自己的数据 |
| "卖给所有需要的人" | "只做租房小户型，30 岁以上、有明确收纳痛点" | 有没有主动放弃的群体 |

**追问句（用户答得含糊时用）**：
- "他现在用什么代替？那个东西多少钱？"
- "你上次看到一个同类产品，是在什么内容里看到的？"
- "他为什么会在今天而不是三个月后买？"

### 1.2 问二：凭什么是我们

```
填空结构
  资源一（工艺/设备/技术）：________________  同行要补上需要多久：______
  资源二（客户关系/渠道）：__________________  同行要补上需要多久：______
  资源三（成本/地理/资质）：________________  同行要补上需要多久：______
  成本优势能否量化：________________________  量化到每件或每单：______
```

**不合格答案**：质量好、有经验、团队专业、价格实惠、供应链稳定。

**为什么不合格**：这些是**所有同行都会说的话**，没有一条构成差异。及格答案必须满足三个条件：有名字（具体什么资源）、有量化（每件省几元、快几天）、有壁垒（别人补上要多久、要多少钱）。

**"别人短期做不到"的检验法**：把你写的资源念给另一个同行听，如果他能在三个月内补上，这条不算数。

### 1.3 问三：明确不做什么

```
填空结构（至少三条，写死）
  不做的人群：________________
  不做的价位段：______________
  不做的渠道：________________
  不做的规格/功能：____________
  不做的客户类型（如 B 端、批发、出口）：________
```

**为什么这一问更关键**：前两问是向外证明自己，第三问是**主动放弃市场**。写不出不做什么，通常说明对目标客户的选择还没做完——因为"什么都做"是拒绝做选择的一种方式。

**判断标准**：**这三条一旦写下，就要作为后续所有决策的筛选器**。新品打样时、渠道选品时、客户定制需求来时，凡是触碰这三条的需求，一律走"额外立项"而不是"顺手做了"。

### 1.4 三问评审结论的四种写法

```
结论一 建议通过
  条件：三问全部答出且有量化支撑；关键假设已列出；测算显示盈亏平衡量在可接受范围
  下一步：进入测算与测款设计

结论二 有条件通过（进入小批量验证，暂不投模具与大货）
  条件：三问有一问答不出或缺量化；或测算显示盈亏平衡量偏高但不确定
  下一步：给出需要补齐的假设清单 + 低成本验证方案（改模、贴牌代工、样品预售）

结论三 建议暂缓
  条件：卖给谁答不出；或资源无可量化差异；或目标人群与现有渠道完全不搭
  下一步：写清"什么条件变化后可以重启"（避免半年后又有人提同一个想法）

结论四 建议放弃
  条件：测算显示结构上不成立（如单件贡献毛利为负且无降本路径）；或切换理由不成立
  下一步：把这次评审的判断线存档，供下一轮立项对照
```

**不要写成"这个品不值得做"**。写成条件式，让老板自己判断——他是决策人，他掌握你不知道的信息（客户关系、产能安排、对赌承诺）。

## 二、小批量测款与需求验证方案

### 2.1 测款三要素

```
一、量：首批量 = 目标预计月销量 × 倍数
   倍数取值：
     验证周期短（2~4 周）、需求确定性高（已有客户意向）：1~1.5 倍
     验证周期需覆盖完整采购周期：1.5~2 倍
     季节性明显或季节不确定：2~3 倍（宁多勿少，缺货会把"没验证出来"变成"没测到"）
   首批量的上限约束：单批投料不超过你能承受的全部损失额 ÷ (单位完全成本 + 固定投入)

二、渠道：主推渠道 + 对照渠道
   主推渠道 = 你计划长期主推的那个
   对照渠道 = 一个规模不同或人群不同的渠道（作用是区分"这个品不行"和"这个渠道不行"）
   对照渠道的选择原则：人群不同、且你自己能低成本运营
   不要用"随便多开一个渠道"当对照——对照渠道要有对照价值

三、价格：两档各半
   档一：按你自己的成本测算价（验证"这个价有没有人买"）
   档二：按用户心里的替代品价格 ± 上浮（验证"愿意为它多付多少"）
   两档必须同时存在。只有一个价时，你无法区分"需求弱"和"价格不对"
```

### 2.2 达标线与停做线（测款开始前就写下来）

```
三条达标线（满足全部才算通过）
  达标线一（卖得动）：售出率 ≥ ____%（售出量 ÷ 上架量）
     参考区间：首测 30%~50% 属可讨论，低于 20% 通常说明人群或卖点有问题
  达标线二（卖得值）：该渠道的毛利率 ≥ ____%，或与对照渠道的毛利率差 ≥ ____ 个点
  达标线三（留得住）：30 天内复购或转介绍信号 ____，退货率 ≤ ____%
     对耐用品用"口碑与返修率"，对快消用"复购率"，对 B 端用"续购意向"

停做线（满足任一即停，判定日写明）
  停做线一：测款期结束，售出率 < ____%
  停做线二：达标线二中有一项未达标，且毛利低于 ____%
  停做线三：退货率 > ____%，且原因集中于产品本身（非物流或客服）
  停做线四：达到试产量上限仍无有效需求信号

判定日：测款开始后第 ____ 天（或覆盖 ____ 个完整采购周期）
判定人：____（写具体名字，避免"大家看看"）
```

**为什么要提前写死**：没有停做线的测款会一直继续，因为每多投一点都沉没成本更高。**停做线是对抗沉没成本的工具，必须在你还清醒的时候写好。**

### 2.3 测款期要留的记录

```
渠道与日期 / 曝光量（后台数据截图或记录）/ 详情页访问 / 加购或询价
成交数与成交价 / 退款与退货原因 / 评价原文（尤其差评，逐条归类）
客服问答记录（高频疑问直接指向下一版改什么）
对照渠道的同口径数据
```

**差评逐条归类**是测款期价值密度高的动作：把差评分成"不是我要的（人群错）""价格不值（价格或性价比错）""质量不行（产品错）""描述不符（信息错）"四类，归类结果直接决定下一版做什么。

### 2.4 测款常见的四种无效做法

| 无效做法 | 问题 | 改法 |
|---|---|---|
| 只铺一个渠道 | 结论无法区分品与渠道 | 加对照渠道 |
| 只测一个价 | 无法得到价格弹性 | 两档各半 |
| 只看首购不看复购 | 首购含好奇与尝鲜 | 追踪 30 天复购、退货、评价内容 |
| 无限期补货 | 没有停做线 | 测款前写死判定日与停做线 |
| 用低价冲量测"有没有人要" | 低价有量不等于能赚钱 | 同步测毛利水平 |
| 在熟人或小圈子测 | 样本偏差大，结论不可迁移 | 目标渠道的真实用户 |
| 测款期同时改了产品 | 数据对应不上是哪个版本 | 一个测款周期只改一个变量 |

## 三、需求验证的其他手段（与测款配合使用）

| 手段 | 适合回答的问题 | 注意 |
|---|---|---|
| 意向预订（预售、意向金） | 有多少人愿意现在付钱 | 预售履约有法律与信披要求，条款与宣传口径需专业复核 |
| 样品寄送试用 | 实物到手后的满意度和缺陷点 | 记录退回率与退回原因 |
| 老客户访谈 | 这个需求他们是否已有替代、为什么不满 | 问"上次买这类是什么时候、为什么换牌子"，不要问"你觉得我的产品怎么样" |
| 渠道数据倒推 | 这个品在该渠道的历史表现 | 需要对方提供或自己历史数据 |
| 竞品差评挖掘 | 现有替代品被抱怨的地方 | 只看公开的评价与问答区内容，不抓取他人数据 |

**判断标准**：**意向预订 > 试用反馈 > 访谈 > 猜测**。预定的说服力在于它有真实成本（付钱、要等、要承担不合适）。越是零成本的信号，参考价值越低。

## 四、这一套逻辑不成立的情形

- **产品已有明确的既定客户订单**（贴牌代工、已有合同）：三问的答案就是客户本身，此时重点转向报价与产能核对，而不是需求验证。
- **季节性极强且窗口已过**：测款来不及，此时靠历史同期数据与预售订单判断，而不是靠小批量铺货。
- **单价极低、需靠量取胜**：小批量测出的量无法线性外推（渠道起量有门槛效应），此时测款的价值是验证"能不能卖得动"，不是测算总量。
- **资源高度依赖单一客户**：三问中的"凭什么是我们"实际答案是"因为这个客户要"，此时评审重点变成"客户流失后怎么办"。
