# 库存老化分级、停产处置路径与备件义务

## 一、库存老化分级与逐段处理路径

### 1.1 五档分级表

| 库龄 | 状态 | 处理目标 | 动作清单（按顺序尝试） | 止损红线 |
|---|---|---|---|---|
| 0~90 天 | 正常 | 正常动销 | 常规运营，不特殊处理 | 无 |
| 91~180 天 | 轻度预警 | 恢复动销 | 换主图/标题、调整主推渠道、参与平台活动、补充内容投放 | 单件处理成本 > 毛利 时转下一档 |
| 181~360 天 | 中度 | 加速回笼 | 组合搭售、降价阶梯、清库存专场、拆零/小份销售、跨渠道分销 | 不跌破同期同类价锚点 |
| 361~540 天 | 重度 | 清仓回款 | 打包处理、让利给经销商、尾货处理、拆件改款 | 优先回款速度，接受亏损 |
| > 540 天 | 深度 | 止损与出清 | 清仓、拆件、回收、报废处理 | 账务与税务处理口径须财务与税务师复核 |

**判断标准**：**先按"动销可能性"分类，再按库龄定档**。同样是 200 天库龄，走量款和季节错配款的处理方式完全不同。**库龄是信号，不是结论**。

### 1.2 分段动作的四个注意点

```
一、不要一次打光
   一次降价清空会拉低同款价格锚点，后续新品难以定价。
   做法：分批放、只清尾货、保留少量在架占位（占位不占库存）

二、清库存与推新品要错开
   同一款老品降价到 49 元，同期新品上市会被比价。
   做法：清库存期间新品不同渠道上，或新品避开同款同图

三、优先动"库存成本"而不是"库存金额"大的
   库存成本 = 货值 × 资金成本率 × 停留月数
   停留 2 年的大额库存，资金成本通常高于停留 3 个月的小额库存。
   做法：先排资金成本高的

四、跨渠道分销要核对该渠道的准入要求
   认证、质检报告、包装规范、售后责任可能与主渠道不同。
   做法：先核对该渠道的准入清单，再决定铺不铺
```

### 1.3 库存台账必备字段

```
SKU / 批次号 / 入库日期 / 数量 / 单件成本 / 库龄 / 呆滞原因 /
可再销售状态（全新/已拆封/外观受损/功能待检）/
可转备件（是/否/需检修）/ 处理结论 / 责任人 / 完成日 / 实际回收金额
```

**"呆滞原因"这一栏容易被跳过，也很有价值**。原因不同，处理方式完全不同：

| 呆滞原因 | 处理方向 |
|---|---|
| 卖不动（人群/卖点问题） | 换渠道、换卖点、组合销售 |
| 季节错配 | 跨季节销售、等下一个季节、此季出清 |
| 备货过量 | 快速降价、压货给经销商 |
| 质量或合规问题 | 隔离待处理、返工或退货、不得混入正常销售 |
| 规格过时 | 折价清仓、拆件改款 |
| 包装或标签问题 | 重新包装或贴标（需核对该渠道规则与法规要求） |

## 二、停产 7 步时序表

```
顺序很重要：先冻结再排产，边做边想退市库存只会越滚越大。

第 1 步 冻结（立即）
  动作：停止新接单、停止备料、停止新开模具与新开发
  产出：冻结通知（内部），记录生效日
  责任：销售负责人 + 生产计划
  风险：不做这步，后面每一步都在扩大损失

第 2 步 排产（冻结后 3~7 天内）
  动作：已投料的在制品与已下单的料排完，给出完工日与完工数量
  产出：排产收尾表（工序、批量、完工日）
  责任：生产计划
  责任：注意：排产期间不再接新单、不再改规格

第 3 步 库存（排产完成后）
  动作：成品 / 在制品 / 半成品 / 原料分层
        成品 → 走老化分级处置
        在制品 → 能当备件评估，不能则改款
        半成品 → 评估改款或降级使用
        原料 → 通用料转其他品、专用料与供应商结算
  产出：库存处置表（每项：数量 / 处置方式 / 责任人 / 完成日 / 回收金额）
  责任：仓储 + 采购

第 4 步 客户（与第 3 步并行准备，第 3 步完成后发出）
  动作：通知已接订单的交付安排、售后承接方与时限、备件供应期限
  产出：客户通知稿（口径、时点、联系人、承诺期限）
  责任：销售负责人
  提示：涉及通知效力与义务边界的部分，请由执业律师审核口径

第 5 步 备件（与第 4 步同步测算）
  动作：见第三节的备件测算
  产出：备件需求量与生产/采购计划
  责任：技术 + 生产

第 6 步 模具与资产（第 3~5 步收尾后）
  动作：模具转移或留存并盘点、专用料处理、设备与工装处置、图纸与资料归档或销毁确认
  产出：模具与资产处置单（双方签字）、专用料结算单
  责任：采购 + 财务
  提示：模具所有权与转移方式、专用料结算、相关税务处理须由执业律师与税务师复核

第 7 步 复盘（收尾后两周内）
  动作：把这次的判断线写下来（立项三问的答案、当时的测算、退出触发点），形成下一个品的对照基准
  产出：复盘纪要 + 判断线归档
  责任：老板本人或产品负责人
```

### 时序总表（可打印）

| 步 | 动作 | 起止时间 | 责任人 | 产出文件 | 完成标志 |
|---|---|---|---|---|---|
| 1 | 冻结 | D0 | 销售 + 生产计划 | 内部冻结通知 | 新单与备料已停 |
| 2 | 排产收尾 | D3~D7 | 生产计划 | 排产收尾表 | 完工日已定 |
| 3 | 库存处置 | D10~D45 | 仓储 + 采购 | 库存处置表 | 库存清零或已定去向 |
| 4 | 客户通知 | D15~D30 | 销售负责人 | 客户通知稿 | 已发并留痕 |
| 5 | 备件安排 | D15~D40 | 技术 + 生产 | 备件计划 | 供应期限已告知 |
| 6 | 模具资产 | D45~D75 | 采购 + 财务 | 处置单与结算单 | 双方确认完成 |
| 7 | 复盘 | D75~D90 | 产品负责人 | 复盘纪要 | 判断线已归档 |

## 三、售后与备件义务测算

### 3.1 备件需求量测算

```
已售出且可能需要备件的数量：
  累计出货量 ______ 件
  × 需要备件的比例 ______%（耐用品按备件需求型零件估，常见 3%~8%）
  = 需备件基数 ______ 件

实际备件需求量 = 需备件基数 × 单位时间故障率 ______% × 承诺服务年限 ______ 年
示例：累计出货 20000 件 × 5% = 1000 件；年故障率 8%，承诺 3 年
      1000 × 8% × 3 = 240 件备件需求

再按渠道与承诺口径调整：
  承诺服务期内的售后责任范围：□ 易损件 □ 电气件 □ 结构件 □ 全部
  渠道是否有额外要求：__________
  备件计划量 ______ 件（建议在此基础上留 ___% 余量）
```

### 3.2 备件的三种处理方式

| 方式 | 做法 | 适用 | 成本与风险 |
|---|---|---|---|
| 自行生产 | 用留存的模具继续生产备件 | 有模具、量够、模具状态可用 | 模具保管费与维护；量太小则单件成本高 |
| 外购替代 | 找替代供应商做备件 | 模具已处理、量小 | 需重新确认质量与交期；客户接受度要评估 |
| 承诺终止 | 明确告知售后截止期限，之后不再供应 | 客户接受、渠道允许 | 涉及通知效力与可能的责任边界，须由执业律师审核口径与表述 |

**判断标准**：**备件承诺的边界（服务几年、哪些件、谁承接）要在停产通知里写清**。口径模糊的"后续不再提供"在纠纷时难以举证。这部分文案请由执业律师审核。

### 3.3 需要同时准备的三份东西

```
1. 客户通知稿：停产/退市说明 + 已接订单处理 + 售后截止期限 + 备件供应期限 + 联系人
2. 备件清单：件号、名称、可供应期限、数量、单价
3. 台账留档：已售出明细（客户、型号、数量、时间）——这是备件义务与售后追溯的基础
```

## 四、库存与在制品的"二次利用"评估

处理库存不等于只能降价。以下四条路要同时评估：

| 路径 | 评估点 | 常见障碍 |
|---|---|---|
| 转备件 | 是否属于易损/易坏件；客户是否需要；是否需检修与检验 | 需检测与检验记录 |
| 改款 | 换包装/换颜色/换配件变新款 | 改款成本 vs 清仓损失；改款后是否又是新库存 |
| 内部消化 | 员工福利、赠品、样品、售后补发 | 需账务处理口径，财务与税务师复核 |
| 退供应商 | 通用料可退；专用料按合同处理 | 合同条款与谈判 |

**判断标准**：**"转备件"和"改款"常被忽略，而它们的回收率通常高于降价清仓**。先评估这两条，再考虑打折。

## 五、这一套逻辑不成立的情形

- **库存数量小、清仓收益覆盖不了处理成本**：直接走简化处置方式（打包或退货），不要搭流程。
- **产品涉及强监管或召回相关**：库存处置有额外约束，相关合规口径须专业复核，不要按普通品处理。
- **已停产多年、库存已计过减值**：账面与实物可能已不一致，先做实物盘点与账实核对，再谈处置。
- **有在途订单且客户是长期大客户**：处置顺序要让位于关系维护，先谈方案再走流程；此时更应该做的是**产品迭代接续**（用新品承接老客户）而不是简单退场。

**提醒**：存货跌价准备的计提与处置损失的税务处理，因企业类型与政策更新而异，须由财务负责人与税务师核实。本表只提供流程与测算方法，不给会计与税务结论。
