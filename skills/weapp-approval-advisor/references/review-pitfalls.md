# 审核被拒案例库（微信小程序）

> 微信审核驳回理由往往含糊（如"页面内容不符合平台规范"）。本案例库按「表面理由 → 真实原因 → 修复方案 → 预防措施」结构整理实战经验。被拒时先在这里定位，再改代码。

## 使用方法

1. 逐字阅读驳回通知，提取关键词（类目、内容、功能、资质）。
2. 在下方按类别定位最接近的案例。
3. 修复时**不要只改驳回点**——一次被拒通常牵连同类问题，全项目排查同签名内容。
4. 重提时在补充材料框写明整改说明（模板见文末）。

## 案例库

### A. 内容合规类

**A1. 含占卜/玄学表述**
- 表面理由：小程序内容涉及封建迷信。
- 真实原因：界面或功能文案出现"算命、占卜、运势、测字、命理、天意、玄机、卦"等词，即使娱乐性质也命中。
- 修复：全部替换为文化向表述——"民俗文化、传统文化体验、汉字文化趣味测试、国学"等；功能定位为"趣味人格心理测试"而非"预测"。
- 预防：提审前跑敏感词扫描脚本。

**A2. UGC 内容无审核机制**
- 表面理由：用户生成内容缺乏审核，存在内容安全风险。
- 真实原因：允许用户发布文字/图片但无任何过滤与举报入口。
- 修复（三件套缺一不可）：① 接入微信内容安全接口（`msgSecCheck` / `imgSecCheck`）做发布前校验；② 每条 UGC 加举报入口；③ 用户协议中加"用户对发布内容负全责"条款。
- 预防：宽松审核机制可以——只硬拦明显违法内容，模糊内容加用户免责声明放行——但**机制本身必须在**。

**A3. 诱导分享/诱导关注**
- 表面理由：存在诱导分享行为。
- 真实原因：出现"分享后解锁""分享到群领取""不分享无法使用"等强制或利益诱导话术。
- 修复：改为自然分享——分享得积分不承诺结果、提供不分享也可用的替代路径；删除所有"必须分享"逻辑。
- 预防：文案避免"分享可解锁/必须转发"句式。

### B. 资质与类目类

**B1. 类目与功能不符**
- 表面理由：小程序涉及 XX 类目，请补充对应资质或调整功能。
- 真实原因：功能越界——用工具类目做了社交/电商/资讯的事。
- 修复：短期砍掉越界功能或加内测开关隐藏；长期补资质或增类目。
- 预防：新功能上线前查类目边界；实验功能用代码级开关保护线上版本。

**B2. 虚拟支付（iOS）**
- 表面理由：iOS 端存在虚拟支付行为。
- 真实原因：iOS 内提供虚拟商品购买（会员、解锁、虚拟币）。
- 修复：iOS 隐藏支付入口（`wx.getSystemInfoSync().platform === 'ios'` 判断），仅安卓开放，或改为 H5 外部引导。
- 预防：涉及虚拟商品变现，架构期就要设计双端差异化。

**B3. 缺少隐私保护指引**
- 表面理由：未配置隐私保护指引 / 用户隐私保护引导不足。
- 真实原因：使用了用户信息类接口（getUserProfile、chooseAddress、getLocation 等）但未在小程序后台填写隐私指引，且代码中未调用 `wx.requirePrivacyAuthorize` 流程。
- 修复：后台「设置 → 服务内容声明 → 用户隐私保护指引」逐项勾选所收集信息并写明用途；代码中处理隐私弹窗回调。
- 预防：每接入一个敏感接口，同步更新隐私指引。

### C. 体验与质量类

**C1. 页面空白 / 功能无法使用**
- 表面理由：小程序页面存在空白页/无法加载。
- 真实原因：审核员实际点开的页面报错——常见于依赖后端数据、云存储图片加载失败、或需要登录才见内容。
- 修复：所有页面提供无数据兜底 UI；关键图片加失败重试与占位图；体验版用完整测试数据自测全页面。
- 预防：提审前用「预览」在真机全页面走查一遍。

**C2. 诱导测试/问卷类功能定位不清**
- 表面理由：页面功能描述与实际不符。
- 真实原因：问卷/测试功能界面像"调查收集信息"，审核担心信息滥用。
- 修复：明示"本问卷数据仅用于 X 用途、本地保存/匿名处理"；问卷类功能建议加内测开关，首版不提审。

**C3. 测试数据残留**
- 表面理由：小程序存在测试内容。
- 真实原因：界面出现 test、测试用户、111、aaa 等占位数据。
- 修复：全局搜索测试数据并替换为真实感内容。
- 预防：上线检查清单必查项。

### D. 名称与商标类

**D1. 名称侵权/含保留词**
- 表面理由：名称不符合规范。
- 真实原因：名称含他人商标、微信/腾讯等保留词、或与已有小程序高度近似。
- 修复：改名（每年有改名次数限制，谨慎使用）；名字定稿前先在微信搜索查重。

## 重提补充材料模板

```
本次整改内容说明：
1. 【驳回问题】针对"XX"问题，已删除/替换 XX 处相关内容（涉及页面：A、B）。
2. 【同类排查】已全项目排查同类表述，共修改 N 处。
3. 【机制补充】已增加 XX（如内容安全审核/隐私指引/免责声明）。
请审核老师复核，谢谢。
```

态度诚恳 + 逐条对应 + 说明排查范围，复审通过率显著提高。
