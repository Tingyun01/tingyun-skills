# 三种比价方式与到手价拆解算法

## 一、先选比价方式

比价方式不选对，后面所有数字都白算。三种方式的差别不在流程形式，在于**它解决的是哪一种不确定性**。

### 1.1 三种方式对照

| 方式 | 做法要点 | 解决的不确定性 | 适用场景 | 前提条件 | 主要代价 |
|---|---|---|---|---|---|
| 书面询价 | 同一份需求书同时发给多家，同一轮次、统一截止时间回收报价 | 需求清晰、价格可比 | 标的通用、供应商数量多、可标准化 | 需求书规格写得够具体，口径写全 | 报价可能与实际承诺有差距 |
| 竞价/招标 | 事先定好资格条件、评审办法、开标流程，逐轮报价并留痕 | 供应商有限、需要公平性与过程留痕 | 金额较大、供应商有限、对流程公正要�� | 有评审办法与开标记录规范 | 周期长、文件工作量大 |
| 协商议价 | 单一或少数供应商，逐项谈价格与条件 | 条件与关系，标准化比不了 | 独家料、定制开发、长期战略合作 | 手里有成本结构与市场参考价 | 易被单点绑定，需防条件滑坡 |

### 1.2 选型判据（按不确定性来源走）

```
问自己：这单的不确定性主要来自哪里？

  来自规格（说不清要什么） → 先别比价，回去补需求书。用任何比价方式都无效
  来自价格（多家报价差异大） → 书面询价或竞价
  来自条件（独家/定制/长期） → 协商议价
  来自价格与条件双头（金额大 + 供应商少 + 需留痕） → 先书面询价取价格锚点，再协商议价谈条件
```

**判断表**

| 情形 | 建议组合 | 理由 |
|---|---|---|
| 通用件、供应商多 | 书面询价 | 标准化程度高，比价效率高 |
| 通用件但需留痕（国企/上市/审计要求） | 书面询价 + 书面评分表 | 形式简单但可回溯 |
| 金额大、供应商 2–3 家 | 竞价 → 协商 | 先拉开差距，再谈条件 |
| 独家料、专利料、专有工艺 | 协商议价 | 没有替代，比价无意义，重点在条款与价格机制 |
| 定制开发、含开模 | 协商议价（配技术方案评审） | 价格取决于方案，先比技术再谈价 |
| 长期战略合作、年框 | 协商议价 + 年度调价机制 | 关注的是价格机制而非单次价格 |

### 1.3 两种方式混用时的顺序纪律

先书面询价再协商议价，顺序不能颠倒：**先拿到价格锚点再谈条件**，否则你手上没有参照，谈出来的条件是对方定的。反过来先谈条件后收报价，容易出现"报价按谈好的条件倒推"。

## 二、比价前的口径对齐清单

比价前必须让各家在同一口径上报价，否则表格是假的。**九项对齐，逐项确认，缺项不开始比价。**

| 序号 | 对齐项 | 不对齐的后果 |
|---|---|---|
| 1 | 标的与规格版本（引用同一版需求书与同一版图纸） | 比的是不同东西 |
| 2 | 含税/不含税、税率、发票类型 | 净价差被税额吃掉，方向可能反转 |
| 3 | 含运/不含运、运费承担方与目的地 | 到手价差 3%–8% |
| 4 | 包装方式、唛头、每箱数量 | 包装与分拣成本被漏掉 |
| 5 | 报价有效期与逾期调价机制 | 签约时价格已过期 |
| 6 | 付款条件（预付比例、节点、账期天数） | 账期成本没进入比价 |
| 7 | 交期与分批安排 | 早批次的成本和风险没定价 |
| 8 | 模具/开模费是否单列、是否含在单价内 | 模具费重复或漏算 |
| 9 | 质保期与售后范围 | 售后成本与责任没对齐 |

**追加一条**：让各家报价单上写明"本报价有效期 __ 天，超过后需重新确认"。这句话本身就在筛供应商——愿意写有效期的通常能兑现。

## 三、到手价拆解算法

### 3.1 三层价格结构

| 价格层 | 定义 | 用途 |
|---|---|---|
| 报价总额 | 供应商写在报价单上的数字 | 仅用于初筛 |
| **到手成本** | 报价总额 + 各项附加成本 − 折让返点 | **比价必须落到这一层** |
| 生命周期成本 | 到手成本 + 质量损失 + 切换成本 + 库存与呆滞 | 评估长期合作对象 |

### 3.2 拆解项与算法

每一项都要能在报价单或谈判中找到出处，填不到的写"待确认 + 谁去问"，不留空格。

| 拆解项 | 算法 / 取数口径 | 常见取值参考 | 取数来源 |
|---|---|---|---|
| 报价总额 | 数量 × 单价（按年度预测量档取） | — | 报价单 |
| 账期资金成本 | 报价总额 × 年化资金成本率 × 账期天数 ÷ 365 | 年化资金成本率按 6%–8% 计（内部资金口径） | 报价单付款条件 + 内部资金成本口径 |
| 运费与物流 | 按整批计（自有车/第三方/买方自提） | 按整批金额的 2%–6% 估 | 报价单或物流询价 |
| 包装与分拣 | 包材费 + 人工分拣，按批次摊 | 每批次固定成本 + 单件包材 | 报价单 |
| 模具/开模费 | 开模费 ÷ 摊销数量 | 摊销数量取年度预测量，不是首单量 | 报价单单列项 |
| 工装/夹具/检具 | 同上，可与模具合并算 | 按工装种类分摊 | 报价单或技术附件 |
| 打样与试产费用 | 打样费 + 试产批损耗 | 按实际发生额计，不摊 | 单独结算项 |
| 检验与认证分摊 | 第三方检测费 + 认证年费 ÷ 年采购额 | 一次性认证按年摊 | 检测机构报价 |
| 售后与备件预留 | 质保期返工/换货预估 + 备件采购 | 按历史不良率折算 | 内部质量数据 |
| 退换货与不良损失 | 不良率 × 单件成本 × 年度用量 | 依行业不良率区间取 | 内部质量数据 |
| 折让与返点 | 年度返点、量价阶梯折扣 | 按年度量谈 | 谈判 |
| 税率差 | 报价总额 × (可抵扣税率 − 不可抵扣或抵扣不足部分) | 由财税口径确认 | 财税专业人士 |

### 3.3 算例（可照此格式套用）

**情形**：定制包装盒，年度用量 12 万个，首单 3 万个；三家报价如下。

| 项 | A 厂 | B 厂 | C 厂 |
|---|---|---|---|
| 报价总额（首单 3 万个） | 180,000 | 168,000 | 195,000 |
| 报价单价 | 6.00 | 5.60 | 6.50 |
| 账期 | 预付 30% + 到货 70%（约 60 天占用） | 全额预付（占用 0 天） | 月结 60 天（占用 60 天） |
| 运费 | 买方自提 | 含运 | 含运 |
| 开模费 | 30,000（首单后转模具所有权） | 36,000 | 24,000 |
| 年度折让 | 无 | 无 | 满 10 万个每千个减 0.15 |

**步骤一：年化总额（按年度用量 12 万个，A、C 假设单价随量阶梯下降）**

```
A：年度采购额 = 12 万 × 6.00 = 720,000
B：年度采购额 = 12 万 × 5.60 = 672,000
C：年度采购额 = 12 万 × (6.50 − 0.15) = 762,000
```

**第二步：账期资金成本（年化 6%）**

```
A：占用约 60 天（预付 30% 长期占用 + 到货款 60 天）
   预付部分 720,000 × 30% = 216,000，长期占用按 180 天计
   216,000 × 6% × 180 ÷ 365 = 6,388
   到货款 504,000 × 6% × 60 ÷ 365 = 4,970
   合计 ≈ 11,358

B：全额预付，占用 0 天 → 0（但把风险全压在自己这边，见下文）
   672,000 × 6% × 90 ÷ 365 = 9,943（若按生产周期 90 天占用 672,000 现金）
C：月结 60 天
   762,000 × 6% × 60 ÷ 365 = 7,514
```

**第三步：模具摊销（按年度用量 12 万个摊）**

```
A：30,000 ÷ 120,000 = 0.25 /个
B：36,000 ÷ 120,000 = 0.30 /个
C：24,000 ÷ 120,000 = 0.20 /个
```

**第四步：折算单件到手价**

```
A：(720,000 + 11,358 + 30,000) ÷ 120,000 ≈ 6.344 /个
B：(672,000 + 9,943 + 36,000) ÷ 120,000 ≈ 5.983 /个
C：(762,000 + 7,514 + 24,000) ÷ 120,000 ≈ 6.613 /个
```

**结论**：B 报价单价较低（5.60），到手价同样较低（5.98），但它是全额预付——现金全压在自己这边且模具费更高。A 到手价居中，C 成本更高。**如果 B 愿意改成 30% 预付 + 月结，A 的优势会进一步缩小；如果 B 不改，则 B 的现金占用风险需要用担保工具对冲。**

**这个算例要记住的三点**：
1. 单价排序（B 5.60 < A 6.00 < C 6.50）和到手价排序在口径不同时会不一致，**只比单价会选错**。
2. 摊销分母必须是年度用量，用首单量摊会把单位成本算高，把一次性摊销费用误判成长期负担。
3. 报价口径全对齐后，价差往往缩到 5%–10%——**这个量级下，条件比价格更重要**（账期、模具归属、质保、退出机制）。

### 3.4 常见算错的地方

| 错误 | 后果 | 纠正 |
|---|---|---|
| 摊销分母用首单量 | 单位成本虚高，误判供应商报价贵 | 用年度预测量 |
| 忽略税与抵扣差异 | 净价差算反 | 与财税确认可抵扣比例 |
| 账期成本按报价总额算而非按实际付款金额算 | 成本高估 | 按各节点实际付款额分别算 |
| 售后预留不算，直接比价 | 选到售后负担重的供应商 | 按历史不良率折算 |
| 把"全额预付"当成占优项 | 现金全压出，谈判无筹码 | 预付条件是成本项，不是优势项 |
| 漏掉打样与试产费 | 首单预算失真 | 单列，不摊入单价 |
| 只算采购成本，不算切换成本 | 高估换供应商的可行性 | 见下节 |

## 四、单价之外的两笔账

### 4.1 切换成本（换供应商要付的代价）

```
切换成本 = 新供应商打样与试产费 + 重新认证与评估工时 + 库存跌价与呆滞
         + 交期中断造成的销售损失 + 模具与工装转移费（若不归本方）
```

**判据**：如果切换成本超过单家供应商全年采购额的 15%，说明你在这条链路上没有议价能力，比价省下的那 3%–5% 会被切换成本一次吃掉。

### 4.2 账期的双向账

对买方有利的一面：延后付款等于把供应商的钱拿来周转。
对买方不利的一面：账期越长，往往意味着供应商不接受你、或者你的规模不足以换条件、或者标的是独家料没有替代。

**账期条件的解读表**

| 对方账期要求 | 通常意味着 | 买方应对 |
|---|---|---|
| 全额预付 | 你不在对方信任名单里，或对方独家地位稳固 | 谈分期；谈不到就换供应商或用担保工具 |
| 月结 60 天 | 常规水平 | 可接受 |
| 预付 30% + 到货 70% | 双方互信 | 常规做法 |
| 要求提前确认订单并付定金后再排产 | 对方产能紧俏 | 争取锁产能但不付全款；签产能预留条款 |
| 报价有效期极短（如 7 天） | 价格易波动或对方想锁死你 | 缩短你的决策周期，或要求价格锁定条款 |
