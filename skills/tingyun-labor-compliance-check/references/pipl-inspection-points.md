# 个保法用工场景要点与稽查点排查

> 仅作合规梳理辅助，涉及员工个人信息处理的具体操作需结合专业意见与当地口径。

## 一、用工场景中属于"个人信息/敏感个人信息"的内容

- 身份信息、联系方式、住址、银行卡；
- 指纹、人脸（生物识别信息，属敏感个人信息）；
- 健康体检、孕产、病史（敏感个人信息）；
- 背景调查获取的犯罪记录、信贷、前雇主评价；
- 考勤定位、工作监控录像。

## 二、个保法四项底线（个人信息保护法）

1. **告知—同意**：处理员工个人信息应告知目的、方式、范围，并取得同意；敏感信息需**单独**告知同意；
2. **必要限度**：只收集与用工管理必要相关的信息，不超范围；
3. **目的限制**：不得用于约定目的之外（如把员工信息转卖、随意提供给第三方）；
4. **安全保障**：采取加密、权限控制，防止泄露。

## 三、高频雷点排查表

| 场景 | 风险动作 | 合规做法 |
|---|---|---|
| 人脸考勤 | 无告知直接采集人脸 | 单独告知同意，提供替代打卡方式 |
| 背景调查 | 未经同意查犯罪/征信记录 | 限定范围、取得书面授权 |
| 健康信息 | 强制收集与岗位无关的病史 | 仅与岗位胜任/职业健康相关，必要限度 |
| 监控 | 在更衣室/卫生间等私域装监控 | 限制在公共工作区域，告知监控范围 |
| 信息外发 | 把员工信息给无关第三方 | 需单独同意或依法依约，留记录 |

## 四、用工稽查常见触发点（合并排查）

- 未签劳动合同、社保漏缴（员工举报较直接）；
- 解除程序缺失、违法辞退；
- 大量使用"外包/兼职"但实质管理从属；
- 员工个人信息泄露或违规处理被投诉；
- 工伤认定争议中暴露未参保。

**备查材料建议**：劳动合同、考勤记录、工资银行流水、社保缴费凭证、规章制度民主程序与公示证据、个保告知同意书、解除通知送达回证。材料齐，稽查时被动变主动。
