# 三类权利对比与自检清单

## 一、三类权利的系统对比

| 维度 | 商标 | 专利 | 著作权 |
|---|---|---|---|
| 保护对象 | 识别性标识（文字、图形、组合等） | 技术方案：发明、实用新型、外观设计 | 表达形式（文字、音乐、美术、影视、软件等） |
| 不保护什么 | 商标本身不是"标记"，保护的是识别功能 | 不保护思想、原理；保护的是权利要求限定的技术方案 | 不保护思想、题材、创意、通用手法 |
| 权利产生 | 注册取得（另有在先使用与在先用权的规则） | 申请取得，经审查授权 | 创作完成即产生（登记是权属的初步证据） |
| 权利期限 | 注册有效期 10 年，可续展 | 发明 20 年、实用新型 10 年、外观设计 10 年（自申请日起） | 自然人作品为作者终生及其死亡后 50 年；法人作品与视听作品为发表后 50 年 |
| 保护范围界定 | 核定使用的商品/服务类别 + 标识近似度 + 混淆可能性 | 以权利要求的内容为准，说明书与附图用于解释；外观设计以表示在图片或照片中的外观为准 | 具体表达部分；实质相似 + 接触可能性 |
| 举证责任 | **权利人初步举证后，被诉方就"不混淆"承担举证责任**（商标侵权特有） | 原则上谁主张谁举证；涉及新产品制造方法的发明专利时，举证责任倒置 | 权利人需证明接触可能性与实质相似；被告主张独立创作的由被告举证 |
| 赔偿计算 | 实际损失 / 侵权获利 / 许可费倍数；恶意侵权情节严重可 1 至 5 倍惩罚性赔偿；均难以确定时 500 万元以下 | 同结构；均难以确定时 3 万元至 500 万元以下 | 同结构；均难以确定时 500 元至 500 万元以下 |
| 惩罚性赔偿 | 《商标法》第63条：对恶意侵犯商标专用权、情节严重的，可在上述方法确定数额的 1 倍至 5 倍 | 《专利法》第71条：对故意侵犯专利权、情节严重的，同上 | 《著作权法》第54条：对故意侵犯著作权、情节严重的，同上 |
| 法定赔偿上限 | 500 万元以下 | 3 万元至 500 万元以下 | 500 元至 500 万元以下 |
| 合理开支 | 包括权利人或委托代理人对侵权行为进行调查、取证的合理费用；符合规定的律师费用可计入赔偿范围 | 同结构 | 同结构 |
| 诉讼时效 | 3 年，自权利人知道或应当知道权利受到损害及义务人之日起算 | 3 年，自权利人知道或应当知道侵权行为及侵权人之日起算 | 3 年 |
| 特有风险 | 连续三年不使用被撤销；被提无效宣告 | 被提无效宣告；实用新型与外观设计未做专利权评价报告时评估难度大 | 独创性被质疑；登记证书单独作为权属证据证明力有限 |
| 适合的起步路径 | 平台投诉（性价比高） | 民事诉讼 + 技术特征比对 | 平台投诉 + 补强权属底稿 |

**一个通用补充**：《民法典》第185条规定，故意侵害他人知识产权、情节严重的，被侵权人有权请求相应的惩罚性赔偿。所以即使某类权利的专门法表述不同，故意侵权且情节严重的情形下仍有惩罚性赔偿的请求权基础。

**一个容易忽略的细节**：商标侵权超过三年起诉，若侵权行为在起诉时仍在持续且商标在有效期内，法院应判令被告停止侵权行为，赔偿数额自起诉之日向前推算三年计算。也就是说，**迟延起诉不一定会导致完全丧失赔偿请求权，但会压缩可主张的时间窗口**。

## 二、授权链核对清单

这一节解决两类问题：权利人自己是否有权发起维权；以及对方主张"我有授权"时如何核对。

### 2.1 权利人侧的授权链核对（维权前先做）

```
□ 1. 我是什么身份？
     □ 商标注册人 / 专利权人 / 著作权人（原始权利人）
     □ 独占许可的被许可人（可独立起诉）
     □ 排他许可的被许可人（可独立起诉）
     □ 普通许可的被许可人（不能独立起诉，需权利人授权或以自己名义起诉但需权利人参与）
     □ 继承人 / 受让人（需提供转让或继承证明）
□ 2. 授权文件是否书面？
     □ 是 / 否（口头授权在诉讼中极难主张）
□ 3. 授权文件是否明确授权了维权行为？
     □ 是否包含"以自己名义提起诉讼""提起行政投诉""发起平台投诉""提起刑事报案"等具体授权表述
     □ 仅有商标使用许可合同而无维权授权条款 → 需补充授权或由权利人出具授权委托书
□ 4. 授权范围是否覆盖本次维权对象？
     □ 授权的地域范围、期限、品类是否覆盖被诉主体与被诉商品
□ 5. 授权是否在有效期内？授权方是否有权再授权？
□ 6. 是否有转授权？逐级授权文件是否链条完整、能否层层追溯到原始权利人？
□ 7. 授权方本身的权利基础是否干净？
     □ 授权方的商标是否可能被提无效或撤三
     □ 授权方是否已将该权利转让或再次许可给他人（双重授权、一权多卖）
□ 8. 我方主体信息是否与平台注册与诉讼主体一致？
     □ 营业执照名称、地址、统一社会信用代码是否准确
     □ 平台账号主体与后续诉讼主体是否需要变更或追加
□ 9. 是否需要办备案或登记？
     □ 商标使用许可合同备案（未备案不影响效力，但备案有助于证明关系）
     □ 专利实施许可备案（对抗第三人、证明效力有帮助）
     □ 著作权转让登记（登记后才对抗第三人）
```

**第 3 项和第 7 项是高频的败因**。前者是"我以为有授权"，后者是"授权方本身就是问题主体"。

### 2.2 对方主张"我有授权"时的核对方法

当被诉方提交上游授权文件作为不侵权抗辩，按这几条核对：

```
□ 1. 授权方是谁？与权利人是什么关系？
     □ 授权方是权利人本人 → 进入第 2 项
     □ 授权方是第三方 → 授权方是否本身持有权利？其权利从何而来？
□ 2. 授权文件是否在有效期内？授权期限是否覆盖被诉行为发生的时间？
□ 3. 授权的商品/服务类别、品类、渠道范围是否覆盖被诉商品与被诉销售方式？
     □ 商标：授权涉及的类别是否与被诉商品类别一致（跨类授权无效）
     □ 专利：授权是否覆盖实施专利的技术方案
     □ 著作权：授权是否为专有许可；被授权方是否有权再许可
□ 4. 授权是否可追溯到原始权利人？链条中是否有断点？
□ 5. 授权方是否已把权利转让给他人？转让发生在授权之前还是之后？
     □ 转让在先 → 原授权方已无权再授权，授权文件失效
□ 6. 被诉方实际使用是否超出授权范围？
     □ 授权是"销售"而实际是"生产"；授权是"A 区域"而实际跨区销售；
       授权是"线上"而实际线下批发；授权期限已过仍在销售
□ 7. 授权文件的形式是否合规？
     □ 是否有签字或盖章、授权委托事项与权限是否载明、期限是否载明
□ 8. 授权文件的真实性是否可查？
     □ 是否有对应的合同、付款记录、发货记录、双方往来的证据配合
```

**核对要点**：**上游授权成立，不等于本次使用不侵权。** 大量被诉方提交的授权文件在形式上完备，但在"品类不符""超范围""超期限""转授权无效"这四个点上被击破。核对时要落到这四个点上，不要只看有没有授权书。

## 三、起诉前的"能不能赢"自检清单

逐条回答，答"否"或"不确定"的项就是待补的短板。**前 6 项任一为否，就不建议起诉。**

### A 组：权利基础（不过则停）

1. 权利是否有效且在有效期内？
2. 商标是否存在连续三年不使用被撤销的风险？专利是否存在被无效宣告的风险？（这两项要查当前法律状态，不是看注册证）
3. 权利的保护范围与被诉行为是否真的对应？
   - 商标：核定类别与被诉商品是否属于相同或类似商品？标识是否近似到容易导致混淆？
   - 专利：被诉产品的技术特征是否落入权利要求的保护范围（**这是必须逐条比对才能回答的问题**）？
   - 著作权：被诉作品与权利人作品在具体表达上是否实质相似，且有接触可能性？
4. 我方主体资格是否成立？（原始权利人 / 独占或排他许可的被许可人 / 有书面维权授权）
5. 授权链是否完整可追溯？
6. 诉讼时效是否还有余量？（3 年；商标超三年起诉时，赔偿只向前推算三年）

### B 组：侵权事实（不过则证据先行）

7. 是否有证据证明对方在**实际经营**而非仅在页面上展示？
   - 有无实际交易记录（订单、支付、物流、实物）
   - 若只有页面而无交易，能否证明其具备经营能力？
8. 侵权行为是否在持续？（有无不同时点的多次取证）
9. 被诉主体是否明确？
   - 店铺名称、经营者名称、收款方、发货方是否指向同一主体
   - 是否存在"店小二"与实际经营者不同的情形（实际经营者往往不是店铺注册主体）
10. 侵权获利或造成的损失是否有计算线索？
    - 被诉商品价格、销量、己方销售变化、许可费标准
    - **若完全无法计算，赔偿将落到法定赔偿区间，需重新评估是否值得诉讼**

### C 组：程序与策略

11. 管辖法院是否明确？是否已有其他法院受理？
12. 是否需要鉴定？鉴定的事项、周期与费用是否可承受？
13. 是否需要先做财产保全或行为保全？担保成本如何？
14. 对方是否有履行能力？（查到的主体是否有实际资产；空壳主体赢了也执行不到）
15. 是否存在不正当竞争的反诉风险？（如投诉明显不实、夸大宣传、恶意投诉）
16. 是否已评估刑事门槛？规模不够时是否明确放弃报案这条路？
17. 组合路径是否已规划（平台投诉 + 行政查处 + 民事诉讼的先后与配合）？

### D 组：成本收益（不过则降级处理）

18. 预期收益 ÷ 预期成本是否大于 3？
19. 时间成本是否可承受？（取证、诉讼、执行的完整周期）
20. 是否存在更省的替代路径（平台投诉、行政查处、行业内部治理）？

## 四、针对三类权利的自检重点差异

| 自检项 | 商标 | 专利 | 著作权 |
|---|---|---|---|
| 权利基础体检重点 | 状态查询、撤三风险、被提无效 | 年费缴纳、无效宣告风险、专利权评价报告 | 登记证书与作品对应、创作底稿、职务/委托作品权属 |
| 保护范围核对重点 | 类别对应 + 标识近似 + 混淆可能 | 技术特征逐条比对（含等同特征） | 具体表达部分 + 实质性相似 + 接触可能性 |
| 特有的"必须先做"动作 | 状态查询确认可投诉 | 办理专利权评价报告（实用新型与外观设计） | 补创作底稿与首次发表证据 |
| 特有的"对方会打" | 撤三申请、无效宣告 | 无效宣告、现有技术抗辩、举证责任倒置 | 独立创作抗辩、思想与表达二分 |
| 平台投诉的可行性 | 高（受理范围明确、比对直观） | 中（需技术比对说明） | 中（需权属与实质性相似说明） |

## 五、三类权利的常见误区

### 商标
- **误区**：跨类的同款商品也算商标侵权。**纠正**：商标保护按核定使用的商品/服务类别走，跨类同款不构成商标侵权（可能构成不正当竞争或其他权利，这要另判）
- **误区**：拿到注册证就能维权。**纠正**：状态失效、被提无效、撤三风险都会让投诉被驳回
- **误区**：平台投诉成功就等于赢了。**纠正**：平台处置不是法律认定，不产生赔偿

### 专利
- **误区**：外观看着像就侵权。**纠正**：专利保护范围以权利要求为准，外观相似不等于落入保护范围；实用新型与外观设计没有专利权评价报告时，评估难度显著上升
- **误区**：权利人不用做任何比对。**纠正**：技术特征比对是案件核心，做不出比对表，诉讼方向会偏
- **误区**：专利被无效了不影响维权。**纠正**：无效宣告是对方常用的拖延手段，需要提前准备应对

### 著作权
- **误区**：登记证书就是确凿权属证明。**纠正**：登记证书是权属的初步证据，单独使用时证明力有限，需配合底稿与发表证据
- **误区**：题材、创意、故事梗概被抄就是侵权。**纠正**：著作权保护表达不保护思想，只比较具体表达部分
- **误区**：对方说"我不知道"就免责。**纠正**：接触可能性与实质性相似的判断中，被告主张独立创作的由被告举证
