# 长护险申请条件与流程框架

> 本页是流程框架与材料整理方法，不是政策条文。各地条件与口径差异大，涉及具体数字、材料份数与时限，请以当地主管部门公布的现行版本为准。

## 一、申请前必须先分清三件事

很多家属一开始就搞混，结果白跑。

| 事情 | 它是什么 | 决定的人/文件 | 常见误解 |
|---|---|---|---|
| 参保 | 你所在地区这项制度是否参保、参保身份是否符合 | 当地社保经办口径 | 以为买了商业长护险就算参保了 |
| 待遇资格申请 | 失能后向经办机构申请，经评估后确定能否享受 | 申请材料 + 评估结论 | 以为病历齐全就一定能享受 |
| 服务/待遇的落实 | 拿到资格后怎么安排照护服务、谁上门、多久一次 | 当地服务安排口径与服务机构 | 以为拿到资格就自动有人上门 |

顺序不能颠倒：**先确认参保状态，再准备申请材料，拿到资格后才是服务安排**。

## 二、条件核对表

逐项核对，标出"已确认 / 待确认"。

### 1. 参保身份与参保状态

- 所在地区是否属于该制度的实施范围（有些地区仍处于试点或尚未实施）
- 参保身份：职工参保 / 居民参保，两类在条件与待遇水平上常有差别
- 户籍与居住要求：部分地区对户籍或常住地有要求，异地居住的家属尤其要确认清楚
- 参保状态是否正常：是否有断缴、是否处于参保有效期内
- 缴费年限或累计缴费情况是否有门槛要求

### 2. 失能状态

- 当地认定的失能口径是什么（重度失能，或按当地评估标准分档）
- 失能是否已持续达到当地要求的时间
- 认知障碍与身体功能障碍是否分别对应不同口径
- 现有医疗记录能否证明功能状态（这是能不能过的关键）

### 3. 年龄与其他

- 是否有年龄下限或上限
- 是否要求指定的医疗机构诊断或康复记录
- 是否有"近若干个月内"的病历时效要求

### 4. 照护条件

- 目前照护由谁提供（家人、护工、机构）
- 居住条件是否满足居家照护的要求
- 是否有本地机构能够承接相应的照护安排

## 三、材料清单（四类）

### 身份与参保类

- 申请人身份证件（户口本、居住证等）
- 社保卡或参保凭证
- 参保记录（缴费年限证明）
- 代办人身份证件及与申请人的关系证明（委托他人办理时）

### 医疗与失能类

- 二级及以上医疗机构出具的诊断证明
- 出院记录 / 住院病历（含既往住院记录，体现病程与功能变化）
- 相关检查检验报告（影像、化验、功能评估类）
- 康复科或相关科室的康复记录与功能评定
- 当地要求的失能状态相关表格或由医师填写的评估材料
- 近期照片（体现当前状态与居住环境，部分地区要求）

### 照护需求类

- 日常照护需求说明（吃、穿、翻身、如厕、行走、进食等具体困难项）
- 居住与照护条件说明（房屋情况、现有照护安排）
- 护理需求评估表（按当地格式）

### 申请表单类

- 申请表（本人签署）
- 知情同意与承诺类文件
- 联系方式与送达地址确认

### 材料自查要点

1. **一致性**：诊断证明的结论与病历、评估表描述的功能状态不能互相打架
2. **时效性**：确认哪些材料要求在近若干个月内出具
3. **完整性**：签字、盖章、日期、页码齐全；复印件是否需要核验
4. **可及性**：优先选择能一次性说明"为什么需要照护"的那几份材料作为主证
5. **留痕**：所有材料扫描留底，提交后自己也要有副本

## 四、流程时间线

各环节时长因地而异，以下为常见顺序与每环节该做的事。

```
第 1 环 咨询与预审     → 到当地经办机构或公布的渠道问清条件、材料、渠道、时限
   ↓
第 2 环 提交申请       → 备齐材料，按渠道递交，取得受理凭证
   ↓
第 3 环 受理与初审     → 材料齐全性核验；缺材料的按告知补正
   ↓
第 4 环 失能评估       → 评估机构上门或按约定方式评定，得出评估结论
   ↓
第 5 环 审核与待遇确定 → 按评估结论确定待遇档次与形式
   ↓
第 6 环 服务落实       → 居家服务安排 / 机构入住安排 / 相关费用结算方式
```

### 每环该做的事

| 环节 | 家属该做的 | 该留的凭证 |
|---|---|---|
| 咨询预审 | 问清：条件、材料份数、渠道、时限、是否有地方性表格 | 咨询记录、拿到的材料清单版本 |
| 提交申请 | 材料自查、递交、索取受理凭证 | 受理回执或凭证 |
| 受理初审 | 按告知补正，注意补正时限 | 补正通知与补齐记录 |
| 失能评估 | 配合时间安排、家属在场说明实际照护情况、准备补充佐证 | 评估记录、结论 |
| 审核确定 | 核对结论与档位，有异议按渠道提出 | 结论文书 |
| 服务落实 | 确认服务内容、频次、收费与结算方式 | 服务协议、结算记录 |

### 时间预期要做的准备

- 病程证明往往依赖既往病历，早期就要开始归集
- 评估环节通常需要等待排期与上门，家属时间要留出余量
- 材料补正会有时限，错过时限可能需要重新排队
- 结论出来到实际服务落地之间通常还有一道手续

## 五、常见误区

| 误区 | 为什么是错的 | 正确做法 |
|---|---|---|
| 买了商业长护险就能报社保长护险 | 两套体系各自独立，商业险的赔付不产生社保待遇资格 | 分别核对两条路径，各自准备 |
| 没到失能就完全不用准备 | 材料要靠病程积累，病历是事后补不出来的 | 从现在起归集病历、记录功能变化 |
| 病历越多越好，全塞进去 | 关键结论之间互相矛盾反而会成为疑点 | 主证突出、结论一致 |
| 认定标准全国一样 | 各地口径差异大，条件与水平都不同 | 按参保地逐项核对 |
| 自己写一份说明就能申请 | 失能认定要靠评估与专业结论 | 申请与评估两条线并行准备 |
| 拿到资格就等于有人上门 | 资格与服务安排是两个环节 | 第 6 环单独确认服务内容与结算 |

## 六、给家属的日常准备动作（还没失能时也值得做）

1. 查清参保地的实施情况、条件与渠道，记下经办机构名称
2. 确认自己的参保状态与缴费年限
3. 建立家庭档案：病历、检查报告、出院记录按时间归集
4. 记录功能变化的时间点与具体表现（能作为评估佐证）
5. 了解当地有哪些可承接居家或机构照护的机构
6. 了解商业长护险在家庭保障结构中的位置（不代替社保，也不重复）
