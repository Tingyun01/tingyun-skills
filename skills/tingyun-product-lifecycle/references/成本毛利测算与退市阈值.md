# 成本毛利测算、退市阈值与品类取舍

## 一、成本三层结构

### 1.1 分层定义与用途

| 层 | 构成 | 用途 | 不足之处 |
|---|---|---|---|
| 第 1 层 | 直接材料 + 直接加工费 | 谈价、报成本 | 漏掉制造费用与管理分摊，看不出这个品是否在养厂 |
| 第 2 层 | 直接材料 + 直接人工 + 制造费用分摊 + 单件摊销 | 判断这个品自身是否成立 | 不含期间费用与战略价值 |
| 第 3 层 | 单位变动成本 vs 含税净单价 → 单位贡献毛利；固定成本 → 盈亏平衡量 | **决策用** | 需数据支撑，假设要显式列出 |

### 1.3 摊销常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 模具按首单量摊 | 单件成本畸高，把可行的品误判为不可行 | 按生命周期预计产量摊，并注明预计产量的来源 |
| 模具摊销随产量上升而下降但产量实际上不去 | 盈亏平衡量算低，实际卖不到 | 摊销量取保守值，并把爬坡期良率损失计入 |
| 制造费用不摊 | 低价高销的品被误判为高利润 | 按机时或工时分摊，注明依据 |
| 期间费用（管理、销售、研发）不计入 | 厂级盈利与品级盈利混在一起 | 在管理层单独看"品级贡献"和"厂级合计" |
| 良率按理想值算 | 试产爬坡期成本被低估 | 用实测良率，爬坡期单独一档 |

## 二、敏感度与盈亏平衡

### 2.1 敏感度测算表

```
基准：单位贡献毛利 ______ 元/件　盈亏平衡量 ______ 件/月

扰动项一：主材价格 ±10%
  涨 10%：单位变动成本 +______ → 贡献毛利 ______ → 盈亏平衡量 ______
  降 10%：单位变动成本 −______ → 贡献毛利 ______ → 盈亏平衡量 ______
  先打穿毛利的是：______（是材料还是价格）

扰动项二：良率 −5 个点（损耗率 +5%）
  成本影响 ______ → 贡献毛利 ______ → 盈亏平衡量 ______

扰动项三：售价 ±5%
  涨 5%：贡献毛利 ______ → 盈亏平衡量 ______
  降 5%：贡献毛利 ______ → 盈亏平衡量 ______

扰动项四：汇率变动 ___%（出口或进口料占比 ______%）
  影响 ______ → 贡献毛利 ______

结论：
  先打穿毛利（贡献毛利 ≤ 0）的因素是：____________
  该因素的可控手段：____________（降本/提价/换料/提良率/调结构）
  若该手段都不做，触发退市评估的价格或成本线是：____________
```

**判断标准**：**敏感度测算是用来排优先级的**。四五个扰动项里，哪一项先打穿毛利，就先动那一项，其余先不管。**同时算不清的时候，先做"只改一个变量"的单因素敏感度**，比做多因素组合更可靠也更容易执行。

### 2.2 盈亏平衡量的用法

```
盈亏平衡量 ______ 件/月
对比三个参照数：
  你的渠道月销量能力 ______ 件/月 → 缺口 ______ 件
  你的产线月产能 ______ 件 → 占用 ______%
  你现在的平均月销 ______ 件/月 → 需要的增长率 ______%

判断：
  盈亏平衡量 < 渠道能力 × 30% → 这是一个可以赌的品（门槛低）
  盈亏平衡量 ≈ 渠道能力 × 50%~80% → 需要较大的销量承诺，风险高
  盈亏平衡量 > 渠道能力 → 除非有结构优势（如客户指定、价格不受竞争影响），否则不成立
```

## 三、退市判定阈值表

### 3.1 六维判定表

每一维给出判定线，触发任意一维即进入退市评估（进入评估不等于立即停产，要走完整的评审与时序）。

| 维度 | 判定线（按自己数据校准） | 观察方式 | 连续观察期 |
|---|---|---|---|
| 销量 | 月销量 < 盈亏平衡量 × 0.7 | 出货台账 | 连续 2 个月 |
| 贡献毛利 | 单位贡献毛利 < 0 | 成本表 | 连续 3 个月 |
| 渠道退货 | 退货率 > 同类品 + 5 个点 | 平台后台 | 连续 2 个月 |
| 交期信号 | 补货周期从 15 天延长到 45 天以上 | 客户补货记录 | 出现即看 |
| 库龄 | 库龄 > 180 天且动销为 0 | 库存台账 | 每月盘点 |
| 资源占用 | 占用的产线时产能创造更高贡献 | 排产表 | 每月排产时 |
| 战略偏离 | 公司已明确不做这个品类/市场 | 内部决策记录 | 一次性 |

**判断标准**：**阈值要允许试错**。1 个月的波动不该砍掉一个本来能起来的品，3 个月的持续不行则不该再拖。**观察期写在表里，是为了在数据难看时先不急着做决定，到第三个月也别放弃决定。**

### 3.2 三种情况的区分（很重要）

| 情况 | 症状 | 判别方法 | 对策 |
|---|---|---|---|
| 这个品本身不行 | 换个渠道还是不行；退款原因集中在产品 | 对照渠道数据同样差 | 退市评估 |
| 渠道不行 | 换个渠道数据明显好于原渠道 | 对照渠道数据明显好 | 换渠道，不退市 |
| 产能被抢 | 单品数据正常，但排产时被压 | 排产表 + 单件工时占用 | 调排产，不退市 |

**判断标准**：**在退市决策前，一定先做一次"渠道对照"和一次"排产核对"**。把渠道问题和产品问题搞混，是常见的误杀。**卖不动和不该做，是两件事。**

### 3.3 退市评审的产出

```
退市评审纪要（需填）
  触发的阈值与数据来源：________________
  已排除的可能：渠道问题（已排除/未排除）　产能问题（已排除/未排除）
  未来现金流判断（不含沉没成本）：
    继续做 → 未来 6 个月贡献 ______，占用现金 ______
    停止   → 一次性回笼 ______，剩余损失 ______
  停产时序与责任人：________________
  复盘归档的判断线：________________
```

**"未来现金流判断"这一栏必须不含沉没成本**。已经花掉的模具费、已经备的料、已经排的产时，不是继续做的理由。

## 四、渠道与品类取舍矩阵

### 4.1 品类组合盘（每个品一行）

```
品名 | 单位贡献毛利 | 月销量 | 月贡献额 | 占线工时 | 库龄 | 渠道数 | 战略标签
```

### 4.2 取舍判定

```
一、按贡献额排序，看资金该往哪边投
  高贡献 + 低占线 → 优先保产线资源、优先备料
  高贡献 + 高占线 → 值得投入降本，扩产需先验证
  低贡献 + 低占线 → 维持，不追加投入，可作引流/凑单品
  低贡献 + 高占线 → 三选一：提价、换规格降本、退出

二、按功能的例外处理（不砍的四种情况）
  引流款：本身贡献低但带来连带购买 → 用连带毛利评估
  凑单品：与主力品强搭配、单独不成单 → 用连带率评估
  渠道门槛品：某些渠道要求品类齐全 → 评估失去渠道资格的代价
  方案型产品：为大客户整体方案的一部分 → 看合同整体毛利

三、叠加压力测试
  新品要占资源 + 老品要清库 → 叠加后现金流缺口 ______
  缺口 ___ 万元，账上可支撑 ___ 个月
  结论：先上新品 / 先清老品 / 两个都推但都要限量 / 都推不了（要用户决策）
```

### 4.3 渠道维度的补充判断

```
同一品在多渠道时，看加权账期与加权退货率，不是看单价更高的那个渠道
  渠道 A：单价高 8%，账期 60 天，退货率 12%
  渠道 B：单价低，账期 15 天，退货率 3%
  → 用加权贡献（扣掉资金成本与退货损失）再比

渠道切换成本：换渠道要重做的清单
  □ 产品规格是否要改（改了就等于重新立项）
  □ 认证与检测是否要重做
  □ 包装与说明是否要重做
  □ 运营内容与客服话术是否要重做
  □ 履约时效是否能做到
  以上每一项都要算成本与时间
```

## 五、这一套逻辑不成立的情形

- **没有任何历史成本与销量数据**：算出的盈亏平衡量是假设的堆叠。此时应把重点放在"要采集哪些数据才能算"上，而不是给一个精确数字。
- **代工型业务（成本由客户指定）**：成本三层不适用，改用"加工费单价 × 工时"的单变量模型。
- **多品类共享同一条产线与同一批人**：单位分摊高度依赖分摊基准，基准一改结论就变。要做双基准测算（按工时、按产值）并看两者差异。
- **出口业务**：涉及汇率、关税、退税、认证与目的国合规要求，成本结构与国内不同，相关税则与合规口径须专业复核。
- **新品处于快速迭代期**：精确的盈亏平衡量意义有限，此时更需要的是"用多小的成本验证多快"。

**提醒**：所有测算都要标注假设与数据来源。**结论的可信度不取决于数字精确到小数点后几位，而取决于假设是否被列出来、是否被验证过。**
