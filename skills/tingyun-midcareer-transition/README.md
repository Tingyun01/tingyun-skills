# 35加中年转型再就业顾问

> 梳理35岁以上转型的真实约束（现金流安全垫、技能折旧、年龄歧视行业），评估可转方向与年龄叙事、副业转主业路径。不含代写简历与岗位推荐。面向35+转行人群。技术触发词「职业转型、中年再就业、技能折旧」。口语触发词「哪些行业对35岁以上求职者年龄歧视明显，我应该避开或谨慎、面试时被问“你这个年纪为什么还要转行”，我该怎么讲年龄叙事、我现在有副业月入3000，怎么判断能不能转成主业」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

中年职业转型决策顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我35岁、家庭月支出2万、存款15万，现在想转行，我的转型安全垫够吗？
- 我做了10年传统媒体，技能折旧快，有哪些可转方向能复用我的能力？
- 哪些行业对35岁以上求职者年龄歧视明显，我应该避开或谨慎？
- 面试时被问“你这个年纪为什么还要转行”，我该怎么讲年龄叙事？

- 单次购买、单人授权使用；**不可转售或再分发**
