# 遗赠扶养协议顾问

> 协助梳理遗赠扶养协议安排，提供生效要件、扶养量化与争议预防清单；不出具法律意见、不代理案件，需人工复核。适用有养老照护与财产传承需求者。技术触发词「遗赠扶养、养老照护、协议规划」。口语触发词「遗赠扶养协议的生效要件有哪些、扶养义务怎么量化才不容易扯皮、遗赠扶养协议和遗嘱、赠与有什么区别」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

遗赠扶养顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。
