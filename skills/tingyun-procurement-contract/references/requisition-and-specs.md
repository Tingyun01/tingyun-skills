# 采购需求书必填字段与规格参数写法

## 一、需求书是干什么用的

需求书有两个用途，缺一不可：

1. **让报价可比**：三家供应商读同一份需求书，报价的是同一个东西。
2. **让到货可判**：货到了，质检只看需求书就能判合格与否。

只满足第 1 条不满足第 2 条，签完必然扯皮；只满足第 2 条不满足第 1 条，比价阶段就废了。

**判据**：把需求书给一个没参与过这次采购的人看，他能不能（a）不问问题就报出可比较的价，（b）收货时独立判合格否。两个都能，才算写完。

## 二、需求书必填字段表

按栏目组织，每个字段都注明"填到什么程度算填完"。

### 2.1 需求基本信息

| 字段 | 填写要求 | 常见写错的样子 |
|---|---|---|
| 需求编号与版本号 | 专用编号 + 版本号 + 修订日期 | 无版本号，改了不知道用的是哪一版 |
| 需求方与对接人 | 部门、姓名、联系方式、技术对接人（另填） | 只写部门不留人，问题没人接 |
| 需求提出日期与期望到货日 | 具体日期，标注"期望"还是"硬性" | 只写"尽快"、"下个月" |
| 采购标的名称与类别 | 名称 + 物料类目/服务类目 | 只有口语名，供应商理解各不相同 |
| 用途与使用场景 | 什么工序、什么终端、什么条件下使用 | 不写，用途不明时供应商按低配报价 |
| 数量与预测周期 | 首单量 + 年度/月度预测量 + 递增节奏 | 只写首单量，模具摊销算不回来 |

### 2.2 技术规格（这一栏决定成败）

| 字段 | 填写要求 | 常见写错的样子 |
|---|---|---|
| 关键尺寸与公差 | 标称值 + 公差带（±0.2 / H7）或注明图号 | 只写"约 30cm" |
| 材质与牌号 | 具体材料名 + 牌号 + 标准号 | "优质金属"、"工程塑料" |
| 表面处理/工艺 | 具体工艺名 + 参数（硬度、镀层厚度） | "表面处理良好" |
| 颜色与色号 | 色号体系 + 色差范围（或封样） | "米白色"（各家理解差异极大） |
| 重量 | 单件重量或单位重量 | 缺失，导致运费与包装成本全错 |
| 承载/寿命/性能指标 | 数值 + 测试方法 + 判定阈值 | 只有数值没有测法，测法不同结果不同 |
| 环保与合规要求 | 适用的标准号与认证要求 | "符合国家标准"（未指明哪一项） |
| 图纸与附件 | 图号、版本、封样编号、参考样照片 | 附件无编号版本，供应商按旧图做 |

### 2.3 商务与交付

| 字段 | 填写要求 | 常见写错的样子 |
|---|---|---|
| 报价口径 | 含税/不含税、含运/不含运、币种、是否含包装 | 不写，导致三家口径不同 |
| 报价有效期 | 具体天数 + 逾期处理方式 | 不写，报价过期后按旧价谈 |
| 交付方式与地点 | 自提/送到指定地、到货地址、卸货责任方 | 只写"送到我司" |
| 交期与分批安排 | 分批节点 + 每批数量 + 时间节点 | 只写总交期 |
| 包装与唛头要求 | 包装方式、每箱数量、外箱标识 | 缺失导致到货混乱与二次搬运 |
| 模具与工装 | 是否开模、模具费金额、归属意向、维护责任 | 完全不提，谈判时被追加 |
| 付款条件 | 预付比例、节点、账期天数 | 需求阶段不写，供应商按有利方向假设 |
| 质保与售后 | 质保期时长、响应时效、备件供应年限 | 不写，售后诉求无依据 |
| 验收标准与方式 | 到货抽检标准、合格判定、异议期天数 | 完全不写（风险较高的一项） |

### 2.4 供应商侧要求

| 字段 | 填写要求 | 常见写错的样子 |
|---|---|---|
| 资质要求 | 需要的证照/许可/认证 + 有效期要求 | 不写，后面只能被动接受 |
| 样品与封样要求 | 是否需打样、封样留存方式与保管方 | 不写，量产与样品不一致时无据可依 |
| 保密要求 | 是否涉及配方/图纸/工艺信息，密级要求 | 不写，图纸外泄后无法追责 |
| 廉洁要求 | 反商业贿赂条款的告知与承诺 | 不写 |
| 场地与实施要求 | 是否需驻场、是否需提供方案与图纸 | 不写后期追加成本 |

## 三、规格参数怎么写才可验收

### 3.1 三段式写法

每条关键规格按这三段写，缺一段就不可验收：

```
判定对象 + 判定方法 + 判定阈值
```

| 需求书原文 | 问题 | 改写后 |
|---|---|---|
| 盒子要结实 | 无法测 | 承重≥5kg，测法：装填物 4kg 后静置 24h，侧壁无塌陷、无永久变形 |
| 表面要好 | 无法测 | 表面处理：喷砂 + 阳极氧化，膜厚 8–12μm，附着测试：百格测试 1 级 |
| 颜色米白 | 各家理解不同 | 色号 PANTONE 7500C，允许色差 ΔE≤2，或以封样件（编号 S-01）为准 |
| 交期要快 | 无法追责 | 首批到货日 2026-03-15，每延迟 1 日按合同额每日 0.3‰ 计违约金，上限 5% |
| 交期要快 | 无法追责 | 首批到货日 2026-03-15，分三批：03-15 交 30%，04-01 交 40%，04-20 交 30% |

### 3.2 参数优先级排序（资源有限时先写哪几个）

预算或时间不够时，按这个顺序保参数，前面的不能省：

1. **安全与合规类**（材料有害物质、承重、电气安全）—— 省了会出安全问题。
2. **功能可用类**（关键尺寸、配合公差、材质牌号）—— 省了装不上、用不了。
3. **一致性类**（外观件颜色与工艺、批次间一致性）—— 省了退货率高。
4. **成本驱动类**（包装方式、重量、单价）—— 可以在合同阶段再谈。

**判据**：前两类参数定错了，后面全盘返工；后两类可以先模糊、签合同阶段锁死。

### 3.3 用封样代替描述

外观类、触感类、手感类参数，写多少字都会偏。**处理办法：做封样 → 编号 → 在需求书里写"以封样 S-01 为准" → 封样双方签字各留一份 → 封样保管与归还规则写清。**这比"符合我方确认样品"这类空话有用得多，因为后者无法指向具体的物。

### 3.4 可验收性自检表

需求书定稿前逐条过：

| 检查项 | 通过标准 |
|---|---|
| 三家是否都能只看需求书就报出同一规格 | 任一家提出"这个要问你们"→ 该处表述有歧义 |
| 每条关键参数能否变成检验动作 | 任一条"要人工感觉一下"→ 补封样或补测试方法 |
| 数量与周期是否给了 | 缺任一项 → 无法算模具摊销与账期成本 |
| 报价口径是否写全 | 含税/含运/币种/包装/有效期 五项缺一 → 返工 |
| 验收标准与异议期是否写 | 缺 → 到货争议无解，风险较高的一项要直接补 |
| 模具、图纸、封样、附件是否都有编号版本 | 缺 → 后续争议无法追溯 |
| 是否含资质与廉洁要求 | 缺 → 签完再补，来不及 |

## 四、按品类调整的重点

| 品类 | 需求书里权重靠前的栏目 | 特有风险 |
|---|---|---|
| 通用物料（标准件、耗材） | 材质牌号、标准号、数量 | 假冒牌号、以次充好 |
| 包材与外观件 | 尺寸公差、色号/封样、工艺参数 | 样品与大货不一致 |
| 定制开发件（含模具） | 图纸版本、模具归属、开模费、试产流程 | 模具被锁死、工装被锁死 |
| 设备类 | 技术参数表、配置清单、验收测试项 | 配置缩水、耗材绑定 |
| 服务类 | 服务范围、交付物清单、SLA 指标、人员资质 | 交付物不清、人员替换 |
| 工程类 | 工程量清单、图纸、隐蔽工程要求、报验节点 | 工程量口径、变更签证 |
