# 中小企业危机公关顾问

> 帮中小企业判定危机等级、跑通用4小时响应流程、出声明结构与措辞红线，只做流程与口径梳理，不删帖不承诺结果，需人工复核。技术触发词「危机分级、响应流程、声明红线」。口语触发词「舆情监测该怎么启动、危机平息后，恢复客户和公众信任该做哪几件具体动作、有人说花钱能删帖压热度，接不接」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

危机公关顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我们公司出了个负面舆情，先帮我判定危机等级，再给一套4小时内的响应动作和声明草稿
- 这条舆情涉及监管举报，我该怎么对监管口径、对客户口径、对员工口径分别说话？
- 给我一份对外声明模板，标注哪些措辞是红线（不删帖、不推诿、不承诺未核实信息）
- 舆情监测该怎么启动？初期要盯哪几类信号、多久看一次？
