# 失能前安排决策清单（规划辅助用）

> 以下为"安排窗口仍有"时的梳理清单，不构成法律意见，全部安排须经持证专业人士复核与线下办理。

## 一、为什么强调"失能前"窗口

意定监护的核心前提是本人仍有完全民事行为能力。一旦进入失能失智且未提前安排，往往只能走法定监护路径，本人意愿难以体现。因此"现在还能清楚表达意愿时"是关键准备期。

## 二、失能前决策清单

- [ ] 选定监护人候选，并沟通其是否愿意承担
- [ ] 选定监督人候选，确认其独立性与可用时间
- [ ] 梳理现有财产清单：银行账户、房产、保单、投资、退休金、债权债务
- [ ] 梳理现有保障：医保、长护险、商业保险、照护资源
- [ ] 订立或更新遗嘱，明确身后财产分配
- [ ] 明确意定监护与遗嘱的衔接：失能期间由监护人管，身故后由遗嘱/继承人接
- [ ] 指定遗产管理人（可选），明确其职责边界
- [ ] 是否就意定监护协议办理公证（衡量举证成本与便利性）
- [ ] 将安排告知至少一位可信亲属或朋友，避免日后无人知晓

## 三、遗产管理人职责边界（梳理用）

可承担的事项（典型）：
- 清理遗产并制作清单
- 向继承人报告遗产情况
- 采取必要措施防止遗产毁损、灭失
- 处理被继承人的债权债务
- 按遗嘱或法定规则协助分割、交付遗产

不宜/不能替代的事项：
- 不能替代继承人作出实体权利处分的终局决定
- 重大处分（如出售房产）通常需依程序并留痕
- 涉及诉讼常以继承人或依法定授权主体名义进行

## 四、遗嘱与意定监护的衔接要点

- 时间线：意定监护覆盖"失能 → 身故前"的人身与财产管理；遗嘱覆盖"身故后"的财产分配。
- 衔接点：若遗嘱指定的执行人/继承人与监护人不同，需在失能到身故这段明确"谁在管钱、谁在管人"。
- 冲突排查：已立遗嘱又设意定监护时，核对两者对财产的描述是否一致，避免日后争议。

## 五、需立即转人工的情形

- 本人已部分失能、表达不稳定 → 意定监护设立存疑
- 家庭对监护人选已有严重分歧 → 协议难落地
- 涉及企业股权、境外资产 → 需专项规划
