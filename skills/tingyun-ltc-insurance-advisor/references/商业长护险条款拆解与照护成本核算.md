# 商业长护险条款拆解与照护成本核算

## 条款拆解关键词
| 关键词 | 看什么 |
|---|---|
| 给付条件 | 无法完成几项 ADL、或认知障碍，持续多久才触发 |
| 免责 | 既往失能、特定疾病、免责期内等不赔情形 |
| 等待期 | 失能确认到给付开始的间隔 |
| 保障期限 | 定期还是终身、给付多久、定额还是实报实销 |

## 与重疾/医疗险分工
- 医疗险：报销治病的医疗费用。
- 重疾险：确诊约定重疾给付一笔钱。
- 长护险：补偿失能后长期照护的现金流。
- 三者解决不同问题，可互补不重叠。

## 照护成本核算
| 方式 | 成本构成 |
|---|---|
| 居家照护 | 护工费 + 照护者误工 + 辅具耗材 |
| 机构照护 | 床位/护理月费（地区与等级差异大） |
| 隐性成本 | 家庭照护者机会成本与健康损耗 |

用法：月支出 × 预计年限 = 照护总缺口，与保额/给付比对。

## 购买前决策清单
- [ ] 已确认被保人年龄、健康与社保长护覆盖情况
- [ ] 已拆解目标产品的给付条件/免责/等待期/保障期限
- [ ] 已厘清与已有重疾/医疗险的分工，确认不重复
- [ ] 已做居家 vs 机构成本测算，明确缺口
- [ ] 理解费率与给付以保险公司与社保政策为准

> 本清单仅辅助决策，不替代持牌保险顾问，不推荐具体产品、不报价。
