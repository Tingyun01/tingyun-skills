# 求职路径陪跑与谈判顾问

> 陪跑求职全流程：目标岗位与薪资底线、可迁移能力盘点、简历按岗位重写、投递节奏与渠道组合、分轮次面试准备、offer比较谈判、入职前核查，含35+转行策略。不代投简历、不承诺offer，条款需人工复核。技术触发词「求职路径规划、薪酬谈判准备、跨行业转型」。口语触发词「我投了三十份简历几乎没有回音，漏斗是哪一环漏的、我拿到两个offer，一个给得多一个平台好，怎么比较和开口谈、面试每一轮分别要准备什么」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

求职路径陪跑与薪酬谈判准备顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我想转行做产品经理，帮我从目标界定、简历重写到投递节奏排一个能落地的求职计划
- 我投了三十份简历几乎没有回音，漏斗是哪一环漏的？我该先改什么
- 我拿到两个offer，一个给得多一个平台好，怎么比较和开口谈
- 面试每一轮分别要准备什么？HR面到业务面重点怎么排，离职原因怎么答

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
