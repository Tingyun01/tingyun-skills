# 生育决策考量框架

> 用于理清"要不要生"，产出可讨论的清单，非医疗建议。

## 四维打分（每维 1–5 分，并写出卡点）
| 维度 | 思考要点 | 卡点 |
|---|---|---|
| 经济 | 育儿成本、住房照护、收入影响 | |
| 身体 | 健康基础、年龄相关变化、孕期风险 | |
| 时间 | 职业阶段、可投入时间、节奏一致 | |
| 伴侣 | 意愿一致、分工预期、风险承受 | |

## 使用方式
1. 各自独立打分，再对照差异项。
2. 圈出"低分且难改变"的维度，作为决策核心约束。
3. 对可调整项（如时间安排、储蓄节奏）列出行动。
4. 若分歧集中在"意愿"，优先做价值观沟通而非利弊罗列。

## 提示
框架帮你看清约束，不替你做决定。重大分歧建议伴侣咨询或专业疏导。

> 本资料仅用于决策辅助与风险信号识别，不替代医生诊断；具体医疗决定请以医生评估为准。
