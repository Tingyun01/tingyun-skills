# 权属、抵押、查封与占用核查路径

> 用途：法拍或不良资产处置住宅买前，把"能不能过户、能不能住进去"两件事分开查清。
> 本表给的是核查路径与红旗信号，不是产权结论；档案结论以登记机构与司法机关出具的材料为准。

## 一、核查顺序（先阻断项，后顺位与资金，再实物）

| 阶段 | 目标 | 动作 | 不通过时 |
|---|---|---|---|
| 阶段一 | 确认这笔交易在法律结构上成立 | 权利人、共有情况、拍卖主体与案号 | 停止 |
| 阶段二 | 确认能取得产权 | 抵押、查封顺位、居住权、优先受偿 | 停止或调价 |
| 阶段三 | 确认能占有 | 在先租赁、实际占有人、户口 | 停止或调价 |
| 阶段四 | 确认住得舒服 | 实物状况、欠费、物业与车位 | 计入修缮预算 |

**为什么先查阶段一和阶段二**：产权没定下来时讨论腾退没有意义；产权能取得但住不进去，后面所有成本测算都要重做。

## 二、核查项与信息源对照表

| 核查项 | 信息源 | 具体动作 | 红旗信号 |
|---|---|---|---|
| 权利人 | 不动产登记信息查询渠道（当地不动产登记中心线上或线下查询） | 拉取登记簿打印件，核对姓名、证件号、共有情况 | 权利人与公告不一致；共有人未全部列明 |
| 共有情况 | 同上 | 看是共同共有还是按份共有，按份共有人是否均需意思表示 | 按份共有但部分共有人未参与或未授权 |
| 抵押 | 同上，抵押信息栏 | 记录抵押权人、抵押金额、登记日期 | 存在抵押且抵押金额与标的估值接近（几近清偿完） |
| 查封与轮候 | 同上，查封信息栏 | 记录查封机关、查封日期、顺位、轮候次数 | 多家法院轮候查封；查封机关与执行法院不一致 |
| 居住权 | 同上，其他登记事项栏 | 确认有无居住权登记、居住权人是谁 | **存在居住权登记 → 阻断项** |
| 异议登记 / 预告登记 | 同上 | 确认有无未注销的登记 | 有以其他权利人名义办理的预告登记 |
| 在先租赁备案 | 房屋所在地住建 / 房管部门租赁备案记录 | 调取备案台账，核对签约日、租期、租金 | 租期超长、租金明显低于周边、签约日晚于查封日 |
| 实际占有 | 现场踏勘 + 走访物业、邻居、门卫 | 确认现在住的是谁、以什么身份住 | 有非产权人长期居住且态度强硬 |
| 户口 | 现场 + 户籍查询走访 | 确认户口是否在房上、是否多户 | 户口与产权人分离、涉及学位占用 |
| 涉诉与执行关联 | 裁判文书、执行信息公开、法院公告与资产处置公告平台 | 按权利人姓名检索 | 同一人多家法院轮候、已被列为失信或限制高消费 |
| 程序状态 | 向承办法官或执行局了解 | 确认是否已启动分配、破产、变价程序 | 已进入破产或分配程序 → 处置规则与优先顺位改变 |
| 是否已设定担保物权 | 登记查询 + 向执行法院确认 | 确认查封之外有无其他优先权 | 存在优先受偿权且金额大 |
| 税费与欠费 | 物业台账、供热与水电燃气营业厅、供暖费台账 | 拉出欠费清单与停供停暖记录 | 欠费大额、已被停供、物业关系紧张 |
| 车位与配套 | 物业与小区车库管理方 | 确认车位是否随房、有无独立权属与欠费 | 车位被占用或另行出租 |

## 三、在先租赁的判断要点（表格化，不下结论）

| 观察点 | 偏向"真实在先租赁"的信号 | 偏向"为对抗执行形成的租赁"的信号 |
|---|---|---|
| 签约时间 | 明显早于查封日 | 晚于或接近查封日 |
| 备案与交付 | 有备案记录、有实际交付与水电使用痕迹 | 无备案、无实际入住痕迹 |
| 租金水平 | 与周边同类房源接近 | 明显偏低，或为象征性金额 |
| 租期长度 | 与市场常规租期接近 | 明显超长（如跨越未来数年） |
| 承租人关系 | 身份可核实、联系方式可验证 | 无法核实、联系方式失效 |
| 支付凭证 | 有连续支付记录 | 无支付记录或只有一次性凭证 |
| 是否有优先购买权主张 | 未主张 | 已向买受人主张同等条件优先购买权 |

**注意**：以上只是"需要进一步核实的方向"。租赁是否对抗买受人、是否应予保护，属法律判断，应交执业律师。采购方的责任是把材料整理齐、把上述观察项逐条写清。

## 四、居住权登记：为什么是阻断项

- 居住权是登记设立的用益物权，**以不动产登记簿记载为准**。
- 房屋所有权发生变动，不影响已登记的居住权。
- 也就是说：**买受人付了全款、办完了过户，居住权人仍可依登记继续居住**，且不存在"腾退"这一常规解法。

处置路径（三选一，事前谈定）：
1. 居住权人书面放弃居住权，并配合办理居住权注销登记；
2. 变更登记内容（如变更居住权所对应的房屋，需按当地登记规则办理）；
3. 把"无法腾退且需长期让渡占有"计入价格，作为折价因素接受。

无论选哪条，都必须在**出价前**拿到书面文件并确认登记机关的办理口径。仅凭口头承诺就出价，等于把风险全押在对方的配合意愿上。

## 五、顺位与分配：钱会流向哪里

- 成交价款的分配通常按法定顺序进行：处置费用、税费、优先受偿权（含抵押权、建设工程价款优先受偿权、职工债权等情形）、剩余部分再按性质分配。
- 结论性影响：**成交价不是全部回到买受人账户**，也不必然偿清被执行人全部债务；不足部分可能继续执行。
- 买前必问执行法院的三句话：
  1. 本标的目前有几轮查封、分别来自哪些法院？
  2. 是否已有其他债权人申请参与分配？分配方案处于什么阶段？
  3. 优先受偿权的种类与大概金额区间是多少？成交价扣除后是否有余额？

## 六、红旗信号清单（命中即降级或停止）

| 编号 | 红旗信号 | 处理建议 |
|---|---|---|
| R1 | 登记簿存在居住权 | 停止出价，直到拿到书面处置文件 |
| R2 | 权利人与公告不符，或存在未披露共有人 | 停止，要求澄清并留书面记录 |
| R3 | 多家法院轮候查封且已启动分配 | 重新测算资金与时间，评估继续持有的合理性 |
| R4 | 查封后签订的长期低租约 | 转律师核实对抗力，同时在价格上计入腾退延迟 |
| R5 | 实际占有人与公告描述不符 | 现场复核、走访物业，取得书面确认口径 |
| R6 | 被执行人明确拒绝腾退且无腾退意愿 | 按"强制腾退"上限估时估钱，并计入机会成本 |
| R7 | 欠费金额大且存在停供停暖 | 计入修缮与欠费垫付，联系物业确认恢复条件与费用 |
| R8 | 抵押金额接近标的估值 | 优先受偿后可能无剩余，向执行法院核实分配口径 |
| R9 | 拍卖公告表述含糊、附件缺失 | 索取完整竞买须知与附件材料 |
| R10 | 处置主体与登记信息链条说不通 | 停止，要求补齐主体资格文件 |

## 七、需要律师回答的问题（交办清单）

1. 本标的的在先租赁是否对抗买受人？若对抗，腾退路径与时间上限如何？
2. 居住权人放弃居住权并办理注销登记的文件应如何拟定与见证？
3. 多轮查封下，本标的变价款的分配是否会影响过户与交付？
4. 若出现案外人异议之诉，成交与腾退的时间成本上限如何估计？
5. 竞拍担保金、悔拍责任的具体条款约定与可主张的救济是什么？
6. 公告中"相关税费由买受人承担"的约定，与法定纳税义务人的划分应如何在实操中处理？
7. 抵押权未注销情形下过户的具体路径与所需材料？
