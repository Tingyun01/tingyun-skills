# 数据分类分级与个人信息处理合规清单

> 本页为合规梳理底稿，不构成法律意见，需持证专业人士复核。不自称律师。

## 一、数据分类分级方法（四级示例）

先按"业务属性"分类，再按"敏感/重要程度"分级。

| 级别 | 典型数据 | 管控要求 |
|---|---|---|
| 核心数据 | 核心工艺参数、全量客户库、源码 | 按需授权、加密存储、全量审计、双人复核 |
| 重要数据 | 财务、人事薪酬、经营报表 | 分级访问、定期权限复核、离岗即收 |
| 一般数据 | 内部文档、系统日志 | 按需访问、常规备份 |
| 公开数据 | 已对外发布信息 | 正常管理，注意再识别风险 |

操作动作：
1. 列数据资产清单（来源、用途、存放位置、责任人）
2. 逐类定级，标注"是否含个人信息""是否涉核心"
3. 按级别套管控，缺口补清单

## 二、个人信息处理合规清单

处理个人信息前，逐条勾选：

- [ ] **告知**：向个人告知处理目的、方式、范围、留存期限
- [ ] **同意**：取得有效同意（法定无需同意的例外情形除外）
- [ ] **必要性**：只收集业务必需字段，不超范围
- [ ] **目的限制**：不用于告知目的之外
- [ ] **准确**：确保信息准确，提供更正渠道
- [ ] **留存期限**：按必要期限留存，到期删除或匿名化
- [ ] **安全**：采取技术与管理措施防泄露
- [ ] **主体权利**：提供查询、复制、更正、删除、撤回同意通道
- [ ] **委托/共享**：对外委托或共享时签协议并约束对方

敏感个人信息（生物识别、金融账户、行踪、医疗健康等）需更严格：单独同意、必要性论证、影响评估。

## 三、数据出境红线（仅提示，须找专业机构）

涉及数据向境外提供，存在法定门槛与路径，常见包括：
- 通过安全评估（特定情形）
- 订立标准合同并备案
- 通过个人信息保护认证

**红线提示**：
- 不要自行"直接传"，先判断是否属于须申报/备案情形
- 重要数据、达量个人信息出境须依法走路径
- 此部分**必须由专业机构评估办理**，本顾问仅作风险提醒，不替代法定评估

## 四、边界

本页为结构与清单辅助，不构成法律意见。是否触发出境申报、条款是否有效、是否违规，须由持证专业人士或主管机关认定。
