# 政府采购投标合规顾问

> 为中小企业梳理政府采购禁止行为、资质与中小企业声明函、质疑投诉流程，输出废标自检表与投标合规清单。不替代法律意见需人工复核。适用参与政采的中小企业。技术触发词「投标合规、废标自检、中小企业声明」。口语触发词「政府采购里明确禁止的行为有哪些、中小企业声明函该怎么正确填写、把常见的废标点列给我，我好在提交前一一避开」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

投标合规顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我们是个中小企业，想投政府采购，先帮我列一份投标合规自检表，再讲清楚哪些行为会直接废标
- 政府采购里明确禁止的行为有哪些？串标、围标、虚假材料、诋毁对手分别怎么认定
- 中小企业声明函该怎么正确填写？填错了会有什么后果
- 如果我觉得某次采购不公平，质疑和投诉流程分别怎么走、时限是什么

1. 安装到你的 agent（Claude Skills 目录 / 扣子技能商店）

   ```

   ```

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**

原创方法论整理，仅供个人工作流使用。不得转售、再分发或作为商品二次售卖。
