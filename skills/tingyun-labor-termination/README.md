# 劳动解除与补偿测算顾问

> 输入解除情形与员工年限工资，输出五类情形分类、N/N+1/2N 测算框架、程序留痕清单、交接结算表。不做个案法律结论，不构成法律专业意见，需人工复核。适用于中小企业老板、HR 与被解除员工。技术触发词「解除情形分类、经济补偿测算、程序留痕清单」。口语触发词「员工被口头通知明天不用来了，公司一分钱没付，这样做风险在哪、解除通知要不要事先通知工会、哪些情形属于法定不得解除的范围」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

劳动解除与经济补偿测算顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 员工在公司干了8年，月薪1.2万，公司现在要裁员，我要准备哪些材料才能不走成一赔二？
- 员工被口头通知明天不用来了，公司一分钱没付，这样做风险在哪？按哪个情形走程序才对？
- 帮我算差额：一个工作3年8个月、解除前12个月平均工资9000元的员工，过失性解除和无过失性解除各要付多少？
- 解除通知要不要事先通知工会？我们公司没有工会，那程序上还缺哪几步？
