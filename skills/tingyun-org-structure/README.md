# 组织架构与岗位职责顾问

> 梳理汇报关系、决策权与结果归属，按职能/产品/区域/客户选择部门划分逻辑，输出岗位职责书，用简化责任矩阵排查职责重叠与空白，给出岗位调整沟通顺序与空转岗位识别口径。技术触发词「汇报关系、岗位职责书、责任矩阵」。口语触发词「按职能、按产品、按区域还是按客户划分部门、帮我写一份采购主管的岗位职责书，要让新入职的人看得懂能照做、销售和交付互相甩锅，用责任矩阵帮我找出职责重叠和没人管的地方」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

组织架构梳理与岗位职责设计顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 公司 60 人，老板一个人拍所有事，帮我把组织架构和决策权梳理清楚
- 按职能、按产品、按区域还是按客户划分部门？我们工业设备在三个省销售
- 帮我写一份采购主管的岗位职责书，要让新入职的人看得懂能照做
- 销售和交付互相甩锅，用责任矩阵帮我找出职责重叠和没人管的地方
