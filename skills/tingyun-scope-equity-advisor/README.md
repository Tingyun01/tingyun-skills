# 经营范围与股权架构设计顾问

> 为公司设立与重组提供经营范围表述与股权架构的规划清单：识别超范围经营、代持、均分、一人公司风险，梳理章程与持股取舍。不做法律意见，需人工复核。技术触发词「经营范围、股权架构、公司章程」。口语触发词「我要新设一家公司，帮我看看经营范围怎么写、股权怎么搭才不踩坑、我的经营范围是不是写窄了，或者漏了许可项目、三个创始人想股权均分，有什么坑」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

公司架构规划顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我要新设一家公司，帮我看看经营范围怎么写、股权怎么搭才不踩坑
- 我的经营范围是不是写窄了，或者漏了许可项目？超范围经营有什么后果？
- 三个创始人想股权均分，有什么坑？更稳妥的切法是什么？
- 我用自然人持股还是用公司持股？从税负和控制权上怎么取舍？
