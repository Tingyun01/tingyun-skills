# 维权路径对比与决策树

## 一、四条路径的完整对比

### 1.1 平台投诉（知识产权投诉）

**法律基础**：《民法典》与《电子商务法》确立的"通知—删除"规则。权利人认为其知识产权受到侵害的，有权通知平台经营者采取必要措施，通知应当包括构成侵权的初步证据与权利人的真实身份信息；平台经营者接到通知后应及时采取必要措施，并将通知转送平台内经营者。

**适用条件**
- 权属清晰、类型在平台受理范围内（主流平台的投诉通道一般覆盖商标、专利、著作权三类，部分平台还受理不正当竞争类投诉）
- 被投诉对象在平台内经营，且有可定位的具体链接
- 投诉主体适格：商标注册人、利害关系人（如被许可人，需提供许可合同）；委托代理的另需授权文件

**材料清单**
- 投诉人身份证明：企业提交营业执照，个人提交身份证件
- 权属证明：商标注册证（注意核定商品或服务类别是否与被诉商品对应）、专利证书与专利登记簿副本及年费缴纳证明（并说明是否已办理专利权评价报告）、著作权登记证书或能证明创作完成时间与发表时间的原始材料
- 侵权比对说明：标识的近似之处、被诉产品技术特征是否落入权利要求保护范围、被诉商品与权利人作品在表达上的实质性相似
- 涉嫌侵权信息的具体定位（商品链接等）
- 授权委托材料（委托代理时）

**处理流程与节奏**
```
① 注册平台知识产权保护账号，提交身份证明
② 提交权属证明，通过知识产权资质认证（首次审核通过后，后续投诉一般无需重复提交）
③ 发起投诉：选择权属类型 → 定位侵权链接 → 填写侵权判定理由与初步证据
④ 平台形式审核：材料不齐会通知补件。注意——平台在受理过程中通知补件或申诉响应，
   权利人未在指定期限内响应或补件的，视为撤回投诉；主动撤回视为自始放弃投诉主张
⑤ 审核通过后，平台对涉嫌侵权链接采取删除、下架、移除侵权信息、冻结店铺资金等处置，
   并将侵权通知转送被投诉卖家
⑥ 被投诉卖家在指定期限内答辩（常见理由：权利已过期、使用了公共领域素材、
   商品与权利人商品不相似、有正当授权等）
⑦ 平台将申诉材料回转投诉人，投诉人在指定期限内回应
⑧ 双方材料齐备后平台作出裁定；如不认可裁定，权利人可提交有管辖权的法院进一步审查
⑨ 卖家在处理完成后补充提交司法或行政裁决等证据的，平台可转送并有权终止或保留处置措施
```

**时限特征**：形式审核一般在数个工作日；材料复杂、需比对说明充分时会拉长。**各平台的时限与规则不同，以平台现行规则为准。** 这里的流程是共性框架，具体节点天数要查平台规则页。

**优势**：成本低、速度快、能一次性覆盖多个链接、处置措施对卖家经营有实际影响。
**局限**：
- 不给赔偿
- 处置是平台规则下的措施，不是对侵权事实的法律认定
- 对方可以换店、换链接继续，需要重复投诉
- 平台处置有时限，链接被重新上架后需要再投诉
- 权利基础瑕疵会在这个环节被放大（权属一旦被质疑，投诉直接被驳回）

### 1.2 行政投诉（向知识产权行政保护部门举报/投诉）

**法律基础**：《商标法》第六十一条至第六十三条、《专利法》第六十五条与第六十八条、《著作权法》相关规定，以及各地知识产权行政保护部门的投诉举报办法。

**受理部门**
- 商标与著作权类：市场监管部门（知识产权保护科/知识产权股），可拨 12315 或通过全国 12315 平台提交
- 专利侵权：管理专利工作的部门（知识产权局系统），受理专利侵权纠纷的行政处理与行政裁决
- 假冒专利（谎称获得专利权）：负责专利执法的部门

**受理条件（常见要求）**
- 请求人是权利人或利害关系人
- 有明确的被请求人（自然人、法人或非法人组织）
- 有明确的请求事项和具体事实、理由
- 属于受案部门的受案与管辖范围
- 当事人尚未就该纠纷向法院起诉（另有仲裁约定的也不受理）

**不予受理的常见情形**
- 无具体明确的被投诉人与涉嫌侵权行为
- 不属于该受案机关受理范围
- 已受理且仍在核查处理过程中就同一事项重复投诉
- 已核查处理结束，无新线索情况下以同一事实或理由重复投诉
- 对同一事实已向其他行政机关投诉、已申请复议、已向法院起诉或已进入上述程序

**材料清单（专利侵权行政裁决类常见要求）**
- 知识产权证书及授权公告文本、登记簿副本、评价报告（一式三份）
- 处理请求书（一式三份）
- 请求人身份证明材料
- 授权委托书
- 实施侵权行为的相关证据及证据材料清单

**时限特征**：受理后一般在 7 日内核查并决定是否受理；专利侵权纠纷行政处理有明确的结案期限要求（常见为自立案之日起 3 个月内结案，复杂的经批准可延长，延长期限依地方规定执行）。行政处理中认定侵权成立的，可责令侵权人立即停止侵权；当事人不服的，可自收到处理通知之日起 15 日内依《行政诉讼法》起诉；期满不起诉又不停止侵权的，行政部门可申请法院强制执行。

**优势**：调查取证能力强（可以查账簿、查合同、进场所、查封扣押）、能罚款没收（对被投诉方是实质威慑）、不收费或成本低。
**局限**：
- **不赔偿你**。行政查处的罚款归国家，不赔权利人
- 周期长
- 属地性强，不同地方口径与力度差别大
- 跨区域批量维权时成本陡增

### 1.3 民事诉讼

**法律基础**：《民事诉讼法》及相关司法解释；《商标法》第五十七条至第六十三条、《专利法》第六十四条至第七十五条、《著作权法》第五十二条至第五十四条；《民法典》第179条（承担民事责任方式）、第185条（惩罚性赔偿）。

**管辖**：由被告住所地法院管辖；侵权行为地（含被诉侵权行为实施地与被诉侵权商品储藏地、销售地）法院也可管辖；涉及平台内侵权的，多地法院均有管辖权，实践上常选择对维权方便利且对被告有约束力的法院。

**核心请求权**
- 停止侵害、排除妨碍、消除危险
- 赔偿损失（三种计算方法见成本收益篇）
- 消除影响、赔礼道歉（涉及商誉损害时）
- 民事制裁：罚款、收缴侵权商品与伪造的商标标识及主要生产工具设备

**关键程序工具**
- **财产保全、行为保全**：专利权人或利害关系人证据证明他人正在实施或即将实施侵权，如不及时制止将造成难以弥补的损害的，可在起诉前申请（行为保全对"断链"很有效）
- **证据保全**：证据可能灭失或以后难以取得的，可在起诉前申请
- **举证责任分配（商标特有）**：在商标侵权诉讼中，权利人证据不足以证明被诉标识使用在相同或类似商品上、容易导致混淆的，由被投诉方承担举证责任
- **专利举证责任倒置（特定情形）**：专利侵权纠纷涉及新产品制造方法的发明专利的，制造同样产品的单位或个人应当提供其产品制造方法不同于专利方法的证明

**时限**：简易程序 3 个月内审结，普通程序 6 个月内审结（可延长）；一审不服可上诉。

**优势**：可主张赔偿的路径；能拿到停止侵权判决；有财产保全与行为保全工具；举证责任分配对商标权利人有利。
**局限**：周期以月计；鉴定与代理费用实；对方可能无履行能力；判决执行难。

### 1.4 刑事报案

**法律基础**：《刑法》第二百一十三条至第二百一十九条等；《关于办理侵犯知识产权刑事案件适用法律若干问题的解释》；《刑事诉讼法》。

**常见罪名与追诉门槛（现行立案追诉标准）**

| 罪名 | 法条 | 主要追诉标准 |
|---|---|---|
| 假冒注册商标罪 | 第213条 | 非法经营数额 5 万元以上，或违法所得 3 万元以上；假冒两种以上注册商标的，非法经营 3 万元以上或违法所得 2 万元以上 |
| 销售假冒注册商标的商品罪 | 第214条 | 销售金额 5 万元以上；尚未销售但货值 15 万元以上；已售与未售合计 15 万元以上 |
| 非法制造、销售假冒注册商标标识罪 | 第215条 | 伪造、擅自制造或销售数量 2 万件以上，或非法经营 5 万元以上、违法所得 3 万元以上；两种以上商标标识 1 万件以上、3 万元以上、2 万元以上 |
| 假冒专利罪 | 第216条 | 非法经营 20 万元以上或违法所得 10 万元以上；给专利权人造成直接经济损失 50 万元以上；假冒两项以上专利的，非法经营 10 万元以上或违法所得 5 万元以上 |
| 侵犯著作权罪 | 第217条 | 以营利为目的，违法所得 3 万元以上或非法经营 5 万元以上；复制品数量合计 500 张（份）以上 |
| 销售侵权复制品罪 | 第218条 | 违法所得 10 万元以上；尚未销售的侵权复制品货值 30 万元以上 |
| 侵犯商业秘密罪 | 第219条 | 造成损失数额 50 万元以上，或因侵犯商业秘密违法所得 50 万元以上 |

**门槛判断要点**
- 达到"非法经营数额"与"违法所得"两个口径，哪个先到算哪个；不同罪名的门槛差异很大（假冒专利 20 万 vs 侵犯著作权 5 万）
- 服务类商标的假冒门槛高于商品类（司法解释征求意见稿对服务类设了更高标准），涉及服务类侵权时门槛要另行核实
- 两年内因相关行为受过行政处罚后再犯的，门槛更低
- 达到十倍以上标准的，可认定为"情节特别严重"

**优势**：一旦立案，调查取证能力远超民事诉讼（可查账册、查流水、跨省）；对生产型侵权方威慑极大；可追究刑责。
**局限**：
- **门槛高**，多数小规模侵权够不上
- 周期不可控，取决于侦查进度
- 报案不等于立案，立案不等于追赃
- **报案人自身风险**：事实不构成犯罪而报案的，可能被追究诬告陷害责任；证据虚假、伪造的，另行担责
- 罚没与追赃的归属按规则处理，不当然等于权利人拿回损失

**你的角色边界**：只做条件对照与门槛测算，**不代写报案材料、不指导如何陈述事实**。事实陈述必须由权利人本人如实作出。

## 二、决策树

```
【第 0 步】权利基础体检
├─ 权利不清晰或即将失效 → 先补权利基础（续展、缴费、无效宣告应对、权属补证）
├─ 主体资格有瑕疵 → 先补授权文件（见授权链核对清单）
└─ 通过 → 进入第 1 步

【第 1 步】目标是哪一个？
├─ A 快速止损 → 平台投诉（先做试点，再放量）
├─ B 拿到赔偿 → 民事诉讼（赔偿主张路径）
├─ C 让对方被罚 → 行政投诉
├─ D 追究刑责 → 先算刑事门槛，不够则不报
└─ E 组合（常见）→ A 打底 + B 收尾 + C 施压

【第 2 步】侵权规模与对方类型
├─ 长尾店铺、链接多、单案价值低 → 平台投诉批量
├─ 头部店铺、有销量数据 → 民事诉讼（可主张惩罚性赔偿）
├─ 实体工厂、批量生产 → 行政处理 + 民事诉讼并行；规模到门槛则报案
└─ 跨境卖家、无实体 → 平台投诉为主（成本低、见效快）

【第 3 步】证据状态
├─ 证据齐备（权属 + 侵权事实 + 损失线索）→ 直接走路径
├─ 证据部分缺失 → 先补关键的那一项，其余并行
└─ 证据基本没有 → 固证据优先。任何路径都不能跳过这一步

【第 4 步】成本收益比
├─ 预期收益 / 预期成本 > 3 → 值得立项
├─ 1 至 3 → 先做平台投诉（低成本），把诉讼留作后手
└─ < 1 → 不投入，把力量放在侵权源头治理与渠道管控上
```

## 三、路径选择的四条经验规则

1. **止损与救济分开算**。平台投诉的收益是止损，不是赔偿。把两者混在一起算，就会得出"投诉没拿到钱所以没用"的错误结论
2. **规模决定路径**。单案金额小的时候，任何正式程序的单位成本都过高；单案金额大到一定程度，正式程序的期望回报才盖得住成本
3. **越靠前越便宜**。证据固定的成本远低于诉讼；平台投诉的成本远低于行政与刑事。同样的目的，越早动手越省钱，但"早"不等于"证据没准备好就动手"——平台投诉可以先做，因为它不消耗证据
4. **刑事门槛是硬门槛**。够不上门槛，报案基本是无效动作，还会给权利人带来被核查的风险。宁可先通过民事与行政固定证据、扩大规模，再评估是否报案

## 四、平台投诉的节奏控制

### 时间线（以提交日为 T+0）

```
T+0        提交投诉，同步启动证据固定（两件事并行，不要等投诉结果再取证）
T+1~T+3    形式审核期：留意是否收到补件通知（未在指定期限响应视为撤回）
T+3~T+10   审核与处置期：平台采取下架等措施并通知卖家
T+7~T+20   答辩期：留意卖家申诉，收到后需在指定期限内回应
T+15~T+30  裁定期：平台综合双方材料作出处理
后续        对裁定不认可时，可提交有管辖权的法院进一步审查
```

**各节点的动作清单**
- 提交前：把证据包整理完整再提交（一次交齐，避免因补件错过程序）
- 提交当日：同步启动取证（这是整个流程里容易漏掉的一步）
- 收到补件通知：立刻响应，逾期视为撤回
- 收到卖家申诉：逐条比对，形成回应意见（回应也要提交，否则视为认可撤回）
- 裁定后：记录结果，对同一主体的其他链接复用同一套材料

### 三个高频投诉被驳回的原因
1. **类目或类别选错**：商标核定使用的商品/服务类别与被诉商品不对应；专利与著作权的投诉理由类型选错
2. **权利基础瑕疵**：商标被提无效或存在撤三风险、专利未缴年费、著作权登记证书与被诉作品不对应
3. **比对说明不合格**：只写"与权利人商标相同""涉嫌侵权"，没有指出具体近似点或技术特征对应关系。**比对说明是投诉材料里权重很高的一段**，它决定审核人员能不能快速确认

## 五、四条路径的组合用法（常见且有效）

```
场景：品牌方在主流电商平台发现多个店铺售卖仿冒品，工厂疑似在生产

T+0   平台投诉（批量，覆盖已发现的链接）+ 同步固定证据（公证购买实物、页面取证）
T+7   举报渠道同步：向监管部门举报生产端线索；如规模接近刑事门槛，准备报案材料
T+30  对已下架的链接发起民事诉讼（此时已有实物证据与购买记录，胜诉概率提升）
T+60  对生产方提起行政处理或报案，视规模与门槛决定
T+90  依据判决或处罚结果，扩大批量投诉覆盖剩余长尾链接（此时材料是现成的）
```

**这个顺序的逻辑**：先用低成本手段止损（平台投诉），同时把证据做实（这是后面所有路径的共同前提），再针对有价值的对象逐层升级（诉讼与行政），规模够时动刑事。**不要一开始就对长尾店铺逐个起诉，那是代价高的解法。**

## 六、成本收益评估与批量策略
### 6.1 成本项拆解

维权成本远不止代理费。把成本算全，才能判断值不值得打。

| 成本项 | 内容 | 常见量级参考 | 说明 |
|---|---|---|---|
| 证据固定成本 | 公证保全、可信时间戳、购买实物、鉴定 | 公证单次数千元不等；时间戳单次约 10 元量级；鉴定视事项而定 | 公证与鉴定是大头，且鉴定常在诉讼中才发生 |
| 代理费 | 律师费或代理服务费 | 按件、按阶段或风险代理三种方式 | 风险代理的比例较高但前期现金支出低；按阶段付费可把支出摊到各阶段，现金流压力小 |
| 诉讼费用 | 案件受理费 | 按诉讼标的额分段累计 | 财产案件按标的额比例分段，标的额越大比例越低；可通过主张合理开支争取部分由对方负担 |
| 鉴定费用 | 专利技术特征比对、损失鉴定、著作权鉴定 | 视事项复杂度 | 专利案件常必需；损失鉴定在主张实际损失或侵权获利时可能需要 |
| 时间成本 | 自己投入的工时、员工配合、决策等待 | 常被忽略，往往是占比较大的一块 | 批量维权尤其明显：每条投诉都要看材料、跟进、答辩 |
| 机会成本 | 资源用于维权而未用于产品、渠道、防御 | 难以量化但真实 | 这一项常让"法律上能赢"的案子不值得打 |
| 关系与声誉成本 | 与平台、渠道、上下游的关系损耗 | 难以量化 | 集中投诉可能影响与平台的关系；处理不当会影响渠道合作 |
| 失败成本 | 投诉不实被反诉、虚假证据被追究 | 尾部风险但后果重 | 见风险清单 |

**一条经验**：把时间成本按自己的时薪折算后，很多看起来"值得打"的小案子会立刻变成不值得。**这通常是正确的结论**——小案子消耗的是注意力，而注意力是稀缺资源。

### 6.2 收益项拆解

### 6.2.1 直接赔偿

三种法定计算方法，权利人可以选择适用（《商标法》第63条、《专利法》第71条、《著作权法》第54条同结构）：

```
方法一：权利人因被侵权所受到的实际损失
方法二：侵权人因侵权所获得的利益
方法三：参照侵权行为的获利倍数 / 许可使用费的倍数合理确定
```

前两种难以确定的，参照第三种。三种都难以确定的，适用法定赔偿：
- 商标：500 万元以下
- 专利：3 万元至 500 万元以下
- 著作权：500 元至 500 万元以下

**惩罚性赔偿**：恶意（商标、著作权表述为"恶意"，专利表述为"故意"）侵犯且情节严重的，可在上述方法确定的数额基础上，**1 倍至 5 倍**确定赔偿数额。计算基数仍是实际损失 / 侵权获利 / 许可费倍数这三项，倍数是乘在基数上的。

**合理开支可计入赔偿**：包括权利人或委托代理人对侵权行为进行调查、取证的合理费用；符合国家有关部门规定的律师费用可计入赔偿范围。**这意味着调查取证与律师费不是纯成本，有机会在赔偿中回收**——这一点在评估时经常被漏掉。

### 6.2.2 计算要点

**实际损失路径**（适用于己方销量因侵权下滑可测算的情况）：
权利人因侵权所造成商品销售减少量 × 权利人商品单位利润。销售减少量需要有对比依据（如侵权出现前后的销量变化、其他同类渠道的变化）。

**侵权获利路径**（适用于己方销量未受影响、但对方有可观销量的情况）：
侵权商品销售量 × 侵权商品单位利润；单位利润无法查明的，参照注册商标商品的单位利润。

**许可费倍数路径**（适用于有可比许可合同的情况）：按许可费的一定倍数确定。

**为什么这条路径更值得投入**：实际损失与侵权获利的举证都在对方手里（销量、成本、利润账册）。权利人往往只能拿到平台显示的销量数字这类参考数据，很难做实。所以**如果有可比对的许可合同或行业平均利润率数据，许可费倍数路径通常是成功率较高的一条**。

**拿不到数据时的现实判断**：如果三类计算方法都难以证明，赔偿将落到法定赔偿区间。商标案件在 500 万元以下区间、专利在 3 万元至 500 万元区间、著作权在 500 元至 500 万元区间内酌定。**这时要重新问一句：这个案子走诉讼还有意义吗？** 除非对方的恶意情节明显（可能被认定情节严重从而适用惩罚性赔偿），或者止损价值本身就够。

### 6.2.3 止损价值

这是容易被忽略、但常常占比较大的一块收益。

```
止损价值 = 侵权链接在存续期间的可成交额 × 保住该部分成交的概率
```

举例：某侵权链接月销 2000 单、单价 80 元、平台投诉处置率 80%，则一次投诉的止损价值量级是 2000 × 80 × 12（年）× 80%。这个数常常远超诉讼能拿到的赔偿。

**这个公式的用法**：它把"要不要维权"从"能不能赢官司"转回"能不能阻止损失"。**很多被认为"不值得起诉"的案子，因为止损价值可观而值得做平台投诉。** 这也解释了为什么平台投诉对品牌方价值很大。

### 6.2.4 无形价值（定性）

- 对同类的威慑：一次成功处置会抑制后续的模仿行为
- 渠道谈判筹码：可用于与平台谈整体治理方案
- 内部合规信号：让内部团队意识到侵权的法律成本

**评估原则**：无形价值不计入定量测算，但用于决策时的两难情形（在两个方案收益接近时，选有威慑效果的那个）。

### 6.3 决策规则

```
预期收益 = 直接赔偿 × 胜诉概率
         + 止损价值 × 处置确定性
         + 无形价值（定性加权）

预期成本 = 证据固定 + 代理费 + 诉讼费 + 鉴定费 + 时间成本（折算）+ 机会成本

比值 = 预期收益 ÷ 预期成本
```

| 比值 | 判断 | 建议动作 |
|---|---|---|
| 大于 3 | 值得单独立项 | 完整走诉讼路径，同步做平台投诉止损 |
| 1 至 3 | 有条件推进 | 先做平台投诉止损，把诉讼留作后手；把成本压低（批量固定证据、选定有利的计算方法） |
| 小于 1 | 不投入正式程序 | 只做平台投诉与行政举报；把资源转向源头治理（渠道管控、权利布局、平台规则沟通） |

**注意**：比值里的"胜诉概率"不要凭感觉填。用自检清单的结果反推：自检 A 组（权利基础）全通过且 B 组（侵权事实）扎实，可给较高概率；A 组有疑点则概率要显著下调，因为权利基础瑕疵会直接导致驳回。

**胜诉概率与赔偿不是独立的**：权利基础有瑕疵时，即便胜诉，赔偿也可能大幅缩水（法定赔偿下限极低）。所以评估时要连带考虑。

### 6.4 批量维权与分散维权的取舍

### 6.4.1 两种模式的对比

| 维度 | 批量维权 | 分散维权 |
|---|---|---|
| 组织方式 | 一次性整理多个链接/多个主体，集中提交 | 逐个主体单独处理 |
| 单案成本 | 随数量增加而下降（固定成本摊薄，模板化） | 恒定甚至上升（重复劳动） |
| 单案收益 | 低（多为长尾店铺，销量小、赔偿低） | 高（可主张实际损失与惩罚性赔偿） |
| 时间跨度 | 短（几天到两周） | 长（每案一个完整周期） |
| 证据质量 | 容易下滑（模板化导致比对说明流于形式） | 容易做扎实（可以逐案做技术比对） |
| 主要风险 | 被认定滥用权利、恶意投诉；被集中反驳后整体崩盘；自身账号被平台风控 | 拖期导致证据灭失、错过诉讼时效、成本失控 |
| 形成的价值 | 断链、清理渠道、快速见效 | 判例与威慑、行业影响力 |

### 6.4.2 决策规则

```
① 单案价值低 + 数量多 → 批量（平台投诉）
② 单案价值高 + 数量少 → 分散（诉讼）
③ 混合 → 分层：
   把对象分成"头部主体"与"长尾店铺"两层
   头部 → 单独诉讼或行政处理（投入重资源）
   长尾 → 批量平台投诉（投入轻资源）
   头部案件的胜诉结果可直接复用为长尾投诉的比对材料
```

### 6.4.3 批量维权的四个必控风险

1. **权利基础风险被放大**：一次权利瑕疵会导致整批投诉被驳回，还可能损害投诉主体在平台的信誉。**批量前必须完成权利状态核查**
2. **被认定为滥用权利或不正当竞争**：投诉明显不实、超出合理范围、反复骚扰同一主体，可能引发反向主张
3. **节奏失控**：一次性全量提交会暴露策略、给对方集中准备反证的时间、也容易触发平台对投诉主体的风控。**分批与错峰更稳**
4. **内部质量失控**：批量场景里比对说明容易变成空话，而比对说明恰恰是审核人员看的重点。**模板必须留出针对具体被诉对象的差异部分**

### 6.4.4 试点验证法（推荐做法）

批量之前，先做一个小规模试点：

```
试点设计
├── 选 5 至 10 个目标链接，覆盖不同类型（一个明显侵权、一个擦边、一个已下架）
├── 提交后记录：形式审核耗时、是否要补件、处置结果、卖家是否答辩、答辩理由
└── 产出：驳回原因清单 + 材料改进清单
```

**试点要验证的四件事**
1. 权属材料能否一次通过认证（会不会要补件）
2. 比对说明是否被认可（看驳回意见）
3. 处置措施的实际力度（是否只是删除链接，还是有扣分与店铺处置）
4. 对方的反应速度与答辩理由（决定后续要不要走诉讼）

**试点的价值大于它的成本**：一次失败的批量提交会消耗投诉主体的信誉，这个信誉的恢复成本远高于做十次试点。

### 6.5 成本压缩的六个可行做法

这些做法不降低维权效果，只是把成本挪到更有效率的形式上。

1. **证据固定方式分级**：标志性单件用公证，批量页面用时间戳。公证费集中在更有价值的那几份证据上
2. **诉前证据整理交给代理**：证据目录、说明、比对表这类格式化工作由代理做，权利人只提供原始材料
3. **按阶段付费**：把代理费拆到各阶段，现金流压力小，也保留了中途退出的余地
4. **一次取证多处用**：同一批公证件同时用于平台投诉、行政投诉与诉讼，摊薄固定成本
5. **诉讼与投诉并行而非串行**：平台投诉免费且快，与诉讼同时进行，两条线互相提供材料
6. **计算方法优选**：诉讼请求的设计直接影响赔偿额，把请求集中在有证据支撑的计算方法上

**不要为省钱做的事**：省掉取证（风险高）、省掉技术比对（专利案件会因此失去方向）、用不实材料（后果严重）。

### 6.6 交付格式

测算结果用这个结构给，方便对方直接决策：

```
【测算结论】
  推荐动作：{平台投诉 / 平台投诉+诉讼 / 诉讼 / 行政查处 / 暂不投入}
  理由：{2 至 3 句，指向关键数字}

【成本】
  证据固定：约 {金额}（{方法与件数}）
  代理与程序：约 {金额}（{方式}）
  时间投入：约 {工时}（{阶段拆解}）
  合计：约 {金额}

【收益】
  直接赔偿：{区间与计算方法} × 胜诉概率 {X} = {金额}
  止损价值：{链接成交额} × 处置确定性 {X} = {金额}
  比值：{收益} ÷ {成本} = {数值}
  判断：{值得立项 / 有条件推进 / 不投入正式程序}

【前提条件】
  补齐后测算才成立：{列出待补证据项}
  若补不齐，结论变为：{调整后的判断}
```

**收尾这句是专业性的体现**：测算永远建立在假设上，把假设写出来，用户才知道结论在什么条件下会变，也才敢拿这个结论去做决策。
