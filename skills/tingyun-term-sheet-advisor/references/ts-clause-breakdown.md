# TS 七大核心条款拆解与影响示例

> 决策辅助，非法律意见；数字为示例，以协议为准。

## 1. 估值（Valuation）
- 区分**投前估值**与**投后估值**，二者差一个融资金额。
- 高估值常绑定高对赌：到期若未达标，回购压力大。
- 示例：投前 4000 万 + 融资 1000 万 = 投后 5000 万，投资人占 20%。

## 2. 优先清算权（Liquidation Preference）
- 公司清算/出售时，投资人先拿回投资本金（常带 1–2 倍）。
- **影响**：若以 5000 万被收购、投资人 2 倍优先即 2000 万先行，剩余才分创始人。
- 关注点：倍数、是否"参与"（参与权会再分剩余）。

## 3. 反稀释（Anti-dilution）
- 后续降价融资时，投资人股权被补偿以防稀释。
- 两类：**广义加权平均**（温和）、**完全棘轮**（严苛，按低价重算）。
- 影响：棘轮下创始人股权被大幅摊薄。

## 4. 对赌 / 估值调整（VAM）
- 未达业绩或上市，创始人/公司需补偿或回购。
- 与**股东**对赌：直接掏腰包；与**公司**对赌：需减资程序才具可执行性。
- 关注点：触发指标、补偿上限、是否含经营豁免。

## 5. 一票否决（Veto）
- 投资人对特定事项一票否决。
- 风险：范围过宽（连日常经营都否）会瘫痪公司。
- 应限定在核心事项（增资、合并、清算、章程修改等）。

## 6. 董事会席位（Board Seats）
- 席位比例决定重大事项话语权。
- 合理区间：按融资比例，早期避免投资人占多数。
- 关注观察员、董事任免机制。

## 7. 拖带权 / 跟售权（Drag / Tag-along）
- 拖带权：大股东售股可强制小股东随售——创始人可能被裹挟退出；
- 跟售权：小股东可随大股东一起卖，保护小股东。
- 关注拖带门槛（如多数投资人同意）与创始人例外。

## 八、逐条自检清单
- [ ] 估值口径（投前/投后）是否写清；
- [ ] 优先清算倍数与参与权；
- [ ] 反稀释采用哪种机制；
- [ ] 对赌主体、触发、上限；
- [ ] 一票否决事项清单；
- [ ] 董事会席位与观察员；
- [ ] 拖带/跟售门槛。
