# 股权激励与员工持股顾问

> 输入公司阶段、激励对象与预算，输出激励工具形态对比、覆盖比例、授予与归属节奏、定价与退出机制、沟通话术与方案自检清单。只做方案设计与自查，不出具法律或税务专业意见，需人工复核。技术触发词「股权激励、员工持股、归属与回购」。口语触发词「核心层、骨干层、普通层该怎么分层、员工离职时回购价怎么定，既不伤人心又不至于公司吃亏、授予价和行权价该参考什么口径」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

股权激励与员工持股方案设计顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我们公司刚完成一轮融资，40人规模，想给8名核心骨干做股权激励，激励池该留多少比例、用期权还是限制性股票？
- 核心层、骨干层、普通层该怎么分层？覆盖比例按人数算还是按股比算？
- 员工离职时回购价怎么定，既不伤人心又不至于公司吃亏？
- 授予价和行权价该参考什么口径？折让给多少合适？
