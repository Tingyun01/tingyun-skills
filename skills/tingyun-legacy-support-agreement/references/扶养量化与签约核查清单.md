# 扶养量化与签约核查清单（规划辅助用）

> 以下为量化框架与核查清单，不构成法律意见，均以持证专业人士与属地规定为准。

## 一、扶养义务量化框架

把"生养死葬"拆成可检查、可留痕的动作：

### 1. 生活照料（量化示例）
- 居住：独居/同住/机构，明确标准
- 饮食与日常：频次、由谁负责
- 探视：每月不少于 X 次，记录留存

### 2. 医疗照护（量化示例）
- 日常就医陪同：次数与响应时限
- 重大医疗决策：由谁签字、费用来源
- 护理等级：依健康变化调整的机制

### 3. 费用承担（量化示例）
- 生活费、医疗费由扶养人承担的比例与上限
- 大额支出（如手术）的确认方式
- 费用凭证的保存与对账周期

### 4. 殡葬（量化示例）
- 殡葬标准与预算上限
- 由扶养人负责办理并凭凭证结算

## 二、履行争议预防清单

- [ ] 条款量化、可检查，避免"好好照顾"这类模糊表述
- [ ] 设立履约记录机制（日志、照片、票据、第三方见证）
- [ ] 约定违约后果与解除条件（如连续 X 月未履行可解除）
- [ ] 约定争议解决方式与监督人/见证人
- [ ] 明确遗产给付的前提（扶养义务履行到何种程度）

## 三、是否公证的建议

建议考虑公证的情形：
- 涉及房产等大额、权属敏感资产
- 双方信任度有限、家庭关系复杂
- 扶养人非近亲属（如组织、朋友）

可不急于公证的情形：
- 金额小、双方高度信任、已有完善记录机制
- 成本敏感、拟先试行再补公证

注意：是否公证不决定协议本身是否成立，只是影响举证与执行顺滑度。

## 四、签约前核查清单

- [ ] 遗赠人行为能力确认（必要时留医疗/鉴定意见）
- [ ] 扶养人身份、履约能力核查
- [ ] 遗产权属清晰、无抵押/查封/共有人异议
- [ ] 与已有遗嘱、赠与无冲突，或已明确优先关系
- [ ] 条款已完成量化，双方理解一致
- [ ] 是否公证已决策，并预留凭证保存方案

## 五、需立即转人工的情形

- 遗赠人意思能力存疑或受胁迫；
- 扶养人明显无履约能力；
- 遗产涉及第三人权利或大额资产。
