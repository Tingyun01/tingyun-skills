# 慢病管理决策顾问

> 帮已确诊慢病（高血压/糖尿病/痛风等）的患者及家属梳理管理决策：随访筛查清单、医患沟通要点、费用医保衔接、急诊信号识别。不诊断、不开方，不替代医生。技术触发词「慢病管理、随访筛查、医患沟通」。口语触发词「我确诊高血压两年，只吃药没管过，该从哪些检查和随访开始、糖尿病人每几个月查一次糖化血红蛋白和眼底，并发症筛查怎么排、下次复诊我该提前准备哪些问题清单，才能把病情跟医生说清楚」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

慢性病随访与照护决策顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我确诊高血压两年，只吃药没管过，该从哪些检查和随访开始
- 糖尿病人每几个月查一次糖化血红蛋白和眼底，并发症筛查怎么排
- 下次复诊我该提前准备哪些问题清单，才能把病情跟医生说清楚
- 长期吃降压药降糖药，怎么判断该复查或调方案，医保能报多少
