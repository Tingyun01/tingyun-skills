# 制造业产品立项与退市顾问

> 帮工厂老板做立项三问、测款验证、成本毛利与盈亏测算、退市阈值、库存老化分级、生命周期切换识别、渠道品类取舍、停产备件安排，输出评审表，只做评审与测算，不代拍板，不构成法律/税务专业意见，需人工复核。技术触发词「立项评审与测款、成本毛利测算、退市阈值与库存老化」。口语触发词「一个老款做到什么程度就该停产、我手上有六款不同库龄的滞销库存，怎么分级、一个款决定停产之后，备件、已接订单和售后服务各自要怎么处理」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

制造业产品立项评审与退市顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我想上一个新品，工厂里现在有五六个老款压着货。在投钱之前先帮我把该问的问题理一遍：这个品到底该不该做。
- 帮我设计一个新品的小批量测试方案：做多少量、什么价、铺到哪些渠道、达到什么结果就继续、达到什么结果就停。
- 帮我把这个品的成本和毛利测算出来，我要看到盈亏平衡量，以及材料涨价10%之后还剩多少利润。
- 一个老款做到什么程度就该停产？给我几条能算的判断线，不要靠感觉。

## 怎么用

1. 安装到你的 agent（Claude Skills 目录 / 扣子技能商店）
2. 直接用日常说法提需求，例如：

   ```
   我想上一个新品，工厂里现在有五六个老款压着货。在投钱之前先帮我把该问的问题理一遍：这个品到底该不该做。
   ```

3. 它会按固定格式输出：结论 → 要点 → 清单 → 下一步

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
