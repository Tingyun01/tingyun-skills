# 员工绩效与末位沟通顾问

> 帮老板与主管做绩效面谈与低绩效处理：面谈结构、可衡量目标、分级路径、改进计划要素、末位与不能胜任的区分、证据链清单。只做沟通准备与流程设计，不出法律结论，需人工复核。技术触发词「绩效面谈、改进计划、证据链」。口语触发词「这个员工连续两次考核末位，我该怎么跟他谈、改进计划该包含哪些要素、给我一份每季度该留存的证据清单，以防后面解除被质疑」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

绩效改进与人员退出沟通顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 这个员工连续两次考核末位，我该怎么跟他谈？给我面谈结构和一条能走通的处理路径
- 给一个业绩月度波动很大的销售岗设可衡量目标，指标该怎么写才既能量化又站得住
- 改进计划该包含哪些要素？哪些写法搞不好会反过来出事
- 我团队里这个人排名末位，但全team 水平都不差，可以直接当成不能胜任处理吗
