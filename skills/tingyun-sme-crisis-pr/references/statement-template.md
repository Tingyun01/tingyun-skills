# 对外声明模板结构与措辞红线

> 本页给一份"不会翻车"的声明骨架，并标注每条红线。所有对外事实必须基于用户已核实信息，模板不构成法律意见。

## 一、声明通用骨架（四段式）

```
标题：关于【事件】的情况说明（避免用"严正声明""郑重辟谣"等激化措辞）

一、已知事实
  仅写已确认的事实，带时间、地点、涉及范围。
  例："X 月 X 日，我司接到客户反馈……经初步核实，……"

第二段 · 已采取动作
  写"我们已经做了什么"，比空话道歉更有用。
  例："已暂停相关批次、成立专项小组、联系受影响客户……"

第三段 · 下一步与联系方式
  给一个可预期的进展节点和对接入口。
  例："X 月 X 日前公布调查结果，专线/邮箱：……"

第四段 · 留余地收尾
  用"以调查结论为准""感谢监督"收，不抢结论。
```

## 二、措辞红线对照表

| 红线 | 禁止写法 | 推荐写法 |
|---|---|---|
| 不删帖不删证据 | "已处理相关负面内容" | 不提删帖；如需说明则写"已固定并整理相关证据" |
| 不推诿甩锅 | "系个别员工个人行为，与公司无关" | "我司对此负有管理责任，正在内部核查" |
| 不承诺未核实 | "已查清，绝无此事""承诺全额赔偿" | "经初步核实……""以调查结论为准" |
| 不空话安抚 | 通篇"高度重视、深表歉意" | 多写"已知事实 + 已做动作 + 下一步" |
| 不抢结论 | "此事纯属造谣" | "相关信息我们正在核实，以调查结论为准" |
| 不攻击爆料方 | "有人恶意抹黑我司" | 不评价对方动机，只回应事实 |
| 不威胁 | "保留追究权利"放标题/首段 | 可放文末低调表述或省略 |

## 三、三套口径分写原则

| 对象 | 核心目的 | 注意点 |
|---|---|---|
| 对监管 | 配合、可核查、留痕 | 讲事实与已采取动作，不修饰；保留提交材料清单 |
| 对客户 | 安抚、给确定性 | 给明确补偿/处理路径与联系人，不模糊 |
| 对员工 | 稳住、统一出口 | 内部先对齐，要求员工不私自对外发言，防"内部人爆料" |

## 四、声明自检清单（发布前逐条勾）

- [ ] 不写"已查清""绝无此事"等未坐实的确定性措辞
- [ ] 没有点名未核实的第三方责任
- [ ] 没有暗示"花钱处理负面"
- [ ] 事实均有内部证据支撑
- [ ] 留了联系入口与下一步节点
- [ ] 出口人单一、口径已内部对齐
