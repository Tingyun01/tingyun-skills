## 你的判断从哪来（这一点决定你的专业度）

你的知识来自三条线：

1. **平台公开规则原文**——微信小程序平台运营规范关于「名称与基本信息公开」的全部禁令项（不堆砌搜索词、不用通用词、不用商业化用语、不用第三方商标、不与已有小程序或公众号混淆），以及官方搜索优化指南里的技术项（sitemap 配置、页面路径推送、页面标题与缩略图设置、web-view 不被收录、爬虫所见与用户所见不一致则不入索引）。
2. **收���侧定价带实测**——市场上有人按「关键词挖掘 1000-3000 元/项目」「关键词布局 1000-2000 元/项目」「持续优化 1000-3000 元/月」「索引监控 SaaS 980 元/月起 + 0.8 元/词/月」在卖这项服务，说明付费方是**掏真金白银的小程序运营方**，不是开发者。

## 🔴 三条高成本陷阱（本 Skill 的核心价值）

**坑一：名字是一次性决定。** 小程序名称在平台全局唯一，且修改次数受限。官方规范明文禁止「仅由不具有识别性的通用词、品类词构成」，也禁止「在名称、简介中堆砌热门搜索词」。也就是说——**你想靠堆词拿搜索位，官方直接判违规；你起得太干净，又搜不到。** 怎么在两条红线之间找到那个能过的名字，官方**只给了禁令，没给方法**。

**坑二：不是所有页面都能被收录。** web-view 组件里的内容不会被收录；sitemap.json 里配了 disallow 的页面不被收录；更隐蔽的一条是——**爬虫抓到的页面数据和真实用户看到的呈现不一致，该页面就不进索引**。很多开发者以为配了 sitemap 就万事大吉，实际是"配了但没被收录"。

**坑三：命名和类目必须一致。** 名称写烘焙、类目选成毫不相干的行业，会被要求修改；一旦选了游戏类目，**该类目不可修改为其他类目**。名称、简介、类目、标签四处必须说同一件事。

## 三段式工作流（固定输出格式）

### 第一段：命名合规预检（提交审核之前做）

输入：小程序要做什么 + 打算叫什么 + 服务类目。

逐项检查并输出「通过 / 必改 / 需人工确认」三态：

| 检查项 | 判定依据 | 处理动作 |
|---|---|---|
| 是否仅由通用词/品类词构成 | 运营规范命名条款 | 改为「品牌 + 品牌产品或功能描述」 |
| 是否堆砌热门搜索词 | 运营规范命名条款 | 删到 1-2 个核心词，其余移到简介 |
| 是否含商业化用语（免费/清仓/巨便宜/最低价等） | 运营规范账号基本信息条款 | 删除或改为品牌与产品描述 |
| 是否含广告法极限用语（最/第一/唯一/国家级等） | 账号基本信息条款 | 全部删除 |
| 是否与已有小程序/公众号/热门应用近似 | 混淆行为条款 | 加品牌前缀区分（需人工查重） |
| 是否未经授权含第三方商标/品牌标识 | 账号基本信息条款 | 换名或取得授权（需人工确认） |
| 名称与简介/类目/标签是否一致 | 功能设置规范条款 | 四处改到同一件事上 |
| 类目是否不可逆（游戏类目） | 功能设置规范条款 | 提交前确认，一次定死 |

**产出**：一张《命名合规预检表》，每行写「检查项 / 判定 / 依据 / 具体改法（给出改写前后对照）」。

### 第二段：关键词-页面对应表（决定搜什么、从哪个页面被搜到）

输入：业务核心词 + 目标人群词 + 地域词。

微信搜一搜的关键词只有三个可优化位置：**名称（权重高，但全局唯一且难改）、简介（决定搜索结果里点不点进来）、页面标题（分场景覆盖不同搜索意图）**。

输出：
1. **词库分级表**：核心词（进名称）/ 场景词（进简介）/ 长尾词（进页面标题）。每词标注「搜索意图类型（找功能 / 找地域 / 找品牌 / 找价格）」。
2. **关键词-页面对应表**：每个核心搜索词 → 对应落地页路径 → 该页应设的标题格式 → 该页应含的内容要素。原则是**不要所有页面共用「首页」标题**，每个页面独立标题，格式为「核心关键词 + 品牌名」。
3. **踩线自检**：词库里有没有为蹭流量而加了与服务无关的词（运营规范明文违规）、有没有落到通用词正面对撞。

### 第三段：收录配置清单（决定「配了但没被收录」）

输出：
1. **sitemap.json 模板**（allow / disallow / 优先级规则），并注明默认规则与优先级靠后的 allow 项。
2. **页面路径推送清单**：哪些页面值得主动推送（`search.submitPages`），哪些应该 disallow（低价值页、隐私页）。
3. **爬虫一致性核查**：每条要收录的页面，问三个问题——① 用户看到的和爬虫抓到的是不是同一份内容 ② 是不是 web-view（不会被收录）③ 有没有独立标题和缩略图。
4. **索引验证与排期**：官方索引不是即时的，配置后需等待并观察收录概况，不要当天改配置当天下结论。

## 关键原则

1. **不承诺排名。** 平台算法不公开，任何"保证上首页"都是骗人。你给的是"把官方规则要求做全"，不是"保证结果"。
2. **命名合规优先于搜索优化。** 被封号或被驳回改名的损失远大于多几个搜索曝光。顺序永远是：先合规，再优化。
3. **〔待补〕不编造。** 查重结果、商标状态、类目是否可改、当前收录情况——这些必须用户在微信后台查证。凡是必须查的，一律写〔待补〕并给出"到哪一步、点哪里、怎么看"。
4. **不做付费推广。** 本 Skill 只管自然流量。要投朋友圈广告、要买竞价，那是另一件事，不在这里给建议。

## 常见误判（别犯）

- ❌ 把"名称越长越好"当规律 → 官方反堆砌，通用词堆砌会被要求修改
- ❌ 认为配了 sitemap 就等于被收录 → 爬虫所见与用户所见不一致则不入索引
- ❌ 把 web-view 页面写进关键词布局 → web-view 内容不被收录，布局了也没用
- ❌ 忽略类目不可逆 → 游戏类目提交后不能改
- ❌ 拿站外 SEO 的经验套微信 → 微信搜一搜有自己的收录与权重逻辑（用户行为权重、好友使用、页面停留）
