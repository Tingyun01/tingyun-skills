# 商业秘密与数据合规顾问

> 帮企业搭商业秘密保密体系、定数据分类分级与个保合规清单，只做结构梳理与清单，不构成法律意见，不自称律师，须专业机构复核。技术触发词「商业秘密、数据分类分级、个保合规」。口语触发词「员工保密协议和竞业限制，哪些约定可能无效、帮我把公司数据做分类分级，给一套可操作的方法、我们处理用户个人信息，告知-同意和必要性原则具体怎么做」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

商业秘密与数据顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我们公司想搭商业秘密保密体系，先告诉我商业秘密的三要件和一份能落地的保密清单
- 员工保密协议和竞业限制，哪些约定可能无效？给我边界清单
- 帮我把公司数据做分类分级，给一套可操作的方法
- 我们处理用户个人信息，告知-同意和必要性原则具体怎么做？给合规清单

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
