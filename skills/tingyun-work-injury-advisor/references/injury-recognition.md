# 工伤认定情形、除外、时限与劳动关系举证

> 本页为决策辅助底稿，不构成法律意见，不替代认定结论，需专业人士复核。

## 一、认定情形对照

| 情形 | 要点 |
|---|---|
| 工作时间内场所内因工作受伤害 | 典型，需证明"工作相关" |
| 前后从事预备/收尾工作受伤害 | 上班准备、下班收尾也算 |
| 因履行工作职责受暴力等意外伤害 | 与履职直接相关 |
| 患职业病 | 以职业病诊断为准 |
| 因工外出期间受伤害或下落不明 | 出差、外勤期间 |
| 上下班途中非本人主要责任的交通事故 | 须"非本人主要责任" |

## 二、除外情形（一般不认定工伤）

- 故意犯罪
- 醉酒或者吸毒
- 自残或者自杀

> "非本人主要责任"以公安机关交通管理部门等出具的事故责任认定为依据。

## 三、申请时限

- **单位**：自事故伤害发生之日起 **30 日内**向统筹地区社保行政部门申请
- **劳动者一方**：单位未申请的，工伤职工或其近亲属、工会组织可在 **1 年内**直接申请
- 超期风险：超过 1 年个人申请窗口，认定程序将受阻，务必提示尽早启动

## 四、材料清单

基础三件：
1. 工伤认定申请表
2. 与用人单位存在劳动关系（含事实劳动关系）的证明材料
3. 医疗诊断证明或者职业病诊断证明书

事故说明：写明时间、地点、经过、证人。

## 五、无合同如何举证劳动关系

用以下证据形成链条（越多越稳）：
- 工资支付凭证/银行流水、工资条
- 工作证、服务证、招工招聘登记表
- 考勤记录、排班表
- 同事书面证言
- 线上聊天/群聊中确认用工、派活、发薪的内容
- 用人单位招工"报名表"、体检表等

> 事实劳动关系同样受保护，关键在于证据链完整。具体认定由法定机关作出。
