# 第二地点选址与扩张取舍

## 一、第二地点选址打分

| 维度 | 权重参考 | 看什么 |
|---|---|---|
| 需求密度 | 高 | 周边人口/企业、消费力、客流 |
| 供应链半径 | 中高 | 配送成本、补货时效 |
| 人员可得性 | 中 | 关键岗位招聘难度 |
| 租金/地价 | 中 | 占营收比是否合理 |
| 竞争格局 | 中 | 同业密度与差异化空间 |
| 与现有点协同 | 中高 | 能否复用团队/供应链/品牌 |

异地扩张额外加权重：管理半径、本地化难度、政策差异。

结论：同域加密（复用供应链与团队）风险通常低于异地新点。

## 二、扩张 vs 深耕取舍框架

先算两项的边际收益与风险：

- **深耕现有点**：提价、增品、提效、会员复购。风险低、见效快。
- **开新点**：增量市场。风险高、回收慢、占用资金。

判断逻辑：
1. 现有点模型未验证（亏损/回本不明）→ 先深耕，不扩。
2. 现有点提升空间大且风险低 → 优先深耕。
3. 单点已近天花板、周边无空间 → 才转新点。
4. 新点启动的触发条件：单点模型稳、资金安全垫足、关键岗位可复制。

## 三、决策检查

- 不拿"感觉周边能火"替代打分。
- 不拿借款去覆盖扩张缺口而不做压力测试。
- 多点的管理精力是否够，避免新点抽血老点。
