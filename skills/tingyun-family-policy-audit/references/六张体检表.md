# 家庭保单体检六表 · 完整可打印表格版

> 本文件是"家庭保单年度体检助手"的配套表格集。示例数据均为**虚构家庭**，仅用于演示填法与阅读方式，不代表任何真实客户的保单信息。
>
> 使用方式：把表 1 抄到一张纸上（或一个表格文件）里，把抽屉里的保单找出来逐份填；填完表 1 后再依次填表 2 到表 6。每张表末尾都留了"填表人自查"一行。

**通用填写原则**
1. 一张保单一行，一种保单不要拆成多行；同一保单有多个保障责任时，在"保障责任"列用顿号并列。
2. 金额一律写数字，不写"大约""几十万"；拿不准就先写区间下限，标注"待核"。
3. 日期一律写 `YYYY-MM-DD` 或 `YYYY年M月`，只记得月份就写月份并标"待核"。
4. 所有"待核"字段在体检报告里会原样保留为待办，不要自己脑补补齐。
5. 保单正本、投保单、续保通知、扣款记录，都可以作为填写依据；找不到正本时，先向承保公司客服或官方渠道索取保单信息页。

## 表 1 · 家庭保单汇总表

**用途**：这是整个体检的底稿。先把所有保单摊平，做到"家里一共买了多少张保单"心里有数，再谈其他。

**列定义与填写说明**

| 列名 | 填什么 | 常见填错 |
| --- | --- | --- |
| 序号 | 与家人对过后的流水号 | 同一张保单拆成两行（主险和附加险各一行） |
| 家庭成员 | 投保人是谁（用"父亲""母亲""孩子"这类称谓即可） | 填成被保险人；投保人与被保险人常不是同一人 |
| 保险公司 | 承保公司全称 | 只写品牌昵称；同一家公司有多个简称 |
| 产品名称 | 保单上的产品全称（以保单信息页为准） | 自己口头叫的"那个重疾" |
| 保障责任 | 合同列明的责任项，如"重疾赔付""一般住院医疗""意外身故" | 只写险种大类；同一保单有多项责任要并列 |
| 保额 | 各项责任对应的保险金额 | 写成"总保额"；医疗险与重疾险的保额含义不同，不能相加 |
| 缴费方式 | 年缴／趸缴／分期 | 写"一次交清"却没写金额；趸缴保单没有年度扣款 |
| 年缴保费 | 每年实际扣的钱 | 把趸缴保费当成年度保费填入，会放大现金流判断 |
| 缴费期 | 交多少年（如"20 年"） | 写成"终身"但没区分缴费期与保障期 |
| 缴费日 | 每年几月几号扣款 | 记成"大概是月底" |
| 缴费月份 | 每年几月扣款 | 漏填，导致倒计时只能按日号估算 |
| 起保年度 | 合同生效那一年 | 写成"买的那年"，与生效年可能差月 |
| 保障期限 | 保障多少年（与缴费期不是一回事） | 用缴费期代填 |
| 满期年度 | 起保年度 + 保障期限 | 直接抄保单上没写的数字 |
| 存放位置 | 保单正本放在哪（抽屉／柜顶／邮箱） | 留空，导致下次体检仍找不到 |

## 表 2 · 基础信息核对表

**用途**：表 1 告诉你"有什么"，表 2 回答"信息还对不对"。投保时填的东西，往往和今天不一样了。

**列定义与填写说明**

| 列名 | 填什么 | 常见填错 |
| --- | --- | --- |
| 对应保单 | 表 1 的序号 | 空着，后面无法追溯 |
| 投保人 | 谁签的合同 | 填成被保险人 |
| 被保险人 | 保障实际覆盖的人 | 多人保单只填一个 |
| 受益人 | 合同上写的具体姓名／份额 | 填"法定"就算指定；"法定"通常意味着**没有指定具体受益人** |
| 受益人份额 | 多人受益时的比例 | 只写"均等"却没核对合同 |
| 扣款账户 | 银行卡／账户标识（不必写全号，尾号即可） | 写得太全，注意个人信息安全 |
| 扣款方式 | 自动扣款／手动转账 | 默认"肯定是自动的"，实际早已改成手动 |
| 账户核验年份 | 最近一次确认账户有效的年份 | 空着 |
| 联系方式 | 手机号、邮箱是否还是现在用的 | 沿用旧号码；换号后未更新，导致通知收不到 |
| 职业 | 投保时登记的职业 | 填现在的职业，与承保记录不一致会影响后续服务 |
| 家庭住址 | 通讯地址 | 与现居所不同，且从未更新 |
| 变更记录 | 改过哪些信息、何时改 | 只记结果不记时间 |

## 表 3 · 保障结构对照表

**用途**：把表 1 摊开的事实，转成"谁、扛什么风险、额度多少、够不够"的四列对照。**"够不够"一列只做客观倍数对照，不写"应该买什么"。**

**列定义与填写说明**

| 列名 | 填什么 | 常见填错 |
| --- | --- | --- |
| 家庭成员 | 被保障的人 | 只填家庭主要收入人，漏掉孩子与老人 |
| 扛的风险 | 该成员实际被覆盖的风险类别 | 按产品名填（"XX 险"），应填风险类别（重疾、住院医疗、意外身故…） |
| 额度 | 该风险对应的保额 | 把医疗险额度与重疾险额度加在一起比较 |
| 家庭实际 | 客观事实：该成员的收入、负债、家庭支出等 | 写成主观判断（"我觉得不够"） |
| 倍数对照 | 保额 ÷ 参照基数 | 参照基数写错（分母用错，结论就反了） |
| 常见区间参考 | 市场上的常见做法参考 | 把它当成"标准答案"或"配置要求" |
| 结构差异 | 事实性描述，只说"有没有" | 写成建议（"建议再买一份"） |

**对照口径说明（均为常见做法参考，实际应结合自身情况）**
- 重疾保额 ÷ 家庭年收入，常见参考 3~5 倍
- 寿险保额 ÷（家庭负债 + 5 年家庭支出），常见参考为覆盖该基数
- 医疗险关注百万医疗类额度，常见参考 100 万元起
- 意外保额 ÷ 家庭年收入，常见参考 5~10 倍

`重疾 | 父亲 | 重疾 | 300,000 | 家庭年收入 600,000 | 0.5 倍 | 3~5 倍（180万~300万） | 有重疾保障，额度低于常见区间参考`

## 表 4 · 时间节点排查表

**用途**：把"哪天要做什么"变成一张日历。这是全表中最能直接减少损失的一张。

**列定义与填写说明**

| 列名 | 填什么 | 常见填错 |
| --- | --- | --- |
| 对应保单 | 表 1 序号 | 空着 |
| 缴费日 | 每年几月几号扣款 | 只记日号不记月份 |
| 下次扣款日 | 推算出的下一次具体日期 | 忘了加上"如果今年已过则顺延到明年" |
| 距今天数 | 与今天相差的天数 | 负数当成"还没到" |
| 宽限期 | 扣款日之后的宽限天数 | 直接套用别家的天数；各家合同约定不同 |
| 宽限期截止日 | 缴费日 + 宽限期 | 宽限期天数填错，导致整个节点前移 |
| 满期年度 | 起保年度 + 保障期限 | 与缴费期混淆 |
| 续保衔接 | 一年期产品下一年度是否已续 | 默认"去年买了今年还在" |
| 体检时点建议 | 一年中什么时候集中核对 | 全年零散处理，最后漏掉 |

## 表 5 · 权益与保单状态表

**用途**：找出"交了这么多年钱、但从没用上的权益"，以及"这份保单其实早就不是它当初的样子了"。

**列定义与填写说明**

| 列名 | 填什么 | 常见填错 |
| --- | --- | --- |
| 对应保单 | 表 1 序号 | 空着 |
| 权益类型 | 增值服务、团险、账户价值、免费体检、专家挂号等 | 只写"有服务"，不写具体是什么服务 |
| 权益来源 | 哪张保单附带的／单位团险 | 把公司福利当成商业保单权益 |
| 是否登记 | 是否已完成激活或登记手续 | 以为"买了就有"，实际需要另行登记 |
| 是否用过 | 历史使用记录 | 记不清就写"未用"，先查再说 |
| 失效风险 | 权益是否随保单失效而终止 | 不知道就留"待核" |
| 账户价值 / 现金价值 | 储蓄型、年金、分红类保单当前账面价值 | 拿当初交的总保费当现价 |
| 保单状态 | 有效／停缴／失效／满期／退保 | 把"没按时扣款"直接当成已退保 |
