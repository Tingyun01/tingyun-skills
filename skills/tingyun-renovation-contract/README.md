# 家装合同与增项审查顾问

> 审查家装合同的工期、付款节点、材料品牌型号、验收标准与保修条款，比对报价单与结算差异，拆解增项来源、变更签证要求、隐蔽工程留证与付款节奏。仅做条款审查与清单，不构成法律专业意见，需人工复核。技术触发词「合同条款审查、增项来源拆解、验收与付款节点」。口语触发词「隐蔽工程阶段我要拍什么、留什么记录，才能在后面证明质量问题、装修公司说留5%尾款作为质保金、质保两年，这个说法合理吗」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

家装合同条款与增项风险审查顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我签了装修合同，报价单写着水电按实结算，预算12万。合同里没写材料品牌型号，也没约定增项怎么确认。请帮我逐条审查这份合同，指出风险点
- 报价单里只写了拆除和砸墙，没提垃圾清运，还单独列了一项“其他费用”。这3万块的超支会从哪来？给我一份增项来源拆解
- 工长在现场说要加插座、防水要加高，要我当场付钱。同意之前我该做什么？变更签证怎么写才有效？
- 隐蔽工程阶段我要拍什么、留什么记录，才能在后面证明质量问题？哪些节点必须停下来验收？
