# 债权申报材料清单与模板

> 本页提供申报材料四类清单、高频缺口、申报书要素模板与金额计算表格式，以及提交留痕要求与债权人会议参与准备。
> 本页为材料准备指引，不构成法律专业意见，需人工复核。

---

## 一、材料清单（四类）

### 1.1 主体资格类（缺则可能被退回）

| 材料 | 适用主体 | 备注 |
|---|---|---|
| 营业执照副本复印件 | 企业债权人 | 加盖公章 |
| 法定代表人身份证明书 | 企业债权人 | 需法定代表人签字或盖章 |
| 法定代表人身份证件复印件 | 企业债权人 | 与主体信息一致 |
| 身份证件复印件 | 自然人债权人 | 正反面 |
| 授权委托书 | 委托代理人申报时 | 写明委托权限（申报、变更、表决）与受托人信息 |
| 被委托人身份证件复印件 | 委托代理人 | |
| 主体名称变更证明 | 曾更名、合并、注销的主体 | 更名须提供工商变更材料；合并提供合并文件；注销主体需确认权利承继主体 |

**主体衔接是高频退回点**。公司曾变更名称的，凭变更证明申报；被合并的，向承继主体申报；已注销但债权未清理的，先确认权利承继主体。

### 1.2 债权证明类（决定金额能否被采信）

| 材料 | 作用 | 强度 |
|---|---|---|
| 生效判决书、裁定书、调解书、仲裁裁决书 | 债权与金额的直接证明 | 强 |
| 合同、订单、采购协议、服务协议 | 债权形成的基础 | 强（需与履行证据配套） |
| 对账单、结算单、确认函 | 金额核对 | 中，需对方签章或配合核实 |
| 送货单、收货单、签收单、验收单 | 履行完成的证明 | 中强 |
| 发票、增值税专用发票 | 交易真实性的证明 | 中 |
| 银行转账凭证、银行流水 | 付款与收款事实 | 强 |
| 催收函、律师函、债务人承诺还款的函件 | 债务人知悉与认可 | 中 |
| 即时通讯、邮件等往来记录 | 过程性证明 | 弱，需与其他证据形成闭环 |

### 1.3 担保与优先权类

| 材料 | 作用 |
|---|---|
| 抵押合同 + 抵押登记证明 | 支撑有财产担保债权主张 |
| 质押合同 + 出质登记凭证 | 同上 |
| 担保合同、担保决议 | 支撑担保债权与顺位主张 |
| 留置证据 | 支撑留置权主张 |
| 评估或价值参考材料 | 辅助管理人核对担保物价值 |

### 1.4 程序性与辅助类

| 材料 | 作用 |
|---|---|
| 法院受理裁定（复印件或截图） | 佐证程序节点与申报期限起算点 |
| 管理人申报通知（复印件或截图） | 佐证收到的具体要求 |
| 债权申报书（正本） | 申报主体文件 |
| 证据目录 | 便于管理人逐项核对 |
| 利息与违约金计算表 | 便于核对金额 |
| 送达地址确认材料 | 减少后续文件送达失败 |

## 二、高频缺口清单（每次申报都要主动问）

| 缺口 | 表现 | 补齐路径 | 优先级 |
|---|---|---|---|
| 对账单无双方签章 | 只有内部台账截图 | 补合同 + 发票 + 付款流水形成闭环；或申请管理人向债务人核实 | 高 |
| 合同有、履行证据缺 | 约了货、交了货无签收单 | 找物流记录、签收单、验收记录、对账单佐证 | 高 |
| 利息未算到受理日 | 少算部分不会被自动补 | 按受理日重算并附计算过程 | 高 |
| 已受偿未扣减 | 与债务人主张重复 | 核对流水与对账记录，明确扣减 | 高 |
| 主体名称与文书不一致 | 曾更名或合并 | 补工商变更/合并文件 | 高 |
| 担保物描述不清 | 只写"有抵押" | 写明名称、数量、存放地、登记机关与编号 | 高 |
| 材料缺法定代表人身份证明 | 主体资格不全 | 补齐 | 中 |
| 代理申报缺授权委托书 | 委托关系不成立 | 补授权委托书 | 中 |
| 债权已部分转让 | 受让人与申报人不一致 | 补债权转让协议与通知债务人的证据 | 中 |
| 债权已设定质押 | 债权本身被质押 | 说明质押情况与质权人，便于管理人核对 | 中 |

## 三、申报书要素模板

> 这是**要素模板**，供参照填写，不是可直接提交的格式文本。具体格式以管理人下发的申报书样表为准。

```
【债权申报书（要素模板）】

一、申报人（债权人）信息
  名称：____________（与主体资格材料完全一致）
  统一社会信用代码 / 身份证件号码：____________
  住所 / 通讯地址：____________
  联系人 / 电话 / 电子邮箱：____________
  法定代表人（负责人）：____________
  委托代理人及委托权限（有则填）：____________

二、债权形成事实
  合同名称与编号：____________
  签订日期 / 履行期间：____________
  履行情况：已交付 / 部分交付 / 未交付（据实填写）
  债权形成原因与依据：____________
  对应证据材料名称与份数：____________

三、债权数额
  本金：____________ 元
  利息：____________ 元（计算区间：____年__月__日至____年__月__日受理日，利率或标准：____，计算过程见附表）
  违约金：____________ 元（计算依据与方式：____________）
  其他：____________ 元
  合计申报债权：____________ 元
  已受偿金额（应扣减）：____________ 元
  申报债权净额：____________ 元

四、担保情况（有则填）
  担保类型：抵押 / 质押 / 留置 / 第三方担保
  担保物：名称、数量、规格、存放地 ____________
  登记机关与登记编号 / 登记日期：____________
  担保人（如有）：____________

五、债权性质主张（勾选）
  □ 普通债权
  □ 有财产担保债权（就上述担保物优先受偿）
  □ 破产费用（共益债务）
  □ 取回权
  □ 主张抵销权（说明对方债务与到期情况）
  □ 其他：____________

六、附随说明
  尚未到期的债权（视为到期申报）：____________
  未决诉讼 / 仲裁进展：____________
  或有债权说明：____________

七、承诺与声明
  本人所申报债权及所附材料真实、准确；如有不实，愿承担相应法律责任。
  申报人（签章）：____________   日期：____________
```

### 3.1 填写要点

| 环节 | 要点 |
|---|---|
| 名称 | 与营业执照/身份证件完全一致，一字不差 |
| 金额 | 逐项列明并附计算过程，不只给总数 |
| 利息 | 写明起止日与利率来源，止于受理日 |
| 证据目录 | 编号与材料一一对应，管理人核对时按号索证 |
| 签章 | 单位申报需盖章，自然人需签字 |
| 份数 | 按管理人要求备份 |

**利息计算示例写法**（表述结构，不是具体数字）：

```

```

## 五、提交与留痕要求

### 5.1 提交

| 环节 | 要求 |
|---|---|
| 提交对象 | 管理人（联系方式以受理公告或通知载明为准） |
| 提交方式 | 按管理人通知要求：现场递交 / 邮寄 / 线上平台上传 |
| 份数 | 按通知要求，一般为申报书正本加证据副本，另有管理人留存要求 |
| 截止 | 公告载明的申报期限截止日；建议提前 5 个工作日寄出或递交 |
| 密封与标注 | 债权信息属敏感材料，标注接收人并保留送达方式记录 |

### 5.2 留痕（四样必须留）

1. **受理回执或接收凭证**——管理人签收的凭证，或邮寄的寄件单与签收记录。这是证明"我在期限内交了"的关键证据。
2. **全部提交材料的复印件或扫描件**——按提交目录编号保存。
3. **提交时间证据**——现场递交的签收记录、寄件的快递单号与物流轨迹、上传的平台提交记录与时间戳。
4. **沟通记录**——与管理人的邮件、函件、书面往来，重要沟通后发一封书面确认。

### 5.3 常见丢件点

| 丢件点 | 后果 | 防范 |
|---|---|---|
| 只交了纸质材料没留回执 | 无法证明按时提交 | 当场索取签收凭证 |
| 邮寄没寄到指定地址 | 视为未申报 | 寄前确认地址与收件人，保留物流轨迹 |
| 线上上传不完整 | 材料缺失被退回 | 上传后逐页核对份数 |
| 提交后又发现材料有误 | 补充提交可能被拒 | 递交前用目录逐项核对 |
| 只留了申报书没留证据 | 金额缺少支撑 | 证据与申报书同时提交并各自留底 |

## 六、债权人会议参与与表决准备

### 6.1 参与方式

| 方式 | 说明 | 准备重点 |
|---|---|---|
| 亲自出席 | 到现场参加债权人会议 | 携带身份证、授权文件、债权确认相关凭证 |
| 委托代理人出席 | 授权委托书明确表决权限 | 授权范围要写明是否含表决权，否则代理人无表决资格 |
| 书面/远程表决 | 按法院或管理人安排 | 提前取得会议材料与表决票 |
| 不出席 | 视为放弃当次表决权 | 涉及自身利益的表决务必出席或委托 |

### 6.2 表决前必做的核对

```
第 1 步：核对表决资格与本组份额
  ├─ 我的债权是否已被列入债权表确认
  ├─ 我被分在哪一组（普通债权组 / 有财产担保债权组 / 职工债权组 / 税款债权组）
  └─ 我在本组的债权额占本组总额的比例

第 2 步：核对表决门槛
  └─ 本组通过所需的出席人数比例与债权额比例（以法院要求与会议材料为准）

第 3 步：拿到会议材料
  ├─ 债权表
  ├─ 重整计划草案 / 和解协议草案 / 财产分配方案
  ├─ 财产变价方案与评估报告要点
  └─ 管理人工作报告

第 4 步：做测算
  ├─ 情景对比（折价率 × 到期年限）
  └─ 与自己底线对照，形成明确表决意向

第 5 步：书面留痕
  └─ 表决意见、送达方式与时间
```

### 6.3 会议议题清单

| 常见议题 | 债权人要关注什么 |
|---|---|
| 核查债权表 | 自己的债权金额、分类、担保记载是否准确 |
| 指定或更换管理人 | 管理人是否独立、专业、推进效率如何 |
| 决定继续或终止破产程序 | 是否转入重整或和解，转换对我有利还是有弊 |
| 财产变价方案 | 变价方式、节奏、是否低价处置 |
| 继续营业与否 | 停业可能让部分设备价值归零 |
| 重整计划草案 / 和解协议草案 | 本组通过门槛、清偿形态与期限 |
| 财产分配方案 | 各顺位比例、本组金额 |
| 破产财产分配后的其他事项 | 追责、免责、注销等 |

### 6.4 会后动作

1. 索取会议记录或决议复印件（可依申请获取）
2. 记下表决结果与自己的表决意见
3. 若表决结果与预期不符，评估是否依法定途径提出异议或救济，并请执业律师判断时机
4. 把会议中获得的财产报告、评估报告、变价进展整理进自己的债权档案
