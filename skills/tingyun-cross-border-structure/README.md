# 跨境架构与出海合规顾问

> 输入目标市场、业务形态与团队，输出出海模式对比（自建/收购/合作/授权）、法域用途对照、常设机构风险提示、合同条款要点、落地自检清单。仅做架构梳理与风险识别，不构成法律或税务专业意见，需人工复核。技术触发词「跨境架构、出海路径、合规筛查」。口语触发词「我们公司打算把产品卖到东南亚，该在本地注册公司还是找代理合作、香港和新加坡在跨境架构里分别适合放在什么位置、我们员工长期驻外当地跑客户，会不会在当地形成常设机构」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

跨境经营架构与出海合规路径顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我们公司打算把产品卖到东南亚，该在本地注册公司还是找代理合作？帮我对比几种模式的成本和风险。
- 香港和新加坡在跨境架构里分别适合放在什么位置？纯控股架构什么时候行不通？
- 我们员工长期驻外当地跑客户，会不会在当地形成常设机构？
- 境内母公司和海外子公司之间的关联交易，税务上要准备哪些资料？
