# 末位区分与证据链留存

> 核心区分工具与归档清单。解除环节的判断与文书须经专业机构复核。

## 一、末位与不能胜任：完整对照

### 1.1 概念对照

| 对比项 | 末位（绩效排序） | 不能胜任（法律要件） |
|---|---|---|
| 含义 | 员工在特定群体内部的相对位置 | 未能按要求完成劳动合同约定的任务，或同工种同岗位人员的工作量 |
| 参照系 | 群体内部排名 | 岗位要求与同岗位平均水平 |
| 必然性 | 群体里必然有人排末位，哪怕全员优秀 | 不是排序概念，不需要有人比他更差 |
| 反向情形 | 全员不达标，仍有人排名靠前 | 排名靠前的人也可能确实不胜任（当标准本身过高时） |
| 举证材料 | 排名表 | 考核依据 + 考核程序 + 客观事实 + 培训或调岗记录 + 改进后仍不达标 |
| 可否单独支撑处理 | 不可 | 不可单独使用，还需"经培训或者调整工作岗位后仍不能胜任" |
| 举证责任 | 用人单位对解除决定负举证责任 | 同上 |

### 1.2 为什么这个区分有实际后果

裁决口径已明确：绩效考核属于企业经营管理权的范畴，但劳动者业绩考核结果属于认定劳动者是否胜任工作的范畴；法律中并无用人单位可以"末位淘汰"为由解除劳动合同的规定。若公司以"末位淘汰"为由解除，既不能证明劳动者不能胜任工作，也不能证明已经培训或调岗后仍不能胜任，构成违法解除。

同时，末位本身也不是无效管理——它是内部绩效排序工具，用于识别需要辅导、改进、调配的对象。**问题不在于做了排名，而在于把排名直接当成了解除理由。**

### 1.3 实务中两种典型败因

**败因 A：只有排名，没有链条**
手里只有一张"本季度考核末位名单"。没有考核标准出处、没有评分依据、没有过程记录、没有培训或调岗。举证不能。

**败因 B：链条有，但"培训"这一环不合格**
公司提交了绩效改进计划跟进表与近三十场培训记录，劳动者主张从未签署过将考核结果与不胜任挂钩的确认文件、也未认可跟进表，且所称培训多为日常部门会议与日常培训、不具有针对性。裁决倾向认定：考核标准未经双方认可、培训不具针对性，故认定不胜任的依据不足。

**败因 C（补足型）：标准过高**
考核标准设定在员工从未达到过的水平，或明显超出同岗位平均水平。审查能否胜任时会审查任务量与定额标准的合理性，不得故意提高定额使劳动者无法完成。

### 1.4 衔接四步法：把末位接上胜任

| 步 | 要做的动作 | 关键要求 |
|---|---|---|
| 1 建标准 | 明确岗位职责与考核标准，事前告知并取得确认 | 标准须事前存在、客观、可核验、与同岗位水平相称 |
| 2 做考核 | 按标准评分，留评分人、依据、时间 | 评分依据与客观事实需能提交 |
| 3 尽义务 | 提供培训或调岗，并留下有针对性的实施证据 | 专项培训而非日常例会；调岗须协商一致并书面变更 |
| 4 看结果 | 改进后评估，评估结论与依据留档 | 评估标准与改进计划中约定的一致 |

四步缺一，链条就有断点。四步齐备，即使后续走单方解除，程序与实体的支撑也远强于只有一张排名表。

### 1.5 员工提出的常见主张与回应原则

| 员工主张 | 回应原则 |
|---|---|
| "我排名末位不代表我干不了" | 承认排序不等于胜任的差异，说明公司在按步骤核事实，同时给出具体差距与标准出处 |
| "标准是事后改的" | 实际核查并出示制度版本与公示凭证；若确有调整，坦率说明并重新评估该周期 |
| "我签了但没看懂" | 记录异议内容并核查签收与讲解记录，不以签字代替举证 |
| "培训就是开开会" | 提供培训通知、专项材料、考核结果，说明针对性 |
| "为什么轮到我" | 不作横向对比；只谈本人事实与目标 |
| "我要复核" | 提供复核渠道与时限，记录诉求与处理结果 |

## 二、季度证据留存清单

按"每季度固定动作"执行，季度结束前归档，不要等出问题时补。

### 2.1 制度层（每季度检查一次是否仍然有效）

- [ ] 现行绩效与考核制度文本（含版本号、修订日期）
- [ ] 职工代表大会或全体职工讨论的记录（涉及劳动报酬、工作时间、劳动定额管理等直接涉及劳动者切身利益的规章制度）
- [ ] 与工会或职工代表平等协商确定的记录
- [ ] 公示或告知的凭证（签收表、培训签到、邮件下发、系统确认记录）
- [ ] 员工手册签收 / 电子阅读确认记录
- [ ] 规章制度与劳动合同、集体合同是否一致的核对结果

### 2.2 目标层（每周期）

- [ ] 季度/周期目标书（员工签字或电子确认，含日期）
- [ ] 岗位说明书（有版本与生效日期）
- [ ] 指标口径说明（计算范围、排除项、数据来源）
- [ ] 上期目标达成情况汇总（连续留档，看趋势而非单点）

### 2.3 考核层（每周期）

- [ ] 考核评分表（评分人、评分项、评分依据、评分时间）
- [ ] 考核原始数据来源说明（系统导出记录）
- [ ] 考核结果告知书 + 送达凭证
- [ ] 排名表（若做排名，作为内部管理工具单独存放，注明不作为解除依据）
- [ ] 校准会/评审会记录（若有多人评分，防止主观偏差）

### 2.4 沟通层（每次）

- [ ] 绩效沟通记录（时间、参与人、事实与差距、员工陈述、下一步）
- [ ] 面谈记录模板（统一格式，含员工意见栏与签署）
- [ ] 员工异议记录与处理痕迹（谁处理、何时、如何反馈）
- [ ] 目标调整的书面确认（调整前后对照）
- [ ] 薪酬调整的书面确认（若涉及，单独文件，不与面谈记录混在一起）

### 2.5 支持层（改进期必备）

- [ ] 培训通知（主题、对象、时长、讲师）
- [ ] 培训材料 / 课件要点
- [ ] 签到表
- [ ] 培训考核结果
- [ ] 带教安排与带教记录
- [ ] 资源与权限调整说明
- [ ] 期内反馈记录（按约定频次，逐次留痕）
- [ ] 期末评估结论与依据

### 2.6 变动层（变动发生时立即留）

- [ ] 岗位调整协商记录 + 书面变更协议
- [ ] 新岗位说明书与目标书
- [ ] 请假、医疗期、工伤、产育假等记录（同时是保护情形排查的输入）
- [ ] 奖惩记录
- [ ] 员工申诉与内部处理记录

### 2.7 归档规范

- 目录结构：年度 / 部门 / 员工 / 周期，一致命名；
- 索引表：每个证据包有编号与清单，便于按人按周期调取；
- 电子件保留原始格式与导出记录（导出时间、导出人）；
- 纸质件扫描归档，原件按需保存；
- 记录不追认、不倒签、不补造；确需补录的，注明补录原因与补录日期。

## 三、群体性处理风险信号

### 3.1 预警信号清单

出现任意一条就要减速并做整体方案评估：

- 同一时间、同一批人、同一理由、同一份模板文书；
- 理由是"末位""优化""名额限制""组织调整"，而没有针对个人的具体标准与事实；
- 考核在同一时间窗口集中打分，评分标准在此期间调整过；
- 目标书与考核标准在考核期结束后补签或补发；
- 人数比例明显异常，且集中在同一部门或同一职级；
- 名单中含孕期产期哺乳期、医疗期、工伤、职业病、临近退休人员；
- 员工之间开始互相打探，公司在多个渠道泄露处理信息；
- 已有人提起内部申诉或向外部渠道反映；
- 提成口径与历史做法不一致（例如把原本按季度发放的提成算作"未达预期"）。

### 3.2 顺序建议

1. **保护情形全量排查放在名单阶段**——不是在谈话阶段。名单里有保护情形人员的，整批方案要重做。
2. **制度与程序先落地**：标准事前明确、民主程序已走完并公示、证据已归档。程序没走完就开谈，是把风险前置到较不可控的环节。
3. **逐个进行、不交叉**。同一批次内不要互相告知；不要建统一通知群。
4. **先谈证据扎实、有改进空间的人**，用前几次谈话校准表述口径与记录格式。
5. **一次处理一个，留缓冲期**。批量同时推进容易被认定为成规模的处置，程序瑕疵会互相叠加。
6. **不承诺结果、不施压签署**。不在情绪化状态下谈话；谈不成就回到路径，不在现场升级。
7. **人数较多、跨部门或可能引发集体争议的，先请专业机构评估整体方案**——包括是否需要先做一轮全员沟通或说明。

### 3.3 沟通表达要点

- 说明依据的是具体标准与本人事实，不是排名；
- 说明后续有改进期与支持安排；
- 说明公司会依法处理，不作结果承诺；
- 记录本人的陈述与异议；
- 结束时给出下一步时间点与联系方式。

### 3.4 不宜做的事

- 统一话术、统一时间点、统一地点同时进行；
- 用"就剩你了""大家都这样"施压；
- 以取消晋升、调岗降薪、扣发项目奖金作为谈判筹码；
- 让员工之间互相打探或自行推排名；
- 在群里或公开渠道讨论具体人员；
- 把考核结果与"是否近期离职"挂钩讨论。

## 四、自查表：我的证据包够不够

每次准备走后续处理前，逐项打勾：

- [ ] 保护情形排查表已完成，无命中情形
- [ ] 岗位说明书与考核标准有版本、有生效日期
- [ ] 制度经过民主程序并公示/告知，留痕完整
- [ ] 目标书事前给出并取得员工确认
- [ ] 考核评分表含评分人、依据、时间
- [ ] 考核结果已告知并有送达凭证
- [ ] 每次绩效沟通有记录，员工异议已留处理痕迹
- [ ] 改进计划八要素齐全，送达留痕
- [ ] 有针对性的培训或调岗记录齐备（材料 + 签到 + 考核 / 协商 + 书面变更）
- [ ] 期内反馈按频次留痕
- [ ] 期末评估结论与依据归档
- [ ] 全部材料时间线连续，无补签倒签

任一项打不上勾，**先补齐再谈下一步**。缺口留着往前走，风险会在收尾一步集中出现。
