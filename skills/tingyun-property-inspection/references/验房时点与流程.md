# 验房时点与执行流程

## 一、三种时点的能力对比

### 时点 A：交付前介入（开放日 / 工地开放 / 样板房）

**典型可查项**
- 防水：涂刷遍数、阴阳角圆弧处理、管根附加层、防水上翻高度（淋浴区通常要求上翻至 1.8m 以上）、材料品牌型号
- 电路：线径（照明常用 2.5mm²、插座常用 4mm²）、穿管敷设、回路数量、线管是否被随意改动
- 给排水：管材材质与壁厚、排水管是否带存水弯（防返味）、管道走向
- 暖通：地暖分水器安装、管路排布、压力测试记录
- 公区：外立面材料、单元门、电梯品牌型号、园林与道路做法
- 结构：地下室与顶板做法、剪力墙位置（这决定你后面能不能拆墙）

**典型查不到**
- 渗漏类问题：需要用水或时间才显现
- 你这一套房的交付实测：样板间与实际交付可能存在差异
- 装饰面完成后的观感与功能：那时才做门窗、地板、橱柜安装

**成本与可行性**：多数项目会开放几次工地，报名成本低但要提前关注预约通道。这属于"看做法"，是三个时点里信息密度高、成本低的一个。

### 时点 B：交付当日 / 集中交付期

**典型可查项**
- 实测面积：对照合同约定的建筑面积与套内面积
- 交付标准：合同附件里写明的装修品牌、型号、材质，有条件就核对
- 房屋现状与附赠设备：车位、储藏室、家电清单
- 当场发现的明显问题：空鼓、划伤、门窗损坏、墙面污染

**典型查不到**
- 隐蔽工程：已经被装饰面覆盖
- 渗漏类问题：交房当天通常不会有人做闭水试验
- 功能性深检：电路容量、地暖压力这类需要仪器和时间的项目

**这一时点的真正价值**：不是查得多，而是**签字前把问题写进交付确认文件**。一旦签了"无异议"，后面所有沟通的起点都会变难。

**给用户的判断条件**：
- 如果用户此前已做过开放日或已委托过第三方验房 → 交付当日重点放在"对照交付标准 + 写进交付文件"，不重复做全面检查
- 如果用户是首次购房、没有做过任何前置查看 → 交付当日至少做一次 30 分钟的走马观查，把明显问题写进去

### 时点 C：交付后、装修前（推荐）

**典型可查项**
- 闭水试验：卫生间、厨房、阳台（沉箱式卫生间要一并确认沉箱是否回填、有无二次排水）
- 墙面与地面：空鼓（敲击）、平整度（靠尺）、垂直度（靠尺）、裂缝
- 门窗：开启手感、密封条、玻璃划痕与自爆风险、五金件、窗台渗水
- 给排水：通水试验、地漏排水速度与返味、热水出水时间
- 电路：插座通断与接线位置（带指示灯的插座测试笔）、回路数量、漏电保护测试按钮
- 暖通与燃气：地暖压力与温度分布、燃气表与管路走向、通风与排烟
- 公区与设备：电梯运行、消防设施、管井、屋面排水、地下车库

**典型查不到**
- 施工过程本身（刷了几遍防水、用了什么材料）——已被覆盖
- 已入住产生的损耗
- 已过责任期、责任人难以落实的问题

**这一时点的真正价值**：这是少数几个**可以在隐蔽工程被覆盖之前**做功能性验证（闭水、排水、电路）的时点。

## 二、选时点决策树

```
第 1 步：这套房交付时是毛坯还是精装？
├─ 毛坯 → 优先时点 A（开放日看做法），因为隐蔽工程届时可见
│         毛坯房的时点 C 主要查观感与尺寸，施工问题的追溯靠时点 A
└─ 精装 → 时点 A 只能看部分做法（外立面、公区、部分开放区域）
          → 主力放时点 C，重点是闭水 + 交付标准逐项对照

第二步：装修什么时候开工？
├─ 两周内开工 → 时点 C 必须前置完成，否则开槽一覆盖就查不到了
├─ 一个月以上开工 → 时点 C 照常做，另外提醒空档期风险（见空档期清单）
└─ 半年后开工 → 建议时点 A + 时点 C 都做，并考虑让第三方做一次

第三步：用户是否打算请第三方验房？
├─ 是 → 你的角色转为"需求方 + 现场对接 + 报告复核"，清单用于比对第三方报告有没有漏项
└─ 否 → 输出可打印清单，按自检方式组织；提示哪些项自检有局限（见下）
```

### 自检有局限、需要第三方或专业检测的项目

| 项目 | 自检能做到什么 | 局限 |
|---|---|---|
| 主体结构安全（裂缝性质） | 记录宽度、走向、位置、是否错台 | 无法定性，需要有资质的检测机构 |
| 防水层做法（遍数、厚度、上翻） | 只能目视估计与询问 | 需开凿或查阅施工记录 |
| 电路负载是否够用 | 测通断、看回路数与线径标识 | 是否满足设计总负荷需看设计图 |
| 室内空气污染（甲醛、苯） | 便携式仪器只能作趋势参考 | 需有 CMA 资质的检测机构出具报告 |
| 渗漏成因定位 | 闭水试验能确认"漏不漏" | 漏点精确定位需专业排查 |
| 地暖压力是否合格 | 现场打压 10 分钟可初判 | 需施工方提供打压记录与合格标准 |

**明确说清**：便携检测仪器与目视检查都不能替代有资质机构的正式报告，出报告是要花钱的。用户请第三方验房是花钱买确定性，你要把这句话说明白，而不是推销。

## 三、验房当天的执行流程

### 进场前（提前一天）
- 确认交付时间与流程安排，确认是否需要预约
- 备齐工具（见 `整改沟通与留证清单.md` 的工具清单）
- 打印清单 + 编号贴纸 + 相机或手机（确认存储空间充足、电池充满）
- 提前联系：物业（有的项目要物业陪同）、楼下邻居（闭水试验要观察楼下顶面）、相邻户（公区问题）

### 第 1 段：公共区域（约 30 分钟，在楼栋内完成）
- 单元门、门禁、电梯（运行是否平顺、有无异响、应急照明、轿厢照明与按钮）
- 楼梯间与疏散通道（是否畅通、消防设施是否齐全、有无被占用）
- 外立面（远观：有无明显裂缝、脱落、渗水痕迹；注意"看不全"是正常现象）
- 地下车库（排水、坡道、照明、车位线、指示牌）
- 屋面与雨棚（排水是否通畅、有无积水、女儿墙）

### 第 2 段：户内主体（约 60-90 分钟，按空间走）
建议顺序（这个顺序有讲究）：
1. **先看整体**：站在门口环视一周，看房型是否与图纸一致、采光朝向、空间比例
2. **再进门厅**：入户门（开启、密封、锁具）、门禁、地面门槛石、玄关柜与鞋柜
3. **客厅与餐厅**：墙面（空鼓、裂缝、色差）、地面（空鼓、拼缝、高差）、门窗（型材、玻璃、五金、密封）
4. **卧室**：同上，重点看窗（南向与北向差异）、飘窗与窗台石
5. **厨房：橱柜与台面（是否按交付标准安装）、墙地砖、**给排水点位、下水、烟道、燃气表位置
6. **卫生间（重点）**：闭水前的目视检查、沉箱、墙地砖、洁具、地漏、管道检修口
7. **阳台与设备平台**：晾衣架、排水、地漏、空调位、热水器位
8. **其他**：储藏室、电动车充电点、燃气表、水表、电表箱位置

### 第 3 段：功能测试（约 30-45 分钟）
- 闭水试验（先做，因为需要等待时间）
- 通水与排水（每个下水口、每个地漏）
- 电路测试（每个插座、每个开关、漏电保护按钮、回路标识）
- 门窗开启与密封（开关次数、密封条贴合、窗台排水孔是否通）
- 暖通（地暖打压与温度分布、地暖分水器、暖气片）
- 燃气（表、软管/管路、通风、报警器、热水器排烟管）
- 照明与智能家居（开关控制对应关系、面板是否与图一致）

### 第 4 段：收尾（约 20 分钟）
- 复看所有拍照位置，确认照片清晰、有比例尺、有位置参照
- 闭水试验结论记录（在楼下观察的结果）
- 填写交付确认文件：把问题逐条写进去，注明"限期整改后书面答复"
- 收好所有材料与证件，确认钥匙、门禁卡、附赠物品清单

## 四、记录方法：让照片和清单能作为后续沟通的依据

### 编号规则
格式：`位置-部位-序号`，例如 `02-卫生间-03`。
- 位置用两位数字，代表房间序号，全套保持一致
- 每个问题一个编号，从发现到整改复验都用同一编号

### 照片四件套
每处问题拍 4 张：
1. **全景定位照**：能看出这在房间的哪个位置、哪个方向
2. **中景照**：整块墙面或整件设备
3. **近景细节照**：能看清裂缝宽度、渗水痕迹、空鼓位置
4. **带比例参照照**：裂缝用卷尺或直尺做参照（拍到刻度），空鼓用硬币或记号笔圈出范围，渗水用纸巾按压留水印痕

### 文字记录四要素
- **位置**：主卧东墙距窗 1.2m 处、下沉式卫生间东北角地漏处
- **现象**：裂缝宽约 0.4mm、呈 45 度斜向、无错台
- **范围**：单条，长约 40cm
- **时间**：某月某日某时（配合照片时间戳）

### 交付文件里的写法
```
问题 1  位置：客厅南面窗下方墙面
        现象：窗下墙面有约 30cm 长水渍，纸压留痕明显
        级别：二级（需返工，需排查外窗密封）
        诉求：限期排查并修复，修复后书面告知结果
问题 2  位置：主卧东北角
        现象：墙面裂缝，宽约 0.4mm，斜向 45 度
        级别：一级（建议做专项检测后再定性）
        诉求：请提供本单元主体结构检测说明；如需整改请出具方案与期限
```

### 三个记录纪律
1. **不修不拆**：发现问题先记录，不要自行修补或拆除。被拆掉的原状是无法恢复的证据
2. **不删不改原始文件**：照片原图保留，标注用副本；不裁剪掉比例参照物
3. **当天整理**：当天回看一遍全部照片，补齐缺项。隔天再翻，很多照片已经想不起对应哪个问题

## 五、空档期：验房之后、装修开工之前

验房完成到装修开工之间通常有一段空置期（从数周到数月不等）。这段时间的问题容易被漏掉，因为没有人在现场。

### 空档期风险清单

| 风险 | 表现形式 | 应对动作 |
|---|---|---|
| 渗漏延迟显现 | 交付时无雨，防水问题未显现；空档期一场大雨后，楼下顶面出现水渍 | 空档期内遇大雨后，主动到楼下顶面看一眼；拍一次楼下顶面全景存档作为基线 |
| 空置返潮与霉变 | 空置较久，尤其南方梅雨季或北方供暖季前后，墙角返潮、霉点 | 空置期间定期通风；有条件的做一次除湿；入住前做一次全屋巡查 |
| 冬季空置冻裂 | 北方地区水阀、暖气片、地暖管、水龙头冻裂 | 水龙头、水阀留一点缝隙不关严；地暖保持低压或排空（按物业要求）；关窗保温 |
| 装修期间二次损伤 | 拆改、钻孔、搬运砸伤已完成但未整改的问题部位 | 装修开工前把问题部位拍照存档，作为责任划分基线 |
| 空置期责任真空 | 期间出现问题，不知该找谁 | 明确"交付之日"作为责任交接节点，交付确认文件的签署日期即节点；期间问题先书面通知物业与开发商，不擅自处理 |
| 保修期错位 | 用户以为保修期从交房起算，实际从竣工验收合格起算 | 查竣工验收时间，核算保修期实际剩余 |
| 整改拖延 | 交付后无人催促，问题长期挂着 | 按"交付后 3 至 7 日内"节点发出书面整改通知 |

### 空档期的三个动作
1. **存档一次楼下顶面**：交付时或空档期开始时，拍一套楼下卫生间/厨房顶面的全景照片，作为"当时无渗漏"的基线。这套照片在后续争议里很有用
2. **保留所有钥匙与门禁权限**：期间允许物业、开发商、施工方进场查看或整改，进场前后都留影像
3. **开工前必须复验一次**：装修动土前，回头看一遍验房清单，确认每一项的状态（已整改 / 未整改 / 待定）。**这是成本较低的一次发现问题机会**——开槽之后，隐蔽工程就再也看不见了

## 六、给用户的三个提醒

1. **不要在交付确认文件上签"无异议"，除非你真的查过**。签了之后，沟通的性质会从"交付即应合格"变成"你确认过还提出异议"，难度上升
2. **验房在装修开工之前完成**。开槽之后发现的隐蔽问题，返工代价是验房阶段发现的几倍
3. **保修期从竣工验收合格之日起算**，不是从交房那天算。这个日期要查，要算，关系到后面每一条保修主张能不能成立
