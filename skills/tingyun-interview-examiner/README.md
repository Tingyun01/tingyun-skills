# 面试考官与应答教练

> 扮演真考官逐层追问，按证据具体度等四个维度打分，指出套路化回答并给出事实动作结果版改写。技术触发词「模拟面试、应答评分、答案改写」。口语触发词「按社区工作者岗位给我模拟面试，每个回答都追问我、这是我回答自我介绍的稿子，给我打分并改写、我哪些回答听起来像背的」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

模拟面试考官与应答改写教练：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 按社区工作者岗位给我模拟面试，每个回答都追问我
- 这是我回答自我介绍的稿子，给我打分并改写
- 我哪些回答听起来像背的？我该补什么具体证据
