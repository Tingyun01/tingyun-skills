# 大客户决策链地图与关键人突破

> 本页为 B2B 销售陪跑的结构化底稿。不构成经营或法律结论，需结合实际情况人工判断。

## 一、决策链六角色模型

| 角色 | 典型职位 | 核心诉求 | 突破要点 |
|---|---|---|---|
| 发起者 | 使用部门主管/工程师 | 解决眼前痛点 | 先听后说，用样板/试用证明 |
| 影响者 | 技术、财务、法务 | 合规、成本、可控 | 用数据、案例、测算说服 |
| 决策者 | 老板、总经理、分管副总 | 投入产出、战略 | 谈价值不谈参数，给向上汇报材料 |
| 把关者 | 采购、招标办 | 流程、价格、合规 | 走标准流程，不绕开，建立信任 |
| 审批者 | 集团/上级/董事会 | 预算、政治正确 | 准备简明决策包 |
| 守门人 | 前台、助理、秘书 | 过滤无关人 | 尊重、求其引荐，留好印象 |

## 二、关键人识别三标准

满足以下三条中的两条，即列为高优先突破对象：
1. **有签字权或否决权**——能推进或叫停
2. **你的方案能帮他完成 KPI**——他有动力帮你
3. **愿意在内部帮你推进**——态度开放、主动回信息

空白角色（你完全不知道是谁）是关键风险点，优先补全。

## 三、突破路径（按已接触程度）

```
阶段 A 陌拜/建联
  - 从守门人切入，态度尊重，明确"想找对的人聊对的事"
  - 通过行业活动、老客户转介绍提高可信度
  - 目标：见到发起者或影响者，拿到一次需求沟通

阶段 B 需求确认
  - 用提问代替推销：痛点、现状、目标、预算窗口
  - 输出一份"需求共识"，让对方确认你听懂了

阶段 C 触达决策者
  - 经由发起者/影响者引荐，不硬闯
  - 给决策者的材料：一页纸价值摘要 + 风险兜底
  - 谈"为什么现在做、做了得到什么"

阶段 D 内部推进
  - 帮关键人准备向上汇报的理由（他的 KPI 怎么被满足）
  - 保持多线联系，避免只押一个人（防止调岗/离职断线）
```

## 四、长周期跟进节奏

- 决策窗口明确（如年底预算）：按节点倒排，关键节点前 2 周密集触达
- 窗口不明：采用"价值节拍"——每 4~6 周给一条有价值的信息（行业动态、案例、测算），不空问"考虑得怎样"
- 信号判断（该加力）：主动问细节、拉你进群、安排你见 higher-up、要正式报价
- 信号判断（该减力/放弃）：长期只读不回、反复换对接人、预算被砍且无重启信号、已选竞品且进入合同阶段

## 五、红线

不教行贿、回扣、围标串标、虚假资质；不指导刺探或冒充客户内部人员。
