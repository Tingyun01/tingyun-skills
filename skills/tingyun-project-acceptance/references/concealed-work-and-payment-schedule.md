# 隐蔽工程与过程资料留存 · 进度款与质保金时间节点

> 用于工程项目的资料留存与款项节点设计。本文是文档与流程辅助，不构成法律专业意见，需人工复核。

## 一、隐蔽工程为什么难取证

隐蔽工程 = 被覆盖、封闭、拆除后无法直接查验的部分。典型包括：给排水与电气管线走向与埋深、防水层与保温层厚度、地基处理、预埋件与套管、线管敷设、暗装设备基础、门窗与幕墙隐蔽构造。

一旦覆盖，三件事同时发生：**看不见、说不清、证不了**。事后只能靠影像、签认记录、检测报告、监理日志等间接证据来还原，而这类证据的证明力高度依赖"形成时间是否早于覆盖时间"。

**三条铁律**：
1. **覆盖前通知**——书面通知到人、到时间、到部位；
2. **覆盖前检查并签认**——对方到场确认，未到场也要有书面记录说明；
3. **覆盖前影像**——带可辨识参照物（轴线标识牌、尺子、房间号牌、同一位置的连续照片）。

## 二、隐蔽工程留存四件套 + 归档顺序

### 四件套
| 件 | 内容 | 缺失后果 |
|---|---|---|
| ① 书面通知 | 隐蔽验收申请（部位、时间、待覆盖内容） | 对方可主张未通知擅自覆盖 |
| ② 签认记录 | 验收记录/签证单，双方签字，带日期 | 无签认 = 单方陈述，证明力弱 |
| ③ 影像资料 | 覆盖前全景 + 中景（含参照物）+ 特写（关键部位细部） | 无法还原位置与规格 |
| ④ 过程记录 | 施工日志、监理日志、材料进场检验与复检报告 | 缺少连续性，无法说明用料是否合格 |

### 归档顺序（贴现场，按时间推进，不许跳步）
```
1 材料进场检验/复检报告  →  2 隐蔽验收通知  →  3 隐蔽验收签认单
   →  4 覆盖前影像（连续拍摄，编号与部位对应）  →  5 施工/监理日志当日记录
   →  6 覆盖施工记录  →  7 检测/试验报告  →  8 竣工图与影像归档
```

**三处顺序错误**：
- 先覆盖后拍照 → 拍不到，等于没拍；
- 先施工后补签认单 → 对方通常拒签，且签认日期与施工日期对不上，一眼可疑；
- 影像只有特写没有参照物 → 无法确定是哪一处、什么尺寸。

### 影像留存要求（可直接做进作业习惯）
- 每个部位一组，不少于 3 张（全景含参照物 / 中景含尺寸参照 / 特写关键点）；
- 参照物优先用带编号的标识牌、卷尺、靠尺，**不要用手指或拳头比划**；
- 文件命名：`项目-楼栋-层-部位-内容-日期`（例：`A-3F-东侧给水支管-管线走向-20260315`）；
- 当日归档，不放在个人手机相册里；按施工顺序编号入目录。

## 三、过程资料留存清单（按阶段）

### 进场与准备
- 施工组织设计与专项方案（及审批记录）；
- 图纸会审与技术交底记录；
- 开工报告与施工许可类文件；
- 进场材料清单与合格证、复检报告；
- 设备进场记录与检验报告。

### 施工过程
- 施工日志（按日，连续不中断）；
- 监理日志 / 旁站记录；
- 检验批 / 隐蔽工程验收记录；
- 试验与检测报告（送检台账 + 报告原件）；
- 设计变更与现场签证（编号与合同对应）；
- 影像资料（按上节规则）；
- 质量问题通知单与整改闭环记录。

### 验收与移交
- 分项/分部/阶段验收记录；
- 竣工验收资料与遗留问题整改闭环；
- 竣工图、竣工资料移交清单（双方签收）；
- 保修书或保修责任约定文件；
- 钥匙/门禁/设备资料移交记录。

### 归档方法（三条，别搞复杂）
1. **按合同编号建一级目录**，按阶段建二级，按单据类型建三级；
2. **原件不外借**：需要提供复印件的，标注"复印件，与原件一致"并签章；
3. **索引表先行**：先做一张资料索引（编号、名称、日期、签署人、归档位置），比堆文件更有用。

## 四、进度款与质保金的时间节点

### 4.1 款项类型（先分清这四类）
| 类型 | 常见触发 | 常见扣减 |
|---|---|---|
| 预付款 | 合同签订、履约担保到位后 | 常有预付款担保 |
| 进度款 | 按形象进度/计量/已完工程量 | 常扣质保金、扣款、代扣代缴 |
| 竣工结算款 | 竣工验收合格后 | 扣质保金、扣未整改缺陷 |
| 质保金 / 质量留存金 | 缺陷责任期届满且无未处理质量问题后返还 | 常以保函替代现金占用 |

> 具体比例、返还条件、返还时点**以合同约定为准**，并受当地管理要求影响，需人工复核后再用。

### 4.2 每个节点记四要素
```
触发条件（什么事件发生）+ 天数（发生后几天内）+ 前置资料（要先交什么）+ 扣减项（扣什么、扣多少）
```
例：竣工验收合格 + 30 日内 + 需提交竣工验收单与结算书 + 扣质保金 3% → 尾款可主张时间 = 验收合格日 + 30 日（前置资料齐备日）。

### 4.3 节点表模板（按项目填写）
| 节点 | 类型 | 触发条件 | 触发日期（实际/预计） | 约定天数 | 金额/比例 | 扣减项 | 前置资料 | 可主张日期 | 状态 |
|---|---|---|---|---|---|---|---|---|---|
| 1 | 预付款 | 合同生效+担保 | | | | | | | 未开始/进行中/待付/已付/逾期 |
| 2 | 进度款1 | 基础验收合格 | | | | | | | |
| 3 | 进度款2 | 主体结构验收合格 | | | | | | | |
| 4 | 结算款 | 竣工验收合格 | | | | | | | |
| 5 | 质保金 | 缺陷责任期届满 | | | | | | | |

**可主张日期 = 触发条件实际发生日 + 约定天数（且前置资料齐备）**，这个公式是整个回款跟踪的核心。

### 4.4 质保金（质量留存金）的常见争议点
| 争议点 | 说明 | 建议做法 |
|---|---|---|
| 返还时点不清 | 合同只写"质保期满退还"，没写具体日期 | 在合同/补充协议里写明具体返还日或计算方式 |
| 返还条件不清 | 是"无质量问题"还是"无重大质量问题" | 明确表述并配套缺陷处理流程 |
| 现金占用 vs 保函 | 现金被长期占用影响现金流 | 评估保函/替代方式是否可行（需专业人士评估） |
| 缺陷期内的扣款 | 从质保金中直接扣 | 扣款要有依据、有通知、有确认记录，避免口头扣 |

**缺陷责任期内**：定期回访 + 发现问题及时书面通知 + 维修完成留记录 + 对方确认。三件事做完，返还时才有底气。

### 4.5 时间节点的风险信号（出现即标红）
1. 触发条件写了但没有对应签署文件（验收单没签，尾款日期就算不出来）；
2. 约定天数从"验收合格"起算，但验收合格日是估算的；
3. 前置资料清单没写，或写了但永远凑不齐；
4. 质保金没有明确返还日；
5. 节点表里"可主张日期"一栏全是空的——说明没人算过。

## 五、款项节点自检（每月）
1. 本月有哪几个节点达到"可主张日期"？
2. 其中哪些已经超期？超期几天？金额多少？
3. 触发条件对应的签署文件是否都已拿到手？
4. 有没有节点因为前置资料没齐而无法起算？
5. 质保金返还日在哪个月的台账上？责任人是谁？
6. 本月新签的签证单是否已回写到节点表（金额与工期影响）？
