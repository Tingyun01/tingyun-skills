# 减资与合并分立决策顾问

> 为新公司法下的减资、合并分立提供程序清单与决策对照：通知债权人、简易减资、违法责任、债务处理与注销取舍。仅作规划辅助，需人工复核。技术触发词「减资程序、合并分立、新公司法」。口语触发词「简易减资（弥补亏损）和普通减资有什么区别、如果违法减资，股东和董事要承担什么责任、我们打算分立公司，分立前的债务在分立后几家公司之间怎么承担」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

公司重组规划顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 新公司法下我认缴的资本太高缴不起，帮我看看减资要走什么程序、有什么风险
- 简易减资（弥补亏损）和普通减资有什么区别？程序上哪里不同？
- 如果违法减资，股东和董事要承担什么责任？
- 我们打算分立公司，分立前的债务在分立后几家公司之间怎么承担？
