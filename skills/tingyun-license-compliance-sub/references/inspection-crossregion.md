# 抽检飞检应对与跨地区备案

## 一、抽检与飞检应对清单

现场应能立刻出具以下材料（平时留痕、随手可查）：

| 类别 | 应备材料 |
|---|---|
| 资质公示 | 证照正本悬挂/公示、许可范围清晰 |
| 人员 | 健康证/执业证/作业证，全员在效 |
| 台账 | 进货、销售、消毒、留样、维保等记录连续 |
| 检测 | 近期第三方或自检报告 |
| 制度 | 质量/安全/应急制度文件与责任人 |
| 自查 | 近期内部自查表与整改记录 |

应对原则：不临时编造、不拒检、对检查意见留痕确认。平时把"能马上拿出的材料"归置到一处。

## 二、跨地区经营备案路径

异地经营常见三种情形：

1. **设分支机构**：在经营地办分支登记，再按当地要求办/备案许可。
2. **经营场所备案**：部分业态需对实际经营地点单独备案。
3. **重新办证**：许可属地性强（如食品、危化、医疗），常须在经营地新办，不能"一证通用"。

判断步骤：先查目标地主管部门对本品类的要求 → 确认是备案还是新办 → 异地动之前完成，避免无证经营。

## 三、条件变化时的补救

| 变化项 | 补救路径 |
|---|---|
| 迁址 | 先核验新址用途合规，再申请地址变更或新办 |
| 增项/扩范围 | 先核条件，走变更或增项，不超范围经营 |
| 人员离职 | 补齐持证人员，空窗期停对应业务 |
| 设备超期 | 安排校验/检定，取得报告前停用相关项目 |

红线：条件已不满足仍继续经营，属违规，应先停后补，而非边经营边补。
