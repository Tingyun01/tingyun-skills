# 保险理赔材料预检助手

## 一、这个技能解决什么问题

理赔最耗时的往往不是"赔多少"，而是"材料没带齐被退回来"。一次退回意味着重新排队、重新等待、错过时效，还可能在第二轮争议中因证据缺失而处于不利位置。各险种口径差别很大：车险要认定书，医疗险要出院小结和费用清单，重疾险要病理报告，身故要死亡证明与受益人关系证明，多数人第一次只带了身份证和病历。

本技能把经验性要求整理成可勾选的自查表，按场景拆成必备、视情况必备、加分三档，说明每项"缺了会怎样""怎么补""补不了走哪条路"，目标是一次交齐少跑。

## 二、适用与不适用

**适用**：已出险、准备提交或被退回后需重新准备材料的投保人、被保险人、家属与协助办理的亲友。

**不适用**（请找对应专业方，不要向本助手求结论）：

- 判定责任归属、事故性质、是否属于保险责任——由承保公司核定，或交管、司法机关认定。
- 认定伤残等级、评定劳动能力——由有资质的鉴定机构或人社部门作出，标准须与合同对应。
- 医疗费用合理性、用药必要性、赔付比例——由理赔审核与医学／法医岗核定。
- 保险产品对比、推荐、公司选择、报价、核保——本技能不涉及。
- 诉讼、仲裁、拒赔争议的举证与法律意见——须咨询执业律师。

依据《保险法》（2009年施行，2015年第三次修正）、《保险销售行为管理办法》（2023年第2号令）、《银行保险机构消费者权益保护管理办法》（2022年第9号令）的一般要求整理，参考资料逐条标注出处。

## 三、六类场景的材料清单

> 通用性经验表述，各公司口径与时效差异较大，**具体以你投保的保险合同和承保公司要求为准**。逐项规格、常见问题、依据及"视情况必备／加分"两档见 `references/claim-materials-checklist.md`。

**3.1 车险**（单方剐蹭、双方事故、剐伤路人、网约车接单中、泡水）

必备：认定书、交强险保单、商业车险保单、身份证、行驶证、驾驶证、损失清单、修车发票、照片
退回：无认定书或责任不清；证件与保单车辆不一致；清单与发票对不上
补齐：认定书缺失先报案由公司定责；票据遗失由收费处补开证明
时限：多数公司要求 24～48 小时内报案，逾期通常仍可赔付但影响定损

**3.2 医疗险**（门诊／住院／特定门诊）

门诊必备：门诊病历、收费票据原件、费用明细清单、身份证明、保单页
住院必备：出院小结、住院费用总清单、住院收费票据原件、身份证明、保单与条款页、诊断证明
退回：只有出院小结没费用总清单，逐项无法核对；票据是复印件；医保报销未扣除
补齐：费用清单由收费处打印盖章；票据遗失由医院补开证明
时限：多数公司要求出院结算后较短时间内提交

**3.3 重疾险**（确诊即赔型／治疗达成型）

必备（两型通用）：诊断证明书、病理报告或组织学诊断、专项检查报告、完整门诊与住院病历、身份证明、保单与给付条件页、账户
退回：只交诊断证明没病理；病理诊断与合同描述不一致；治疗达成型疗程未做完就申请
补齐：切片归档的可申请借阅或指定机构复核；医生按合同出具书面评估
时限：确诊后应在时效内提出；条件型给付以完成约定治疗为节点留阶段记录

**3.4 寿险身故**（一般／意外／交通工具身故）

必备：死亡证明、户籍注销证明、被保险人身份证明、受益人身份证明、受益人与被保险人关系证明、保单与身故责任页、账户
退回：只有死亡证明没销户证明；受益人无法证明关系继承权；意外身故缺事实证明
补齐：继承纠纷可办继承权公证或由法院文书定份额；院外死亡由公安机关出证明并销户
时限：身故争议集中，越早提交越利于认定

**3.5 伤残**（意外伤残／疾病伤残）

必备：伤残等级鉴定报告、身份证明、完整诊断与病历资料、检查检验报告、申请人身份与收款账户、保单与伤残条款页
退回：自行委托的鉴定机构不被认可；鉴定标准与合同不一致；工伤案件缺认定决定书
补齐：鉴定前先确认承保公司认可的机构与标准；工伤走人社部门认定

**3.6 雇主责任险／团体意外**

必备：工伤认定决定书、医疗或伤残或死亡证明材料、用工关系证明（劳动合同、社保、工资表、考勤）、保单与被保险人名单、事故经过说明、账户
退回：涉事员工不在团体保单名单内；用工关系只有口头说明；团体保单未附名单
补齐：无劳动合同的可提供工资流水、社保记录与考勤；名单争议向公司调投保清单

## 四、三步自检流程

**第一步：材料齐备性勾选。** 确定场景，打开 `references/claim-materials-checklist.md` 对应表逐项对照"手上有／没有"，拿不准的按"没有"处理。三档含义：必备（不交进不了流程）、视情况必备（很可能要）、加分（加快审核）。

**第二步：判断缺件影响。** 看清单里的"缺了会怎样"，分三类优先处理：**阻断型**（认定书、出院小结、病理报告、死亡证明、鉴定报告）缺了直接不受理；**核减型**（费用清单、误工与护理证明）缺了不驳回但砍金额；**争议型**（投保前病史、意外性质）缺了让审核挂起。

**第三步：生成"一次交齐"清单。** 写成带责任方的清单：材料名／谁出（医院、交警、公司、雇主、个人）／怎么拿／预计耗时。能一次办完的集中办，需本人到场的单独约。提交前再对照公司清单。

配套脚本可半自动化：

```bash
python scripts/claim_precheck.py --scenario medical_inpatient --materials "身份证,出院小结,费用清单"
```

输出齐备率、风险等级（低于 60% 高风险、60%～85% 中风险、高于 85% 低风险）、按档位分组的缺件清单及前三条行动。加 `--json` 供上层调用。

## 六、边界与免责

本助手**不做**：①不判定能否赔付、不预测金额；②不认定责任归属与事故性质；③不认定伤残等级；④不做医疗费用合理性审核；⑤不推荐任何保险产品、公司或渠道，不报价不核保；⑥不出具法律意见、不预测诉讼结果；⑦不代替承保公司的正式材料清单；⑧不对个人信息存储外传。

**免责声明**：本助手输出为经验性提示，仅用于协助准备材料，不构成理赔结论、法律意见或保险建议，也不构成承保承诺。所有材料要求以你投保的保险合同与承保公司要求为准。涉及金额较大、责任认定争议、伤残等级认定、已进入诉讼或仲裁程序等高风险场景，材料须由具备相应责任的人员（执业律师、理赔专业人员、法医或鉴定人员）复核后提交。

## 七、常见问答

**Q1：材料交上去多久会被退回？**
多数公司收件后一次性反馈缺件清单，也有先收后审分批补件。提交时附自制清单逐项编号，说明哪些暂缺（如"病理报告下周出具"）并约补交时间，比等逐条问省。

**Q2：住院理赔只带了出院小结和发票，还缺什么？**
通常还需住院费用总清单（收费处打印）、被保险人身份证、保单信息页与条款页、出院诊断证明；手术类另需手术与麻醉记录；重大疾病另需病理报告。缺费用总清单最常见。

**Q3：票据丢了怎么办？**
先找医院，多数可补开收费证明并盖章，或提供医保结算单与费用明细。遗失证明加情况说明有时也接受，能否替代看公司，先问。

**Q4：病历上有既往病史记录，理赔上要注意什么？**
本助手不能预判赔付结论，需公司核保与条款共同认定。可做的是主动完整提交投保前就诊记录，同时提交本次疾病的诊断依据与病程，讲清因果。

**Q5：车损修好才发现对方全责，能找对方赔吗？**
可以主张，但要看保单是否含代位求偿服务、对方有无交强险与三者险。对方无保险时通常由你的车损险赔付并由公司向你追偿。

**Q6：家里老人去世后理赔有什么特殊要求？**
核心三件套：死亡证明、户籍注销证明、受益人关系与身份证明。意外身故还需意外事故证明（交管、派出所、单位或物业）。未指定受益人的靠继承公证定份。

**Q7：网约车接单途中出险，算营运车事故吗？**
多数营运车辆承保条件与私家车不同，是否在保保范围看保单约定。提交时说明接单状态并附平台订单，由承保公司认定；本助手不判断属责。

**Q8：单位帮我投的团体意外险，我要准备什么？**
团体险由单位统一提交，个体重点准备工伤认定决定书、诊疗与伤残材料、身份与收款账户信息。用工关系与名单由单位与公司核对。

## 八、给 Agent 的调用说明

脚本零第三方依赖，仅用 Python 标准库：

```bash
python scripts/claim_precheck.py --list-scenarios
python scripts/claim_precheck.py --scenario medical_inpatient --materials "身份证,出院小结" --json
```

**场景枚举**：`vehicle_accident`、`vehicle_injury`、`medical_outpatient`、`medical_inpatient`、`critical_illness`、`death_claim`、`disability`、`employer_liability`。

**匹配规则**：传入文本归一化后与材料名或别名互相包含即视为已备（传"出院记录"可命中"出院小结（出院记录）"）。建议按材料名原文传。

**JSON 字段**：`completeness_rate`、`risk_level`、`missing_counts`、`missing`（三档分组，含 `name`、`spec`、`missing_consequence`、`alternative_path`）、`top_actions`。

**使用建议**：先问清场景与关键事实再调用；拿到 `missing` 后按必备 → 视情况必备顺序整理成带责任方与耗时的清单。凡涉及赔付结论、责任认定、伤残等级、用药合理性、产品推荐的追问，说明本助手不判断并指向专业方。
