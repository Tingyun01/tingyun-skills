# 稽查应对流程、纳税人权利与自查清单

> 规划辅助，正式稽查请结合专业税务师/律师意见。

## 一、稽查基本流程
1. 选案：基于风险推送或举报等；
2. 检查：调取账簿凭证、询问、实地检查；
3. 审理：核实事实与法律适用；
4. 决定：出具处理/处罚决定；
5. 执行：补缴、缴款、强制执行。

## 二、纳税人的程序权利
- **持证检查**：检查人员须出示税务检查证和检查通知书；对无证现场检查可提出异议。
- **陈述申辩**：对认定与处罚有权陈述、申辩。
- **申请回避**：与案件有利害关系的检查人员可申请回避。
- **保守秘密**：有权要求税务机关保守商业秘密与个人隐私。
- **拒绝越权**：对超出检查范围、调取无关资料可提出异议。

## 三、应对动作清单
- [ ] 先核实文书真伪与检查范围（通过正规渠道确认）；
- [ ] 指定对接人，统一口径，避免多人随意作答；
- [ ] 按通知要求提供资料，建立资料交接清单；
- [ ] 对存疑事项准备书面情况说明与佐证；
- [ ] 行使陈述申辩权，不盲目签字确认；
- [ ] 全程留痕，重要沟通留书面记录。

## 四、自查补正清单（稽查前主动做）
- [ ] 复核近 3 年申报数据与账簿一致性；
- [ ] 排查进销项、成本费用凭证真实性；
- [ ] 核对税收优惠适用条件是否仍满足；
- [ ] 补全缺失凭证、合同、银行流水；
- [ ] 对确实少缴的，评估主动补缴以争取从轻。

## 五、配合边界
- 如实提供、不隐匿、不销毁凭证；
- 但对明显超出范围、与案件无关的资料，可依法异议；
- 任何"花钱摆平""找关系"的提议都应拒绝——合法配合是稳妥路径。

## 六、何时升级找专业人士
已立案、收到《税务行政处罚事项告知书》、涉嫌偷逃骗抗税、或金额较大责任不清时，立即委托税务师或税务律师介入。
