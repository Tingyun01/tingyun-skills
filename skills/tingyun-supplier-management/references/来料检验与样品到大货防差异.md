# 来料检验、样品到大货防差异与断供应对

## 一、样品到大货：12 类常见差异与拦截点

绝大多数"样品很好、大货不行"，根因不在工人手艺，而在**没有把口头共识变成可检验的文件**。

| 差异类型 | 典型表现 | 根因 | 拦截点（事前） | 拦截点（事中/事后） |
|---|---|---|---|---|
| 材质降级 | 手感变硬、掉色、变薄 | 换了低价牌号或混用回收料 | 规格书写明材质牌号 + 主材产地 | 核对来料检验报告中的牌号，留样比对 |
| 颜色偏差 | 批次间色差明显 | 换了染缸/色母供应商 | 用 Pantone/色号 + 封样实物双基准 | 每批留样对比，封样随货流转 |
| 尺寸偏差 | 装配不合、孔位对不上 | 模具磨损或未修模 | 关键尺寸标公差范围 | 关键尺寸每批抽测，超差即拦截 |
| 表面处理差异 | 镀层薄、喷涂不均、手感不同 | 工艺参数未写明 | 规格书写明工艺路线与后处理要求 | 首件确认 + 巡检记录 |
| 结构改动 | 少一个卡扣、加一个垫片 | 工程变更未同步 | 变更须书面同意并重新送样 | 核对变更单与实物零件数 |
| logo/印刷差异 | 位置偏、颜色浅、丝印变烫金 | 工艺未确认、尺寸放大 | 确认工艺类型 + 尺寸 + 色号 | 首件确认留影像 |
| 配件缺失 | 少配件、少说明书 | 打包工序无复核 | 装箱清单 + 配件齐套表 | 抽箱核对配件数 |
| 包装差异 | 缓冲材料减少、箱规变小 | 换包装供应商省成本 | 缓冲材料规格 + 跌落测试要求 | 到货抽箱目视 + 缓冲厚度抽测 |
| 气味/环保差异 | 刺鼻味、掉色沾手 | 换胶水/涂层供应商 | 环保与安全要求条款 + 检测报告 | 抽检气味、必要时送检 |
| 模具差异 | 用旧模、拼模、非本款专用模 | 模具台账不清 | 模具编号 + 模具房盘点 + 影像 | 每批核对模具编号 |
| 组装差异 | 螺丝扭矩不足、线材长度不同 | 工序无标准工时 | 关键工序作业标准 | 扭矩抽检 + 首件全检 |
| 混料 | 不同批次料混在同一箱 | 无分区、无标识 | 分区标识与先进先出要求 | 开箱抽检标识与料批号 |

### 双基准锁定法

```
基准一：实物封样
  做法：按颜色/材质/工艺分项封样，双方各持一套，签样注明版本号
  封样编号：SKU-版本-日期-项号（例如 A1001-V2-20260915-03）
  保存：避光、避热、防变形；封样破损或变色即重新封样并说明原因

基准二：书面规格书
  做法：把可检验的项写成数字或可对照的描述
  写法对照：
    差  "质量好""手感不错""跟样品一样"
    好  "主体 ABS 牌号 XXX；克重 ≥ 180g/件；主色 Pantone 185C； 
         关键装配孔距 62±0.3mm；表面喷细纹哑光；附配件齐套 8 件"
  原则：能测量的写数值，能比对的写基准，不能量也不能比的项要说明判定方式
```

**关键原则**：**封样与规格书必须同时签**。只有封样没有规格书，供应商说"这就是你要的"你无法反驳；只有规格书没有封样，颜色与手感这类无法量化的项会扯不清。

### 变更控制条款要点

- 涉及材质、牌号、染料/色母、模具、产线、生产场地、工艺路线、关键辅料供应方的变更，须**事先书面通知并取得买方书面同意**，未经同意到货的按不合格处理
- 通知时限与响应时限写清（例：变更须提前 15 天书面通知，5 天内答复）
- 变更后需**重新送样确认**并留存首件
- 实际条款的效力与违约后果请由执业律师起草与审核

## 二、来料检验（IQC）项目表

### 2.1 抽样规则

按 GB/T 2828.1 一般检验水平 II 执行，缺陷等级对应 AQL：

| 缺陷等级 | 定义 | AQL | 判定要点 |
|---|---|---|---|
| 致命缺陷（CR） | 影响安全、导致伤害或违法 | 0 | 出现即拒收该批 |
| 严重缺陷（MAJ） | 影响功能、显著影响外观与使用 | 0.65 / 1.0 | 按抽样表判定 |
| 轻微缺陷（MIN） | 不影响功能与使用 | 2.5 | 按抽样表判定 |

**抽样批量与检验水平**：批量越小，抽样比例越高。日常可按"小批量全检 + 大批量按 AQL 抽检"的方式落地，把全检/抽检切换点写进合同附件。

### 2.2 检验项目表

| 类别 | 检查项 | 方法 | 记录 |
|---|---|---|---|
| 数量 | 装箱数、件数 | 抽样核对 | 箱数/实数 |
| 外观 | 划伤、脏污、缺件、毛刺、装配缝隙 | 目视，按限度样判定 | 缺陷数、位置 |
| 尺寸 | 关键尺寸（装配相关） | 卡尺/高度规/塞规 | 实测值 |
| 材质 | 牌号、手感、克重、硬度 | 手感 + 称重 + 必要时送检 | 报告编号 |
| 颜色 | 色差 | 封样比对 + 色卡 | 判定结论 |
| 功能 | 通电、装配、承重、开合次数 | 试装、试机 | 通过/失败 |
| 配件 | 配件数、说明书、标贴 | 抽箱核对 | 缺件清单 |
| 包装 | 箱规、缓冲厚度、印刷 | 目视 + 卡尺 | 判定 |
| 标识 | 生产日期、批号、标签 | 目视 | 批号记录 |

**限度样（限度样本）**：把可接受与不可接受的实际样品各留一套，形成判定基准，比文字描述有效得多。

### 2.3 判定与处置

```
抽样判定（依 GB/T 2828.1 抽样表）
  Ac = 接收数，Re = 拒收数
  判定：抽检数 ≤ Ac → 接收；> Re → 拒收；中间区需继续抽样
  注意：接收不等于"全部合格"，抽样存在漏检风险；对高风险 SKU 考虑加严检验

批次不合格四种处置（选其一，写进判定单）
  A 返工/挑选：合格后按正常价格结算，返工成本与返工期间仓储由供方承担
  B 全检/挑选：出挑检费，合格后正常结算，不合格部分按拒收处理
  C 退货：整批退回，货款按合同处理，运费与包装损失由供方承担
  D 让步接收：限定使用场景与限制条件，书面记录让步原因与审批人，
             同时计入会影响后续议价与记分卡

时限要求：到货后 ____ 小时内完成检验并出具书面判定（写清小时数与工作日口径）
```

**让步接收容易被滥用**。判断标准：**让步接收必须限定使用场景**（例如"仅用于内销包装、不用于出口外箱"），且**每次让步都要在记分卡留痕**。无条件让步等于把问题转移到自己仓库。

## 三、交期与产能核验（简版执行）

### 3.1 交期承诺的可执行写法

```
不可执行："交期 20 天"
可执行：
  下单确认：T+0（收到订单与确认图当天）
  物料齐套：T+5
  开始生产：T+7
  生产完成：T+18
  货到：T+20
  每节点对应交付物：齐套需附物料清单；生产完成需附完工照片与数量
  延迟约定：每延迟 1 天按合同金额的 ____% 计，延期超 ____ 天可拒收
```

**判断标准**：**交期是否可执行，看它有没有"交付物"**。只给一个总数的交期无法追责；有节点、有交付物的交期才能在延迟时定位是哪一段出了问题。

### 3.2 产能四要素速算

见 `references/供应商分级与准入评估表.md` 第二节，此处只记要点：**问上个月实际出货量，不要问日峰值产能；四要素取低值；换线与待料要扣掉。**

## 四、断供应急清单

### 4.1 断供信号（分级预警）

| 级别 | 信号 | 判断依据 | 动作 |
|---|---|---|---|
| 黄色 | 交期小幅漂移（3~7 天）；报价有效期缩短；回复变慢 | 连续 2 次出现 | 加密沟通（下单改为周确认）；开始问备选可行性 |
| 橙色 | 预付比例要求提高；关键员工离职被提及；模具被转做他人订单 | 出现 1~2 项 | 启动备选打样；提高安全库存；锁定关键料备用量 |
| 红色 | 明确提出涨价且不接受商量；拒绝确认在手订单交期；产线可见产量明显下滑 | 出现任一项 | 立刻启动切换排期；与客户沟通供应预期 |

**判断标准**：**红色信号出现时，不要先谈价格**。这时候价格谈不谈得下来都不重要，交付能不能续上才是核心问题。

### 4.2 库存覆盖天数测算（先算这个，它决定你能等多久）

```
日均出货量 = 近 30 天出货总量 ÷ 30（在手订单未交付的不计）
现有可用库存 = 仓库现货 + 已确认在途（能确认到货日的才计）
库存覆盖天数 = 现有可用库存 ÷ 日均出货量
```

```
覆盖天数 ≥ 切换周期 + 打样确认天数 → 有时间从容切换
覆盖天数 < 切换周期 → 已在断供边缘，必须三线并行：
   1) 提高现有供应商排产优先级（在商订单加量、加急费）
   2) 立即启动备选打样（用加急费换产能）
   3) 与客户沟通交期与替代方案（不要等到货期前一周才说）
```

### 4.3 应急期的手续不要省

应急不等于可以跳过文件。以下三项即使在断供期也要做：

1. **加急订单仍需书面确认**（价格、工期、交付节点）——口头加急是日后争议的来源
2. **加急批次也要留样**——断供期容易被塞进次品
3. **加急费用与责任划分写清**——加急费、返工责任、优先排产的对价

### 4.4 与客户沟通的三种口径

```
口径一（尚能覆盖）：提前说明排产紧张，给出具体到货日区间与确定性说明
口径二（部分缺口）：给出"哪些型号有货、哪些延迟、延迟多少天"的明细，不给模糊的整体承诺
口径三（整体缺货）：给替代方案（规格替换、替代供应商、延期、退订的账期与责任处理）
```

**不做的事**：不承诺无法确认的到货日；不用"包票没问题""肯定能赶上"这类话（既不可信，也可能构成不当陈述）；不在渠道评论区或公开场合讨论供应问题。

## 五、这一套逻辑不成立的情形

- **产品单价极低、SKU 极多**：逐批检验与封样管理的成本会超过质量问题的损失。此时应改为"按批次抽检 + 关键 SKU 严检 + 其余靠供应商自检并留记录"。
- **你自己没有检验能力（无人、无检具、无判定标准）**：检验方案再全也执行不了。此时该做的是：要求供应商提供出厂检验报告并承担复检责任、约定不合格的退换货与费用承担、要求留样并由你保留三方比对。
- **交期长期由对方垄断且无可替代**：所有管控手段的效果都被削弱，重点应放在合同条款（交期节点、交付物、违约）与资金安排（不提前打款）上。
- **货值低于检验成本**：改为"目视 + 抽抽"和"到货开箱验数"即可。
