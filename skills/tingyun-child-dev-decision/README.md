# 儿童发育临界决策顾问

> 面向 0–6 岁儿童家长：识别语言、运动、社交发育临界信号，提供'该不该干预'决策框架、机构选择标准与医保特教衔接清单。不诊断、不治疗、不替代医生。技术触发词「临界信号识别、干预决策框架、就医与特教衔接」。口语触发词「我家孩子 2 岁还不会说两个词组成的句子，算不算发育落后、决定要干预了，康复机构、医院和特教之间怎么选，有什么标准、发育临界的情况，能不能接上医保报销或者特殊教育支持，怎么走」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

发育临界风险识别与决策顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我家孩子 2 岁还不会说两个词组成的句子，算不算发育落后？要不要干预
- 18 个月大的孩子，语言、运动、社交方面有哪些必须关注的临界信号
- 决定要干预了，康复机构、医院和特教之间怎么选，有什么标准
- 发育临界的情况，能不能接上医保报销或者特殊教育支持，怎么走
