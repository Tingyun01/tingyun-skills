# 照护机构选择标准 · 父母身后持续安排清单

> 信息梳理用，不构成医疗或法律意见，实际以专业评估与当地机构为准。

## 一、照护机构选择标准（打分表）

| 维度 | 看什么 | 红线信号 |
|---|---|---|
| 资质合规 | 有无登记/备案、经营范围 | 无资质、拒出示证照 |
| 人员配比 | 照护员与对象比例、专业培训 | 一人管过多、无急救培训 |
| 医疗衔接 | 是否近医疗机构、应急通道 | 周边无急诊、无预案 |
| 环境与安防 | 防滑、门禁、防走失 | 隐患明显、管理松散 |
| 费用透明 | 收费结构、调价机制 | 含糊、强制捆绑 |
| 探视与沟通 | 探视便利、定期反馈 | 限制探视、信息不透明 |

**做法**：列出 3 家候选，按上表各打 1–5 分，优先看"资质+安防+医疗衔接"三项是否都达标，再比费用。

## 二、父母身后持续安排清单

1. **法律文件齐备**：监护安排（监护人+监督人）、遗嘱/遗产指向、信托文件均已生效并有人保管副本。
2. **资金通道确认**：信托或保险能自动接续支付，无"断供窗口期"。
3. **监护人交接手册**：孩子的医疗史、用药、作息、喜好、应急联系人写成可交接文档。
4. **监督机制激活**：监督人/保护人已知责，并约定定期核查频率。
5. **机构预案**：若当前照护安排失效，备选机构与转介路径已备。
6. **亲人知情**：兄弟姐妹/近亲属知悉安排，减少身后争议。
7. **定期复查**：每 1–2 年复核一次架构与待遇资格，随政策与孩子状况调整。

**紧急补位提示**：若父母突遇意外且尚未安排，先确定临时监护人与财产控制人，再补办正式文件，并联系律师与公证机构。
