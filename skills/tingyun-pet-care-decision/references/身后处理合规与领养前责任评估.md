# 身后处理合规与领养前责任评估

## 一、宠物身后处理（合规 + 情感，不评判告别方式）

**合规要点**
- 选择具备**动物无害化处理或宠物殡葬资质**的机构；下单前索看资质与收费标准。
- 确认火化方式：单独火化还是集体火化，骨灰是否归还，能否陪同。
- 索取票据与协议，明确服务内容与费用，警惕无资质"上门火化"低价陷阱。
- 各地对动物尸体处理有规定，具体以当地主管部门公布为准。

**情感安顿**
- 允许哀伤，不急着"再养一只"来替代。
- 留存纪念：照片、爪印、毛发，写几句话。
- 如哀伤持续影响生活，可引导向宠物哀伤支持资源或心理咨询。

## 二、领养前责任评估（把冲动养了又弃养的概率压下来）

**成本账（年度大致构成）**
- 基础：食物、猫砂/用品、疫苗、驱虫、绝育。
- 周期：年度体检、牙齿护理。
- 预备：突发疾病/意外医疗准备金（建议按月存一笔）。

**时间账**
- 犬类：每日遛狗、陪伴、分离焦虑应对、训练。
- 猫类：陪伴互动、环境丰容、清理。
- 出差/搬家时的托管与安置方案是否就绪。

**责任账**
- 租住是否允许宠物、押金与退租风险。
- 家人是否一致、有无过敏。
- 能否承诺十余年（犬猫常见寿命跨度）的持续照护。

## 三、领养前自检清单

- [ ] 成本账算过、有稳定预备金
- [ ] 时间账排得开、出差有人接手
- [ ] 住所允许、家人一致、无过敏
- [ ] 接受"它可能不是理想中的样子"
- [ ] 想清楚弃养的成本（对动物与对自己）并承诺不弃养

> 本页只提供合规要点与责任结构，具体机构资质与政策以当地主管部门为准。
