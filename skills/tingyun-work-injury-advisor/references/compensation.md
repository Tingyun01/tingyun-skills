# 赔偿项目测算逻辑、侵权竞合与争议路径

> 本页为决策辅助底稿，不构成法律意见，具体金额与等级须由法定机关认定，需专业人士复核。

## 一、赔偿项目与测算逻辑（提示性，非确定金额）

| 项目 | 测算逻辑要点 |
|---|---|
| 医疗费用 | 符合工伤保险诊疗项目目录、药品目录、住院服务标准的实际支出 |
| 住院伙食补助 | 按当地标准 |
| 停工留薪期工资 | 原工资福利待遇不变，期限按医疗机构/鉴定意见 |
| 护理费 | 生活不能自理期间，按标准 |
| 一次性伤残补助金 | 与伤残等级、本人工资挂钩（等级越高月数越多） |
| 伤残津贴 | 一至四级伤残按月支付，按比例 |
| 一次性工伤医疗/就业补助金 | 五至十级解除关系时，按地方标准 |
| 工亡待遇 | 丧葬补助金、供养亲属抚恤金、一次性工亡补助金 |

> 本人工资口径（含加班费与否）、地方标准、等级鉴定均影响金额，须以法定核算为准。

## 二、与民事侵权竞合处理

上下班途中遇第三方交通事故等情形：
- 可同时主张工伤保险待遇与向第三方侵权索赔
- **医疗费等"实际支出"类项目一般不适用重复赔偿**（填平原则）
- 伤残补助金、一次性工亡补助等"定型化"项目，各地司法口径有差异

> 竞合部分务必提示以当地规定与司法口径为准，必要时咨询律师。

## 三、争议处理路径

```
对工伤认定结论不服
  → 可依法申请行政复议
  → 对复议不服或可提起行政诉讼（具体以当地程序为准）

对劳动能力鉴定结论不服
  → 申请再次鉴定（向省级劳动能力鉴定委员会）

对赔偿数额/劳动关系争议
  → 劳动仲裁 → 对裁决不服可诉讼
```

## 四、给双方的风险提示

- **员工**：不要轻率签"私了协议"放弃法定待遇；先认定再谈赔偿更稳
- **企业**：瞒报或不报可能承担工伤保险待遇之外的行政/民事风险；依法参保是关键防线
- 诉讼/复议策略、具体赔付谈判建议咨询律师或当地法律援助

> 本页不构成法律意见，不替代任何法定认定或司法结论。
