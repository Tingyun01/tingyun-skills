# 个体户经营异常名录与税务异常手册

配套文件：`../SKILL.md`（方法论正文）、`field-guide.md`（字段对照表与自检清单）。

**核对日期：2026-11-01。**
**官方查询入口方向：以国家企业信用信息公示系统（gsxt.gov.cn）与主管税务机关公布的信息为准。**

> 使用说明：本手册只整理"异常类型 → 触发原因 → 影响 → 解除路径 → 时限 → 注意事项"这一层信息，**不代替登记机关与税务机关的正式认定**。所有影响均标注"通常影响"，并注明以当地口径为准。

## 1. 列入经营异常名录

- **异常类型**：列入经营异常名录。
- **触发原因**：
  1. 未在规定期限内公示或报送年度报告；
  2. 公示企业信息隐瞒真实情况、弄虚作假；
  3. 不按规定期限公示定期报告的相关信息（部分地方口径）。
- **对经营的影响（通常影响，以当地口径为准）**：
  - 在国家企业信用信息公示系统向社会公示，信用记录留痕；
  - 可能影响开票与正常经营状态（是否影响取决于税务与银行侧的实际联动口径）；
  - 可能影响政府采购、工程招投标、国有土地出让、授予荣誉称号等事项的资格；
  - 满 3 年仍未履行相关义务的，列入严重违法失信企业名单；
  - 可能影响银行授信审批与商业信用评估。
- **解除/修复路径（一般步骤）**：
  1. 确认异常原因与列入时间；
  2. 补报或改正应公示的信息（补报年度报告、修正公示内容）；
  3. 向登记机关提交移出经营异常名录申请（线上或线下）；
  4. 登记机关受理后核实；
  5. 公示 3 个工作日，无异议后作出移出决定。
- **时限**：一般自受理起 3 个工作日内公示，公示期满无异议方可移出。具体以登记机关口径为准；补报年度报告本身还需符合年报报送期限规定。
- **注意事项**：
  - 未履行相关义务满 3 年的会被列入严重违法失信企业名单，届时法定代表人、负责人 3 年内不得担任其他企业法定代表人、负责人，**先移出异常名录再考虑其他事项**；
  - 不要在移出申请提交后立即注销主体，注销后无法再移出；
  - 移出后应同步检查税务侧状态（非正常户需先恢复正常户状态）。
- **官方查询入口方向**：国家企业信用信息公示系统查询主体状态与列入原因；以登记机关公布为准。

## 2. 未按期公示年度报告

- **异常类型**：未按期报送年度报告（尚未被列入异常名录的独立状态）。
- **触发原因**：未在每年 1 月 1 日至 6 月 30 日期间报送上一年度年度报告。
- **对经营的影响（通常影响，以当地口径为准）**：本身不直接产生信用记录，但登记机关会在年度结束后将未按期报送的列入经营异常名录；同时可能面临罚款处理。
- **解除/修复路径**：在期限内补报年度报告；逾期未报的，先移出经营异常名录再继续。
- **时限**：补报应尽快完成，避免跨年度累积。
- **注意事项**：
  - 补报不等于免罚，未按期报送的仍可能面临处罚（可处 1 万元以下罚款）；
  - 连续多期未报会累积为严重违法失信风险。
- **官方查询入口方向**：国家企业信用信息公示系统的年报公示记录。

## 3. 列入严重违法失信企业名单

- **异常类型**：严重违法失信企业名单。
- **触发原因**：列入经营异常名录满 3 年仍未履行相关义务（未按期报送年报等）。
- **对经营的影响（通常影响，以当地口径为准）**：
  - 在国家企业信用信息公示系统公示并实施 List 标记；
  - 法定代表人、负责人 3 年内不得担任其他企业法定代表人、负责人；
  - 可能影响政府采购、招投标、国有土地出让、荣誉称号等事项；
  - 可能影响银行授信与商业信用。
- **解除/修复路径**：先履行相关义务（补报年报、改正公示信息）→ 申请移出经营异常名录 → 由登记机关依程序移出名单相关标记。具体流程与期限以登记机关要求为准。
- **时限**：从移出经营异常名录起算恢复，各项限制的解除时点以登记机关与相关部门口径为准。
- **注意事项**：**任职限制是硬约束**，涉及法定代表人变更、继承、股权重组等安排前应先确认状态。
- **官方查询入口方向**：国家企业信用信息公示系统。

## 4. 税务登记状态非正常户

- **异常类型**：非正常户（税务登记状态异常）。
- **触发原因**（常见情形，以主管税务机关认定为准）：
  - 逾期未申报纳税申报表；
  - 到期未缴清税款、滞纳金；
  - 未按规定期限办理税务登记变更；
  - 走逃失联。
- **对经营的影响（通常影响，以当地口径为准）**：
  - **可能无法正常开具发票**；
  - 税务登记被锁定，申报与缴款功能受限；
  - 正常经营状态受影响，可能影响上下游合作与平台入驻；
  - 长期不恢复正常状态的，可能按规定处理税务登记（如按规定转入异常状态处理流程），并影响纳税信用评级。
- **解除/修复路径（一般步骤）**：
  1. 到主管税务机关办税服务厅或通过电子税务局查询非正常户原因；
  2. 补申报、缴清税款、滞纳金与应作罚款处理；
  3. 处理发票相关事项（已开具发票的核对与补报）；
  4. 申请恢复正常户状态。
- **时限**：具体时限以主管税务机关核定要求为准；涉及按规定处理税务登记的，按税务机关告知的期限执行。
- **注意事项**：
  - **先处理逾期申报与欠税，再申请恢复正常户**，顺序反了会被退回；
  - 滞纳金按日计算，拖得越久成本越高；
  - 恢复前不要强行开票，走逃失联性质严重。
- **官方查询入口方向**：电子税务局"纳税人信息查询"、主管税务机关办税服务厅。

## 5. 逾期申报（纳税申报）

- **异常类型**：逾期申报。
- **触发原因**：未按规定的期限办理纳税申报（月度或季度终了后 15 日内、年度汇算规定期限内）。
- **对经营的影响（通常影响，以当地口径为准）**：
  - 责令限期改正，可以处 2000 元以下罚款；情节严重的，可以处 2000 元以上 1 万元以下罚款（《税收征收管理法》第六十二条）；
  - 加收滞纳金；
  - 连续或多次逾期可能被认定为非正常户；
  - 影响纳税信用评价。
- **解除/修复路径**：立即补申报 → 缴清税款与滞纳金 → 接受相应处罚处理。
- **时限**：以税务机关责令的期限为准；补申报越早，滞纳金越少。
- **注意事项**：
  - 零收入、零税额、停业状态**同样需要按期申报**，这是最常被忽略的一点；
  - 逾期填报与不填报性质不同，主动补申报通常比被认定不申报的处理结果轻。
- **官方查询入口方向**：电子税务局申报表查询、主管税务机关。

## 6. 逾期缴纳税款与滞纳金

- **异常类型**：欠税、逾期缴纳税款。
- **触发原因**：已申报但未按期缴纳应纳税款。
- **对经营的影响（通常影响，以当地口径为准）**：
  - 加收滞纳金（日加收，比例以法律规定执行）；
  - 可以处 2000 元以下罚款，情节严重的处 2000 元以上 1 万元以下罚款；
  - 影响纳税信用评级；
  - 可能被限制出境、财产保全等（《税收征收管理法》相关规定情形）。
- **解除/修复路径**：缴清税款与滞纳金 → 接受处罚处理 → 恢复相应权限。
- **时限**：以税务机关通知的缴纳期限为准。
- **注意事项**：
  - 先确认是否存在税收争议（如有异议走行政复议或纳税争议处理程序），避免先缴后主张；
  - 账户余额不足导致的逾期也计入逾期，不能以"不是故意的"抗辩。
- **官方查询入口方向**：电子税务局欠税查询、主管税务机关。

## 7. 欠税（未缴清税款）

- **异常类型**：欠税。
- **触发原因**：应纳税款到期未缴（含零申报后经核查发现应补税的情形）。
- **对经营的影响（通常影响，以当地口径为准）**：影响纳税信用评级；可能被公示欠税信息；与异常名录、非正常户状态相互关联；可能影响部分招投标与补贴事项。
- **解除/修复路径**：缴清欠税 → 办理相关状态处理手续。
- **时限**：以税务机关通知为准。
- **注意事项**：主动缴清后仍需确认相关状态是否已同步恢复正常，不能只缴不管状态。
- **官方查询入口方向**：电子税务局欠税信息查询。

## 8. 未按规定使用发票

- **异常类型**：发票违法事项（未按规定开具、取得、保管发票等）。
- **触发原因**：取得或开具的发票不符合规定；为他人代开发票；使用不符合规定的票据作进项抵扣等。
- **对经营的影响（通常影响，以当地口径为准）**：
  - 已抵扣的进项税额不得抵扣，须作进项税额转出；
  - 可以处 2000 元以下罚款，情节严重的处 2000 元以上 1 万元以下罚款；
  - 影响纳税信用评价。
- **解除/修复路径**：作进项税额转出 → 补缴税款 → 接受处罚处理 → 整改开票习惯与内部管理。
- **时限**：以税务机关通知为准。
- **注意事项**：**不要为了"有发票"而购买或接受不合规发票**，转出与处罚通常会同时发生。
- **官方查询入口方向**：电子税务局发票查询与风险提示。

## 9. 发票违法（虚开、走逃失联等）

- **异常类型**：发票违法案件。
- **触发原因**：虚开发票；走逃失联（与上述第 4、5、6 项常并发）；其他严重违反发票管理法规的情形。
- **对经营的影响（通常影响，以当地口径为准）**：
  - 追缴税款、加收滞纳金、处以罚款；
  - 可能被移送司法机关追究刑事责任；
  - 主体可能被认定为非正常户；
  - 严重的社会信用影响。
- **解除/修复路径**：这不是"自行修复"的事项——**应当第一时间委托执业税务师或律师**，配合税务机关调查处理。
- **时限**：以调查处理程序确定的期限为准，无统一自办时限。
- **注意事项**：
  - 不要自行销毁账簿、凭证、聊天记录；
  - 不要在未咨询专业人士的情况下做出陈述或提交说明；
  - 这属于本技能明确不覆盖的场景。
- **官方查询入口方向**：主管税务机关稽查与法制部门。

## 10. 风险纳税人（进项异常、上下游异常）

- **异常类型**：风险纳税人管理措施。
- **触发原因**：进项税额异常（如取得的发票异常、进项占比异常）、上下游企业异常（上下游被认定为异常纳税人）、其他风险指标。
- **对经营的影响（通常影响，以当地口径为准）**：
  - 进项税额不得抵扣，须转出并补税；
  - 可能被约谈、实地核查；
  - 可能被列入关注名单或从严管理；
  - 正常的发票开具也可能受限。
- **解除/修复路径**：核对风险提示 → 说明业务真实性与对应凭证 → 按要求作进项转出并补税 → 解除相应管理措施。
- **时限**：以税务机关下达的风险提示或通知要求为准。
- **注意事项**：
  - 优先准备业务真实性证据（合同、物流、资金流、发票链条说明）；
  - 不要等到核查当天才准备，先归集底稿。
- **官方查询入口方向**：电子税务局风险提示与提示函。

## 11. 税务登记信息与实际不符

- **异常类型**：税务登记信息异常（信息与实际不一致）。
- **触发原因**：名称、地址、法定代表人、经营范围、联系方式等登记事项发生变化未办理变更登记；或提交的变更材料与实际不符。
- **对经营的影响（通常影响，以当地口径为准）**：影响发票开具与纳税申报的准确性；可能被要求限期改正并处罚款；信息不符也会造成年报、汇算与登记信息自相矛盾。
- **解除/修复路径**：核对登记事项与实际情况 → 办理变更登记 → 同步修正年报与申报表中的相关信息。
- **时限**：以税务机关要求的期限为准。
- **注意事项**：**变更后要同步检查上一年度年报与汇算中引用的是否为旧信息**，这是同一主体的多处信息不一致最常见的来源。
- **官方查询入口方向**：电子税务局纳税人信息查询、主管税务机关。

## 12. 涉税专业服务与代办违规

- **异常类型**：涉税专业服务信用与执业违规（针对找代办的用户与代办机构两侧）。
- **触发原因**：涉税专业服务机构在执业过程中违反规定；用户委托不合规代办，或向不具备资质的主体提供影响真实性的资料。
- **对经营的影响（通常影响，以当地口径为准）**：对用户侧，代理申报行为本身不改变用户的法定申报责任；对机构侧，可能影响涉税专业服务信用记录、业务承接。
- **解除/修复路径**：对用户侧，重点是**核对并自行确认申报数据的真实性与依据**，必要时更正申报；对机构侧，按涉税专业服务主管机关要求处理。
- **时限**：以主管机关要求为准。
- **注意事项**：
  - **不要把账号密码交给代办方**；
  - 代办提交后仍要自己抽查关键数字（可用本技能的十项自检清单）；
  - 虚假申报的责任不会因为"是代办做的"而转移。
- **官方查询入口方向**：涉税专业服务信用评价与主管税务机关。

## 13. 个体户被认定为需要采取管理措施的情形

- **异常类型**：登记机关对个体工商户采取的管理措施（部分地方口径中称之为"规范管理"或列入重点监管）。
- **触发原因**：登记事项不规范、地址失联、经营场所无法核查、提交材料虚假等。
- **对经营的影响（通常影响，以当地口径为准）**：可能限制变更登记（住所、经营范围等）；可能被要求先行整改；影响业务连续性与合作方尽调。
- **解除/修复路径**：按通知书要求整改 → 提交核查材料 → 申请解除管理措施。
- **时限**：以通知书载明的整改期限为准。
- **注意事项**：**不要在整改期内擅自变更地址或注销**；先与登记机关沟通清楚再操作。
- **官方查询入口方向**：国家企业信用信息公示系统、登记机关。

## 通用排查顺序（拿到异常后按这个次序做）

1. **先定位异常类型与归口**：是登记机关的异常名录，还是税务机关的非正常户、逾期申报、风险提示？两者不要混着处理。
2. **调出原始记录**：国家企业信用信息公示系统查列入原因与列入时间；电子税务局查申报与欠税记录。
3. **列出待补的动作**：补报年报、改正公示信息、补申报、缴清税款与滞纳金、发票问题转出与补税、变更登记信息。
4. **按依赖顺序执行**：通常先补报与补缴 → 再申请移出或恢复正常户 → 最后确认状态已在系统更新。
5. **留存全过程证据**：申请回执、缴款书、完税证明、更正后的申报表截图。
6. **确认状态已更新**：以公示系统与税务机关系统显示为准，而非以"我交材料了"为准。

## 三条最容易踩的坑

1. **顺序反了**：先交移出申请、后补材料，或先申请恢复正常户、后补申报，都可能被退回，等于多耗一个周期。
2. **只处理一头**：异常名录移出了但税务侧仍是非正常户，或反过来。开票依然会出问题。
3. **以为"没人查就没事"**：列入异常名录是自动比对的结果，不需要有人举报；补报之后系统仍会留下记录，影响是长期但可修复的。
