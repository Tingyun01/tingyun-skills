# tingyun-social-insurance-handbook

> 按属地查社保医保公积金的高频事项办理指引，输出材料清单、办理顺序与不白跑提醒
>
> 面向个人参保人、灵活就业者与个体户经营者的社保医保公积金办事指引助手。按异地就医备案、门诊慢特病认定、公积金提取、灵活就业参保与断缴补缴四类高频事项，用谁都能看懂的五段式说明：谁能办、要带什么材料、怎么办、多久办好、什么情况会白跑一趟。

## 这个 Skill 做什么

把「社保医保办事」这个场景最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

### 解决什么问题

普通人卡住的不是"不知道有件事"，而是四件事答不准：

1. **该办哪个**——门诊报销可能落在普通门诊统筹、慢特病认定、异地就医备案、异地门诊慢特病备案四条路径上，选错要跑第二趟。

2. **办哪个最省**——线上能不能办、要不要到场、能不能一次办完。异地就医备案线上几分钟办结，排队两小时是白跑。

3. **哪天截止**——承诺制备案有补材时限，补缴有年度截止日，提取有额度限制。错过截止日，材料再齐也办不成。

4. **缺哪份材料会白跑**——居住证必须是公安制式居住证，社区开的居住证明不算；转诊单须由有转诊资质的定点医院开具。

政务 APP 说"有哪些事项"，通用 AI 说"大概流程"，都不告诉你"这个省这个市这条材料要什么规格"。**通用逻辑写死在方法论里，属地差异放数据文件每天更新**。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 异地就医备案要准备什么材料才不会白跑
- 门诊慢特病怎么申请
- 租房提取公积金要什么材料
- 灵活就业断了以后怎么补缴

## 怎么用

1. 安装到你的 agent（Claude Skills 目录 / 扣子技能商店）
2. 直接用日常说法提需求，例如：
   异地就医备案要准备什么材料才不会白跑
3. 它会追问关键信息（缺的信息会标〔待补〕，不会替你编）
4. 输出可直接用的清单 / 对照表 / 台账

## 输出

- 判断步骤与检查清单
- 对照表 / 台账
- 待办与需要人工核实的问题

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
