# 腾退估算、税费测算与竞拍策略

> 用途：把"这套房我真实要花多少、要等多久"算成一张能拿去做决定的表。
> 所有区间均为估算口径，需以实际核查结果与当次竞买须知修正。

## 一、腾退时间与成本估算框架

### 1. 先按占有情形定档

| 情形编号 | 占有情形 | 时间量级（估算） | 主要成本项 | 关键变量 |
|---|---|---|---|---|
| A | 空置，钥匙或门锁由处置方保管 | 数日至两周 | 换锁、开锁、保洁 | 现场确认一次即可定档 |
| B | 产权人自住且有腾退意愿 | 一至三个月 | 搬迁补助、临时租房、物业欠费垫付 | 意愿强度、是否需分户安置 |
| C | 产权人自住但拒绝搬离 | 六个月至一年以上 | 强制腾退申请成本、执行异议诉讼费、额外补偿主张 | 是否进入执行异议程序 |
| D | 有租户且租期未满 | 到期或协商解约期间 | 剩余租期租金、搬家补偿、诉讼成本 | 租赁的签订与备案时间 |
| E | 第三人占有并主张权利 | 一年以上，交割可能停滞 | 异议之诉成本、机会成本、标的变价风险 | 主张的依据与强度 |
| F | 存在登记居住权 | 无法通过常规腾退解决 | 需协商放弃或变更登记，否则长期让渡占有 | 居住权人配合意愿 |

**档位判定要点**：不要采信口头描述。腾退档位只能由"现场踏勘 + 物业与邻居走访 + 处置方书面回复"三者交叉确认后确定。

### 2. 时间也要折成钱

腾退等待期不是"免费等待"。把它折算成资金成本：

```
腾退期资金占用成本 = 尾款金额 × (资金机会成本年化 ÷ 12) × 腾退月数
腾退期机会成本     = 同期可实现的其他用途收益（按你自己的口径，保守取 0 或低值）
```

**建议做法**：把腾退月数按"中性档"取值，同时记录"悲观档"月数，两档都算出总成本，看差额是否在你的承受范围内。差额过大，说明这单的风险结构不适合用折扣收益去覆盖。

### 3. 三档测算表（模板）

| 成本项 | 乐观档 | 中性档 | 悲观档 | 备注 |
|---|---|---|---|---|
| 成交价 |  |  |  | 起拍价或你的熔断价 |
| 应缴税费（自担部分） |  |  |  | 契税、登记费、印花税等 |
| 垫付税费（卖方部分） |  |  |  | 增值税及附加、个税、土地增值税等 |
| 腾退成本 |  |  |  | 按情形 A~F 取值 |
| 腾退期资金占用成本 |  |  |  | 按月折算 |
| 修缮与家电补足 |  |  |  | 实物查勘后填 |
| 欠费垫付（物业、水电燃气、供暖、车位） |  |  |  | 台账实数 |
| 风险准备金 |  |  |  | 中性档上浮两至三成 |
| **到手总成本** |  |  |  | 三档求和 |
| 对比：同小区可比普通二手真实成交价 |  |  |  | 取近期成交中位区间下沿 |
| **净溢价 / 净折价** |  |  |  | 总成本 − 可比价 |

**读法**：净溢价为正且在你容忍范围内 → 可继续；净溢价超出容忍度 → 回到出价上限压价；悲观档击穿容忍度 → 这套房的腾退风险超出定价体系能覆盖的范围，建议放弃。

## 二、税费与处置环节费用测算逻辑

### 1. 税费三段式

**自付段：买受人直接承担**
- 契税：税率与家庭住房套数、房屋面积、房屋性质相关；首套与二套差异明显，需按当地当期口径确认
- 印花税、登记费、登记测绘与评估等行政事业性费用
- 共有权人份额过户涉及税费分摊的，按份额比例计

**垫付段：法定纳税义务人常为卖方，但实务中需买受人先行垫付**
- 增值税及附加：与取得成本、持有年限、房屋类型相关；满一定年限的情形可能免征，需单独确认
- 个人所得税：一般按财产转让所得计征
- 土地增值税：涉及收入与扣除项目认定，金额较大时需专业人员测算

**随房段：随房走的欠费类**
- 物业费、供暖费、水电燃气、有线宽带、车位管理费
- 停供停暖恢复的条件与费用

### 2. 处置环节费用（读当次竞买须知，别凭经验）
| 项目 | 常见承担口径 | 备注 |
|---|---|---|
| 拍卖佣金 | 网络司法拍卖通常不单独向买受人收取；线下委托拍卖常按约定收取 | 以当次公告与竞买须知为准 |
| 平台服务费 | 视平台与法院安排，可能由买受人承担 | 金额明确，通常不大 |
| 评估费 | 通常由委托方承担 | 确认是否另有分摊条款 |
| 公告费、公告服务费 | 视约定 | |
| 竞买担保款（担保金性质款项） | 竞拍前缴付，未成交通常原路退还 | 竞拍成功但悔拍时通常不予退还 |
| 尾款 | 通常规定在竞拍后数日内一次性付清 | 逾期可能触发违约或悔拍责任 |
| 过户与登记费用 | 按规则 | |
| 评估与测绘、公告媒体等杂项 | 逐项核对 | 金额小但项目多，易漏 |

### 3. 关键提醒
- **纳税义务人 ≠ 实际垫付人 ≠ 终局承担人**。三者不一致时，向卖方追偿的实际回收率通常很低，因为卖方已是无力偿付的被执行人。所以测算时按"买受人全额先掏"计算，再评估能否收回。
- 公告中的税费承担条款是当事人之间的约定，不改变法定纳税义务人的地位；遇到金额大的税种，请专业人员复核处理方式。

## 三、竞拍策略与出价上限

### 1. 四个价格别混用

| 价格 | 来源 | 含义 | 常见误用 |
|---|---|---|---|
| 挂牌价 | 处置方或中介对外发布 | 吸引注意，常有上浮空间 | 拿来当成交价预期 |
| 评估价 | 评估机构出具，常按快速变现口径取值 | 起拍价的定价基础 | 当作市场均衡价 |
| 起拍价 | 法院或处置方按规则设定，常在评估价基础上打折 | 首次开拍门槛 | 当作"捡漏价" |
| 成交价 | 实际竞价结果 | 你真实付出的价格 | — |

**判断纪律**：市场均衡价只能从"同小区近期真实成交"里找，挂牌价不能用来比较。

### 2. 出价上限公式

```
心理价上限 = 同小区可比普通二手房近期真实成交价（中位区间下沿）
             − 应缴与垫付税费合计
             − 腾退成本（含时间折价）
             − 修缮与家电补足成本
             − 欠费垫付
             − 资金占用成本（尾款占用月数折算）
             − 风险准备金
             − 认可的净溢价容忍度（0 ~ 3 个百分点）
```

写出来给用户看，让每一项占多少一目了然。上限一旦算出，写成明确数字并当场确认"到 X 停手"。

### 3. 四条竞价纪律

| 纪律 | 具体做法 | 原因 |
|---|---|---|
| 设熔断线 | 出价前把上限写成明确金额，委托亲友或自己严格执行 | 现场有围观人数、有其他买家情绪推着走 |
| 留流拍位置 | 不在首拍用尽预算；流拍后通常有降价再拍安排 | 起拍价常高于市场均衡价，降价空间是机会 |
| 看参与结构 | 报名家数、是否有多家专业机构参与 | 客观提示竞争强度，避免高估自己的出价能力 |
| 事前算资金 | 竞拍日—尾款日之间留出税费、过户垫资、腾退过渡期借款 | 尾款逾期后果严重，现金流断裂比价格谈高几个点更致命 |

### 4. 流拍后的备选打法

| 情形 | 含义 | 该做什么 |
|---|---|---|
| 首拍流拍 | 起拍价高于市场接受度 | 记录流拍原因（是没报名还是没加价），判断是价格问题还是资格问题 |
| 降价再拍 | 价格下调但标的状态可能变化 | 重新核查一次：被执行人配合度、欠费累积、市场变化 |
| 变卖阶段 | 处置节奏与规则可能不同 | 重新读竞买须知，注意期限与付款条件的差别 |
| 以物抵债或协议处置 | 路径不确定性明显上升 | 重新评估是否还值得继续跟进 |

## 四、悔拍、尾款逾期与流拍的后果

| 事件 | 通常后果 | 事前应对 |
|---|---|---|
| 竞拍成功后悔拍 | 已缴担保款通常不予退还；可能被限制在一定期间内再次参与该标的竞拍；造成损失的还可能承担赔偿责任 | 把担保金视为已支出，纳入总成本上限 |
| 尾款逾期未付 | 通常按违约或悔拍处理，担保款不退，并可能承担相应责任 | 资金计划写到"尾款日到账"的银行流水层面 |
| 中途出现案外人异议 | 交割停滞，时间与资金成本上升，标的可能变价 | 把这项列入悲观档，并在上限里预留缓冲 |
| 标的存在登记居住权 | 取得产权但无法占有 | 视为阻断项，不出价 |

**资金计划模板**：
```
竞拍日 T
  ├─ T+0：缴担保款（额度：起拍价的一定比例，以竞买须知为准）
  ├─ T+3 ~ T+7（以竞买须知为准）：付尾款
  │    └─ 资金来源：自有 / 过桥资金，需提前预约
  ├─ T+15 ~ T+30：涂押、注销查封、办理过户（以当地办理周期为准）
  ├─ 交付节点：腾退完成、房屋交接
  └─ 期间支出：税费、腾退、修缮、过渡期租金、借款利息
```
每一环都要预留缓冲，缓冲依据是本单三档测算里的悲观档。

## 五、交付时该做的动作

- 交接单据列明：水电燃气读数、供暖、有线、家具家电归属、钥匙与门禁数量、门锁更换、物业欠费结清确认
- 现场拍照与录像留存（房屋现状、设施损坏、表读数）
- 要求处置方或执行法院出具腾退与交接的书面记录
- 确认户口迁出情况与结果，记录未迁出部分的处理方案
- 保存全部沟通记录与书面回复，作为后续争议的事实基础
