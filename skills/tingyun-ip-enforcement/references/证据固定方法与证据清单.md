# 证据固定方法与证据清单

## 一、四种固定方法的对比

| 方法 | 证明什么 | 大致成本 | 出证速度 | 适用场景 | 局限 |
|---|---|---|---|---|---|
| 公证证据保全 | 取得过程与内容真实性 | 单次数千元不等（含录制、刻录、封存等环节） | 一般 10 个工作日内出具（法定 15 个工作日内） | 关键证据、需要高证明力、需要固定交易全过程 | 成本高、耗时长、必须到公证处 |
| 可信时间戳 | 内容在特定时间已存在且此后未被篡改 | 每次约 10 元量级（各机构与服务不同） | 即时出证 | 批量固定网页、店铺页、作品底稿、源文件 | 单独使用证明力有边界，需配合过程留痕 |
| 交易取证（购买实物） | 市场上有真实交易、商品实物状态 | 货款 + 时间 | 自行控制 | 需要证明"有实际销售"、需要实物比对（专利）、需要销量与单价 | 只能固定单件，无法覆盖全部销售量 |
| 平台记录 | 平台对链接与主体的处理记录 | 近乎为零 | 随平台流程 | 证明平台已认定侵权、证明被投诉主体身份 | 属间接证据，需与其他证据配合 |

### 关于可信时间戳的证明力边界（重要）

司法实践中，时间戳认证证书能被采信，**通常不是因为出具机构本身权威，而是因为取证过程与时间戳结合形成了完整的证据链**。被对方质疑时，法院看的是：
- 取证过程是否有同步录像
- 视频文件与被保全内容是否分别做了时间戳认证
- 取证前是否做了计算机或设备的清洁性检查
- 全过程是否连续、有无剪接跳跃

**所以仅有截图 + 一张时间戳证书，强度是明显不够的。** 正确做法是：录屏取证时把"清洁性检查 → 打开设备 → 输入网址 → 页面滚动 → 点击查看详情"全程连续录制，把录像文件与页面内容分别做时间戳认证。司法实践中已有法院因这套完整链条而采信时间戳证据的案例，也有因缺乏过程留痕而被质疑的情形。

### 关于公证与时间戳的成本对照

网络电子证据保全公证的收费通常按件计，公证处公示的证据保全收费有不同档次（侵权行为和事实证据保全、声像资料与电脑软件保全等），实际执行中因需录制、刻录、保存光盘等环节，费用往往高于公示基准。可信时间戳的单次认证成本要低得多，适合批量场景。

**成本差异带来的策略含义**：批量固定的场景用时间戳，标志性单件用公证，两者组合使用往往是合理配置。这条建议要给出，但要提示用户以当地公证处与所选机构的实际报价为准。

## 二、通用取证规格要求

### 2.1 录屏取证的规格

| 要求 | 说明 |
|---|---|
| 连续性 | 从设备清洁检查开始到取证结束全程录制，不剪辑、不跳剪 |
| 环境信息 | 画面中出现浏览器地址栏完整 URL、账号登录状态、页面时间 |
| 轨迹完整 | 显示滚动过程、点击进入详情页的过程、翻页过程 |
| 设备与账户 | 记录使用的设备类型、登录账号（能关联到主体就录进去） |
| 双向固化 | 录像文件与被保全的页面内容分别做时间戳认证或公证 |
| 原始文件 | 保留原始录像文件与原始照片，不做二次编辑 |

### 2.2 截图的规格

- 完整保留地址栏、页面顶部信息、账号信息
- 不裁掉关键信息（很多投诉材料因裁剪导致关键信息缺失被驳回）
- 多张截图之间要有重叠，能拼出完整路径
- 截图本身再做一次时间戳认证

### 2.3 交易取证的步骤与留证

```
① 记录店铺信息：店名、店铺链接、主体名称、平台显示的经营者信息、客服回复记录
② 下单：保留订单号、商品标题、SKU、价格、销量/评价截图
③ 支付：保留支付记录（付款方与收款方）
④ 收货：保留物流单号、签收记录、开箱视频（连续拍摄，不间断）
⑤ 验货：拍实物细节（标识位置、包装、生产日期、批次码、材质做工），带比例参照物
⑥ 维权证据：向平台或商家发送的沟通记录、商家承诺、售后记录
```

**关键**：支付记录与订单截图能证明交易真实存在；开箱视频能证明所购商品与被诉商品是同一物；实物能支撑专利的技术特征比对。这三样加在一起，才能把"网页上的说法"变成"市场上存在实际交易"。

## 三、商标类证据清单

### 3.1 权属证据
- 商标注册证（核验：注册号、核定使用的商品/服务类别、有效期、当前状态）
- 商标状态查询结果（有无异议程序、无效宣告程序、连续三年不使用撤销的隐患）
- 权利人主体资格证明：营业执照（企业）或身份证件（个人）
- 若为被许可人投诉或维权：商标使用许可合同（注意未备案不影响效力，但需能证明许可关系与授权范围）
- 若为转授权：逐级授权文件链条完整

### 3.2 侵权证据
- 被诉标识的使用位置截图（商品标题、主图、详情页、店铺招牌、包装、说明书）
- 标识的近似点说明：图形构成、文字、读音、含义、整体视觉效果，以及在相同或类似商品上的使用是否容易导致混淆
- 类似商品判断的依据：功能、用途、生产部门、销售渠道、消费对象相同或相关公众认为存在特定联系
- 交易证据（同 2.3 全部步骤）
- 被诉主体的关联信息：店铺名称、店铺链接、经营者名称、客服账号、收款方、发货方、可能的关联店铺
- 持续状态：多次不同时间的截图，显示侵权行为在持续

### 3.3 损害与获利线索
- 被诉商品价格与己方商品价格的对比
- 平台显示的销量、评价数量（作为初步参考，不是确证数据）
- 己方商品的销售下滑数据、市场份额变化
- 促销与广告投入因对方出现的调整

## 四、专利类证据清单

### 4.1 权属证据
- 专利证书
- 专利登记簿副本（含法律状态、年费缴纳情况、权利变更）
- 年费缴纳凭证
- **专利权评价报告**（实用新型与外观设计专利在维权中的作用很关键：它可以作为审理、处理专利侵权纠纷的证据，被控侵权人也可以主动出具。实用新型与外观设计专利如果没做评价报告，在诉讼中评估会显著变难）
- 发明专利的申请公布文本与授权公告文本

### 4.2 侵权证据（这是三类中难度较高的一部分）
- **被诉产品与权利要求的技术特征比对表**：逐个权利要求、逐个技术特征，写明"被诉产品对应特征是什么""是否相同""是否属于等同特征"。**这一步是专利侵权案件的核心，不能只做外观对比**
- 被诉产品实物（用于比对，必要时送鉴定）
- 购得被诉产品的完整交易证据
- 生产端线索：包装上的生产企业名称与地址、生产批号、发货方信息、公开宣传材料（招工、厂房照片、产品目录）
- 被诉产品的销售规模线索

### 4.3 专利特有的抗辩点（要提前想到对方会说什么）
- 现有技术或现有设计抗辩：被控侵权人有证据证明其实施的技术或设计属于现有技术或现有设计的，不构成侵犯专利权
- 专利无效宣告程序：对方通常会提，用来拖延
- 权利用尽：专利产品或依照专利方法直接获得的产品，由专利权人或经其许可的单位、个人售出后，使用、许诺销售、销售、进口该产品的，不视为侵权
- 合法来源与在先使用抗辩
- 举证责任倒置情形：专利侵权纠纷涉及新产品制造方法的发明专利的，制造同样产品的单位或个人应当提供其产品制造方法不同于专利方法的证明

**注意**：涉及实用新型与外观设计专利时，被控侵权人也可以主动出具专利权评价报告。这意味着你的评价报告不是"我方的武器"，而是双方都会用的一把尺子。

## 五、著作权类证据清单

### 5.1 权属证据
- 著作权登记证书（**它是权属的初步证据，单独作为权属证据时证明力偏弱**，需配合其他证据补强）
- 创作底稿、草图、源文件、工程文件（带时间信息）
- 首次发表的证明：出版记录、发表页面、上线记录、登记证书记载的首次发表日期
- 创作过程记录：邮件往来、聊天记录、云端版本历史、提交记录
- 委托创作或职务创作的证明：委托合同、劳动合同、职务作品认定
- 转让或许可文件（若是受让方或被许可人维权）

### 5.2 侵权证据
- 被诉作品与权利人作品的对比：文字作品看具体表达部分；美术作品看整体视觉与构成；软件看代码与界面；影视作品看片段
- **实质性相似的说明**：哪些具体表达部分相同或近似
- **接触可能性的线索**：被诉方是否有渠道接触过作品（合作、公开传播、平台推荐、同行业展会等）
- 交易证据（若涉及销售复制品）
- 网络传播证据：链接、上线时间、播放量、传播范围

### 5.3 著作权特有的抗辩点
- 独立创作抗辩（不接触 + 不相似）
- 思想与表达二分：思想、题材、创意、通用手法不受著作权保护，只比较具体表达
- 合理使用与法定许可
- 作品未达到独创性要求的质疑

## 六、取证顺序与不可逆节点

**顺序原则**：先把不可逆的固定下来，再做可重复的。

```
【不可逆，越早越好】
① 平台页面取证（对方随时可能删链接、改标题、下架）—— 提交投诉当日同步启动
② 交易购买（对方随时可能察觉异常后停售或换品）
③ 实物购买与开箱（实物只有一件，耗损后无法复现）
④ 生产端线索（工厂会转移、注销、销毁包装）

【可逆或可补充，相对靠后】
⑤ 权属材料的补全（登记簿副本、评价报告、状态查询）
⑥ 损害与获利数据（需要对方账册，主要靠诉讼中的举证责任分配与法院调查）
⑦ 平台处理记录（投诉流程走完才有）

【强烈建议并行】
- 平台投诉与证据固定同时启动，不等投诉结果
- 权属补全与侵权取证同时启动
```

### 一个常被忽略的节点
**平台提交投诉后，被投诉方通常会在数日内收到通知并做出反应**（下架、改名、换图、停售）。这意味着：

- 提交投诉这一动作本身，是"惊动对方"的动作
- 如果你的取证还没做，投诉完再取证可能什么都取不到了
- 所以正确顺序是：**先固定关键证据 → 再提交投诉 → 提交后立即补取其余证据**

如果用户已经先投诉了才来找你，你要立刻提示："先别再做任何会惊动对方的动作，现在开始按不可逆顺序取证。"

## 七、证据包的组织方式

提交或交付时，按这个结构组织，避免散乱：

```
证据目录
├── 一、权属证据
│   1-1 商标注册证（副本加盖骑缝章）
│   1-2 商标状态查询结果
│   1-3 主体资格证明
│   1-4 授权文件（如适用）
├── 二、侵权证据
│   2-1 网页取证（每个链接一组：录屏 + 截图 + 时间戳证书）
│   2-2 交易证据（订单、支付、物流、开箱视频，按顺序编号）
│   2-3 实物照片（带比例参照物与编号）
│   2-4 主体关联信息汇总
├── 三、损害与获利线索
│   3-1 价格对比
│   3-2 销量/评价参考数据
│   3-3 己方销售数据
└── 四、证据说明
    4-1 取证方法与时间线说明
    4-2 证明目的对应表（每份证据对应证明什么事实）
```

**4-2 证明目的对应表是提升材料质量的关键**。审核人员与法官看材料时，需要快速判断"这份证据要证明什么"。每份证据后面用一句话写清证明目的，效率会明显不同。
