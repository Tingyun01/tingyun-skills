# tingyun-family-policy-audit

> 帮家庭年度盘点全部保单，核对保障缺口、缴费节点、失效风险与白扔的权益，输出待办清单
>
> 面向持有多份保单的家庭的年度保单体检助手。引导用户把家庭成员的所有保单汇总成一张表，核对保障类型与保额是否与当前家庭结构匹配、缴费日是否冲突、宽限期与失效复效节点、受益人与保费扣款账户、团险与增值权益是否被忽略、长期未用的保单是否已失效。

## 这个 Skill 做什么

把「家庭保单体检」这个场景最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

### 解决什么问题

大多数家庭的保单不是"买少了"，而是"不知道买了什么"：一份五年前在老家办的、每年自动扣钱却没人看过条款的保单；一张躺在抽屉深处的单位补充医疗；一张去年停缴、家人还以为在保的定期寿险。

**投保跨度长，记忆不可靠。** 保单常分散在十来年间的不同时间点与渠道。让人回答"家里一共几张保单、各保多少、什么时候扣钱"，答案通常是"记不清了"。记不清就无法判断风险是否被覆盖。

**保障责任模糊。** 大多数人知道产品名，不是保障责任。"我买了重疾险"——保额多少？保哪些疾病？受益人是谁？这些决定关键时刻能否派上用场的信息，恰是投保时最易跳过、事后最难补。

**增值权益被系统性忽略。** 住院垫付、就医绿通、康复服务、年度体检，通常要投保人另行登记才生效，不主动问就永远不知道。等到住院想用，才发现从没激活。

本技能把它整理成一套每年执行一次的动作：把保单摊到一张表上，核对客观数据，标出时间节点，产出待办清单。你得到的是**一份看得清家底的体检报告**。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 家里买了好几份保险都不知道保了什么
- 能帮我把全家保单理一遍吗
- 保单放在抽屉里好几年了还能不能赔
- 续保日期快到了我该注意什么

## 怎么用

1. 安装到你的 agent（Claude Skills 目录 / 扣子技能商店）
2. 直接用日常说法提需求，例如：
   家里买了好几份保险都不知道保了什么
3. 它会追问关键信息（缺的信息会标〔待补〕，不会替你编）
4. 输出可直接用的清单 / 对照表 / 台账

## 输出

- 判断步骤与检查清单
- 对照表 / 台账
- 待办与需要人工核实的问题

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
