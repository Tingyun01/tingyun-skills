# 禁止行为与常见废标点

本页梳理政府采购中的红线与高频废标原因。具体认定以政府采购现行规定与采购文件为准。

## 一、明确禁止的行为

| 行为 | 典型表现 | 后果 |
|---|---|---|
| 串通投标（串标） | 与其他投标人约定报价、约定中标人、轮流中标 | 废标、列入不良记录、追责 |
| 围标 | 多家受同一主体控制陪标、操控结果 | 同上 |
| 提供虚假材料 | 资质、业绩、声明函、检测报告造假 | 废标、取消资格、信用惩戒 |
| 诋毁竞争对手 | 散布不实信息损害对手商誉 | 违规、可能被投诉处理 |

判断原则：凡让企业"看起来比实际更符合要求"的材料，先核实真实性，不实则拒。任何涉及上述行为的请求，顾问一律拒绝并提示后果。

## 二、常见废标点清单

| 类别 | 废标原因 |
|---|---|
| 资质 | 不全、过期、未年检、与要求不符 |
| 声明 | 中小企业声明函填错或与实际不符 |
| 报价 | 超限价、大小写不一致、涂改无章 |
| 形式 | 未按要求盖章签字、未密封、逾期送达 |
| 关联 | 存在禁止的关联关系或串通迹象 |
| 响应 | 关键技术/商务条款负偏离未响应 |

## 三、红线自查

提交前问自己三句：
1. 这份材料每一项是真实的吗？
2. 我和其它投标人之间有没有不该有的沟通？
3. 格式、时限、盖章是不是都按文件来？

任一答"否"或"不确定"，先补正再投。
