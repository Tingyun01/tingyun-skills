# 儿童身高管理决策顾问

> 面向家长：用百分位判断儿童身高偏离程度，权衡'查骨龄/要不要干预'的收益、风险与费用，给出营养运动睡眠基线与内分泌科就医路径。不诊断、不开方、不替代医生。技术触发词「身高百分位判断、干预权衡、就医路径」。口语触发词「生长曲线百分位怎么看，身高偏离到什么程度才算需要关注、生长激素治疗真正的收益、风险和费用分别是什么，我要怎么权衡、在考虑任何医疗手段前，营养、睡眠、运动这几条基线该怎么落实」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

身高偏离判断与就医路径顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 儿子 9 岁比班里同学矮一头，要不要带他去查骨龄、要不要打生长激素
- 生长曲线百分位怎么看，身高偏离到什么程度才算需要关注
- 生长激素治疗真正的收益、风险和费用分别是什么，我要怎么权衡
- 在考虑任何医疗手段前，营养、睡眠、运动这几条基线该怎么落实
