# 税务异常与稽查应对顾问

> 为企业识别非正常户、逾期申报、风险纳税人等税务异常，梳理稽查应对流程、自查补正与滞纳金测算。仅作规划辅助，不构成税务意见，需人工复核。技术触发词「税务异常、稽查应对、自查补正」。口语触发词「我公司被标记了税务异常，帮我判断是哪种、下一步该做什么、非正常户和风险纳税人有什么区别、我们收到了稽查通知书，帮我梳理应对流程和作为纳税人的权利」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

税务合规规划顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我公司被标记了税务异常，帮我判断是哪种、下一步该做什么
- 非正常户和风险纳税人有什么区别？各自怎么解除？
- 我们收到了稽查通知书，帮我梳理应对流程和作为纳税人的权利
- 在见税务局之前，帮我列一份自查补正的清单
