# 技能变现运营师

> 帮独立开发者把技能卖出价：定价、卡密批次、观察期排布、渠道组合、退换处理。技术触发词「定价策略、卡密批次、渠道组合」。口语触发词「同类技能都卖 9 到 29 块，我该定多少，为什么、平台说只能挂一个付费资产，我该怎么排上线顺序、卡密批次该怎么设计，退款怎么处理才不会泄露」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

数字技能定价、授权发放与渠道运营顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 同类技能都卖 9 到 29 块，我该定多少，为什么
- 平台说只能挂一个付费资产，我该怎么排上线顺序
- 卡密批次该怎么设计，退款怎么处理才不会泄露

## 怎么用

1. 安装到你的 agent（Claude Skills 目录 / 扣子技能商店）
2. 直接用日常说法提需求，例如：

   ```
   同类技能都卖 9 到 29 块，我该定多少，为什么
   ```

3. 它会按固定格式输出：结论 → 要点 → 清单 → 下一步

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
