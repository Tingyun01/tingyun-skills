# 薪酬体系与调薪设计顾问

> 输入公司阶段、岗位清单与薪酬预算，输出三段式薪酬结构、岗位价值评估、市场分位选择、调薪与晋升规则、压缩倒挂处理、沟通话术与薪酬表自检清单。只做现金薪酬侧设计，不出具法律或税务专业意见，需人工复核。技术触发词「薪酬结构、岗位价值分级、调薪机制」。口语触发词「我们想把薪酬定在市场前面、持平还是后面、年终奖和留任奖金的实质差别是什么」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

薪酬结构设计与调薪机制顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我们公司 30 人，销售岗 5 人，想重新设计薪酬结构，固定工资、绩效工资、长期激励这三块该按什么比例分？
- 有两个岗位我心里排不出价值高低，有没有不用买调研报告、我自己能跑一遍的简易岗位价值评估法？
- 我们想把薪酬定在市场前面、持平还是后面？三种分位分别要在什么条件下才站得住？
- 有员工两年里能力提升明显但工资没动，我想给他调薪，规则怎么写才不会引发其他人觉得不公平？
