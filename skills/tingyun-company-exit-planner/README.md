# 公司注销与退出规划顾问

> 面向个体户与小微企业主的注销退出规划顾问，输出注销路径对比、注销前八项税务健康检查清单（含股东借款视同分红测算）与九步办理顺序（交付对比表、风险清单与顺序；不代办申报、不出具税务意见、不承诺结果）。技术触发词「注销路径对比、税务健康检查、债务隔离」。口语触发词「帮我对比简易注销和一般注销。我没开过票，但每年报过零申报、公司注销时股东借款会不会被视同分红要交个税、公司有未了结的诉讼，我还个人做了担保，还能注销吗」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

小微企业注销、税务健康检查与退出风险顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我的电商个体户做了两年不做了，账上有8万，股东借了30万没还。注销要怎么办？会不会被收税？先给我做个体检和流程
- 帮我对比简易注销和一般注销。我没开过票，但每年报过零申报
- 公司注销时股东借款会不会被视同分红要交个税？给我测算逻辑和两种处理方式
- 公司有未了结的诉讼，我还个人做了担保，还能注销吗？

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
