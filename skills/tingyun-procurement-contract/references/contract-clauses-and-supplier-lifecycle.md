# 采购合同必备条款、资质核查与供应商全流程清单

## 一、必备条款清单（八组）

每组列"必写内容 / 可选项 / 落地要点"。**判定某条要不要写的标准：真出分歧时，这条能不能直接拿去用。**

### 1.1 交付

| 必写内容 | 可选项 | 落地要点 |
|---|---|---|
| 标的名称、规格、图纸号与版本、数量与分批安排 | 品牌指定 | 图纸号版本必须与附件一致，写"按甲方确认图纸"等于没写 |
| 交付时间节点与地点、交付方式 | 分批交付的触发条件 | 时间写具体日期；分批要写每批数量与节点 |
| 包装方式、唛头、每箱数量、堆码要求 | 托盘规格 | 与仓储条件对齐，否则到货二次搬运 |
| 风险转移时点 | 卸货责任 | 写清"签收单签收后风险转移"或"到货验收合格后转移"，别留空 |
| 延迟交付的责任形式与计算方式 | 免责情形 | 写基数（合同额）、比例、上限，别只写"承担违约责任" |

### 1.2 验收

| 必写内容 | 可选项 | 落地要点 |
|---|---|---|
| 验收标准（引用需求书与图纸版本号） | 第三方检测机构 | 标准要能指向具体文件与版本 |
| 验收期限（到货后 X 个工作日内完成） | 验收费用承担 | 无期限 = 对方可以无限期不验 |
| 异议期（到货后 X 天内提出，逾期视为合格） | 隐蔽缺陷不受异议期限制 | 这是采购方较容易被删掉的一条 |
| 合格判定与不合格处理流程 | 降级接收的条件与折价规则 | 处理路径要写：退货/换货/返修/折价 |
| 抽检比例与判定标准 | 复检费用承担 | 写清抽样方式与判定依据 |
| 质保期内发现质量问题的处理 | 质保期与异议期的衔接 | 二者都要写，别只写一个 |

### 1.3 付款

| 必写内容 | 可选项 | 落地要点 |
|---|---|---|
| 各付款节点、比例、金额计算方式 | 发票类型与税率 | 节点写"触发条件 + 天数"，不写"按合同执行" |
| 付款触发条件（收到什么文件后 X 天内付） | 预付担保形式 | 触发条件要可验证：验收单 + 发票 + 对账单 |
| 发票与单据要求 | 承兑方式与贴现费用承担 | 写明需要哪几份单据、几份原件 |
| 逾期付款的责任 | 付款条件先于质保金返还 | 双向写才公平，单向写会被对方要求对等 |
| 质保金比例与返还条件与时间 | 质保金上限 | 返还条件写清"质保期届满且无未处理质量问题的书面确认" |

### 1.4 质保与售后

| 必写内容 | 可选项 | 落地要点 |
|---|---|---|
| 质保期起算点与时长 | 延长质保 | 起算点写"验收合格之日"，别写"交货之日" |
| 质保范围与除外情形 | 备件价格表 | 除外情形写明：人为损坏、超规范使用、不可抗力 |
| 响应时效与到场时效 | 服务等级与考核 | 分级：电话响应、到场、维修完成，三个时长分别写 |
| 备件供应年限与价格调整机制 | 停产通知期 | 写停产后继续供应年限（如 5 年） |
| 质量事故的处理与损失承担 | 客户索赔的分担 | 分担比例写清，避免全部推给一方 |

### 1.5 违约与救济

| 必写内容 | 可选项 | 落地要点 |
|---|---|---|
| 违约金种类、计算基数、比例、上限 | 实际损失赔偿 | 比例要给区间参考（如延迟交付每日 0.3‰，上限 5%） |
| 解除合同的触发条件 | 视为解除的情形 | 触发条件要可判断：连续两次延迟超 X 天 |
| 争议解决方式与管辖 | 协商前置期 | 写清适用规则与管辖地 |
| 通知与送达方式 | 送达地址确认 | 约定地址与邮箱，变更需书面通知 |
| 合同生效与附件效力顺序 | 附件清单 | 附件与正文冲突时以哪个为准，写明 |

### 1.6 保密

| 必写内容 | 可选项 | 落地要点 |
|---|---|---|
| 保密信息范围与例外 | 例外情形 | 例外写：公开信息、独立开发、依法披露 |
| 保密期限 | 商业秘密长期有效 | 期限写具体年数 |
| 人员与分包商的保密义务传递 | 返还与销毁义务 | 供应商须把保密义务传导到其分包方 |
| 违约救济 | 通知与披露程序 | 披露须提前书面通知 |

### 1.7 知识产权与模具归属

| 必写内容 | 可选项 | 落地要点 |
|---|---|---|
| 模具/工装所有权归谁 | 模具保管方与地点 | 归属方 + 保管方 + 维护责任三件事都要写 |
| 模具设计成果与图纸所有权 | 图纸交付范围与份数 | 图纸要写明交付形式与份数，含源文件与否 |
| 供应商既有技术的处理 | 背景技术许可条款 | 区分"背景技术"与"本项目成果"，前者不转移 |
| 终止合作时模具与图纸移交 | 移交期限与逾期责任 | 期限要具体（如终止后 15 个工作日内），逾期有责任形式 |
| 模具维护费用与寿命损耗 | 模具保养责任方 | 约定保养周期与责任方 |
| 侵权担保与第三方索赔处理 | 索赔抗辩与赔偿上限 | 供应商承诺交付物不侵犯第三方权利，并负责抗辩与赔偿 |
| 项目成果（图纸、工艺方案、配方）归属 | 改进成果归属 | 改进成果归属要写，否则后续改动说不清 |

### 1.8 廉洁与反商业贿赂

| 必写内容 | 可选项 | 落地要点 |
|---|---|---|
| 双方廉洁承诺与禁止行为清单 | 举报渠道与奖励 | 禁止行为要具体：现金回扣、好处、宴请、返利给个人 |
| 违反的后果（解除权、赔偿） | 单据审计要求 | 后果要能执行：立即解除 + 赔偿 + 列入黑名单 |
| 礼品与招待的处理规则 | 费用报销合规 | 给出金额门槛（如单次超过 200 元的招待须书面同意） |
| 举报与调查配合义务 | 调查费用承担 | 供应商须配合内部调查并提供记录 |

## 二、资质与证照核查清单

### 2.1 三类证照问题（按严重度排）

| 类型 | 说明 | 处理 |
|---|---|---|
| 硬否决一：证照无效或已过期 | 营业执照注销/吊销、许可证过期、认证过期 | 缓签或不签，无替代口径 |
| 硬否决二：范围不覆盖 | 经营范围不含本次标的；资质类别与标的不匹配（如无医疗器械经营许可却供医疗器械） | 缓签，要求补充或换供应商 |
| 高风险：主体或产线不一致 | 证照主体与实际供货方不同（代工）；认证工厂与实际生产厂不同；实际产线未覆盖认证范围 | 补充确认：实际产线现场照片、认证范围说明、代工关系书面披露；仍不清楚则缓签 |

### 2.2 逐项核查表

| 核查项 | 需要对方提供的证据 | 判定口径 |
|---|---|---|
| 经营主体 | 营业执照（副本） | 统一社会信用代码与合同签约方一致 |
| 经营范围 | 营业执照经营范围页 | 覆盖本次标的类目 |
| 存续状态 | 信用信息查询结果 | 正常存续，无吊销注销、无严重经营异常 |
| 签约授权 | 授权委托书 + 经办人身份证明 | 授权范围与期限覆盖本次签约；经办人签字或盖章与授权一致 |
| 生产许可/资质 | 相应行业许可证或资质证书 | 类别覆盖、编号可核、有效期覆盖交付期 |
| 体系认证 | 体系认证书 + 认证范围 | 认证范围含本次生产地点与产品；证书在有效期内 |
| 产品检测报告 | 有资质机构出具的检测报告 | 报告上的产品名称与型号与本次标的对应 |
| 质量体系责任人 | 质量负责人任职与授权 | 与实际对接人一致或已书面指定 |
| 财务状况 | 审计报告或资信证明（按需） | 与其报价规模匹配，排除明显异常 |
| 环保与安全 | 环保验收、排污许可、安全生产许可（按需） | 有效期覆盖，服务类采购常忽略 |
| 过往同类业绩 | 合同或验收单复印件（去敏） | 同类标的、同等规模，能提供联系方式核验 |
| 供应商廉政承诺书 | 廉洁承诺书 | 签署并纳入合同附件 |

### 2.3 缓签触发条件（出现任一项，先缓）

1. 证照无法提供原件或提供的是无法核验的复印件，且拒绝配合核验；
2. 有效期在交付期内到期，且不承诺续期；
3. 签约主体与收款主体不一致，且无法给出合理说明；
4. 要求付款到个人账户；
5. 资质是借用或挂靠，书面确认存在但拒绝把代工关系写进合同；
6. 关键检测报告的产品型号与本次需求不一致；
7. 拒绝签廉洁条款或拒绝接受反商业贿赂条款；
8. 拒绝提供授权委托书，理由是"我们老板直接签"但无法落实签字人。

**核实的动作边界**：只做书面与公开渠道核对。**不去实地验厂、不查个人征信、不做超出公开信息范围的反向调查**，这些交给采购体系内的专业机构或第三方。

## 三、供应商从引入到退出的全流程清单

### 3.1 引入阶段

| 步骤 | 动作 | 产出物 | 通过标准 |
|---|---|---|---|
| 1 需求登记 | 录入需求、预算、品类 | 需求登记表 | 预算与时间明确 |
| 2 供应商寻源 | 从既有库、展会、行业渠道、推荐中筛出候选 | 候选清单 | 候选数量≥3 或有单一来源说明 |
| 3 初步资质核 | 按第二节核查表过一遍 | 资质核查表 | 无硬否决项 |
| 4 需求书与询价 | 发同一版需求书与图纸 | 询价记录、报价单 | 口径齐全、报价有效 |
| 5 比价与定标 | 口径对齐、到手价测算、评分 | 比价表、定标记录 | 评审留痕、结论可复算 |
| 6 打样与封样（按需） | 样品试制、封样编号 | 封样记录 | 样品指标达标、双方签认 |
| 7 合同签署 | 条款谈判与定稿 | 合同正本、附件清单 | 必备条款齐、附件编号版本一致 |
| 8 准入建档 | 归档证照、报价、样品、合同 | 供应商档案 | 一户一档，可检索 |

### 3.2 合作阶段

| 节点 | 动作 | 频率 |
|---|---|---|
| 下单 | 按需求书与合同下订单，注明版本号 | 按次 |
| 过程跟进 | 交期确认、异常预警（延期、涨价、停产、证照到期） | 按里程碑 |
| 到货验收 | 按验收标准与期限执行，出验收单 | 按次 |
| 付款 | 按节点与触发条件执行 | 按节点 |
| 质量跟踪 | 不良率、退货率、客诉、返修记录 | 按月 |
| 绩效评价 | 质量、交期、价格、服务、合规五维打分 | 按季度或半年 |
| 证照续期提醒 | 到期前提醒并收新证 | 按证照周期 |
| 变更管理 | 需求变更、图纸变更、价格调整的书面确认 | 按需 |

### 3.3 退出阶段

| 步骤 | 动作 | 关键点 |
|---|---|---|
| 1 触发判定 | 连续不良超标、连续延期、证照失效、廉洁违约、商业行为、战略调整、主动替换 | 事先在合同或供应商协议里写明触发条件与处理路径 |
| 2 物料与库存处理 | 在手订单、在途货物、库存品、专用包装的处理方案 | 分：可继续用 / 可转用 / 报废 三类处置 |
| 3 模具与资产回收 | 模具、工装、图纸、专用设备、资料清单式移交 | 逐项核对签收，缺项书面追索 |
| 4 债权债务清理 | 未付货款、预付款退回、质保金结算、赔偿主张 | 逐笔对账，书面确认结清 |
| 5 保密与信息回收 | 回收图纸、样品、账号权限、保密义务延续确认 | 回收清单签收；保密义务在合同终止后继续有效 |
| 6 关系交接 | 若有替代供应商，安排试产与切换验证 | 切换时点与旧供应商退出时点衔接 |
| 7 档案封存 | 完整档案归档，标注"已退出"及退出原因 | 供后续复用与审计查询 |

### 3.4 退出时较容易漏的五项

1. **模具与工装**：合同没写归属，退出时拿不回来；
2. **在途与在手订单**：退出会引发交付纠纷，未结订单要先结；
3. **专用包装与标签**：库存作废，报废成本要预先算；
4. **质保责任**：退出不解除已交付产品的质保义务，需书面确认衔接；
5. **保密义务延续**：合同终止后保密条款仍然有效，要在终止确认书里写明这一点。

## 四、签约前自检表（勾完全部再签）

| # | 检查项 | 通过 |
|---|---|---|
| 1 | 需求书与图纸有版本号，报价引用同一版本 | ☐ |
| 2 | 九项口径已对齐，比价表落到到手成本层 | ☐ |
| 3 | 模具摊销分母用年度用量，不是首单量 | ☐ |
| 4 | 资质核查表逐项过完，无硬否决项 | ☐ |
| 5 | 交付时间、验收期限、异议期都写了具体天数 | ☐ |
| 6 | 付款节点写的是触发条件 + 天数，不是"按合同执行" | ☐ |
| 7 | 模具与图纸归属、维护、移交三件事都写了 | ☐ |
| 8 | 背景技术与本项目成果已区分 | ☐ |
| 9 | 廉洁条款已列入，签署方确认 | ☐ |
| 10 | 附件清单与正本编号一致，效力顺序已写 | ☐ |
| 11 | 授权委托书、经办人身份证明已收 | ☐ |
| 12 | 违约责任有基数、比例与上限，不是空条款 | ☐ |
| 13 | 争议解决方式与管辖已确认 | ☐ |
| 14 | 需求书与封样、检测报告作为附件收录并编号 | ☐ |
| 15 | 对账单与验收单样式已约定（付款触发要用） | ☐ |
