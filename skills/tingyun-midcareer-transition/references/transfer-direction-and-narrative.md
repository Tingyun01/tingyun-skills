# 可转方向评估框架 · 年龄叙事 · 副业转主业

## 一、可转方向评估框架（四步）

1. **列能力清单**：把当前工作拆成"硬技能 / 软技能 / 行业认知 / 人脉资源"四类。
2. **打分迁移性**：对候选方向，给"能力复用度（0–5）""入门门槛（资格证/学历，0–5 越高越难）""市场热度（0–5）"三项打分。
3. **算综合分**：迁移成本 = 入门门槛 − 能力复用度；优先选"复用度高、门槛低"的方向。
4. **小成本验证**：用 20 小时兼职/项目制接触目标行业，确认体感后再投入。

**迁移成本排序参考**
| 方向特征 | 迁移成本 | 建议 |
|---|---|---|
| 复用度高 + 门槛低 | 低 | 优先选，可快速变现 |
| 复用度高 + 门槛中 | 中 | 需补 1–2 项资质 |
| 复用度低 + 门槛低 | 中 | 适合兴趣/副业，难为主业 |
| 复用度低 + 门槛高 | 高 | 谨慎，时间成本单列 |

## 二、年龄叙事怎么讲（按面试场景）

**核心逻辑**：把"年纪大"重构为"成本低、产出稳、少试错"。

- **被问"为什么这个年纪转行"**：讲"能力平移"——"我过去 10 年练的是 X 能力，正好解决贵司 Y 痛点，转行只是场景切换，不是从零开始。"
- **被问"能不能加班/学新东西"**：用结果说话——"我用 2 周自学了 Z 工具并落地了项目（举例），学习方式成熟，不需要靠时间堆。"
- **被问"稳定性"**：反向利用——"家庭责任让我更看重长期扎根，离职率反而低。"
- **忌**：卖惨（"年纪大了没办法"）、攻击原行业、夸大转型热情而显得不务实。

**简历写法**：突出"成果 + 能力标签"，弱化年份堆砌；用"近 X 年聚焦"而非罗列全部工龄；项目经历按能力模块重组而非按时间。

## 三、副业转主业判定阈值

满足以下 3 条中 **2 条**，可考虑转：
1. 副业连续 3 个月收入 ≥ 当前主业收入的 40%；
2. 副业收入呈稳定或上升趋势（非一次性）；
3. 副业主业化后的合规与税务成本可承受（个体户/代账/社保自缴）。

**过渡路径**：副业试水（不影响主业）→ 收入达阈值 → 降低主业投入比例 → 主业收入被副业覆盖后正式切换 → 完成社保与税务身份变更。
