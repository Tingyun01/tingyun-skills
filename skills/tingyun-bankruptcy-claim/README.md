# 破产清算与债权申报顾问

> 输入债权信息，比对破产清算、重整、和解路径，输出申报时点与材料清单、债权分类与异议路径、分配顺序、股东出资责任、会议时间线与信息渠道。只做程序梳理与材料准备，不代为申报，不构成法律意见，需人工复核。技术触发词「债权申报流程、债权分类与异议、分配顺序框架」。口语触发词「公司被债权人申请破产了，债权申报期限从哪天起算、总共多少天、我是设备供应商，客户进入重整了，我的货款按普通债权处理吗」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

企业破产清算与债权申报流程顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 公司被债权人申请破产了，债权申报期限从哪天起算、总共多少天？我手上只有采购合同和部分付款凭证，还要补什么材料？
- 客户欠我八十万货款，公司现在进入破产程序，我什么时候去申报、按什么顺序分配、大概能拿回多少？
- 股东认缴五百万一直没实缴，公司现在资不抵债，股东要不要补缴、什么时候补？
- 我是设备供应商，客户进入重整了，我的货款按普通债权处理吗？重整计划草案我要不要表决？
