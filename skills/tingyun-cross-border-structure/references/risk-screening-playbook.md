# 风险信号与事前动作手册

覆盖实际经营地与常设机构、转让定价、受益所有人信息与信息交换、出口管制与制裁名单筛查四类高频风险。每项给出"信号 → 事前动作 → 触发条件"。

---

## 一、实际经营地与常设机构

### 1.1 常设机构风险源清单

| 风险源 | 常见触发场景 | 事前可做的动作 | 出现即升级 |
|---|---|---|---|
| 固定营业场所 | 在当地长期租办公室、仓库、展厅、仓储 | 核实租约用途与期限，评估是否有本地场所可被认定；必要时改用第三方仓储或共享办公并留存服务证据 | 租期跨年且人员长期驻场 |
| 依赖型 | 代理商以公司名义长期洽谈、签约、报价 | 在代理协议中限定权限范围、有效期，禁止代签与长期背书行为 | 代理协议无期限限制或允许代签 |
| 工程与项目型 | 长期驻场实施、设备安装、督导 | 按项目周期设计人员与场地安排，明确项目结束即撤场 | 项目周期连续、无中断记录 |
| 服务提供型 | 员工或顾问在境内持续提供销售、技术、安装服务 | 事先了解当地对"提供服务的常设机构"判定口径，明确服务合同主体与收费方式 | 员工常驻超过当地标准时长 |
| 采购与仓储 | 大宗备货、寄售、寄仓 | 明确货物所有权归属与仓储责任方，选择由第三方承担库存职能 | 自有仓存放于当地且规模持续扩大 |

### 1.2 事实与结构一致性检查表

结构设计的目的是让"结构"与"事实"说同一件事：

```
问 1  当地有没有人长期办公？         → 有 → 结构里要体现该地人员与职能
问 2  决策在哪里做出？                → 境外 → 治理文件、会议记录、签署地要一致
问 3  货从哪里发、库存放在哪？        → 在当地 → 仓储与服务安排要一致
问 4  客户合同谁签、以谁名义？        → 境外主体 → 当地实体的角色要能解释
问 5  风险由谁承担、出事谁负责？      → 不一致 → 结构与保险、担保安排要一起调
```

任何一问答不上来，说明存在"结构与事实脱节"，这正是被重新认定纳税义务的起点。

### 1.3 人员流动的驻外时长管理

| 动作 | 说明 |
|---|---|
| 建立驻外台账 | 记录每次外派的起止日期、地点、角色、审批人 |
| 设置上限与审批 | 对超过特定天数的驻外安排要求额外审批并评估影响 |
| 保留行程证据 | 机票、住宿、考勤、客户拜访记录 |
| 周期复核 | 每季度核对台账与实际派驻情况是否一致 |

台账的作用不是"记录违规"，而是让驻外事实可解释、可核对。

## 二、转让定价与关联交易

### 2.1 需要能解释的关联交易类型

| 类型 | 常见内容 | 需要准备的东西 |
|---|---|---|
| 服务费 | 管理服务、研发支持、售后支持 | 服务范围清单、成本归集方法、定价公式、第三方比价 |
| 特许权使用费 | 商标、专利、软件授权 | 许可范围与期限、关联度分析（研发支出占比）、定价基准 |
| 采购与销售 | 集团内采购、成品转售 | 采购价依据、市场比价、库存与毛利分配说明 |
| 资金往来 | 股东借款、资本金 | 借款协议、利率、期限、资本金到位证明 |
| 成本分摊 | 集团费用分摊 | 分摊动因、分摊基础、分摊方法一致性说明 |

### 2.2 文档准备清单

| 文档 | 作用 | 触发条件 |
|---|---|---|
| 主体文档 | 集团整体关联交易政策与组织结构 | 集团存在跨境关联交易即需准备 |
| 本地文档 | 单一实体层面的转让定价分析 | 达到门槛或被要求时准备 |
| 国别报告 | 集团各法域的税收与经济数据 | 按门槛适用 |
| 支持性资料 | 成本归集、转让定价可比分析 | 定价采用非标准方法时 |
| 预约定价安排申请 | 事先与主管机关确认定价方法 | 交易金额大、结构复杂、争议风险高时适用 |

### 2.3 高频质疑点

- **利润分布与价值创造不匹配**：利润集中在无实质的持股层，而研发与市场活动在别处。这是被质疑的高频点。
- **无实质的持股层**：只有注册地址与名义董事，没有决策、雇员与开支记录。
- **定价公式与实际执行不一致**：合同约定成本加成，执行中却用其他方式结算。
- **同期资料缺失或过期**：超过适用期限未更新。

事前动作：把"为什么是这个利润分布"写成一份内部说明，和商业逻辑一起归档。

## 三、受益所有人信息与信息交换

### 3.1 压力来源

各法域正在推进税务信息自动交换，持股链条上的中间层如果只有名义股东，信息交换与后续核查会指向实际受益人。同时：

- 享受税收协定待遇通常需要满足受益所有人判定（可参照公开上市、持股比例、收入门槛等判定标准）
- 反洗钱与客户尽职调查要求金融机构向上穿透到实际受益人
- 母公司对子公司的信息义务（持股、受益所有人、财务信息）在多地已成常规要求

### 3.2 事前动作清单

- [ ] 持股链条每一层的实际受益人是否清晰、有书面记录
- [ ] 中间层是否有真实功能与真实收益来源（分红、服务费、许可费）
- [ ] 各地信息申报义务（工商、税务、外汇）是否已建档，谁负责、什么时点
- [ ] 股东名册与受益所有人名册是否定期更新（人员变动时同步）
- [ ] 集团内是否有统一的"实体台账"（成立时间、功能、持股、雇员、账簿所在地、申报义务）

实体台账是成本不高、收益很高的一件事：核查一来，翻台账就能回答大部分问题。

## 四、出口管制与制裁名单筛查

### 4.1 筛查对象清单

| 对象 | 为什么必须筛 |
|---|---|
| 客户与买方 | 直接交易对手 |
| 实际收货人与终端用途方 | 需求方可能与合同方不同 |
| 中间贸易商与转口方 | 链条上任何一环都可能改变流向 |
| 物流与货代 | 承运路线可能经过受限制司法辖区 |
| 银行与支付通道 | 资金链路合规 |
| 集团内其他实体 | 内部交易同样受管 |
| 技术支持与软件服务 | 服务与数据传输可能被纳入管制范围 |

### 4.2 筛查维度

- 各类制裁名单（按适用辖区分别管理）
- 管制物项与技术类别的判定（产品、软件、技术资料是否落入管制范围）
- 需要特别许可的司法辖区与终端用途限制
- 所有权与控制关系（个人与实体是否被实质控制）
- 行业特定限制

### 4.3 筛查制度三要素

```
谁负责     → 指定岗位与备份人，不能是"人人负责"
什么时候筛 → 签约前、收款前、发货前、客户信息变更时
留多久     → 按可核查期限留存筛查记录与命中处置记录
```

### 4.4 命中处置流程

```
命中 → 暂停交易推进
     → 记录命中项与比对依据
     → 核实是否为误报（同名、名称变体、国籍变更）
     → 真实命中：上报合规负责人与法务/专业机构评估
     → 决定终止、要求前置条件、申请许可、或其他处置
     → 归档全部处置记录
```

判断要点：**命中不等于违规**，但**没有筛查流程等于把风险全接了**。事前建立流程与事后被查到，风险量级差别很大。

## 五、风险排序方法

按"发生概率 × 影响程度 × 事前可控度"给风险排序，先处理可控度高、影响程度大的项：

| 优先级 | 特征 | 典型事项 |
|---|---|---|
| P0 | 影响大且事前完全可控 | 合同主体与争议解决条款、筛查流程建立、代理协议权限约定、实体台账与名册更新 |
| P1 | 影响大但需要外部专业判断 | 常设机构判定、转让定价方法、协定待遇适用 |
| P2 | 影响中、可在运营中调整 | 资金路径优化、雇员结构、许可补充材料 |
| P3 | 影响中、触发频率低 | 商标在个别市场的补充注册、非关键单据格式 |
