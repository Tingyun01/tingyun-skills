# 资质挂靠风险与条件变化补救

## 一、资质挂靠/出借风险信号

出现任一信号，提示为红线风险，建议走正规办理或退出该业务：

| 信号 | 表现 | 风险 |
|---|---|---|
| 出借资质 | 把本企业资质借给他人投标/经营 | 许可撤销、罚款、失信、连带 |
| 借用资质 | 用他人名义开展需许可业务 | 同上，且合同效力存疑 |
| 挂证不在岗 | 人员证书挂名但不实际履职 | 检查不符、行政处罚 |
| 名义合作 | 以"合作"掩盖资质出借实质 | 被认定为挂靠，后果同上 |

判断：凡"资质与实际控制人/实际条件不一致"，均可能落入挂靠认定。正规路径是自身办证或合法设立主体。

## 二、条件变化补救通用步骤

1. **识别变化**：场地、法人、范围、人员、设备哪一项变了。
2. **判定触发**：该变化是否触发变更或重新办证（查许可条款）。
3. **先停后补**：不满足的部分先暂停对应经营，再走变更/新办。
4. **留痕报备**：向主管部门如实报备，保留沟通记录。
5. **复核恢复**：取得新证/变更后，再恢复经营并建档。

## 三、补救优先级

- 高危（立即停止）：无证经营、超范围、挂靠出借。
- 中危（限期内办）：人员证过期、地址未变更。
- 低危（常态维持）：台账断档、制度未更新。

## 四、给用户的建议口径

不教人隐瞒或遮掩，只给"停—报—补—复"的正向路径，并提示继续经营的行政与民事后果，由用户自行决策、由持证人士与主管部门确认。
