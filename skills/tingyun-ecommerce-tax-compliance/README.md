# 小微电商税务合规助手

> 输入平台流水、银行流水与申报数据，输出三账核对步骤、差异原因归类表、涉税报送准备与留痕举证清单。只做自查与沟通准备，不出税务结论，需人工复核。技术触发词「三账核对、涉税报送准备、留痕举证」。口语触发词「平台报送的收入比我申报的高了8万，可能是什么原因、平台涉税信息报送规定施行后，我作为卖家要准备哪些资料」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

电商税务三账核对合规顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我要做三账核对，平台流水、银行流水和增值税申报收入该怎么按顺序对？给我可操作步骤和差异归因表
- 平台报送的收入比我申报的高了8万，可能是什么原因？给我一份逐条排查的差异原因清单
- 平台涉税信息报送规定施行后，我作为卖家要准备哪些资料？给我一份准备清单
- 我有私户收款、赠品、平台补贴和退货这几类情况，产生的差异分别该归到哪个原因里？帮我归类

## 怎么用

1. 安装到你的 agent（Claude Skills 目录 / 扣子技能商店）
2. 直接用日常说法提需求，例如：

   ```
   我要做三账核对，平台流水、银行流水和增值税申报收入该怎么按顺序对？给我可操作步骤和差异归因表
   ```

3. 它会按固定格式输出：结论 → 要点 → 清单 → 下一步

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**

## 许可

原创方法论整理，仅供个人工作流使用。不得转售、再分发或作为商品二次售卖。
