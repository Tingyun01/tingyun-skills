# 求职目标界定与能力盘点

> 本页提供填写用的表格与模板。用户按自己的实际情况填写，本页不代填、不虚构。

## 一、目标四要素界定表

四要素缺一不可。缺"薪资底线"会在谈判时失去锚点，缺"可迁移能力"会导致简历无法定向。

| 目标职级 | |

**判断标准**：能写出 2~3 个具体岗位名称，才算定清楚。只写"互联网行业""管理岗"不算。

### 2. 目标城市

| 项目 | 填写内容 |
|---|---|
| 优先城市 | |
| 可接受的第二城市 | |
| 是否接受异地/ 远程 | |

**判断标准**：城市选择要和现实约束对齐。为一个不成立的岗位池硬投，是投递无回音的常见原因。

### 3. 薪资三档

**这一步必须写出三个数字，而不是一个。**

| 档位 | 数字 | 说明 |
|---|---|---|
| 理想值（税前月薪或总包） | | 有竞争力但可遇不可求的区间 |
| 可接受值 | | 拿到就愿意签的水平 |
| 拒绝值（底线） | | 低于此线则放弃这个机会 |

再拆一层，把薪资拆成结构，避免只看一个总数：

| 构成 | 你的数字 | 说明 |
|---|---|---|
| 固定月薪 | | |
| 年终奖月数（按几个月算） | | |
| 绩效系数预期 | | 绩效是打折还是有保底 |
| 股权/期权价值 | | 折算方式与流动性 |
| 签字费 | | 是否有、一次性还是分期 |
| 补贴与其他 | | 交通、餐补、租房补贴等 |
| 到手估算 | | 扣除社保公积金与个税后的实际到手 |

**判断标准**：如果只写一个数字，面试官一问"期望多少"你就会把底线交出去。

### 4. 可迁移能力

## 二、可迁移能力盘点法

### 第1 步：列出关键经历

列 3~5 段，每段用一句话写清：什么场景、我做了什么、产出了什么结果。

| # | 场景 | 我的角色与动作 | 结果 |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| 3 | | | |
| 4 | | | |
| 5 | | | |

选经历的标准：与目标岗位相关的优先；即使不相关但能量化、能体现方法论的也可留作备选。

### 第 2 步：拆出能力

对每段经历追问：用了什么方法？承担了什么责任？带过什么人？协调过什么资源？

### 第 3 步：判定可迁移性

| 档位 | 判定标准 | 处理方式 |
|---|---|---|
| 直接可用 | 目标岗位明确要求，且我有可验证成果 | 放简历前段，作为主打卖点 |
| 需要转译 | 底层能力相同，但术语、场景、评价口径不同 | 写桥接句，用对方语言重述 |
| 用不上 | 与目标岗位无关 | 压缩篇幅，不占注意力 |

### 第 4 步：给"直接可用"的每项配证据

| 能力 | 证据类型 | 证据示例 |
|---|---|---|
| 数据分析 | 规模 | 分析过 2000+ 条订单数据 |
| 项目推进 | 周期与协作方 | 协调 5 个部门推进 3 个月上线 |
| 客户沟通 | 客户量与留存 | 对接 30 家客户，续约率 85% |
| 带团队 | 人数 | 带 4 人小组，成员均晋升 |
| 流程优化 | 前后对比 | 审批时长从 3 天压到 4 小时 |

### 第 5 步：为"需要转译"的写桥接句

**模板**：
> 我在原岗位负责 {原场景}，做法与 {目标岗位} 的 {目标场景} 一致，差别只在 {行业/客户/规模}，迁移后需要适应的部分是 {具体差异}。

**示例（硬件转产品）**：
> 我在原岗位负责硬件产品线的需求评审与量产交付，做法与产品经理的需求定义和排期一致，差别在决策依据从技术可行性变为市场验证，迁移后需要适应的是用用户反馈而非器件参数来排优先级。

**写桥接句的三个检查点**：
1. 有没有落到目标岗位真的在做的事上
2. 有没有诚实说明差异（面试官一定会追问，事先说明比被问出来好）
3. 有没有说明适应路径（说明你知道差距在哪、准备怎么补）

## 三、简历按目标岗位重写步骤

```
第 1 步 读岗位描述并标关键词   → 抄下职责与要求，标出反复出现的词
第 2 步 用关键词筛经历          → 与目标无关的段落删掉或压缩
第 3 步 重写开头一句            → 身份 + 能解决什么问题 + 目标方向
第 4 步 统一段落结构            → 场景 → 我做了什么（动词开头）→ 结果（带数字）
第 5 步 跨行业做术语转译        → 用目标行业语言重述原经历
第 6 步 校对                   → 错别字、时态、位置、联系方式
```

### 改写对照表

| 常见写法 | 问题 | 改写方向 |
|---|---|---|
| 负责公司官网内容运营 | 没有结果，看不出水平 | 补运营动作与量化结果 |
| 熟悉项目管理流程 | 只有能力名词，无案例 | 换成主导过的项目与关键数字 |
| 参与了数据平台建设 | 角色不清 | 写清你负责的模块与决策 |
| 沟通能力强 | 无法验证 | 换成具体场景与结果（跨部门协调几个方） |
| 有多年行业经验 | 年限本身不构成价值 | 换成该年限内积累的判断与方法 |
| 负责部门行政工作 | 与目标岗位无关 | 删掉，用空间换给相关经历 |

### 开头句写法

> 我是 {行业/年限} 的 {职能}，做过 {一件有代表性的事}，{一项可验证的能力}是我的强项。现在想转到 {目标方向}，因为 {具体动因}。

跨行业时，把目标行业语言放在前 1/3，原行业经历后置并加桥接句，避免读者在开头就流失。

**关键字段说明**：
- **简历版本**：标记用了哪一版，方便后面归因（哪一版转化好）
- **状态**：区分"已投递"和"已结束"，否则漏斗统计会失真
- **下一步动作**：写具体动作与时间，不写"等消息"

## 五、本阶段自检

定完目标后，用这几条自查：

- [ ] 能说出 2~3 个具体的target岗位名称
- [ ] 写了理想/可接受/拒绝三个薪资数字
- [ ] 列出了 3~5 项带证据的可迁移能力
- [ ] 至少写了 1 条桥接句
- [ ] 简历开头句已按目标岗位重写
- [ ] 简历中与目标无关的经历已删减
- [ ] 投递记录表已建立，简历版本已编号

若前四项有缺项，先补齐再进入投递环节——方向没定就投，邮件量再多也难有回音。
