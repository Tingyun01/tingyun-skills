# 微商选品与压货决策顾问

> 帮小微卖家判断：这个品该不该进、这批压货怎么出、卖给谁。给出可执行的判断与动作清单。技术触发词「选品判断、客群匹配、压货处理」。口语触发词「我想进一批货，帮我判断这个品值不值得做、卖给谁、我压了 200 件货，清仓、换个渠道还是降价、供应商要我多拿量给好价，我该先确认什么再决定」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

微商选品、客群匹配与压货处理决策顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我想进一批货，帮我判断这个品值不值得做、卖给谁
- 我压了 200 件货，清仓、换个渠道还是降价？帮我算清楚哪个划算
- 供应商要我多拿量给好价，我该先确认什么再决定
