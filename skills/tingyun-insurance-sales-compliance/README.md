# tingyun-insurance-sales-compliance

> 按监管处罚案例逐条体检保险销售全流程合规状况，输出风险分级与整改台账
>
> 面向中小保险中介机构、保险专业代理机构与转型独立代理人的销售合规自查顾问。按双录、销售适当性、夸大承诺、返佣费用、保费管理、未如实告知、销售误导、无证展业、自保互保、数据消保十组三十项检查，逐项给出怎么查、常见表现、监管依据与风险等级，配套真实行政处罚案例库与可自查脚本，输出风险分级与整改台账。

## 这个 Skill 做什么

把「保险销售合规」这个场景最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

### 解决什么问题

监管处罚不是抽象的。近十八个月公开的处罚公示里，双录不合规、销售误导、给予合同外利益、虚列费用、未如实告知、委托无资格机构展业这六类反复出现，单笔机构罚款从 0.5 万元到 70.5 万元不等，个人同步单罚。

问题是：**大部分中小机构不知道该查哪几项，也不知道自己已经踩了哪几条。** 现有材料要么是几万到几十万的合规 SaaS（买不起），要么是律师普法讲座（听完不知道怎么落到自己的台账上）。

这个技能把公开处罚案例拆成可执行的自查动作——每一项都写清楚「怎么查、常见什么表现、依据是哪条、风险多高」，配一个本地脚本自动生成风险分级和整改台账。

**核心用法**：先跑脚本拿风险分，再对着检查项逐项人工核。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我们支公司双录怎么做才不会被罚
- 销售适当性要留哪些东西
- 有哪些保险销售的红线不能碰

## 怎么用

1. 安装到你的 agent（Claude Skills 目录 / 扣子技能商店）
2. 直接用日常说法提需求，例如：
   我们支公司双录怎么做才不会被罚
3. 它会追问关键信息（缺的信息会标〔待补〕，不会替你编）
4. 输出可直接用的清单 / 对照表 / 台账

## 输出

- 判断步骤与检查清单
- 对照表 / 台账
- 待办与需要人工核实的问题

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
