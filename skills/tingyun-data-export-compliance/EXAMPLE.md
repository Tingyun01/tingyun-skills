# 产出示例：数据出境与跨境合规顾问

> 这是一个**真实格式**的产出示例（内容为结构演示，非具体案件结论）。
> 买之前你应该知道它交付出来长什么样。

## 输入

```
我们公司要做一个面向海外客户的后台系统，境内收集了境内员工的身份证号和手机号，也把境内用户的行为数据同步到境外云。这算数据出境吗？需要走哪条路径？
```

## 输出（结构演示）

```markdown
### 一、结论先行
（3 行以内说清：这件事是什么性质、当前最大风险在哪、现在最该做的一件事）

### 二、关键判断点
| # | 判断点 | 怎么认定 | 你的情形 |
|---|--------|----------|----------|
| 1 | ……    | ……      | ……      |
| 2 | ……    | ……      | ……      |

### 三、行动清单
- [ ] ……（要做什么 + 谁做 + 什么时候之前）
- [ ] ……

### 四、风险与红线
- 不可碰：……
- 需转专业机构：……
```

## 为什么这样交付

因为这类事情**贵在不出错，不在说得漂亮**。所以输出是清单和对照表，不是长篇分析；
先给结论再给依据，让你 30 秒内知道该不该慌、下一步做什么。
