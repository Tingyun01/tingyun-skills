# 干预决策与资源衔接

## 干预强度阶梯（按评估结论逐级对应）
1. 家庭引导：适用于仅略慢、各项达标者。日常游戏、绘本、互动为主。
2. 机构小组课：适用于单项触线、需结构化引导者。
3. 机构个训：适用于多项触线、需一对一强化者。
4. 医疗康复：适用于确诊、需治疗性康复者，由医疗机构出具方案。

> 不盲目拉满：先按评估结论的起点档位介入，按月复盘再调。

## 机构选择标准
- 资质：医疗机构看《医疗机构执业许可证》与科室设置；康复/特教机构看民政或教育主管部门备案。
- 流程：先评估后定方案。拒绝"不评估直接卖课包"。
- 透明：目标、频次、周期、费用书面化，可量化。

## 医保与特教衔接方向
- 康复救助：部分地区对持证残疾或发育迟缓儿童有康复救助/门诊报销，需先到指定机构评估建档。
- 特殊教育：持评估结论可向当地特殊教育指导中心或随班就读资源教室咨询。
- 以上政策因地而异，资格、额度、流程以当地主管部门公布口径为准。
