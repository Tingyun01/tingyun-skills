# 投标前合规自检表

提交前逐条打勾，任何"否"都先补正再投。本表为通用框架，以采购文件具体要求为准。

## 一、资质与主体

- [ ] 营业执照在效期内，与投标主体一致
- [ ] 采购要求的专项资质/许可齐备且有效
- [ ] 无被限制投标的不良记录（自查）
- [ ] 联合体/分包（如适用）材料齐全

## 二、中小企业声明

- [ ] 声明函按文件格式填写
- [ ] 划型数据与可核实来源一致
- [ ] 签章完整、无涂改

## 三、报价与商务

- [ ] 报价未超采购限价
- [ ] 大小写一致、涂改处盖章
- [ ] 商务条款无负偏离或已按要求响应
- [ ] 交货/服务期满足要求

## 四、技术与形式

- [ ] 关键技术参数逐条响应
- [ ] 投标文件的格式、份数符合要求
- [ ] 盖章、签字、法人授权齐全
- [ ] 密封与标识符合规定

## 五、合规红线

- [ ] 所有材料真实，无虚假内容
- [ ] 与其它投标人无不当沟通（串标/围标）
- [ ] 未诋毁竞争对手
- [ ] 送达在截止时间前

## 六、结论

- 全部打勾 → 可投。
- 任一项"否" → 标注风险，补正后再投。
- 涉及红线项（虚假/串通/诋毁）→ 立即停手，不可投。
