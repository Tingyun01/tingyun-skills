# 装修报价单增项防守助手

## 一、这个技能解决什么问题

业主真正难受的不是"看不懂材料清单"，而是**看不懂别人写给他的那份合同附件**。

**漏项是行业系统性现象。** 报价单是销售工具，条目越少越容易报出"看起来不贵的总价"；施工时该有的工序一项都不会少，缺的部分只能以增项回来。业主拿到的往往是一份"看起来很全"但口径没锁死的清单。

**问题性质是"没说清"，不是"报贵了"。** 同样一套水电改造，写"400 米 × 120 元"和写"400 米 × 120 元（按实际发生）"，前者锁死、后者开放。差别不在价格高低，在条款是否留了后路。

**金额可量化，痛点就能量化。** 每行都有金额，"缺什么、留了什么口"最终落到可估算的区间上。这让"看不懂"变成"看得清但说不破"——而谈判需要的恰恰是后者。

本技能做的事：**逐行拆成可核对要素，标出开口条款，算出风险量级，给出能直接说出口的话术和能直接粘进合同的条款。**

## 二、适用与不适用

**适用：** 手上有装修公司的报价单（纸版、照片、表格、截图均可）；想知道自己是否可能被增项、大概增多少；想弄懂"按实结算""综合费用"的含义；想在签合同前补上关键条款。

**不适用（硬边界）：**
- **不做工程造价鉴定，不评价工程合理性。** 不回答"这项目贵了""这单价应该多少""这份报价亏不亏"，只回答"这条写清楚了没有"。
- **不出具法律意见。** 条款文本是谈判素材，不是法律结论。重大合同请咨询执业律师。
- **不做装修预算规划**（不帮业主从零做方案与预算分配），**不替业主谈判**（只给话术），**不推荐品牌**（只检查"写没写明"）。

## 三、报价单六要素拆解法

每行报价单都应能被这六个要素回答。缺一个，这一行就是不可控的。

| 要素 | 怎么看 | 缺了会怎样 |
|---|---|---|
| **项目** | 名称是否具体到能判断"这一项到底做了什么" | 写成"综合费用"时无法核对包含范围，也不知道是否重复计费 |
| **单位** | 计量口径：㎡、米、延米、项、个、樘、车次 | 单位不明则结算无基准；同大类混用单位（延米与㎡）易折算重复 |
| **数量** | 确定值还是"约""暂定""按现场定" | 数量待定 = 金额未锁定，主动权全在对方 |
| **单价** | 包干单价还是"暂定""面议" | 单价待定则总价只是参考数，谈不上预算控制 |
| **是否按实结算** | 找"按实""实报""据实""以实际发生为准" | 最典型的活口：报价金额不是最终金额，且通常无上限 |
| **是否写明品牌型号** | 具体品牌+型号+规格，还是"优质""合资""一线" | 只写修饰词时，换料不算违约，也无法同品牌比价 |

**顺序建议：** 先横向扫"是否按实结算"和"品牌型号"两列（活口最密集），再逐行核对项目与单位。

## 四、十大活口条款清单

每条五个维度：条款长什么样 / 留了什么后路 / 金额量级 / 怎么改写 / 合同里补哪句。

| # | 条款长什么样 | 留了什么后路 | 金额量级（常见参考） | 怎么改写 | 合同里补哪句 |
|---|---|---|---|---|---|
| 1 | **按实结算**：水电 400 米 × 120 元（按实际发生） | 金额只是预估，按现场量结算且无上限 | 上浮 10%–30%（水电 15%–25%） | 改包干价，增减不超 ±5%，超出须书面确认 | 约定计量方式、结算上限、确认流程 |
| 2 | **名称笼统**：综合费用 6000 元、零星辅材若干 | 范围不明可无限扩张，且可能与已列条目重复 | 争议金额数百至数千元 | 逐项拆成可核对条目，拆不出的删除 | 不得以概括名替代；零星费用须逐笔书面确认并注明单价 |
| 3 | **品牌只写等级**：乳胶漆 一线品牌、瓷砖 优质款 | 等级词不是品牌，换料换系列换产地都不算违约 | 品牌不明项上浮 8%–20% | 写"某品牌 XX 系列 XX 型号 XX 规格"，换品牌须书面同意并调价 | 品牌型号须书面附件列明；擅自更换有权要求更换 |
| 4 | **数量待定**：拆除若干、开槽按现场、点位暂定 20 个 | 报价金额不成立，对方可在任何时点主张增加 | 没有金额上限，最难封顶 | 给出上限数量，超出按约定单价另行书面确认 | 暂定数量须写明上限数量与超出单价 |
| 5 | **单价待定**：水电单价面议、辅材暂定 60 元 | 单价 × 数量 = 金额，单价不定则总价不定 | 占比 10% 以上科目，单价浮动 20% 即可拉动总价 | 暂定单价 60 元/m，调整须书面确认且不超 ±10% | 暂定单价须写明数值、浮动上限与确认方式 |
| 6 | **以实际发生/现场为准**：垃圾清运以实际发生为准 | 定价权交给现场判断，连被动对账基准都没有 | 清运类争议幅度 20%–50%；车次不足、超距是主因 | 按 X 车次包干，超出每车次单价 Y 元并须书面确认 | 须写明计量方式、单价、上限、确认流程四项，缺一不成立 |
| 7 | **增项不设上限**：只写"增项按实结算"，无总价上限条款 | 合同金额上限开放，"包干"二字不构成约束 | 是"其他条款全部失效"的放大器，争议金额可达原合同价 10%–30% | 总价含全部施工内容；增项须书面确认且累计不超合同总价 10% | 总价上限 + 增项上限 + 书面确认，三者同时具备才生效 |
| 8 | **拆项重复计费**：同一件事拆成拆除+清运+装袋+搬运多行 | 一个总价拆成多个单价条目，每项不高但合计远超市场普遍水平 | 重复多发于管件、瓷砖胶、砂浆，常见在原列金额 10%–25% | 要求完整明细，标注每项是否已含在"综合费用"内 | 同一施工内容不得在多个条目中重复计价 |
| 9 | **质保范围模糊**：质保 2 年、终身维护、有问题包换 | 没写"什么坏了包修""保修谁出材料""响应时间" | 隐蔽工程出问题的返工与损失，争议金额数千至数万元 | 隐蔽工程质保 X 年、饰面工程质保 X 年，保修期内免费维修 | 分项质保年限表 + 响应时限（X 小时响应、X 天到场） |
| 10 | **付款节点过密**：开工 40%、水电 30%、泥木 20%、竣工 10% | 钱先付完筹码就没了，后期一旦增项只能接受 | 前两节点超 60% 时中途增项议价空间基本为零 | 开工 30%、水电验收 30%、泥木验收 20%、竣工验收 15%、整改完成 5% | 节点与验收一一对应；保留 5%–10% 尾款至整改完成 |

## 五、四步谈判流程

**收集。** 拿齐完整报价单（要明细页）、合同草案、付款节点表、材料品牌页。合同草案里没有的条款，正是要补的条款。

**拆解。** 用六要素逐行过一遍，标出：哪几行按实结算、哪几行品牌型号不明、哪几行数量或单价待定。记成"项目/单位/数量/单价/按实结算/品牌型号/风险等级"表，先不急着算钱。

**换算。** 把活口条款换成两个数字：这行金额、这行可能的浮动范围。加总得总体风险区间；同时按付款节点算前两个节点收走多少钱，判断自己处在什么谈判位置。

**谈判。** 顺序很重要：**先锁条款，再谈价格。** 一上来砍价等于承认价格是变量、条款是常量；先把按实结算改成包干、把品牌型号写死、把增项上限写进合同，再谈总价和优惠。条款锁死后，总价的议价空间通常自然扩大。

## 六、增项区间的客观算法

```
单项增项风险 ≈ 该项报价金额 × 经验系数
总体增项区间 ≈ Σ（各项增项风险）取低值 ~ 取高值
```

**经验系数**（常见市场做法的量级参考，非造价依据）：按实结算类——拆改与清运 15%–30%，水电 15%–25%，瓦工与木工 10%–15%，其余按实项 10%–15%；品牌不明或品牌模糊 8%–20%；名称笼统 10%–20%；数量/单价待定、增项不设上限按"不可控"处理。

**为什么用系数而不用绝对数**：绝对金额高度依赖城市、房型、档次，直接给"你会多花 X 元"是编造；而"某科目常出现的上浮比例"可以观察、可以说清来源。系数法给的是**量级和相对排名**，用来决定先谈哪一条、留多少预算余量，恰好够用。

> 所有区间均为估算区间，不构成造价鉴定。实际增项取决于现场条件、设计变更、材料选择与合同约定。

## 七、边界与免责

1. 输出为**报价单要素自查与条款参考**，不构成工程造价咨询、造价鉴定或计价结论。
2. 不出具法律意见。条款文本是谈判素材，不是法律结论。**重大合同请咨询执业律师。**
3. 不评价任何单项报价的高低、贵贱、盈亏，只判断要素是否缺失、条款是否留了后路。
4. 增项区间为经验估算，**不构成造价鉴定**，不作为索赔、结算或诉讼依据。
5. 品牌与材料只检查"是否写明"，不推荐品牌、不评价质量优劣。
6. 不评估施工工艺是否合格、不提供施工方案建议。
7. 不做装修预算规划与投资建议，不预测最终成交价。
8. 所有结论基于用户提供的报价单文本；现场、图纸、原始合同未核实时结论可能有偏差，需人工复核。
9. 涉及具体纠纷维权时，建议同步咨询执业律师或当地相关机构。
10. 输出的金额、比例、区间均为常见做法的量级参考，实际以现场和合同为准。

## 八、常见问答

**Q1：报价单总额比预算低，是不是说明很靠谱？**
不能这么判断。低价报价单最常见的做法是把容易涨的部分挪出去：水电写"按实"、拆除写"实际发生"、垃圾清运留空。总价低往往正是活口多的表现，判断标准是总价之外还有多少开口项。

**Q2："按实结算"具体是什么意思？**
最终金额不按报价单数字定，而按现场实际工程量（或用量）算，再乘约定单价。问题在于三点通常都没写：怎么计量、按什么单价、封顶多少。改法是加"包干 ±5%"或"计量方式 + 单价 + 上限"。

**Q3：装修增项一般能有多少？**
没有全国统一数字。行业较常见的观察是：最终支出相对报价单合计的上浮幅度常见落在 5%–15%；活口多、条款松的，落到 15%–30% 也不罕见。**若按实结算项占总价超过三分之一，大概率落在上沿。**这是量级参考，不是造价结论。

**Q4：对方说"这价已经是市场最低"，怎么接？**
不要在总价上硬顶。回："总价我认可，但我需要你把按实结算的部分和品牌型号写进合同，写完我们再谈优惠。"把话题从价格挪到条款。反过来先砍价，等于替对方把"按实"这个口子留住。

**Q5：品牌只写"一线品牌"，不能要求写具体型号吗？**
可以要求，这是最常见的谈判点。业主要求写明品牌、系列、型号、规格是正常诉求；对方坚持只写等级词，说明在给自己留换料空间。可折中：允许在两三个同档品牌里选，但必须**事前写明是哪几个、什么档次、单价是否随品牌变动**。

**Q6：报价单里"综合费用"不给拆开合理吗？**
从核对角度不合理——它无法被验证是否包含别的条目。通行做法是要么拆成具体项目，要么整体删除并注明"不含零星辅材"。可以说："这 6000 元我不接受，把它拆开；拆不开就从总价去掉，后期真有零星费用按单价逐笔确认。"

**Q7：拆项重复计费怎么识别？**
看三处：辅料中的管件/瓷砖胶/砂浆是否与"综合费用"重叠；人工与辅料是否同时按面积计；清运的装袋、搬运、车次是否分成多项。把报价单里所有含"、""及""等"字的项目标出来，这些最容易藏内容，要求对方书面说明每项包含范围。

**Q8：已经签了合同才发现有活口条款，还有办法吗？**
有，但性质变了。重点从"事前锁定"变成**执行时留痕**：所有口头承诺（品牌、型号、包干范围、增项上限）都要求书面或微信确认后再施工；每次变更前书面报批；付款严格按节点走，验收不通过不进入下一节点。同时尽快梳理补充协议，把最关键几条一次性写进去。

**Q9：付款节点怎么排比较稳妥？**
通行做法是节点与验收绑定：开工 30%、水电验收 30%、泥木验收 20%、竣工验收 15%、整改完成 5%。要点是整体保留 5%–10% 尾款到整改完成，且任何增项不改变已有节点比例——否则对方会用一次"增项"把你前面几期全收走。

**Q10：这份报价单我要不要直接签？**
本技能不做"该不该签"的结论，只给自查结果。可自己判断：若高风险项为 0、活口条款都锁死、增项上限和品牌附件都在，条款层面就是可控的；若高风险项多、按实项占比高、付款还压前，就**先不谈价格，先把条款补齐再签**。

```bash
python scripts/quote_audit.py --input quote.json          # 可读报告

```

输入 JSON（示例数据，非真实项目；字段 project 项目名 / unit 单位 / qty 数量 / price 单价 / settle_actual 是否按实结算 / brand_spec 品牌型号 / note 备注；budget 与 payment_schedule 可选）：

```json
{"budget": 200000, "payment_schedule": [0.3, 0.3, 0.2, 0.15, 0.05], "quotes": [
  {"project": "拆除", "unit": "㎡", "qty": 85, "price": 55, "settle_actual": false, "brand_spec": "", "note": ""},
  {"project": "水电改造", "unit": "米", "qty": 400, "price": 120, "settle_actual": true, "brand_spec": "", "note": "按实际发生"}]}
```

判定逻辑：总价与预算对比（含预留 5%–10% 提示）、按实结算识别并给出经验系数区间、品牌缺失与品牌模糊识别、名称笼统识别（综合/杂项/其他/零星/辅助）、数量单价待定识别、同大类单位混用检测、前 N 阶段付款占比检测（默认前 2 节点超 60% 提示"付款过前"）。输出含总金额、风险清单（按等级排序）、各项增项影响金额估算、追问话术清单与总体评级（低/中/高）。**分工**：脚本负责"把活口找齐、把量级排出来"，Agent 负责"讲清楚每处该怎么问、合同里该补哪一句"，脚本标签需人工复核后再给用户。
