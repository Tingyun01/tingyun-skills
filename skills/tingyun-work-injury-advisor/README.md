# 工伤认定与赔偿决策顾问

> 帮企业和员工梳理工伤认定情形、时限材料、赔偿测算与争议路径，只做决策辅助与流程梳理，不替代认定结论，不构成法律意见，需人工复核。技术触发词「工伤认定、赔偿测算、争议路径」。口语触发词「员工下班路上出了车祸，算不算工伤、我们没有签劳动合同，员工受伤了怎么证明劳动关系、帮我把赔偿项目列出来，并讲清楚各项大致怎么测算」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

工伤赔偿决策顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 员工下班路上出了车祸，算不算工伤？先告诉我认定情形、申请时限和要准备的材料
- 我们没有签劳动合同，员工受伤了怎么证明劳动关系？给举证要点
- 帮我把赔偿项目列出来，并讲清楚各项大致怎么测算
- 工伤和第三方侵权撞车了，能不能两边都要？竞合怎么处理
