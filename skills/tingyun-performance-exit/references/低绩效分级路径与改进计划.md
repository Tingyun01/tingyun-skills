# 低绩效分级路径与改进计划

> 流程设计辅助。各阶段的法律要件与文书制作须经专业机构复核。

## 一、路径总览与出口条件

| 阶段 | 触发条件 | 核心动作 | 出口条件 | 是否必须留书面 |
|---|---|---|---|---|
| 1 辅导与目标澄清 | 单期考核不理想，或存在标准理解分歧 | 面谈 + 澄清标准 + 确认新目标 | 达标 → 回常规；未达标且再次触发 → 阶段 2 | 目标确认书 |
| 2 书面改进期 | 连续两期不达标，或目标达成率明显低于约定值 | 下达改进计划 + 提供支持 + 期内反馈 + 期末评估 | 达标 → 改进期结束；未达标 → 阶段 3 | 改进计划全套 |
| 3 调岗 | 改进期未达标 | 协商一致的岗位调整方案 + 新目标 | 达标 → 正常管理；未达标 → 阶段 4 | 协商记录 + 新岗位材料 |
| 4 协商解除 | 改进期 + 调岗/培训后仍不达标，证据链完整 | 提出协商解除方案 | 达成一致 → 协议解除；未达成 → 阶段 5 | 沟通记录 + 书面协议 |
| 5 单方解除 | 满足"不能胜任 + 培训或调岗后仍不能胜任"要件 | **本顾问不设计方案**，转专业机构评估 | — | 由专业机构指导 |

**跳级的风险**：从阶段 1 直接跳到阶段 4/5，中间缺"培训或调岗"这一环节，程序要件就不完整。路径的价值在于每一环都在为下一环积累证据，跳过去等于把风险全堆到收尾一步。

## 二、各阶段细则

### 阶段 1：辅导与目标澄清

**做什么**：
- 核对考核标准是否存在理解偏差（这条不解决，后面全是冲突）；
- 把差距落到可改进动作；
- 设定下一周期的明确目标（用五要素模板）。

**不做**：不做评级结论，不提"改进期"，不暗示后果。

**出口判断**：下一次考核达标 → 归档为一次常规辅导记录。未达标 → 进入阶段 2，同时检查一件事：**上一轮目标是否真的清楚**。如果当时目标含糊，升级到阶段 2 要格外谨慎，因为"不能胜任"的认定建立在明确标准之上。

### 阶段 2：书面改进期

**期限参考**：常见做法是一个考核周期或 30~90 天。关键是"能观察到改善动作并有复评节点"，而不是"越长越好"。期限过短看不到动作，过长容易变成拖延。

**期内动作三件套**：
1. 改进计划送达并确认收到；
2. 按约定频次提供反馈（每周或双周，每次有记录）；
3. 提供约定的支持（培训、带教、数据、必要权限调整），并留下提供过的痕迹。

**期末评估**：由谁评、依据什么材料、什么时点出结论——这三点在改进计划里就要写死，否则期末会变成"感觉还是不行"。

**出口判断**：
- 达标 → 改进期结束记录，进档案，不影响后续发展；
- 未达标但差距明显缩小 → 可延长一次（记录延长理由与新的目标），不建议无限次延长；
- 未达标且差距未缩小 → 阶段 3。

### 阶段 3：调岗

**调岗方案要写清**：岗位名称与主要职责、薪酬与考核方式、工作地点与通勤安排、汇报关系、到岗日期。

**合规要点**：
- 岗位调整属于劳动合同内容的变更，原则上需与劳动者协商一致，并书面变更劳动合同；
- 调岗不应当作惩罚手段：避免同时降薪、迁往远端、安排明显低于原岗位强度的杂务。这类产品问题本身会形成独立争议点；
- 新岗位要有对应的目标书与标准，不能"调过去但不给标准"，否则后续无从认定；
- 对方拒绝调岗的，不要在此处强行推进，转阶段 4 协商路径。

**出口判断**：新岗位达标 → 正常管理；仍不达标 → 阶段 4。

### 阶段 4：协商解除

**为什么优先走协商**：协商解除的争议空间小，双方可谈补偿、交接、离职证明、保密与竞业提示；相比单方解除，程序与要件压力都低。

**方案要素**：
- 经济补偿（协商一致解除时通常需支付，按工作年限与月工资基数计算，具体标准与算法由专业机构核算）；
- 离职时间与交接安排（交接清单、交接验收标准、离职证明出具时点）；
- 社保与公积金处理、工资结算时点；
- 保密、知识产权、竞业限制（如涉及，写清范围、期限与补偿）；
- 离职证明与背调口径的表述方式。

**沟通要点**：给方案，也给真实选择空间（接受/不接受/再考虑多久）。写"自愿离职"但实质是逼迫的，后续可能被主张意思表示不真实。

**未达成时的提醒**：协商不成的常见误区是"那就走解除程序"——这一步必须先过专业机构的评估，不能由管理岗自行决定。

### 阶段 5：单方解除（转专业机构前的自查）

本顾问只列"进入专业评估前需要备齐什么"，不出方案：

**必备要件（概述）**：
- 实体要件：证明劳动者不能胜任工作，且经培训或者调整工作岗位后仍不能胜任；
- 程序要件：提前三十日以书面形式通知劳动者本人，或者额外支付劳动者一个月工资；单方解除应当事先将理由通知工会；
- 保护情形排查：无第 42 条所列情形（从事接触职业病危害作业未进行离岗前职业健康检查或疑似职业病人在诊断或医学观察期间；在本单位患职业病或因工负伤并被确认丧失或部分丧失劳动能力；患病或非因工负伤在规定医疗期内；女职工在孕期、产期、哺乳期；在本单位连续工作满十五年且距法定退休年龄不足五年等）；
- 举证材料：解除决定属于用人单位作出劳动合同决定发生争议的，用人单位负举证责任。

**进入专业评估前应备齐**：阶段 1~3 的完整证据包、绩效改进计划全套、考核标准与公示凭证、目标书与员工确认记录、保护情形排查表。

**成本提示**：违法解除或终止劳动合同的，劳动者不要求继续履行且劳动合同已不能继续履行的，需依照经济补偿标准的二倍支付赔偿金。这笔成本通常远高于协商解除方案，评估时值得直接比较。

## 三、改进计划八要素模板

```
一、员工信息（姓名/岗位/部门/入职日期/当前周期）
二、依据文件（劳动合同第 X 条 / 岗位说明书版本与生效日 / 目标书编号与日期 / 制度名称与版本）
三、差距事实（逐条：时间 + 事项 + 结果 + 数据，3~5 条）
四、改进目标（按五要素：指标/口径/基线/时限/数据来源，逐项列）
五、改进期限（起止日 + 中期复盘日 + 期末复评日）
六、用人单位支持（培训项目/带教人/数据支持/权限调整/其他资源，逐项列明）
七、复评方式（评估主体 + 依据材料 + 出结论时点 + 结论形式）
八、员工意见与签署（认同/部分异议/不认同 + 理由；员工签署或电子确认 + 日期）
九、送达记录（送达方式 + 日期 + 签收人/凭证编号）
十、附则（解释主体、异议提出渠道与期限、注意事项）
```

## 四、改进计划合规边界对照表

| 常见写法 | 风险 | 建议改法 |
|---|---|---|
| "考核不合格即解除劳动合同" | 把考核结论直接等同于法定要件，且跳过法定程序 | "本期改进目标未达成的，公司将依据法律程序与您协商处理后续人事安排" |
| "限 [日期] 前不达标自动解除" | 预设结论、排除协商程序、缺少"经培训或调岗"环节 | 写清改进期、支持内容、复评方式与后续"依据法律程序处理"的表述 |
| "因你排名末位，公司决定与你解除" | 末位是排序结果，不是不胜任认定 | "本期您的 [量化指标] 未达目标值 [ ]，与目标书约定的差距如下" |
| "不服从管理/态度恶劣" | 主观评价，无法举证 | 换成具体行为与时间节点："[日期] 安排的 [任务] 未在 [时限] 内完成，导致 [后果]" |
| 目标值高于该岗位以往的高位水平 | 标准合理性会被审查，不得故意拔高定额 | 以同岗位可完成水平为参照，以往高位水平仅作参考 |
| 目标值按"团队平均 × 1.5"设定 | 参照基准错误（应参照同岗位平均工作量，不是放大值） | 明确参照对象为同岗位平均水平或岗位说明书约定标准 |
| 改进期零培训零资源 | 缺少"经培训或者调整岗位"这一环节，前序努力归零 | 明确列出培训项目、带教安排、时间与材料 |
| "培训"= 每周例会、晨会 | 日常部门会议不具有针对性，可能被认定不构成有效培训 | 提供有针对性、有材料、有考核的专项培训并留签到与考核记录 |
| 员工不签改进计划即视为拒绝 | 不能以此直接进入后续处理 | 员工不签的，记录并送达留痕，同步安排面谈说明，必要时转专业机构 |
| 倒签日期、补造签到表 | 记录虚假一旦被发现，其他真实证据的可信度也会受影响 | 真实记录，缺项如实补录并注明补录原因与日期 |
| 让员工写"自愿离职申请" | 意思表示不真实，后续可能被主张撤销 | 走协商解除方案，条款完整、给考虑期 |
| 在改进计划里写"保留追究法律责任权利" | 谈判式施压，激化对抗且无实益 | 删除；改为客观说明复评与后续安排 |
| 同一模板批量发给多人，仅改姓名 | 会被认定为未针对个人具体事实 | 每人单独撰写差距事实与目标部分 |

## 五、改进期内的反馈写法

期内反馈容易流于形式。合格的反馈记录包含四项：

| 项 | 要求 | 反例 |
|---|---|---|
| 观察到的具体行为 | 时间 + 事项 + 结果 | "近期状态不好" |
| 与哪个约定对照 | 指向改进计划中的具体条目 | "不符合要求" |
| 影响 | 客观后果 | "大家都不满意" |
| 下一动作与时点 | 具体、可执行 | "希望加油" |

**反馈频次按约定执行并逐次留痕**。期内无任何反馈记录、只在期末出一次结论，是改进期常见的失分点——无法证明过程履行过。

## 六、文件与沟通的顺序纪律

1. 目标书与标准确认（早于考核，且早于问题发生）；
2. 考核评分表（评分人、依据、时间）；
3. 结果告知与送达凭证；
4. 面谈记录（员工陈述与异议一并记录）；
5. 改进计划与送达凭证；
6. 期内支持提供记录与反馈记录；
7. 期末评估结论；
8. 后续处理材料。

顺序错误会导致单项材料失去证明力。补签、倒签、补造是不可逆的损害，且性质比本来存在的问题严重得多。

## 七、什么情况下停止推进改进路径

- 命中保护情形（第 42 条）；
- 员工在改进期内提交医疗诊断或工伤认定材料；
- 改进期即将届满但公司未按计划提供培训或支持（此时强行推进，前序程序反而是空转）；
- 员工提出异议已进入内部申诉或外部渠道且未结；
- 涉及人数较多、需成规模处理；
- 员工提出反申请或要求对考核依据的复核，尚未完成复核。

出现上述任一情形，先处理原因，再谈路径，不要在未解决前置问题时继续往下推。
