# 商业秘密三要件、保密体系清单与竞业限制边界

> 本页为体系搭建底稿，不构成法律意见，需持证专业人士复核。不自称律师。

## 一、商业秘密三要件（缺一不可）

| 要件 | 要点 | 企业自检 |
|---|---|---|
| 秘密性 | 不为公众所知悉，具有一定门槛 | 该信息能否从公开渠道轻易获得？ |
| 价值性 | 具有现实或潜在商业价值 | 泄露会不会造成可预见损失？ |
| 保密措施 | 权利人采取了合理保密措施 | 有没有协议、权限、物理/技术管控？ |

缺"保密措施"是失败：仅"没公开"不够，必须主动采取合理措施。

## 二、保密体系搭建清单（可照做）

**制度层**
- [ ] 制定保密制度，明确保密范围与责任人
- [ ] 与涉密员工签保密协议（明确保密信息与期限）
- [ ] 对高管/核心技术人员评估是否签竞业限制（需补偿）

**物理与技术层**
- [ ] 核心数据分级权限，按需授权
- [ ] 客户名单、工艺文档加密与访问日志
- [ ] 离职交接清点和权限回收流程

**管理动作**
- [ ] 保密培训并留记录
- [ ] 对外合作（代工/供应商）签保密条款
- [ ] 定期复核涉密资产清单

## 三、员工保密与竞业限制边界

**保密义务**
- 对真实商业秘密可约定保密，不依赖补偿也可成立（但建议留痕）
- 避免"一切信息皆保密"的过宽表述，聚焦明确资产

**竞业限制（易无效情形）**
- 适用对象限于：高管、高级技术人员、负有保密义务的人员
- 必须约定并实际支付经济补偿（按月）
- 期限不得超过两年
- 普通岗位强制竞业且无补偿 → 效力存疑
- 把一般考勤/纪律包装成"保密费"克扣工资 → 不合规

## 四、疑似泄露应急动作

```
1. 固定证据：留存访问记录、邮件、聊天、文件流转痕迹
2. 止损：立即回收权限、改密、限制继续扩散
3. 评估：信息是否具备三要件、损失范围
4. 决策：协商 / 发函 / 报案或诉讼 —— 此步须交专业机构
```

> 第 4 步涉及法律行动，超出本顾问范围，建议咨询律师。
