# 岗位题库与追问树

## 通用必问

1. 自我介绍（考结构与岗位相关度）
2. 一段经历展开（考证据具体度）
3. 一次失败或没做成的事（考归因诚实度）
4. 为什么是这个岗位（考动机是否具体）
5. 未来 1 到 2 年想做什么（考是否自洽）

## 追问三层

| 层 | 问法 | 听什么 |
|---|---|---|
| 1 | 具体怎么做的 | 有没有事实 |
| 2 | 当时的约束是什么、怎么选的 | 有没有判断 |
| 3 | 有没有失败过、后来怎么改 | 有没有复盘能力 |

## 岗位差异

| 岗位 | 重点追问 |
|---|---|
| 社区/基层 | 群众工作、纠纷处理、承压 |
| 运营/电商 | 选品逻辑、数据复盘、活动效果 |
| 程序员 | 方案取舍、故障处理、代码之外的影响 |
| 文职/行政 | 流程细节、突发事件处理、细致度 |
| 教师/培训 | 课堂处理、学员差异、家校沟通 |

## 不算追问

- "你还有什么优点"
- "再说说你的优点"
- "你觉得自己适合吗"
