# 高频退回原因库

> 配套技能包（保险理赔材料预检助手）使用。**本库记录的是"材料形式层面"的高频退回情形，用于帮你提前自查；它不构成对赔付与否的判断，也不代表任何保险公司的具体理赔政策。** 各公司口径差异较大，实际处理以承保公司要求与你的保险合同为准。
>
> 严重程度定义：**高** = 不解决基本无法立案或被直接驳回；**中** = 不解决会长期挂起或大幅核减；**低** = 影响效率但不改变结果倾向。

---

## 一、车险

### R01 无交通事故认定书

| 项 | 内容 |
| --- | --- |
| 场景 | 车险车辆损失、车险人身伤亡与第三者责任 |
| 现象描述 | 提交车辆损失或人伤赔付申请时，没有随附交警部门出具的事故认定书，只有当事人自行协商的记录或口头说明 |
| 退回原因 | 责任划分是赔付的前提。保险公司没有书面责任依据，既无法确定损失归属，也无法核算赔付比例，只能退回补充 |
| 补齐方式 | 由当事人及时向交警部门报案并申请出具认定书；轻微事故可由派出所出具情况说明，或由双方到交警部门协商处理并签字确认 |
| 替代路径 | 认定书确实无法取得的：先向承保公司报案，由理赔人员介入现场调查定责；已达成赔付协议的，附协议原件与双方签字的协商记录 |
| 依据出处 | 责任认定文件（交管部门出具）；保险合同约定的责任认定与理赔申请文件要求 |
| 严重程度 | 高 |

### R02 行驶证与保单标的车辆不一致

| 项 | 内容 |
| --- | --- |
| 场景 | 车险车辆损失 |
| 现象描述 | 提交时提供的行驶证车牌号或车架号与保单上记载的被保险车辆不同，或行驶证为过户前的旧证 |
| 退回原因 | 车辆是保险标的的唯一识别依据，标的物无法对应就无法确认损失属于承保车辆，赔款归属与金额均无从核定 |
| 补齐方式 | 提供最新行驶证主页与副页；若为过户后投保，说明车辆变更情况并提供过户后的登记证书 |
| 替代路径 | 行驶证遗失的，由车辆管理所出具机动车信息证明；证照正在办理更换的，提供临时行驶证并说明办理进度 |
| 依据出处 | 保险合同（保险标的约定）；车辆管理相关规定 |
| 严重程度 | 高 |

### R03 损失清单与维修发票金额对不上

| 项 | 内容 |
| --- | --- |
| 场景 | 车险车辆损失 |
| 现象描述 | 只提交了修车发票与结算单，没有列明受损部位与维修项目的损失清单，或清单项目与发票内容无法一一对应 |
| 退回原因 | 赔付金额需按实际受损项目逐项核定。只有总额而无项目明细，审核无法区分哪些属于本次事故、哪些属于既有损伤或正常损耗 |
| 补齐方式 | 由维修厂出具加盖公章的维修项目清单，逐项列明受损部位、施工项目、零件数量与工时费 |
| 替代路径 | 已完成维修的，可提供维修厂的工时与配件结算明细单；尚未维修的，先由保险公司定损并出具定损单 |
| 依据出处 | 损失核定所需材料 |
| 严重程度 | 中 |

### R04 缺少事故现场照片

| 项 | 内容 |
| --- | --- |
| 场景 | 车险车辆损失 |
| 现象描述 | 申请时只有维修后的照片，没有事故现场的车辆位置、受损部位特写与全车照片 |
| 退回原因 | 现场影像用于还原事故形态与受损成因。缺少现场照片时，无法排除既有碰撞痕迹，损失真实性与程度难以查证 |
| 补齐方式 | 补交现场全景、受损部位特写两组照片，尽量包含拍摄时间信息；保留原始文件不要二次编辑 |
| 替代路径 | 当时未拍摄的：提供行车记录仪原始视频、周边监控或路过车辆影像；车辆已修复的可提供维修厂留存的拆检照片 |
| 依据出处 | 损失核定所需材料 |
| 严重程度 | 中 |

### R05 对方无保险信息未说明

| 项 | 内容 |
| --- | --- |
| 场景 | 车险车辆损失（对方全责情形） |
| 现象描述 | 对方车辆全责，但申请时没有提供对方的交强险与商业险信息，也没说明对方是否有保险、是否愿意赔偿 |
| 退回原因 | 赔付路径取决于能否通过对方保险公司代位求偿。信息不明时无法确定是走代位还是直接赔付，容易在环节间反复流转 |
| 补齐方式 | 提供对方车牌号、驾驶人姓名与联系方式，委托承保公司查询对方保险信息 |
| 替代路径 | 对方拒绝配合的，通过交警部门或法院调取车辆信息；已确认对方全责的，先按己方车损险赔付，由保险公司后续追偿 |
| 依据出处 | 保险合同（代位求偿相关约定）；责任认定文件 |
| 严重程度 | 中 |

### R06 车辆泡水后二次启动

| 项 | 内容 |
| --- | --- |
| 场景 | 车险车辆损失（泡水） |
| 现象描述 | 车辆涉水后再次启动，之后才联系保险公司送修，报案记录与维修记录之间存在时间差 |
| 退回原因 | 涉水后二次启动造成的发动机损坏，通常被认定为扩大损失，与原始事故损失需要区分；无法区分时赔付范围容易产生争议 |
| 补齐方式 | 提供报修记录、维修厂检修说明，说明二次启动的时间与当时不知情的具体情况；附维修厂对损坏部位的区分意见 |
| 替代路径 | 争议较大的，可要求第三方对损坏部件与涉水因果关系出具评估意见；已由保险公司定损的，以定损结论为分界点 |
| 依据出处 | 保险合同（损失范围与责任免除约定） |
| 严重程度 | 中 |

### R07 网约车接单中出险未说明营运性质

| 项 | 内容 |
| --- | --- |
| 场景 | 车险车辆损失 |
| 现象描述 | 事故发生在网约车接单营运期间，但申请时只描述为"开车出门"，未说明接单状态，也未提供平台订单记录 |
| 退回原因 | 营运性质与私家车的承保条件不同，承保状态需由保险公司认定。未说明可能导致案件在核保状态核查环节长期挂起 |
| 补齐方式 | 主动提供平台接单记录、订单详情、行程截图与营运性质说明，并说明当时是否载客、处于何种运营状态 |
| 替代路径 | 已完成接单但无平台记录的，附行车记录仪、导航轨迹与乘客说明；平台数据可申请保险公司协助调取 |
| 依据出处 | 保险合同（车辆使用性质约定） |
| 严重程度 | 高 |

### R08 伤者医疗费用只有发票没有总清单

| 项 | 内容 |
| --- | --- |
| 场景 | 车险人身伤亡与第三者责任 |
| 现象描述 | 提交了医疗费票据原件，但没有住院费用总清单或门诊费用明细，无法逐项核对治疗内容 |
| 退回原因 | 人伤赔付需逐项核对药品、诊疗与耗材开支并剔除与本次事故无关的项目。缺明细时审核无法开展，容易整笔核减 |
| 补齐方式 | 向医院收费处打印住院费用汇总清单或门诊费用明细，加盖收费章 |
| 替代路径 | 已出院且医院不便提供的，可申请复制住院费用清单；确无明细的，附长期与临时医嘱、处方作为佐证 |
| 依据出处 | 损失核定所需材料 |
| 严重程度 | 高 |

## 二、医疗险

### R09 只有出院小结没有费用总清单

| 项 | 内容 |
| --- | --- |
| 场景 | 医疗险住院 |
| 现象描述 | 提交出院小结、疾病诊断证明与收费票据，但没有住院费用总清单 |
| 退回原因 | 费用总清单是逐项核定的唯一依据。缺清单时审核无法确认具体用药与项目，通常整笔暂缓核定，需退回补件 |
| 补齐方式 | 到住院收费处或自助机打印住院费用汇总清单，含西药、中药、诊疗、检查、检验、床位、耗材的名称、数量、单价与金额 |
| 替代路径 | 医院已不能打印的，可由病案室或收费处出具费用情况说明并加盖公章；同时补交医嘱单与出院带药处方作为佐证 |
| 依据出处 | 损失核定所需材料 |
| 严重程度 | 高 |

### R10 医疗费票据为复印件

| 项 | 内容 |
| --- | --- |
| 场景 | 医疗险门诊与住院 |
| 现象描述 | 提交的是收费票据复印件，原件已被用于社保报销或其他用途 |
| 退回原因 | 票据原件通常用于核销，复印件无法作为唯一凭证；多数公司要求原件或医保结算单 |
| 补齐方式 | 向医院补开收费证明或提供加盖医院收费章的票据复印件；已社保结算的，提供医保结算单 |
| 替代路径 | 票据确已遗失的，由医院出具收费情况说明并加盖公章，同时提供费用明细清单作为金额佐证 |
| 依据出处 | 损失核定所需材料 |
| 严重程度 | 中 |

### R11 医保已报销部分未扣除

| 项 | 内容 |
| --- | --- |
| 场景 | 医疗险门诊与住院 |
| 现象描述 | 提交的费用金额是医保结算前的全额，未提供医保结算单，也未说明哪些部分已由基本医保或补充医保支付 |
| 退回原因 | 存在重复报销风险，保险公司需先扣除社保已报销部分才能核定给付金额。缺结算单时无法确定扣除金额 |
| 补齐方式 | 提供医保结算单与个人自付、自费部分明细；未结算的，先完成医保结算后再提交 |
| 替代路径 | 自行支付的，附支付凭证与说明；异地就医的，附异地就医结算单或转诊证明 |
| 依据出处 | 损失核定所需材料 |
| 严重程度 | 中 |

### R12 就诊医院超出合同约定范围

| 项 | 内容 |
| --- | --- |
| 场景 | 医疗险门诊与住院 |
| 现象描述 | 在二级及以上公立医院范围外的医疗机构就诊，或未经转诊直接前往三级甲等医院，未提供转诊单与医院等级证明 |
| 退回原因 | 多数医疗险对就诊医院范围与等级有约定，超出范围的部分可能不予赔付 |
| 补齐方式 | 补交医院等级证明；确需转诊的，由社区或基层医院开具转诊单 |
| 替代路径 | 紧急情况下的，可提供急诊记录与病历说明；事先未确认医院范围的，提交前先向承保公司确认认可医院名单 |
| 依据出处 | 保险合同（就诊医院范围约定） |
| 严重程度 | 中 |

### R13 出院小结缺医院公章

| 项 | 内容 |
| --- | --- |
| 场景 | 医疗险住院 |
| 现象描述 | 出院小结是复印件或复印件上加盖了个人签章，没有医院公章或病案室盖章 |
| 退回原因 | 出院小结是住院事实与诊断结论的核心凭证，无有效盖章无法确认其真实性与出具主体 |
| 补齐方式 | 到医院病案室或出院窗口重新打印或加盖病案专用章 |
| 替代路径 | 医院不便重新出具的，可提供加盖医院公章的疾病诊断证明书与住院病案首页作为补充佐证 |
| 依据出处 | 医疗事实认定所需材料 |
| 严重程度 | 中 |

### R14 病理报告缺失导致重疾线索无法延续

| 项 | 内容 |
| --- | --- |
| 场景 | 医疗险住院、重疾险 |
| 现象描述 | 诊断证明已明确疑似恶性病变，但没有提供病理报告或组织学诊断结论 |
| 退回原因 | 病理诊断是判断疾病性质的关键依据。缺病理报告时无法确定疾病类型，赔付核定缺少支点 |
| 补齐方式 | 病理科出具正式病理报告，含标本来源、病理诊断、免疫组化结果与病理号；未出报告的，凭病理科受理单说明进度 |
| 替代路径 | 切片已归档的，申请借阅蜡块或切片配合保险公司指定的复核；尚未手术的，在诊断明确后补做并提交 |
| 依据出处 | 保险合同（疾病定义与确诊方式约定）；医疗事实认定所需材料 |
| 严重程度 | 高 |

## 三、重疾险

### R15 诊断名称与合同疾病类型描述不一致

| 项 | 内容 |
| --- | --- |
| 场景 | 重疾险（确诊即赔型） |
| 现象描述 | 提交的诊断证明写的是具体病名或病变描述，而合同约定的疾病类型是一段描述性文字，两者用词不同 |
| 退回原因 | 赔付以合同约定的疾病状态为准。诊断名称与约定描述的对应关系需要专业判断，双方理解不一致时会转入审核或调查 |
| 补齐方式 | 附主治医生或病理科出具的诊断说明，援引检查数据说明与合同约定描述的对应关系；同时提交保单疾病定义页供比对 |
| 替代路径 | 争议较大的，可按承保公司指引到指定机构或通过专家会诊出具意见；结论未明前，案件会长期停留在审核阶段 |
| 依据出处 | 保险合同（疾病定义与给付条件约定） |
| 严重程度 | 高 |

### R16 治疗达成型疗程未完成即申请

| 项 | 内容 |
| --- | --- |
| 场景 | 重疾险（治疗达成型） |
| 现象描述 | 合同约定需完成若干疗程或特定手术方式，实际只完成部分治疗就提交给付申请 |
| 退回原因 | 治疗达成型以"达到约定状态"为给付条件，疗程未完成即不满足条件 |
| 补齐方式 | 提交完整治疗过程病历（各次住院、化疗、放疗、手术记录与疗程起止时间）与对应费用凭证，并附医生出具的当前治疗状态说明 |
| 替代路径 | 尚在治疗中的，先整理已完成疗程的清单与凭证向承保公司预沟通，确认还差哪些阶段再一次性申请 |
| 依据出处 | 保险合同（治疗状态约定与给付条件） |
| 严重程度 | 高 |

### R17 投保前已有就诊记录未主动说明

| 项 | 内容 |
| --- | --- |
| 场景 | 重疾险、医疗险 |
| 现象描述 | 投保前已有门诊或住院记录、异常体检指标或长期服药情况，申请理赔时未主动提交 |
| 退回原因 | 投保前健康状况是责任关联性核实的重要依据。未主动说明而在核查阶段被发现，会转入既往症调查，审核周期显著拉长 |
| 补齐方式 | 主动、完整提交投保前的门诊病历、体检报告、住院记录与既往诊断说明，把疾病演变的时间线讲清楚 |
| 替代路径 | 记录已在医院或体检机构保存的，可申请复印或调取；确实无法取得的，可提供本人情况说明与相关就诊凭证 |
| 依据出处 | 保险合同（如实告知与责任关联性核实相关约定）；消费者权益保护相关规定 |
| 严重程度 | 中 |

### R18 病理切片未配合复核

| 项 | 内容 |
| --- | --- |
| 场景 | 重疾险（确诊即赔型） |
| 现象描述 | 承保公司要求复核病理结论，但切片已归档无法提供，或不愿配合到指定机构复核 |
| 退回原因 | 缺少切片实物或复核意见，诊断依据无法二次确认，给付流程停滞 |
| 补齐方式 | 向出具报告的病理科申请蜡块或切片借阅手续，按承保公司指引配合送检或到指定机构复核 |
| 替代路径 | 切片确已销毁或无法借出的，可申请病理科出具情况说明，并结合其他检查报告与专家意见推进 |
| 依据出处 | 保险合同（理赔调查配合相关约定） |
| 严重程度 | 中 |

## 四、寿险身故

### R19 有死亡证明没有户籍注销证明

| 项 | 内容 |
| --- | --- |
| 场景 | 寿险身故（一般／意外／交通工具） |
| 现象描述 | 提交了医疗机构或公安机关出具的死亡证明，但没有户口注销证明，也没提交户口簿注销页 |
| 退回原因 | 身故给付需确认被保险人身故状态已由户籍机关正式登记注销。缺注销证明时，被保险人身份状态存疑，案件无法进入给付流程 |
| 补齐方式 | 到户籍地派出所办理户口注销并取得注销证明；或提交户口簿整页（含注销页）复印件并加盖户口章 |
| 替代路径 | 身故已确认但注销手续未办的，可先提交死亡证明并附派出所出具的户籍信息证明，说明注销办理进度 |
| 依据出处 | 保险合同（保险事故证明文件要求）；户籍管理相关规定 |
| 严重程度 | 高 |

### R20 受益人无法证明关系或继承权

| 项 | 内容 |
| --- | --- |
| 场景 | 寿险身故 |
| 现象描述 | 保单未指定受益人或指定受益人已身故，多名家属同时申领，但只有户口本复印件，没有亲属关系证明或继承权公证 |
| 退回原因 | 给付对象与份额无法确定。多家同时申领且无份额确认文件时，保险人无法择一支付，容易引发纠纷并长期挂案 |
| 补齐方式 | 办理继承权公证，明确各受益人份额；或由法院生效判决、调解书确定份额 |
| 替代路径 | 争议较小的，可由全体继承人签署份额协商一致的书面文件并附亲属关系证明（户口簿、社区或公安机关出具） |
| 依据出处 | 保险合同（受益人与给付对象约定）；消费者权益保护相关规定 |
| 严重程度 | 高 |

### R21 意外身故缺意外事故证明

| 项 | 内容 |
| --- | --- |
| 场景 | 寿险身故（意外身故） |
| 现象描述 | 提交了死亡证明，但只有"猝死""原因待查"或医生填写的自然疾病原因，没有能证明意外事故发生的书面材料 |
| 退回原因 | 意外身故责任与疾病身故责任的给付条件不同。缺事故事实证明，无法区分属于哪种情形，案件转入调查并暂缓给付 |
| 补齐方式 | 交通事故由交警部门出具认定书；其他意外由派出所、物业管理、用人单位、监护人或目击者出具情况说明并签字 |
| 替代路径 | 无法取得官方证明的，先收集现场照片视频、目击者证言、单位或社区书面说明，作为事故性质的初步证据提交 |
| 依据出处 | 责任性质区分所需材料；保险合同（意外身故与疾病身故的给付条件约定） |
| 严重程度 | 高 |

### R22 死因存在争议但未做医学鉴定

| 项 | 内容 |
| --- | --- |
| 场景 | 寿险身故（意外与疾病并存、疑似非意外身故） |
| 现象描述 | 死亡原因记载为"意外""待查"或同时存在多种可能，各方对死因有不同主张，但没有申请死因医学鉴定或尸检 |
| 退回原因 | 死因是判定给付责任类型的前提。争议未解决前，保险人不能确定适用条款，给付无法启动 |
| 补齐方式 | 由承保公司或司法机关委托具备资质的机构出具死因鉴定意见；需要时提供尸检报告 |
| 替代路径 | 鉴定费用一般需先行垫付，可与承保公司确认费用承担方式；未做鉴定时案件会持续停留在调查状态 |
| 依据出处 | 保险合同（理赔调查与死因认定相关约定） |
| 严重程度 | 高 |

## 五、伤残

### R23 自行委托的鉴定机构不被认可

| 项 | 内容 |
| --- | --- |
| 场景 | 伤残（意外／疾病）、重疾险 |
| 现象描述 | 自己联系鉴定机构做了伤残等级鉴定，提交后保险公司表示不予采信，要求重新鉴定或走法院委托 |
| 退回原因 | 伤残等级结论须由具备相应资质、且与保险公司存在委托或法院委托关系的鉴定机构作出。自行委托的结论在程序上不被认可 |
| 补齐方式 | 鉴定前先向承保公司确认其认可的鉴定机构名单与流程，约定鉴定标准版本与费用承担，再委托 |
| 替代路径 | 已自行委托的，可保留结论作为参考，同时按承保公司指引重新鉴定；进入诉讼的，由法院委托鉴定 |
| 依据出处 | 伤残等级评定相关规定；保险合同（伤残等级评定标准与流程约定） |
| 严重程度 | 高 |

### R24 鉴定标准版本与合同约定不一致

| 项 | 内容 |
| --- | --- |
| 场景 | 伤残（意外／疾病） |
| 现象描述 | 鉴定按现行标准执行，而合同约定的是另一版本的标准，等级结论因此产生差异 |
| 退回原因 | 伤残等级与给付金额的对应关系以合同约定的评定标准为准。标准版本不同，结论无法直接套用 |
| 补齐方式 | 确认合同约定的评定标准名称与版本，要求鉴定机构按该版本出具结论；提交保单伤残给付条款页与等级对照表供比对 |
| 替代路径 | 版本确实存在歧义的，向承保公司书面确认以哪个版本为准，保留沟通记录；争议无法解决时走司法途径 |
| 依据出处 | 保险合同（伤残等级评定标准与给付比例约定） |
| 严重程度 | 高 |

### R25 缺生活自理能力或护理依赖程度评估

| 项 | 内容 |
| --- | --- |
| 场景 | 伤残（意外／疾病） |
| 现象描述 | 合同约定按丧失劳动能力或生活自理能力比例给付，但只提供了伤残等级鉴定报告，没有功能评估或护理依赖程度评估结论 |
| 退回原因 | 按比例给付的项目需要单独的功能或护理依赖评估支撑，缺该项则该部分金额无法核定，通常被整项核减 |
| 补齐方式 | 向承保公司确认认可的评估机构与评估标准，委托出具生活自理能力或护理依赖程度评估结论 |
| 替代路径 | 工伤案件可依劳动能力鉴定结论中的护理依赖项主张；确实无法评估的，按最保守口径预估并与承保公司沟通 |
| 依据出处 | 保险合同（护理依赖或劳动能力比例给付约定）；伤残等级评定相关规定 |
| 严重程度 | 中 |

## 六、雇主责任险 / 团体意外

### R26 涉事员工不在团体保单被保险人名单内

| 项 | 内容 |
| --- | --- |
| 场景 | 雇主责任险 / 团体意外 |
| 现象描述 | 出险员工是单位在职人员，但提交时没有附团体保单的被保险人（员工）名单，审核时发现名单中没有此人 |
| 退回原因 | 团体保险以名单确定承保标的。员工不在名单内即不属于承保范围，案件不予赔付 |
| 补齐方式 | 向承保公司或投保单位调取完整的被保险人名单原件核对；确认属于漏报的在承保期间内补报并缴费后再申请 |
| 替代路径 | 名单确实未含该员工的，由用人单位承担相应责任另行处理；已实际投保个人险的，转由个人险申请 |
| 依据出处 | 保险合同（被保险人范围约定） |
| 严重程度 | 高 |

### R27 用工关系只有口头说明没有书面证据

| 项 | 内容 |
| --- | --- |
| 场景 | 雇主责任险 / 团体意外 |
| 现象描述 | 提交时只有"他确实是我们员工"的说明，没有劳动合同、社保记录或工资发放凭证 |
| 退回原因 | 保险人需要书面证据确认涉事人员属于承保的雇员范围。口头说明无法采信，案件会退回补充或转入调查 |
| 补齐方式 | 提交劳动合同、社保缴纳记录、工资发放表、考勤记录或任职文件中的任意多项组合，形成证据链 |
| 替代路径 | 无书面劳动合同的（实际常见的灵活用工情形）：提供工资流水、社保记录、考勤表与工作安排证据的组合，并附单位的情况说明 |
| 依据出处 | 保险合同（被保险人范围与雇员定义约定） |
| 严重程度 | 高 |

### R28 缺工伤认定决定书

| 项 | 内容 |
| --- | --- |
| 场景 | 雇主责任险 / 团体意外 |
| 现象描述 | 员工在工作中受伤，提交了医疗费用票据与诊断证明，但没有人社部门出具的工伤认定决定书 |
| 退回原因 | 是否属于工伤、伤害程度与责任主体需由人社部门认定。缺认定文件则事故性质无法确认，赔付核定缺乏基础 |
| 补齐方式 | 由用人单位向人社部门申请工伤认定，取得决定书后一并提交；认定期间可先提交受理回执与医疗材料说明进度 |
| 替代路径 | 尚未认定但事实清楚的，同步准备事故经过说明、现场照片与同事证言作为过渡佐证 |
| 依据出处 | 工伤认定相关规定；保险合同（保险事故认定与理赔申请文件要求） |
| 严重程度 | 高 |

### R29 误工费与一次性伤残补助金缺计算依据

| 项 | 内容 |
| --- | --- |
| 场景 | 雇主责任险 / 团体意外 |
| 现象描述 | 提交了伤残等级结论与几项金额，但没有逐项的计算表，也没附收入标准与相关天数证明 |
| 退回原因 | 每个赔偿项目都需要明确的计算基数、标准、天数与结果，缺计算依据时会被逐项核减甚至退回 |
| 补齐方式 | 按当地工伤保险待遇口径与合同约定分别计算，列出基数、标准、天数与金额，并附在职证明、工资流水或纳税凭证 |
| 替代路径 | 无固定工资的，提供个体经营凭证或承包合同；单位对计算口径有异议的，可附与单位协商一致的书面文件 |
| 依据出处 | 损失核定所需材料；工伤保险待遇相关规定 |
| 严重程度 | 中 |

### R30 团体保单未附完整名单

| 项 | 内容 |
| --- | --- |
| 场景 | 雇主责任险 / 团体意外 |
| 现象描述 | 提交了保单首页与部分名单，但没有完整的被保险人清单，无法核对涉事员工是否在保 |
| 退回原因 | 名单是核对承保标的与保费对应关系的依据。名单不全时审核无法完成核对，案件退回补件 |
| 补齐方式 | 向承保公司或投保单位索取完整的被保险人名单（含姓名、身份证号、工种与保障期间），并加盖单位或公司章 |
| 替代路径 | 名单由多家单位共同提供的，索取全部参保单位名单并注明涉事员工所属单位 |
| 依据出处 | 保险合同（被保险人清单约定） |
| 严重程度 | 中 |

## 七、通用与跨场景

### R31 姓名或身份证号与保单不一致

| 项 | 内容 |
| --- | --- |
| 场景 | 全部场景 |
| 现象描述 | 提交的身份证明件上的姓名或身份证号与保单记载不一致，或存在错别字、曾用名 |
| 退回原因 | 主体信息无法与保单对应，无法确认申请人对保单权益的资格，付款对象也无法确定 |
| 补齐方式 | 以身份证件为准更正申请信息；确因录入错误产生的，联系承保公司申请更正或出具批单 |
| 替代路径 | 曾用名的，提供公安机关出具的更名证明与户口簿；姓名完全不同的，需先确认是否同一自然人（出生日期、家庭关系等佐证） |
| 依据出处 | 保险合同（投保人、被保险人与受益人信息约定）；消费者权益保护相关规定 |
| 严重程度 | 中 |

### R32 缺少保单信息页与条款页

| 项 | 内容 |
| --- | --- |
| 场景 | 全部场景 |
| 现象描述 | 只提供了投保单或保险凭证，没有包含保障责任、免赔约定、等待期、就诊医院范围等内容的条款页 |
| 退回原因 | 条款是判断本次申请是否属于保险责任、是否在保障期内的依据。缺条款页则责任范围与给付条件无法对照，审核无法进行 |
| 补齐方式 | 登录投保平台或致电承保公司客服调取电子保单全文（含条款与批单），自行打印或由公司出具 |
| 替代路径 | 投保记录已无法查询的，提供投保时的投保单、缴费凭证与保险凭证等可证明承保关系的材料 |
| 依据出处 | 保险合同（保险单与条款为合同组成部分） |
| 严重程度 | 中 |

### R33 材料复印件不清晰或关键信息被遮挡

| 项 | 内容 |
| --- | --- |
| 场景 | 全部场景 |
| 现象描述 | 身份证、行驶证、病历等复印件模糊、缺页，或关键信息（姓名、日期、金额、盖章）被裁掉 |
| 退回原因 | 无法识别关键信息或无法确认出具主体，等同于材料无效，会被直接退回 |
| 补齐方式 | 重新复印或用手机翻拍，确保四角完整、文字清晰、无反光；复印件需注明"与原件一致"并签字或按公司要求附原件 |
| 替代路径 | 原件遗失的，到出具单位（医院、交警、派出所、车管所）申请补开带公章的证明件 |
| 依据出处 | 各类材料的格式与可识别性要求 |
| 严重程度 | 中 |

### R34 补件时未附材料清单与说明

| 项 | 内容 |
| --- | --- |
| 场景 | 全部场景 |
| 现象描述 | 每次被要求补件，就只交被点名的那一样材料，没有说明本次补件对应第几项，也没有附完整清单 |
| 退回原因 | 补件环节需要把材料与缺件清单逐项对应。缺少清单与编号说明时，审核难以确认补件是否齐全，容易出现"这次补了 A、下次说缺 B"的循环 |
| 补齐方式 | 每次提交都附一份材料清单，逐项编号并标注状态（已交／本次补交／待出具／客观原因暂缺），同时写明预计补齐时间 |
| 替代路径 | 已多次补件的，把历次提交记录与缺件通知一并整理附上，缩短核对时间 |
| 依据出处 | 理赔流程与材料清单约定；消费者权益保护相关规定 |
| 严重程度 | 低 |

### R35 超过约定时限未提出申请

| 项 | 内容 |
| --- | --- |
| 场景 | 全部场景 |
| 现象描述 | 出险后长时间未提交理赔申请，或补件长期拖延，保险公司提示可能涉及时效问题 |
| 退回原因 | 保险合同通常约定理赔申请与资料提交的时间要求，超期或长期未提交会被要求说明原因，可能影响受理与核定 |
| 补齐方式 | 立即提交现有材料并附一份时间线说明（何时出险、何时报案、为何延迟、材料何时可补齐） |
| 替代路径 | 确有客观原因的（人在外地住院、资料遗失、诉讼中止等），提交可证明的书面说明与相关凭证 |
| 依据出处 | 保险合同（保险事故发生后的通知与申请时限约定）；《保险法》关于保险事故通知与时效的一般规定 |
| 严重程度 | 高 |

### R36 提交了不相关或无关紧要的材料

| 项 | 内容 |
| --- | --- |
| 场景 | 全部场景 |
| 现象描述 | 申请时附了大量无关材料（如多年病历、其他险种的理赔单、与本次事故无关的影像） |
| 退回原因 | 无关材料不推进审核，反而增加信息核对成本与个人信息暴露面；部分涉及他人隐私的材料还可能引发信息安全问题 |
| 补齐方式 | 按承保公司给的材料清单逐项对应提交，只交与本次事故直接相关的材料 |
| 替代路径 | 需要提供病史全貌的，先与承保公司沟通确认范围与形式（可做脱敏处理） |
| 依据出处 | 消费者权益保护相关规定（个人信息保护相关要求）；材料清单对应要求 |
| 严重程度 | 低 |

## 使用建议

1. **按现象检索**：拿到保险公司的补件通知后，在本库检索"现象描述"相近的编号，按其"补齐方式"处理。
2. **看严重程度排序**：高 → 中 → 低，同等条件下先解决"高"，否则整案都无法推进。
3. **看替代路径**：确实补不齐的，按"替代路径"走替代方案，避免无限期等待。
4. **主动附清单**：每次提交都附编号清单与状态说明（R34），这是减少补件轮次最有效的一招。
5. **保留沟通记录**：与理赔人员的沟通时间、渠道与答复要点都记下来，争议时可用。

> 本库为材料准备辅助工具，不构成理赔结论，也不代表任何保险公司的具体政策。严重程度判断基于常见实务经验，具体以承保公司的实际要求为准。
