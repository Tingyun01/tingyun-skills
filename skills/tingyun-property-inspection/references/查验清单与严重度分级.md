# 分类查验清单与严重度分级

本文按部位给出可打印打勾的查验项。每项含：查什么、怎么查、依据/注意、发现问题后的判定级别。

**级别定义**

| 级别 | 含义 | 处置基调 |
|---|---|---|
| 一级 | 可能影响结构安全、使用安全，或达到严重影响正常居住使用的程度 | 限期书面答复 + 必要时做有资质检测 |
| 二级 | 隐蔽工程或功能失效，修补无法恢复原状，需拆开重做 | 限期返工 + 复验 + 留痕 |
| 三级 | 可通过刮补、涂刷、更换配件解决，不涉及拆改 | 批量归集，一次性提出 |

## 一、结构与渗漏

### 1.1 墙体裂缝

| 查什么 | 怎么查 | 注意 |
|---|---|---|
| 裂缝宽度 | 用卷尺或直尺贴靠拍照，肉眼配合刻度读数 | 记录到具体数值（mm），不要写"比较宽" |
| 裂缝走向 | 观察是水平、垂直还是斜向 | 斜向裂缝比水平裂缝更需要重视 |
| 是否贯穿 | 敲击听空鼓声，两侧声音差异明显可能已贯穿 | 需要条件有限时只记录现象 |
| 有无错台 | 用靠尺横跨裂缝两侧，看有无高差 | 错台提示结构变形可能 |
| 位置关系 | 是否在剪力墙部位、是否与楼板平行 | 结合户型图判断是否在承重构件上 |
| 发展迹象 | 裂缝两端有无延伸、是否新出现 | 老裂缝会记录但不一定严重，新出现的更值得追 |

**判定**
- 一级：斜向贯穿裂缝、伴随错台或明显变形、位于承重构件上的裂缝
- 二级：非承重墙上的纵向裂缝、裂缝处伴随空鼓
- 三级：非承重墙上的短横向裂缝或收缩缝、无延伸迹象

**注意**：裂缝性质认定需要有资质的检测机构。你给的是分级建议和记录方法，不是定性结论。

### 1.2 空鼓

| 查什么 | 怎么查 | 注意 |
|---|---|---|
| 墙面空鼓 | 用空鼓锤或硬币柄逐块敲击，声音清脆为实、沉闷发空为鼓 | 逐间逐墙敲，不抽查 |
| 地面空鼓 | 同上，重点敲贴砖区域与门槛、墙根 | 空鼓范围比数量更重要 |
| 空鼓位置 | 圈出范围并拍照 | 需写明面积估计值 |

**判定**
- 二级：卫生间、厨房、阳台地面空鼓（涉及防水层与后续铺贴）
- 三级：墙面局部点状空鼓（面积小，可刮补）

### 1.3 平整度与垂直度

| 查什么 | 怎么查 | 依据 |
|---|---|---|
| 墙面平整度 | 2m 靠尺贴靠墙面，用塞尺量间隙数值 | 常用验收标准：墙面平整度允许偏差 4mm（2m 靠尺） |
| 墙面垂直度 | 2m 靠尺竖向贴靠 | 允许偏差 4mm |
| 地面平整度 | 靠尺贴地 | 允许偏差 4mm |
| 顶面平整度 | 靠尺贴顶 | 允许偏差 4mm |

**判定**：超差且在合同交付标准中有明确约定的 → 二级或三级（按约定条款定）；合同无约定的 → 三级，列为观感问题。

**注意**：允许偏差的具体数值以合同交付标准附件和现行验收规范为准，不同项目与部位可能不同，这里给的是常用参考值。

### 1.4 外渗漏与内渗漏

| 查什么 | 怎么查 | 注意 |
|---|---|---|
| 外墙水渍 | 远观外立面，尤其窗角、窗台、女儿墙根部、外墙保温接缝处 | 需晴天或雨后看更明显 |
| 窗角渗漏 | 检查窗框与墙体交接处、窗台下沿有无水渍、霉点 | 常见成因是密封胶未打或打得不连续 |
| 顶面渗漏 | 检查卧室、客厅顶面有无水渍、返潮、霉点、掉粉 | 顶面问题要往上找对应住户（楼上防水） |
| 墙根返潮 | 检查外墙内侧墙根、窗台下方 | 与楼体防水、窗框密封都有关 |
| 外墙脱落风险 | 观察外墙饰面有无空鼓、脱落痕迹、明显裂缝 | 涉及高空安全，判定为一级 |

**判定**
- 一级：外墙饰面脱落风险、成片空鼓、外墙明显裂缝
- 二级：顶面渗漏水渍（意味着楼上防水失效，需协调）、窗框渗漏（需拆开重打密封或更换）
- 三级：局部墙面返潮、霉点（可通过处理与通风改善，但需查明是否持续）

### 1.5 空鼓与裂缝的关系
一条裂缝同时伴随空鼓时，取较重的一级，并注明"裂缝+空鼓并存"。

## 二、防水

### 2.1 闭水试验（重点方法）

**适用**：卫生间、厨房、阳台等有防水要求的部位。

**步骤**
1. 防水层施工完成后需等其干燥固化，一般 24 小时以上
2. 封堵地漏与下水口（用堵漏工具或防水沙袋，要封严实）
3. 门口用砂浆临时砌一道挡水坎，高约 3 至 5cm
4. 蓄水深度不小于 20mm（常用 20 至 30mm），在墙面用记号笔标水位线
5. 蓄水时间不少于 24 小时（条件允许做到 48 小时更稳，冬季与渗漏风险高的位置建议做 48 小时）
6. 期间观察：前期每小时到楼下看一次，后期每 2 至 3 小时看一次
7. 结束前复测水位下降量：普通住宅卫生间面积在 4 至 5 平方米时，下降 1 至 4mm 可视为蒸发与渗透的正常变化；超过 5mm 需延长观察；达到 5 至 10mm 可判为防水失败
8. 结束后到楼下检查顶面、管道周边、墙角有无水渍、洇湿、滴水

**依据**：《住宅室内防水技术规范》JGJ 298-2013 与《建筑地面工程施工质量验收规范》GB 50209-2010 均要求做蓄水检验，蓄水深度不小于 20mm、时间不少于 24 小时。

**注意**：验收建议会同物业与楼下邻居共同现场检验并签字确认，照片视频留档。

### 2.2 排水试验
- 每个地漏、洗手盆、厨房下水、马桶逐一放水，记录下水速度与是否返味
- 下沉式卫生间（沉箱）要确认沉箱内是否回填、是否有二次排水、是否做满水试验
- 阳台、露台排水口是否通畅，排水坡度是否明显
- 屋面排水：雨后或用水冲洗观察有无积水

### 2.3 防水层做法（需在交付前或开放日查）
- 防水涂刷遍数（常见为 2 至 3 遍，横竖交叉）
- 淋浴区墙面上翻高度（通常要求 1.8m 以上；非淋浴墙面常见要求 0.3m）
- 管根、地漏、阴阳角是否做附加层与圆弧处理
- 沉箱是否回填、是否做过二次排水
- 材料品牌型号是否与合同约定一致

### 2.4 防水相关判定
| 现象 | 级别 |
|---|---|
| 闭水失败，楼下顶面有水渍 | 二级（需定位漏点并重做） |
| 淋浴区墙面上翻明显不足（目视可见防水层未达要求高度） | 二级 |
| 沉箱无二次排水、回填不实 | 二级 |
| 沉箱有异味返出 | 二级 |
| 闭水通过但墙根轻微返潮 | 三级 |

## 三、门窗

### 3.1 型材与玻璃
| 查什么 | 怎么查 | 注意 |
|---|---|---|
| 型材壁厚 | 常用主受力部位 1.4mm 以上（推拉窗 1.2mm 以上为常见参考） | 对照合同约定 |
| 玻璃配置 | 中空玻璃是否双层、有无夹胶玻璃（安全与隔声）、有无单片 | 有无划痕、裂纹、边角磕碰 |
| 玻璃自爆 | 观察玻璃内是否有黑点状杂质、边缘是否损伤 | 自爆多在交付后数月到数年发生，不一定当场能看出 |
| 品牌型号 | 对照交付标准附件逐项核对型材、玻璃、五金品牌 | 与合同不符是明确可主张的项 |

### 3.2 五金与开启
- 把手、铰链、滑撑、锁点是否完整、是否与合同品牌一致
- 每一扇都开关几次：手感、卡顿、回落、闭合是否到位
- 窗扇扇缝是否均匀，密封条是否贴合、有无老化变形或脱出
- 排水孔是否通畅（这是窗台渗漏的常见原因）
- 卫生间与厨房的窗：安全开启角度是否受限、是否有防误开装置

### 3.3 渗漏与结露
- 雨天或淋水试验后检查窗框与墙体交接、窗台内侧有无水渍
- 卫生间窗、厨房窗内壁是否有 persistent 结露或水痕
- 判级：窗框渗漏需拆开重打密封或更换 → 二级；玻璃划痕、把手松动 → 三级；品牌型号不符 → 按合同条款主张

## 四、给排水

### 4.1 管道
| 查什么 | 怎么查 | 注意 |
|---|---|---|
| 给水管材质 | 目视与对照合同（常见 PPR、PE、镀锌钢管） | 表面标识、接口方式 |
| 排水管材质 | 目视（常见 PVC、PP-R） | 是否带专用存水弯（防返味关键） |
| 管道走向 | 开槽前记录墙内管道位置 | 有利于后期避免钻破 |
| 检修口 | 检查水表、阀门、检修口位置是否被包死 | 被包死后期无法维修，重要 |

### 4.2 功能测试
- 每个阀门开合是否正常、是否能关严
- 水压：打开所有龙头同时出水，观察压力下降情况与末端出水
- 热水器出水时间、上下水是否通畅、有无异味
- 排水：所有下水口放水，观察速度与返味

### 4.3 判级
- 排水无存水弯导致返味 → 二级
- 阀门无法关闭、水表被包死 → 二级（影响后期维修）
- 给水压力明显不足、末端不出水 → 二级
- 龙头轻微渗漏、接口松动 → 三级

## 五、电路

### 5.1 配电箱与回路
| 查什么 | 怎么查 | 注意 |
|---|---|---|
| 回路数量 | 数空开与回路数量 | 与户型图对照；空调、厨房、卫生间、照明应分开 |
| 漏电保护 | 按下试验按钮，应立即跳闸 | 不跳闸属于安全隐患，判一级 |
| 标识 | 回路是否有清晰标注 | 无标注后期维护困难 |
| 线径 | 打开底盒目视 | 照明常用 2.5mm²、插座常用 4mm²；空调与厨房回路常用 4mm² 或 6mm² |
| 接地 | 三孔插座是否有地线、接地是否可靠 | 属于安全项 |

### 5.2 插座与开关
- 带指示灯的插座测试笔逐个测试：通断、左右火线、接地
- 每个开关对应哪一路灯，在配电箱处核对标识
- 面板是否水平、是否松动、缝隙是否均匀
- 插座位置是否符合交付标准（数量、位置、床头与沙发旁、厨房台面、卫生间防溅盒）

### 5.3 判级
| 现象 | 级别 |
|---|---|
| 漏电保护不跳闸、无接地 | 一级（用电安全） |
| 回路数不足、空调与厨房共用一路导致同时使用跳闸 | 二级 |
| 插座点位与交付标准不符（数量缺失） | 二级（按合同条款主张） |
| 面板不平、单个插座故障 | 三级 |

## 六、暖通与燃气

### 6.1 地暖与采暖
| 查什么 | 怎么查 | 注意 |
|---|---|---|
| 地暖打压 | 现场打压并保压观察 | 保压期间压力表不下降方为有效 |
| 分水器 | 位置是否合理、每路阀门是否可用、有无排气阀 | 排气阀是后续排除故障的关键 |
| 管路布置 | 分水器到房间的走向、是否交叉过多 | 交叉过多是温度不均的成因 |
| 温度分布 | 通热后测各房间地面温度 | 冷热不均要记录具体位置 |
| 暖气片 | 数量、位置、是否牢固、有无锈蚀 | 与设计图对照 |
| 采暖期/供冷期 | 保修期限按 2 个采暖期、供冷期计 | 交房当年即计入首个采暖期 |

### 6.2 燃气
| 查什么 | 怎么查 | 注意 |
|---|---|---|
| 燃气表 | 位置、是否完好、有无铅封 | 被包死无法检修是问题项 |
| 管路走向 | 是否为明装、是否穿墙穿柜 | 管路违规穿橱柜或被封死属安全隐患，判一级 |
| 连接软管 | 长度、是否超期、有无破损 | 燃气专用软管长度一般不超过 2m |
| 报警器 | 是否安装、是否在有效期内、位置是否合适 | 燃气泄漏报警装置是重要安全项 |
| 通风与排烟 | 厨房是否有通风口、热水器排烟管是否接到位 | 直排室外、不穿墙是要求 |
| 热水器 | 品牌型号是否与合同一致、安装是否合规 | 燃气热水器安装在浴室属高风险 |

### 6.3 判级
- 燃气管被封死、穿橱柜、热水器装在浴室、缺报警器、漏电保护不跳闸 → 一级
- 地暖分水器无排气阀、管路交叉过多致明显不均 → 二级
- 暖气片数量不足、位置不符 → 二级（按合同）
- 品牌型号不符 → 按合同条款主张

## 七、公区与设备

### 7.1 楼栋与单元
- 单元门：开启、闭门器、门禁、可视对讲
- 电梯：运行平顺度、层站平层、应急照明、轿厢按钮与显示、检验标识有效期
- 消防：灭火器、消火栓、应急照明与疏散指示、消防通道是否被占用
- 楼梯间：扶手、踏步、防滑、是否畅通
- 楼道：照明、墙面、单元门牌

### 7.2 小区与车库
- 地下车库：排水、坡道、照明、车位线与指示牌、地面有无渗水
- 屋面：排水通畅、女儿墙、防水层外露状态
- 井盖：有无缺失、破损、异响、下沉
- 围墙、大门、门岗
- 绿化与道路：排水坡向、路面破损
- 公共管网井：是否被填埋或改动

### 7.3 判级
- 电梯无有效检验标识、应急照明失效、消防通道被占用、消防设施缺失 → 一级
- 车库大面积渗水、井盖缺失、屋面排水不畅导致外墙受潮 → 二级
- 单元门闭门器失效、楼道灯不亮、指示牌缺失 → 三级

## 八、新房与二手房差异对照表

| 维度 | 新房 | 二手房 |
|---|---|---|
| 责任主体 | 建设单位与施工单位承担保修责任 | 通常无保修；责任在卖方（隐瞒瑕疵）或买方自担 |
| 保修期 | 按《建设工程质量管理条例》第四十条：地基基础与主体结构为设计文件规定的合理使用年限；屋面防水、有防水要求的卫生间与房间及外墙面防渗漏 5 年；供热与供冷系统 2 个采暖期、供冷期；电气管线、给排水管道、设备安装与装修工程 2 年；**自竣工验收合格之日起算** | 无此体系，需靠买卖合同条款与卖方过错认定 |
| 隐蔽工程 | 交付前可见（开放日）；精装交付后已覆盖 | 已被前手覆盖，必要时开孔查验 |
| 查验重点 | 交付标准对照、施工做法、实测面积 | 前任改动（承重墙、防水重做、燃气改位、电路增容、管道移位）、设备寿命、房龄 |
| 面积 | 合同约定建筑面积与套内面积，实测后算面积误差比 | 同上，且需核实是否为"已售"状态、有无抵押或查封、共有权人是否签字 |
| 渗漏验证 | 闭水试验可做 | 闭水试验可做，但需先查楼下是否有历史渗漏纠纷线索（可问物业与邻居） |
| 燃气 | 已开通或具备开通条件 | 需确认燃气户内设施是否为合规安装、是否被改动 |
| 电容量 | 按设计配比 | 常见增容需求，需核实入户线径与总容量是否够用 |
| 附带风险 | 延期交付、交付标准与样板间不符 | 卖方逾期未办产权、户口未迁、欠费、房屋被抵押 |
| 装修影响 | 交付后到开工前有空档期（见空档期清单） | 拆改多，承重与外立面改动可能触碰结构与外立面管理规定 |

### 二手房额外必查项
1. **承重结构是否被拆改**：对照原始结构图，核对墙体位置；拆改会牵涉安全与卖方责任
2. **防水是否被重做**：卫生间地面被凿开、做过防水但未做闭水或做法不合规的，属于隐患
3. **燃气是否改位**：私自移动燃气管道、把燃气表移入柜内
4. **电路是否增容**：改动是否规范、线径与总容量是否匹配
5. **管道移位**：改动是否影响楼下、是否使用了违规材料
6. **设备寿命**：热水器、空调、暖气、电梯等的使用年限与剩余寿命
7. **房屋用途与产权状态**：是否被查封、抵押、是否已出租、户口是否迁出、物业费与水电燃气是否欠缴
8. **上下邻居的渗漏历史**：向物业和邻居侧面了解，问具体位置与时间
