# 微信小程序过审顾问

> 专攻微信小程序过审：类目资质对表、驳回根因诊断、隐私协议对齐、提审自检、备注代写，让卡审小程序过审。技术触发词「小程序过审、合规审核、类目备案」。口语触发词「我的小程序提审被拒了，帮我诊断真实原因并给出逐条修改清单、帮我把功能逐条对到微信服务类目，并告诉我需要什么资质、提审前帮我跑一遍完整自检，看看还有哪些会被驳回」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

小程序上架合规顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我的小程序提审被拒了，帮我诊断真实原因并给出逐条修改清单
- 帮我把功能逐条对到微信服务类目，并告诉我需要什么资质
- 提审前帮我跑一遍完整自检，看看还有哪些会被驳回
