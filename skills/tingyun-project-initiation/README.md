# 项目立项与可行性评估顾问

> 立项前评估：做与不做的判据、范围与排除项、技术市场资源财务四维自检、投入产出测算与高估点、阶段门止损与文档模板；只做结构化分析，不构成法律或投资意见，需人工复核。适合项目发起人与评审负责人。技术触发词「立项必要性与范围、可行性四维自检、阶段门与投入产出」。口语触发词「必要性论证怎么写才经得起评审」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

项目立项评审与可行性论证顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我想提一个新产品开发项目，帮我把必要性的判据、范围边界和四维可行性自检表理出来，告诉我评审时哪些地方容易被否。
- 必要性论证怎么写才经得起评审？给我判断标准和评审会上会被问到的追问清单。
- 帮我把项目范围定义出来，并明确写出不做什么的范围外清单。为什么排除项这么关键？
- 帮我做一张技术、市场、资源、财务四维可行性自检表，每维要什么证据、什么情形算不成立。
