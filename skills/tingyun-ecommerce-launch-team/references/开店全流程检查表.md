# 开店全流程检查表

## 阶段一：定方向（0 到 3 天）

- [ ] 目标人群写下来了吗（谁、什么场景、预算带）
- [ ] 主类目选定了吗（先只做一个）
- [ ] 资质要求查过了吗（类目准入、报白、品牌授权）
- [ ] 竞品价格带看过了吗

**产出**：一页纸开店画像 + 资质清单 + 红线清单

## 阶段二：备货与上架（3 到 10 天）

- [ ] 候选品用四问筛过了吗
- [ ] 真实成本算过了吗（拿货+扣点+物流+售后+退货损耗）
- [ ] 首批量是现金流倒推出来的吗
- [ ] 类目挂对了吗（挂错的改动成本极高）
- [ ] 标题主图过红线自检了吗
- [ ] 售后口径（发货时效、运费险、退换）确认了吗
- [ ] 客服高频问答写好了吗

**产出**：候选品表 + 首屏素材 + 客服话术

## 阶段三：测流量（10 到 20 天）

- [ ] 有自然流量进来吗（说明标签与内容匹配）
- [ ] 点击率如何（低就是首屏问题，不是流量问题）
- [ ] 转化率如何（低就是详情页/价格/信任问题）
- [ ] 差评和咨询集中在哪（这是最真实的产品反馈）

**产出**：第一版问题清单 + 改哪一处的优先级

## 阶段四：放量（20 天后）

- [ ] 主推哪 1 个品（不要全推）
- [ ] 补货节奏定了吗（别压货）
- [ ] 利润表有吗（把推广费用算进去）
- [ ] 违规扣分检查过了吗

**产出**：主推品 + 补货计划 + 真实利润表

---

## 最容易踩的三个坑

| 坑 | 现象 | 原因 | 规避 |
|---|---|---|---|
| 类目挂错 | 改类目要重新审核，链接权重清零 | 为凑流量挂了热门类目 | 开店前查准入，定了就不改 |
| 资质后补 | 上架时没资质，等于白上架 | 想先试水 | 资质先行 |
| 素材违规 | 一次扣分是累计的，后面很难补 | 沿用同行文案 | 每条文案过红线自检 |
