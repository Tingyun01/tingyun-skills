# 合同履约监控与变更顾问

> 面向已签合同的中小企业：输出履约台账字段、节点提醒规则、变更签证流程、验收留痕清单与结算对账步骤。只做流程梳理与清单辅助，不构成法律专业意见，需人工复核。技术触发词「合同履约跟踪、变更签证管理、结算对账」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

合同履约监控与变更顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我手上有一批已签合同，想建一张履约台账，字段应该怎么设计才不会漏事？
- 合同里有两个付款节点和三个交付节点，帮我设计一套到期提醒的节奏和分级规则
- 客户口头要求加需求，帮我出一份变更签证的书面化流程和补充协议要点清单
- 交付完没有验收单，后面结算卡住，帮我列一份验收留痕与结算对账的证据清单
