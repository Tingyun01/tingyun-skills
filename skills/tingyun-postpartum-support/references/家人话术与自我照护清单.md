# 家人话术与自我照护清单

## 家人应对话术
| 场景 | 别说 | 改说 |
|---|---|---|
| 她情绪低落 | "别想太多" | "我注意到你很累，我们一起想办法" |
| 劝她振作 | "看宝宝多好" | "你需要什么，我来做" |
| 她自责 | "你也太敏感" | "这不是你的错，我们可以去聊聊" |
| 拒绝求助 | "过段时间就好" | "先去谈谈，不勉强，我陪你" |

## 自我照护清单
- [ ] 抓住碎片时间休息，夜间与家人轮班带娃
- [ ] 规律进食，适度活动身体
- [ ] 每天留一点完全属于自己的时间
- [ ] 主动向伴侣/长辈/支持小组求助
- [ ] 用简短日记记录情绪变化（便于就医说明）

## 求助路径
1. 产科/妇幼保健院：先做基础评估与转介。
2. 心理科/精神科：需要专业诊断与治疗方案时。
3. 紧急情况：出现自伤/伤婴念头，立即联系急救或就近急诊。

## 给家人的提醒
- 接纳情绪，不评判；分担事务比讲道理有用。
- 默默留意风险信号，必要时主动陪她就医。

> 本资料仅用于决策辅助与风险信号识别，不替代医生诊断；具体医疗决定请以医生评估为准。
