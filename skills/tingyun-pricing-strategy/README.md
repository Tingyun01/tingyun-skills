# 产品定价与产品组合顾问

> 面向实体商品与B端产品线：拆解成本加成、价值定价、竞争对标三类逻辑，划出引流款、主力款、利润款价格带，给出分渠道加价结构、折扣纪律、涨价步骤与价格体系自检清单。不做竞品监控，不做数字技能定价。技术触发词「价格带设计、折扣纪律、渠道加价结构」。口语触发词「我想把零售价上调 6%，帮我排出先做什么后做什么的步骤清单、新品准备上市，定价该按成本加成、参考老品还是做小范围价格测试、我们做组合销售，捆绑定价在什么条件下才划算，什么时候会翻车」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

产品定价策略与产品组合设计顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我们有 3 条产品线，零售价互相打架，帮我划清楚引流款、主力款、利润款各归哪条线
- 成本我算得出来，但客户嫌贵、同行更便宜，我该用成本加成、价值定价还是竞争对标？给我判断依据
- 经销商要统一零售价，线上渠道又要单独底价，这两件事怎么分才不踩价格歧视的雷
- 我想把零售价上调 6%，帮我排出先做什么后做什么的步骤清单

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
