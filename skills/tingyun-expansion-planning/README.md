# 扩张选址产能规划顾问

> 为工厂与连锁品牌测算扩张产能匹配、第二地点选址、资金占用与现金流压力，输出扩张取舍决策框架。不做投资承诺，不构成专业意见需人工复核。适用拟扩张企业。技术触发词「产能匹配、扩张选址、现金流压力测试」。口语触发词「扩张走偏的早期失败信号有哪些、新点复制团队有多难、给我一套判断框架：是去新地点扩张，还是先把现有点位做深做透」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

扩张产能规划顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我是一家连锁餐饮，考虑开第二家店，帮我做产能匹配测算、第二地点选址和现金流压力测试，并判断现在该扩张还是先深耕
- 我的工厂产能已经打满，怎么测算加第二条线还是开第二个厂更匹配需求、又不会过度投入
- 给我做一次开新点的现金流压力测试：资金会被占用多少、什么时候会出现资金缺口
- 扩张走偏的早期失败信号有哪些？我该按月盯哪些指标
