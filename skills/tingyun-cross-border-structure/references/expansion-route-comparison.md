# 出海模式对比、法域用途定位与结构选型维度

---

## 一、四种出海模式对比

### 1.1 总览对照表

| 维度 | 自建（设子公司/分支） | 收购现成主体 | 合作/合资 | 授权/许可 |
|---|---|---|---|---|
| 启动成本 | 中高 | 高 | 低至中 | 低 |
| 上手速度 | 慢 | 中（尽调+交割） | 快 | 快 |
| 控制权 | 高 | 高 | 中（看协议与股权） | 低（靠合同） |
| 落地门槛 | 注册、银行、雇员、许可、账务 | 尽调、估值、融资、员工与许可承接 | 伙伴筛选、协议谈判、治理搭建 | 合同谈判、商标与权利归属 |
| 品牌与客户归属 | 归自己 | 归自己（但需整合） | 共存，取决于协议 | 属被授权方，回收难 |
| 退出难度 | 高（清算成本高） | 高 | 中（股权退出看协议） | 低（终止合同即可） |
| 主要风险 | 实质经营、常设机构、当地合规成本 | 或有负债、历史税务与用工遗留 | 依赖伙伴、僵局、分红汇出 | 知识产权外溢、被绕开、难回收 |
| 适用信号 | 有当地长期投入计划、需要控数据与品牌 | 有时间窗口、需牌照/团队/客户关系 | 缺本地资源与关系、想快速验证 | 只想试水、产品高度标准化 |

### 1.2 决策树

```
问 1：这一步的核心约束是"时间"吗？
  是 → 问 2：需要的资源（牌照/团队/客户关系）是现成资产吗？
          是 → 收购
          否 → 问 3：本地伙伴能提供这些资源吗？
                  是 → 合作/合资（但治理条款要写透）
                  否 → 自建 + 加速招聘/授权过渡

问 1：核心约束是"控制权"吗？
  是 → 需要长期在该市场经营、涉及数据与品牌 → 自建（或收购后整合）

问 1：核心约束是"风险敞口"吗？
  是 → 产品标准化、可远程交付、客户不敏感于对手 → 授权/许可
```

### 1.3 各模式的落地动作要点

**自建**
- 主体形式（有限责任公司、代表处、分公司）按当地法律与业务实际选，代表的经营范围与开票能力差别很大
- 银行账户与收付路径要在开业前跑通，否则注册完无法出款
- 当地雇员与派遣人员的比例安排会影响实质经营认定
- 会计与账簿落地要求（是否需要本地记账、审计、申报频率）

**收购**
- 尽调清单：股权与历史沿革、税务申报与潜在补税、员工与用工遗留、知识产权归属与职务成果、诉讼与合规处罚、牌照与许可有效性、数据合规历史
- 或有负债的处理：价格调整机制、赔偿上限与存续期、交割后过渡期的责任划分
- 交割后的整合：财务与账簿统一、商标与系统迁移、团队留任、遗留员工安置

**合作/合资**
- 治理条款清单：股权比例、董事席位、决策机制（哪些事项需一致同意）、僵局解决（主动买断/卖出/仲裁）、关联交易约束、退出与转让限制、竞业与品牌使用规则
- 分红与资金汇出安排：利润分配前提条件（弥补亏损、留存比例）、分红时点与审批程序
- 知识产权与客户资源的归属写清，避免合作结束后资产留在合作方

**授权/许可**
- 授权范围：地域、期限、独占与否、用途限制、可否再授权
- 权利担保：权利人承诺其有权授权、权利不被第三方主张
- 质量与合规承诺：产品符合当地强制标准、许可方对出口管制与制裁合规的协助义务
- 终止与回收：终止情形、库存处理、商标与资料回收、竞业限制

## 二、常见法域的用途定位

只讲"通常拿来做什么"与"使用前提"，具体税务结论一律交专业机构。

### 2.1 用途定位表

| 法域 | 常见用途 | 使用前提 | 常见误用 |
|---|---|---|---|
| 香港 | 区域贸易与结算、供应链与合约签署地、部分持股平台 | 有真实人员、业务与决策安排 | 只开公司不做业务，纯资金与合约通道 |
| 新加坡 | 东南亚区域运营与销售、区域管理与资金安排 | 有实质经营、决策与雇佣落地 | 只有注册地址与名义董事 |
| 开曼/英属维尔京等离岸法域 | 多轮融资的持股主体、资本运作与期权池承载 | 作为持股层与实际经营层分离使用 | 与经营地混同；把离岸当作税务豁免的答案 |
| 目标市场本地 | 当地销售、雇佣、售后、牌照承载 | 有真实经营需求与本地合规能力 | 只为收钱而设，业务与合同主体错位 |
| 其他区域节点（如中东、东南亚枢纽） | 区域分销与转口、中转结算 | 需核实当地转口与合规规则 | 忽略当地对转口与再出口的审查 |

### 2.2 关于香港与新加坡的实操提示

- **香港**：属地征税原则下，源自香港的利润需纳税；法团利得税标准税率 16.5%，自 2018/19 课税年度起首 200 万港元应评税利润部分按 8.25%、超出部分按 16.5%（两级制）。同时自 2023 年 1 月 1 日起，外国来源收入豁免机制（FSIE）覆盖利息、股息、知识产权收入与股权处置收益，2024 年起扩展到股权处置以外资产的处置收益；对跨国企业集团实体，若不满足经济实质要求或参股豁免条件，相关外源收入可能被视作源自香港。这意味着"注册一个香港公司收境外利润"这类安排在当前规则下需要专门评估，而不是默认免税。
- **新加坡**：企业所得税标准税率 17%，对部分应税所得有减免；税务居民按管理与实际控制机构所在地认定，与注册地无关；境外来源所得汇入并符合主体豁免条件（税率门槛与已实际承担税款）时可获豁免；无实质活动的纸面控股安排难以取得居民企业身份。另外 GST 税率在 2024 年 1 月起由 8% 上调至 9%，年应税营业额超过 100 万新元须强制注册。
- 两条都指向同一个判断：**法域是工具，不是答案。** 任何"选某个法域省税"的说法都要回到业务实质与事实证据上。

### 2.3 结构选型的判断维度

按顺序过这 6 个维度，答案会自然收敛：

1. **业务实质**：钱从哪来、合同谁签、货从哪发、服务谁提供、决策在哪做出
2. **实体功能**：每层实体承担什么（持股、融资、销售、雇佣、持有知识产权）——说不出功能就删掉这一层
3. **风险落点**：汇率、税务、监管、劳动、知识产权、诉讼各落在哪一层，谁承担
4. **税与合规衔接**：利润分布与价值创造是否匹配、转让定价能否解释、申报义务谁承担
5. **资金路径**：收入在哪里、怎么归集、怎么分配、能否合规汇出
6. **退出与调整**：两年后想换模式时，这套结构改起来容易吗

## 三、控股层与经营层的分离逻辑

### 3.1 两层结构（多数场景够用）

```
境内母公司 / 创始团队
        │
        ▼
海外控股平台（持股、融资、期权池、协议签署）
        │
        ▼
目标市场运营实体（销售、雇员、许可、售后）
```

适用条件：持股平台与经营实体不在同一法域、且两层各自能讲清功能。

### 3.2 三层结构（何时才需要）

增加中间层的典型理由：
- 未来需要在多个市场分别引入投资者，持股层需要按市场切分
- 同一法域内要隔离不同业务的风险（例如把高风险业务放在单独实体）
- 需要有独立的融资主体承接某一轮投资

不增加中间层的理由（这些是"过度设计"的信号）：
- 只是为了"看起来更国际化"
- 只是为了层数多显得复杂
- 中间层没有真实的人员、决策或资产安排

### 3.3 分离是否成立的三个检验问题

1. 中间层是否承担了**真实功能**（持有资产、承担风险、提供融资、做管理）？
2. 各层之间是否有**真实商业安排**（服务协议、许可协议、融资协议）并按合理定价执行？
3. 面对核查时，能否**用文件说明每一层为什么存在**？

三问中有任意一问答不上来，这层就不该存在，或者需要重做安排。
