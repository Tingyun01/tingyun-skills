# 劳动关系认定自检表与假外包真派遣对照

## 一、劳动关系三要素（劳社部发〔2005〕12号）

同时具备以下三点，通常被认定为劳动关系：
1. 用人单位和劳动者符合法律、法规规定的主体资格；
2. 用人单位依法制定的各项劳动规章制度适用于劳动者，劳动者受用人单位的劳动管理，从事用人单位安排的有报酬的劳动；
3. 劳动者提供的劳动是用人单位业务的组成部分。

## 二、逐项自检清单（逐条打勾）

| 检查项 | 是（偏劳动关系） | 否（偏承揽/外包） |
|---|---|---|
| 是否打卡/排班/接受直接指挥 | □ | □ |
| 报酬是否按月固定+绩效，而非按件/项目 | □ | □ |
| 工具、场所、材料是否由公司提供 | □ | □ |
| 做的事是否公司核心业务一环 | □ | □ |
| 公司是否对其进行奖惩、考核、培训 | □ | □ |
| 是否签劳动合同而非承揽/服务协议 | □ | □ |

≥4 项"是" → 高概率被认定劳动关系，应补齐合同与社保。

## 三、假外包真派遣识别（高频败诉点）

真外包的特征（满足越多越安全）：
- 外包公司自行招人、自行管理、自行考核；
- 甲方只验收工作成果，不接触外包人员日常管理；
- 费用按成果结算，而非按人头/工时；
- 外包公司具备相应资质，独立承担雇主责任。

以下信号一旦出现，存在被穿透认定为派遣甚至直接劳动关系的风险：
- 甲方直接给外包人员排班、考勤、奖惩；
- 甲方指定具体人员、长期驻场且受甲方管理；
- 只是换了个发薪主体，管理实质没变；
- 外包人员与甲方员工混岗、同工不同酬。

## 四、派遣的硬约束（《劳务派遣暂行规定》）

- 只能在**临时性、辅助性、替代性**岗位使用；
- 用工单位劳务派遣人数不得超过用工总量**10%**；
- 应与本单位同类岗位劳动者**同工同酬**；
- 违法使用派遣，面临责令改正、罚款及补缴社保等后果。

## 五、定性后的动作边界

- 定性为劳动关系：30日内签合同、参保，否则面临双倍工资与补缴风险；
- 定性为承揽/外包：签书面协议，明确成果标准、费用结算、责任划分，保留"不管理"的证据；
- 疑似假外包真派遣：优先整改为真实外包或合规派遣，不要仅靠一纸合同"挡雷"。
