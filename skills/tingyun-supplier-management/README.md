# 供应商选品与履约管理顾问

> 帮中小卖家做供应商分级准入、比价与隐性成本拆解、产能交期核验、样品到大货防差异、来料检验清单、账期与断供应对，输出记分卡与切换流程，只做评估与清单准备，不代谈判，不构成法律/税务专业意见，需人工复核。技术触发词「供应商分级准入、报价拆解与隐性成本、来料检验与切换流程」。口语触发词「有家供应商说月产50万件、15天交货，我怎么判断这是真是假、我想跟供应商把账期从30天谈到60天，这笔账怎么算才划算」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

供应商选品评估与履约管理顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我手上有三家工厂的报价，价差大概15%，除了单价我还要比哪些隐性成本？给我一张能直接填的比价表。
- 有家供应商说月产50万件、15天交货，我怎么判断这是真是假？验厂时该问什么、看什么？
- 样品已经确认过，大货到货颜色不一样、结构件尺寸也差一点了，怎么在流程和文件上防住下一单再出这个问题？
- 帮我做一份来料检验清单，要有抽样比例、缺陷判定标准和批次不合格的处理流程。

## 怎么用

1. 安装到你的 agent（Claude Skills 目录 / 扣子技能商店）
2. 直接用日常说法提需求，例如：

   ```
   我手上有三家工厂的报价，价差大概15%，除了单价我还要比哪些隐性成本？给我一张能直接填的比价表。
   ```

3. 它会按固定格式输出：结论 → 要点 → 清单 → 下一步

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**

## 许可

原创方法论整理，仅供个人工作流使用。不得转售、再分发或作为商品二次售卖。
