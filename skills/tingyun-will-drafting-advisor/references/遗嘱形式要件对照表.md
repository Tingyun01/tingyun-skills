# 遗嘱形式要件对照表（规划辅助用）

> 本表用于梳理差异、辅助决策，不构成法律意见，具体生效要件以属地规定与持证专业人士意见为准。

## 一、五种常见遗嘱形式对照

| 形式 | 核心要件（典型） | 常见注意点 |
| --- | --- | --- |
| 自书遗嘱 | 本人亲笔书写全文、签名、注明年/月/日 | 部分打印、他人代写易生争议 |
| 代书遗嘱 | 两个以上见证人在场、其中一人代书、遗嘱人/代书人/其他见证人签名、注日期 | 见证人资格与数量是关键 |
| 打印遗嘱 | 两个以上见证人在场、遗嘱人/见证人在每一页签名、注日期（依相关规定） | 仅在尾页签名可能不满足 |
| 录音录像遗嘱 | 两个以上见证人在场、记录遗嘱人及见证人姓名/肖像与日期 | 音画不清、无日期易无效 |
| 公证遗嘱 | 经公证机构办理 | 举证力强，但非只有这一种有效形式 |

## 二、见证人资格排查（清单）

下列人员通常不宜/不能作为见证人（以属地规定为准）：
- [ ] 无民事行为能力人、限制民事行为能力人
- [ ] 继承人、受遗赠人
- [ ] 与继承人、受遗赠人有利害关系的人

## 三、常见无效情形排查（清单）

- [ ] 遗嘱人无民事行为能力或限制行为能力时订立
- [ ] 受欺诈、胁迫所立
- [ ] 伪造、被篡改部分
- [ ] 形式要件缺失（如缺签名/日期/见证人）
- [ ] 未为缺乏劳动能力又无生活来源的继承人保留必要份额
- [ ] 处分了不属于本人的财产（如配偶名下部分）

## 四、多份遗嘱衔接提示

- 内容冲突时，通常以符合法定要件、时间在后的为准（具体以属地规定为准）。
- 立新遗嘱时，明确是否撤销旧遗嘱的相关部分，避免歧义。
- 公证遗嘱被后续符合要件的其他形式遗嘱取代的情形，依相关规定处理。

## 五、需立即转人工的情形

- 对遗嘱真实性、意识能力存疑；
- 涉及大额、涉外、企业或股权资产；
- 继承人已就有效性发生争议。
